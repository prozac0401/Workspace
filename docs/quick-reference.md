## 파일을 어디에 둘까요? {#where}

| 지금 상황 | 할 일 |
|---|---|
| 새 파일을 받았는데 어디에 쓸지 모르겠어요 | 새 자료를 잠시 두는 `00_Inbox`에 넣으세요. 용도를 알게 되거나 사용할 때 알맞은 폴더로 옮기세요. [폴더별 용도](policies/workspace.md) |
| 지금 하는 업무의 자료예요 | 진행 중인 업무를 두는 `10_Active`에서 해당 업무 폴더를 찾아 넣으세요. [반복 업무 폴더](policies/kits.md) |
| 새 업무 폴더가 필요한가요? | 목적·일정·결과물이 다른 업무를 시작할 때 만드세요. 같은 업무에서 나온 자료는 쓰던 폴더에 넣으세요. [업무 폴더를 나누는 기준](policies/workspace.md#container) |
| 다음에도 쓸 양식과 순서예요 | 복사용 기본 폴더인 `MASTER`에 넣고 `20_Operations`에 보관하세요. 실제 업무는 복사해서 진행하세요. [복사용 기본 폴더 만들기](policies/kits.md#master) |
| 참고자료인지 끝난 업무 기록인지 헷갈려요 | 여러 업무에 참고할 매뉴얼은 `40_Reference`에 두세요. 끝난 업무의 결과물과 근거는 `80_Archive`에 두고, 다시 참고할 때는 그 위치를 연결하세요. [폴더별 용도](policies/workspace.md) |
| 업무가 끝났어요 | 남은 일과 문제, 보관 조건을 확인하세요. 확인이 끝나면 업무 폴더 전체를 `80_Archive`로 옮기세요. [업무 마무리와 보관](policies/archive-security.md) |
| 잠깐 쓰고 지워도 되는 파일이에요 | 없어져도 업무 기록이 남아 있는 파일만 `90_Temp`에 두세요. 하나뿐인 결과물이나 근거 자료는 해당 업무 폴더에 두세요. [보관 기준](policies/archive-security.md) |

## 다음에 무엇을 할까요? {#work}

| 지금 상황 | 할 일 |
|---|---|
| 반복하는 업무를 새로 시작해요 | 복사용 기본 폴더인 `MASTER`를 `10_Active`에 복사하세요. 복사본 이름을 이번 업무에 맞게 바꾸고 기본정보와 날짜 계산의 기준일(예: 교육 시작일)을 적으세요. [업무 시작하기](policies/kits.md#master) |
| 어디까지 했는지 확인하고 싶어요 | FolderState를 사용한다면 단계별 폴더의 상태를 보세요. 상태는 담당자가 직접 바꾸므로 실제 진행 내용도 함께 확인하세요. [진행 상태 표시하기](tools/folderstate/index.md) |
| 언제까지, 누가 해야 하나요? | 회사에서 기준으로 정한 일정표나 일정 시스템을 보세요. 운영현황 파일을 쓴다면 일정표(`Schedule`)와 연락처(`Contacts`)에서 확인하세요. [운영현황 파일 쓰기](policies/kits.md#overview) |
| 빠뜨린 확인사항이 있을까요? | 확인 목록(`Checklist`)에서 세부 항목을 보세요. 폴더에 이미 표시한 완료 여부는 다시 적을 필요가 없습니다. [확인 목록 쓰기](policies/kits.md#overview) |
| 완료로 표시해도 될까요? | 필요한 자료를 만들고, 필요한 승인과 전달까지 마쳤는지 확인하세요. 확인한 뒤 담당자가 완료로 표시하세요. [상태를 바꾸는 때](policies/kits.md#events) |
| 결정한 이유를 남기고 싶어요 | 쓰고 있는 문제·결정 기록(`Issues / Decision Log`)에 결정한 내용, 이유, 근거 자료의 위치를 짧게 적으세요. [결정 이유 적기](policies/kits.md#overview) |
| 답장을 기다리고 있어요 | 메일은 할 일이 남은 `Action` 또는 회신 대기용 `Waiting`에 두세요. 다시 확인할 날짜는 기존 일정표에 적으세요. 기한 안에서 기다리는 동안은 진행 중, 문제가 생겨 일을 이어갈 수 없으면 확인 필요로 표시하세요. [메일 정리](policies/files-email.md) · [상태 선택](tools/folderstate/index.md) |
| 같은 파일이 여러 곳에 있어요 | 계속 수정할 파일 하나를 원본으로 정하세요. 다른 곳에는 원본의 위치를 연결하세요. [원본 정하기](policies/workspace.md#source-of-truth) |

## 메일과 예전 자료는 어떻게 할까요? {#less-work}

| 지금 상황 | 할 일 |
|---|---|
| 메일의 첨부파일을 모두 저장해야 하나요? | 실제로 작업할 파일만 업무 폴더에 저장하세요. 승인이나 비용의 근거처럼 따로 보관해야 하는 자료는 회사의 기록 보관 기준을 따르세요. [파일과 메일 정리](policies/files-email.md) |
| 예전 자료가 많이 쌓여 있어요 | 지금 있는 곳에 두세요. 다시 쓰거나 다른 담당자에게 넘길 자료가 생기면 그때 필요한 것만 옮기세요. [예전 자료 보관](policies/archive-security.md) |
| 받은 자료와 메일을 매일 다 정리해야 하나요? | 자료는 사용할 때 위치를 정하세요. 메일은 내용을 확인한 뒤 할 일이 남으면 `Action`, 처리가 끝났으면 `Archive`로 옮기세요. [정리할 때](policies/workspace.md#principles) |
| 운영현황 파일을 채우는 데 시간이 너무 걸려요 | 같은 내용을 여러 번 적는 칸을 줄이세요. 자꾸 빠뜨리는 내용이 있을 때만 필요한 칸을 더하세요. [기록 부담 줄이기](policies/folder-workflow.md) |

## 교육 안내문을 보낸다면

아래는 가상의 교육 업무 예시입니다.

1. 복사용 기본 폴더를 `10_Active`에 복사하세요.
2. 이번 교육 폴더 안에서 안내문을 작성하세요.
3. 발송과 필요한 확인을 마치면 해당 단계를 완료로 표시하세요.
4. 교육 업무가 모두 끝나면 남은 일과 보관 조건을 확인하세요.
5. 확인이 끝난 업무 폴더를 통째로 `80_Archive`에 옮기세요.

일정은 쓰고 있는 일정표에, 중요한 변경 이유는 결정 기록에 적으면 됩니다. FolderState의 모든 단계가 완료로 표시되어도 남은 일은 담당자가 확인해야 합니다. 폴더 이동도 담당자가 직접 합니다.

처음 설정한다면 [업무 하나로 시작하기](getting-started.md)를 보세요. 자주 쓰는 방법은 [자료 정리의 10가지 습관](principles.md)에 모았습니다. 답장을 놓치거나 업무를 넘길 때 같은 문제가 반복되면 [일을 이어서 하고 다른 사람에게 넘기기](policies/folder-workflow.md)를 참고하세요.
