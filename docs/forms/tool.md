# 도구 명세 양식

```markdown
# 도구명 · 제품 명세
도구 ID:
버전·상태:
제품 책임:
적용 정책:
관련 ADR:

## 사용자와 목적
구체적인 업무 시작점·결과.

## 요구사항
ID | 요구 행동 | 완료 기준 | 테스트·근거

## 범위와 금지 동작
읽기/쓰기 경로, 재귀·네트워크·외부 전송 여부.

## 데이터 계약
파일·스키마 버전, 소유 확인, 크기 제한, 원본.

## UX
시작·성공·실패·빈 상태·진행·취소·접근성.

## 동시 실행과 복구
잠금, 재실행, 중단 복원, 외부 변경 보존.

## 설치·업그레이드·제거
권한, 설치 위치, 서명, 보존할 사용자 데이터.

## 검증·지원
OS·저장소·한글·긴 경로·실패 시험·제약.

## 명세 대응표와 배포 기록
구현/자동 검증/수동 검증/미검증을 분리.
```
