# 운영현황·키트 양식

이 페이지는 Excel 또는 내부 Markdown으로 옮겨 사용할 필드 설계입니다. 실제 .xlsx 파일을 생성하는 자동화는 별도 도구 범위입니다.

## Overview

| 필드 | 입력 기준 |
|---|---|
| 업무·회차명 | 연월 + 업무 식별 |
| 시작·종료 | 일정 원본의 기준일 |
| 장소·대상·인원 | 운영에 필요한 범위 |
| 책임·담당 | WHAT / WHEN / WHO 연결 |
| 공식 원본 | 결과물·명단·일정 시스템 |
| MASTER 버전·복사일 | 표준 변경 추적 |
| 보관 위치 | 종료 후 갱신 |

## Schedule

| 항목 | 기준 | 일수 | 실제 마감 | 담당 | 근거 |
|---|---|---|---|---|---|
| 모집 시작 | D | -30 | 회차에서 계산 | 역할 | 승인된 표준 |
| 입과 안내 | D | -10 | 회차에서 계산 | 역할 | 승인된 표준 |
| 설문 | E | +1 | 회차에서 계산 | 역할 | 승인된 표준 |
| 비용처리 | E | +7 | 회차에서 계산 | 역할 | 승인된 표준 |

휴일 조정과 영업일 여부를 함께 명시합니다. 예시 일정을 확정 조직 일정으로 간주하지 않습니다.

## Checklist / Contacts / Issues

Checklist: 단계 / 세부 확인 / 담당 / 확인일. 폴더 상태와 같은 완료 표시를 다시 입력하지 않습니다.

Contacts: 역할 / 조직 / 필요한 연락수단 / 관련 업무. 비밀번호와 불필요한 개인정보는 제외합니다.

Decision Log: 날짜 / 문제 / 결정 / 이유 / 담당 / 근거 위치 / 후속 행동. 소프트웨어 설계 결정은 저장소 ADR에 기록합니다.

## 키트 변경 기록

키트 버전 / 변경 이유 / 변경한 단계 / 검증한 회차 / 적용일. 기존 회차를 자동 덮어쓰지 않습니다.
