# 정책 양식

정책 제목과 관련 정책은 내용을 알 수 있는 자연어 이름으로 적고, 참조할 때 해당 문서 링크를 연결합니다.

```markdown
# 정책 제목
상태: 제안 / 검토 / 승인 / 대체 / 폐기
버전:
책임 역할:
승인자·승인일·적용일: 실제 승인 후 기입
관련 명세·정책:
대체하는 문서:

## 목적과 적용 범위
어떤 문제를 해결하고 누구에게 적용하는가.

## 규칙
구체적인 행동과 데이터의 원본·담당.

## 예외
예외 조건, 결정 담당, 적용 기간, 기록 위치.

## 실행 예시
민감한 실제 값 대신 가상 예시.

## 검증
준수 여부를 어떤 업무 사례에서 확인하는가.

## 변경 이력
날짜 | 버전 | 이유 | 영향 | 검증 | 관련 PR/ADR
```
