# 설계 결정 양식

```markdown
# ADR-번호 · 결정 제목
상태: 제안 / 채택 / 대체 / 폐기
날짜:
결정 담당:
관련 요구사항·정책:
대체·대체됨 관계:

## 맥락
어떤 실제 요구와 제약 때문에 결정이 필요한가.

## 결정
선택한 방식과 책임·데이터·실행 경계.

## 검토한 대안
각 대안의 이점과 비용, 선택하지 않은 이유.

## 영향과 이행
사용자 행동, 호환성, 마이그레이션, 권한, 배포.

## 실패와 복구
충돌·부분실패·중단·롤백 시 행동.

## 검증
필수 자동 시험과 수동 검증, 미확인 환경.
```
