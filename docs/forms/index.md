# 재사용 양식

새 문서는 양식을 복사하고 ID·책임·범위부터 채웁니다. 양식 파일 자체의 빈 칸은 실제 정책 승인이나 구현 완료를 뜻하지 않습니다.

- [정책 양식](policy.md): 운영 기준 제안과 개정.
- [ADR 양식](adr.md): 대안·이유·영향이 있는 설계 결정.
- [도구 명세 양식](tool.md): 소유 데이터와 복구 범위를 먼저 정하는 개발.
- [업무 정보와 일정 양식](operation.md): 이번 업무에서 무엇을, 언제까지, 누가 할지 적는 항목.

실제 회사 경로·담당자 연락처·명단을 채운 운영 양식은 내부 업무 저장소에 보관합니다.
