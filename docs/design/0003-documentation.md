# ADR-0003 · Markdown과 GitHub Pages

상태: 구현에 채택 · 날짜: 2026-09-12 · 관련: GitHub io 게시 요청 / [정책 문서 작성 규칙](../policies/documentation.md)

후속 결정: [ADR-0004](0004-public-handbook.md)가 사이트 공개 범위를 업무 운영 정책·사용법으로 제한합니다.

## 결정

docs/의 Markdown을 유일한 문서 편집 원본으로 사용합니다. MkDocs Material로 정적 페이지를 생성하고 GitHub Pages에 게시합니다. 코드·정책·ADR·검증 결과를 같은 저장소에서 검토합니다. 최초 01·02 원문은 별도 보존합니다.

## 이유와 영향

정책 변경 이유와 도구 동작을 함께 검토할 수 있고 향후 도구가 같은 양식을 사용할 수 있습니다. 정적 사이트는 독자가 별도 계정 없이 열람할 수 있습니다. 실제 업무자료와 민감한 운영값은 공개하지 않습니다.

회사별 확정이 필요한 내용은 결정 목록으로 분리합니다. GitHub Pages 설정과 배포 성공 여부는 문서 작성 완료와 별도로 확인합니다. 문서 빌드의 내부 링크 오류를 실패로 처리합니다.

## 변경 방식

사용 안내 수정은 Markdown 변경과 strict 빌드로, 데이터 계약·권한·배포 방식 변경은 새 ADR과 도구 검증으로 처리합니다.
