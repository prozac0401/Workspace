# ADR-0019 · 공개 payload를 재사용하는 단일 설치 EXE

상태: 채택 · 실제 Excel 검증은 배포 기록에서 별도 판정

날짜: 2026-09-27

결정 담당: 개발·검증 담당

관련 요구사항·정책: [원작업지시](../tools/visible-cells-paste/original-specification.md), [도구 개발 기준](../policies/tools.md), [백로그 T05](../delivery/WORKSPACE_Tool_Backlog_20260926.md)

대체·대체됨 관계: [ADR-0010](0010-visible-cells-paste-com.md)의 COM 제품 구조와 기존 설치 엔진을 유지하며 사용자 배포 진입점을 추가한다.

## 맥락

공개 0.1.1은 ZIP 전체를 풀고 Install.cmd를 실행한다. T05는 단일 EXE 또는 MSI와 기존 installation.xml 설치의 전환을 요구한다. 종료 수정이 검증된 공개 DLL을 패키징 때문에 다시 변경할 이유는 없다. 로컬의 같은 이름 ZIP이 공개 ZIP과 다른 해시여서 공개 자산을 직접 확보해 고정했다.

## 결정

서명 없는 .NET Framework 단일 EXE에 검증한 공개 ZIP 바이트를 그대로 포함한다. 공개 ZIP의 명시한 SHA-256과 17개 파일 inventory·내부 해시·COM 정적 메타데이터를 빌드 때 검사한다. EXE는 실행 때 내장 ZIP 해시를 확인하고 자기 GUID 임시 폴더에만 압축을 푼 다음 기존 설치 엔진을 실행해 그 종료 코드를 반환한다.

기존 엔진이 Office 비트수 확인, HKCU 등록, installation.xml 소유권, 변경 파일 보존, rollback, 제거를 계속 담당한다. 설치·제거 등록을 중복 소유하는 새 MSI를 만들지 않는다. EXE는 asInvoker이며 관리자 권한·개발 SDK·스크립트 실행·보안 설정 변경을 요구하지 않는다.

## 검토한 대안

| 대안 | 판단 |
|---|---|
| 새 MSI에 모든 파일·등록 이관 | 기존 XML 소유권과 외부 수정 보존을 다른 엔진에 다시 구현하고 이관해야 한다. 현재 요구는 단일 설치 파일이므로 선택하지 않음 |
| ZIP을 풀어 cmd 실행 유지 | 기존 정상 경로로 보존하지만 단일 파일 요청은 충족하지 못함 |
| 검증한 ZIP과 설치 엔진을 단일 EXE로 감쌈 | 제품 DLL·소유권 경계를 유지하면서 사용자 설치 단계를 줄이므로 채택 |

## 영향과 이행

사용자는 Excel을 저장·종료하고 EXE 하나를 실행한다. 안내 확인 후 현재 사용자에 설치하며 다음 정상 Excel 시작 때 메뉴가 준비된다. 기존 ZIP으로 설치한 제품은 같은 위치의 installation.xml을 그대로 인식한다. Windows 설치된 앱 제거 경로도 기존 엔진을 사용한다. 단일 EXE의 `--uninstall`도 제공한다.

제품 버전과 DLL은 0.1.1이며 wrapper 파일 버전은 0.1.1.1이다. 이번 EXE는 로컬 평가 산출물이고 공개 다운로드는 계속 기존 ZIP을 가리킨다. 인증서·배포 승인·공개 게시를 완료했다고 표시하지 않는다.

## 실패와 복구

경로 이탈·중복 경로·크기 초과·해시 불일치·재분석 경로는 설치 엔진 실행 전에 거절한다. Excel 실행 중에는 기존 엔진이 중단하며 프로세스를 강제 종료하지 않는다. 설치 실패 코드를 그대로 반환한다. 임시 정리는 이번 추출 inventory의 파일과 비어 있는 상위 폴더만 대상으로 하며 알 수 없는 항목은 남긴다. 강제 종료·잠금 때문에 임시 파일이 남을 수 있고 이를 다른 실행의 임시 파일까지 스캔해 정리하지 않는다.

## 검증

압축 경로·상한·중복·정리·Windows 인자 roundtrip 등 24개 검사, ZIP 설치→단일 EXE 전환·잠금 실패→재설치·사용자 비활성화 및 미지 파일/등록 보존·제거 멱등성19개 검사를 통과했다. 실제 UI 설치·정상 Excel 자동 메뉴·붙여넣기·즉시 Undo·종료는 별도 배포 기록에서 최종 상태를 확인한다. x86 DLL 정적 검증을 실제 x86 Office 시험으로 확대하지 않는다.
