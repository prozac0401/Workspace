# ADR-0016 · 그림 복사·저장의 첫 우클릭 메뉴 독립 명령

상태: 채택 · 저장 명령 위치에 대한 사용자 승인. G0 실기 검증 전  
날짜: 2026-09-25  
결정 담당: 사용자(메뉴 위치 승인), 도구 개발·검증 담당(구현·검증)  
관련 요구사항·정책: [v1.0 원명세](../tools/image-copy-save/ImageCopySave_Requirements_v1.0.md), [v1.1 개정명세](../tools/image-copy-save/ImageCopySave_Requirements_v1.1.md), [G0 검증 기록](../tools/image-copy-save/G0_Menu_Feasibility.md), [추가 도구 개발 기준](../policies/tools.md), [정책 문서 작성 규칙](../policies/documentation.md)  
대체·대체됨 관계: [ADR-0015](0015-image-copy-save-g0.md)의 메뉴 위치 및 해당 G0·AT-08 시험 위치만 대체한다. G0 실증 의무와 독립 엔진 경계는 유지한다.

## 맥락

v1.0은 실제 폴더의 Windows 기본 ‘새로 만들기’ 안에 저장 명령을 두도록 요구했다. 기존 G0 조사에서는 이 위치와 클립보드 상태별 완전 숨김을 함께 입증하지 못했고, 실제 탐색기 UI 시험은 NOT RUN이었다. 문서에서 방법을 찾지 못했다는 사실을 구현 불가능성 증명으로 취급하지 않는다.

사용자는 “요구사항을 변경”하여 “해당 메뉴를 새로만들기 안에 두지 않아도 됩니다”라고 승인했다. 이에 따라 저장 명령을 실제 로컬 폴더 빈 공간의 Windows 11 첫 우클릭 메뉴에 독립 명령으로 배치한다. 승인 범위는 메뉴 위치 변경이며, 이미지가 없으면 숨겨야 한다는 조건이나 설치·배포의 검증 기준을 완화하지 않는다.

## 결정

1. 저장 명령의 이름은 ‘복사한 그림 저장’이다. 실제 로컬 파일시스템 폴더의 빈 공간에서 여는 Windows 11 첫 우클릭 메뉴의 독립 명령으로 둔다. 기존 ‘새로 만들기’ 안에 앱 항목을 추가하지 않는다.
2. native `IExplorerCommand`와 package identity를 사용하는 경로를 최소 구현·검증 대상으로 삼는다. `GetState`에서 문맥과 지원 클립보드 형식의 가용성을 빠르게 판정하고, 지원 이미지가 없거나 판정에 실패하면 `ECS_HIDDEN`으로 완전히 숨긴다. 일반 API 계약과 제품의 실제 메뉴 표시·설치 성공을 구분한다.
3. 메뉴를 다음에 열 때 상태를 다시 평가한다. 메뉴가 열린 동안의 실시간 변경은 요구하지 않는다. 상태 판정에서 이미지 바이트 읽기·디코딩·파일 쓰기·네트워크 호출을 수행하지 않는다.
4. 이미지 처리·파일 생성·클립보드 게시·사용자 피드백은 별도 helper에 위임한다. 작업 종료 뒤 helper는 종료하며, 지속성을 상주 프로세스로 대체하지 않는다.
5. 회색 비활성 항목, 항상 보이는 항목, ‘더 많은 옵션 표시’에만 존재하는 명령, 빈 앱 상위 메뉴, 감시기, 반복 레지스트리 수정, Explorer 강제 종료, OS 내부 후킹은 허용하지 않는다.
6. 설치기가 앱 소유 등록과 제거를 처리해야 한다. 일반 사용자에게 수동 DLL 등록·레지스트리 편집·스크립트 실행·개발자 모드를 요구하지 않는다. 기존 New 항목·기본 이미지 연결·기본 복사/붙여넣기는 유지한다.

v1.0 파일은 바이트 그대로 보존한다. v1.1에서 MNU-01·AT-08과 연관 시나리오·G0 시험 위치를 갱신하고 AT-01~AT-44의 번호를 유지한다. 기능 B ‘그림으로 복사’와 저장·복사·이미지 품질·데이터 안전 계약은 변경하지 않는다.

## 검토한 대안

| 대안 | 검토 결과 | 결정 |
|---|---|---|
| 기본 New 내부의 동적 항목 | 기존 G0에서 미실증. 사용자가 위치 조건을 해제함 | 이전 조사 기록을 보존하고 현행 구현 목표에서 제외 |
| 실제 로컬 폴더 빈 공간의 첫 메뉴 독립 명령 | 사용자가 위치 변경을 승인함. native IExplorerCommand와 package identity 경로를 검증할 수 있음 | 현행 위치로 채택. G0 실기 통과는 별도 필요 |
| 레거시 메뉴 또는 ‘더 많은 옵션 표시’ 전용 | 첫 우클릭 메뉴 요구를 충족하지 못함 | 제외 |
| 고정·회색 메뉴, 감시기, 반복 등록 변경, 내부 후킹 | 완전 숨김·무상주·기존 OS 동작 보존 계약에 어긋남 | 제외 |

## 영향과 이행

사용자는 그림을 복사한 뒤 실제 로컬 폴더 빈 공간을 우클릭하고 ‘복사한 그림 저장’을 선택한다. 메뉴 표시 조건과 PNG 생성·파일 선택 동작은 기존 요구를 유지한다. 이미지가 없으면 저장 명령 자체가 보이지 않아야 한다.

현재 native IExplorerCommand와 package identity 경로의 최소 구현을 진행한다. 구현 파일이나 패키지 정의가 존재하는 것만으로 Windows 11 첫 메뉴 배치·동적 숨김·일반 사용자 설치가 검증되지는 않는다. 기존 New 경로의 BLOCKED 기록은 당시 조사 결과로 보존하고, 변경된 최종 경로의 G0 실기 결과는 NOT RUN으로 시작한다. 이전 자동 시험이나 위치 승인으로 G0·44개 수용시험을 PASS로 올리지 않는다.

사용자별 등록·제거와 package identity의 실제 설치 경로는 최종 패키지로 시험한다. 서명 인증서, 패키지 신뢰 배포, 조직의 설치 허용 정책은 미결정이다. 이번 위치 승인으로 인증서 신뢰 추가·정책 변경·조직 승인·출시 승인까지 확정하지 않는다. 원격 업로드·배포·회사 PC 설정 변경은 별도 지시 범위를 따른다.

## 실패와 복구

설치·등록·업데이트가 중단되거나 실패하면 앱 소유 변경만 정리하거나 복원해야 한다. 기존 New 항목, 타사 등록, 기본 연결, 사용자 PNG 및 원본 그림 파일을 보존한다. 제거·재설치 뒤 중복 메뉴와 이전 버전 잔재가 없는지 확인한다.

G0에서 첫 메뉴 배치나 숨김·설치 계약을 충족하지 못하면 해당 결과를 BLOCKED 또는 FAIL로 기록한다. 회색 메뉴·상주 감시·수동 등록을 대체 해법으로 배포하지 않는다. 이후 다른 위치가 필요하면 별도 요구 변경으로 취급한다. 저장·복사 실패와 취소·충돌·동시 실행의 복구 계약은 v1.1의 기존 SAV·CPY·NFR 요구를 그대로 따른다.

## 검증

최종 경로의 G0 실기 검증은 **NOT RUN**이다. 이 ADR의 채택은 구현 완료나 실제 시험 통과를 의미하지 않는다. Windows 빌드·등록 방식·API·권한·패키지 식별자·증거를 함께 기록하여 아래를 확인한다.

- AT-08: 실제 로컬 폴더 빈 공간의 첫 우클릭 메뉴에 독립 명령 ‘복사한 그림 저장’이 표시되고, 같은 위치에서 조건부 숨김이 충족되는지 확인한다.
- AT-01~AT-07: 빈 상태·텍스트·URL/HTML·파일 목록에서는 완전히 숨기고 지원 이미지에서만 표시한다. 이미지→텍스트→빈 상태→이미지 전환을 20회 반복하며 매번 메뉴를 다시 연다.
- AT-09~AT-10: 첫 메뉴 접근과 메뉴 열기만으로 파일 생성·전체 이미지 읽기·클립보드 변경이 없음을 확인한다.
- AT-40~AT-44: 일반 사용자 설치·재설치·업데이트·제거, 사용자 PNG 보존, 무상주, 기존 New·기본 연결·기본 복사/붙여넣기 회귀를 확인한다.
- 나머지 AT는 번호·기대 결과를 유지하며 실제 수행한 환경과 결과만 기록한다. 이미지 엔진 자동 시험을 탐색기 UI 또는 외부 앱 붙여넣기의 실기 PASS로 환산하지 않는다.

2026-09-25: 사용자 승인에 따라 저장 명령 위치만 변경하고 v1.1·ADR-0015의 부분 대체 관계를 기록했다. 최종 메뉴·패키지 경로의 실증과 서명·조직 정책 결정은 완료되지 않았다.
