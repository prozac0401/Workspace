# ADR-0034 · ProbPacker 오피스 자동화 도구의 공개 안내와 배포 연결

상태: 채택 · 날짜: 2026-10-06 · 결정 담당: 저장소 관리

관련: 사용자 요청 — ProbPacker의 `dist` 0.3.1을 새 릴리스로 올리고 Workspace에 기능 소개와 사용 방법을 추가해 게시. [정책 문서 작성 규칙](../policies/documentation.md), [추가 도구 개발 기준](../policies/tools.md), [Pages 운영](../delivery/pages.md).

## 맥락

ProbPacker의 제품명은 Office Automation Tools입니다. 기존 릴리스 v0.2.0과 로컬 `dist` 0.3.1이 달랐으며 사용자는 0.3.1 게시를 선택했습니다. 원본 저장소가 비공개여서 인증하지 않은 사용자는 해당 릴리스 자산을 받을 수 없습니다. Excel 병합·분리와 템플릿 채우기를 공개 Workspace에서 찾고, 실행 파일을 받고, Python 없이 실행하는 방법과 필요한 Office 프로그램을 함께 이해할 수 있어야 합니다.

## 결정

- 공개 원본은 `docs/tools/office-automation/index.md`, 주소는 `tools/office-automation/`로 정합니다. 기능 소개, 다운로드, 실행 조건, 첫 작업, 세 기능의 상세 사용, 설정·기록, 중지·재개, 업데이트·제거, 문제 해결을 한 페이지에 모읍니다.
- 홈페이지·프로그램 받기 메뉴·상황별 안내·README에서 연결합니다. 공개 안내는 20개에서 21개로 늘고 기존 이동 문서 2개와 공개 자산 15개는 유지합니다. MkDocs와 공개 검사기의 허용 목록을 함께 갱신합니다.
- 기존 `dist`의 단일 EXE와 두 ZIP을 재빌드하지 않고 비공개 `prozac0401/ProbPacker`의 `v0.3.1`에 게시합니다. 공개 다운로드는 같은 파일과 체크섬만 Workspace의 `office-automation-tools-v0.3.1` Release 자산으로 제공합니다. 두 저장소의 배포물은 해시가 일치하며 공개 안내에서는 Workspace 자산만 연결합니다. Pages에는 바이너리·인증서·QA 자료를 복사하지 않습니다.
- ZIP·EXE의 버전·해시·동일성을 확인합니다. 기존 서명은 자체 서명이며 현재 PC의 유효 판정을 다른 PC의 신뢰 보장으로 해석하지 않습니다.
- 전체 배포 EXE의 GUI·생성·종료 재검증과 단일 EXE 임시 폴더 삭제 경고의 해결 확정이 남아 있어 사전 릴리스로 제공합니다. 기존 소스 시험은 날짜와 범위를 구분하며 이번 작업의 새 기능 시험으로 계산하지 않습니다.
- 로컬 미커밋 소스와 기존 태그의 차이를 숨기지 않습니다. ProbPacker의 소스 스냅샷에 v0.3.1 태그를 붙이고 Workspace의 공개 배포 태그는 안내 커밋을 가리킵니다. 제품 개발 소스와 원시 진단을 Workspace로 옮기지 않습니다. 현재 작업 트리와 다른 개발 작업은 보존합니다.

## 검토한 대안

기존 v0.2.0에 연결하는 방법도 제시했으나 사용자는 로컬 0.3.1의 새 게시를 선택했습니다. ProbPacker를 공개로 변경하면 제품 배포와 무관한 과거 소스와 기록까지 공개될 수 있으므로 선택하지 않습니다. 비공개 릴리스 링크만 제공하면 공개 안내의 다운로드가 실패합니다. 따라서 제품 원본은 비공개로 유지하고 검증한 배포물만 공개 Workspace 릴리스에서 제공합니다. 개발 매뉴얼을 통째로 Pages에 옮기지 않고 필요한 사용자 안내를 작성합니다.

## 영향과 이행

기존 공개 문서·다운로드와 조직 정책 상태는 유지합니다. EXE는 설치 프로그램이 아니라 바로 실행하는 파일입니다. Python은 포함하지만 Excel 및 템플릿용 Word·PowerPoint는 별도로 설치되어 있어야 합니다. 병합·분리는 값과 셀 서식만 내보내며 수식·매크로·다른 시트 보존을 설명하지 않습니다.

## 실패와 복구

다운로드 자산이 없거나 해시가 다르면 게시 완료로 표시하지 않고 해당 링크를 수정합니다. 문서 게시 실패 시 소스 수정과 실제 공개 상태를 구분해 기록합니다. 되돌리기는 원본 변경으로 새로 빌드하며 생성 HTML을 직접 수정하지 않습니다.

## 검증

EXE 버전과 자체 서명, ZIP 손상 여부, 직접 EXE와 ZIP 내부 EXE의 해시, 업로드된 자산과 비인증 다운로드를 확인합니다. `python -m mkdocs build --strict`와 `python scripts/check-site.py site`로 허용 범위·로컬 링크·검색·사이트맵을 확인합니다. 게시 후 Documentation 성공과 실제 새 페이지·홈페이지·메뉴·검색·사이트맵을 확인합니다. 실제 결과와 미실행 항목은 [배포 기록](../delivery/probpacker-031-publication-20261006.md)에 남깁니다.
