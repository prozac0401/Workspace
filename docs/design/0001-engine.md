# ADR-0001 · 최소 개입 상태 엔진

상태: 구현에 채택 · 날짜: 2026-09-12 · 관련: 원문 01 §2, §5–8, §16 / POL-006

## 맥락

반복 업무의 폴더 경로는 문서 링크와 다른 도구에서 참조될 수 있습니다. 상태만 바꾸기 위해 경로를 바꾸거나 내부 업무파일을 검색할 필요가 없습니다.

## 결정

C# 엔진에서 선택 폴더의 상태·표현·Portable 아이콘만 관리합니다. 상태는 버전이 있는 INI, 표현은 desktop.ini로 분리합니다. 원래 아이콘은 바이트와 속성으로 백업하고, 변경 전후 복원 기록을 먼저 저장합니다. 동시 요청은 경로별 잠금으로 직렬화합니다. 연결 폴더와 하드링크 메타데이터는 거부합니다.

## 대안과 영향

폴더명 태그는 경로 변경 때문에 제외했습니다. 전역 DB만 사용하면 복사된 회차에 상태가 따라가지 않습니다. Shell overlay 확장은 배포와 호환성 부담이 큽니다.

고정 메타데이터가 추가되지만 업무파일은 건드리지 않습니다. Windows의 표시 캐시·보안 정책 때문에 즉시 표현을 보증할 수 없습니다. 원자적 파일 교체와 여러 파일 트랜잭션은 구분하며 중단 기록으로 후자를 복원합니다.

## 검증

원본 바이트·속성, 외부 편집 보존, 실패 주입, 동시 요청, 긴 경로와 10,000파일 시험을 사용합니다. 공유 저장소·강제 전원 손실은 별도 검증 대상입니다.
