# ADR-0012 · 보이는 칸 붙여넣기의 공개 사용 안내와 릴리스

상태: 부분 대체 — 고정 다운로드 링크는 [ADR-0014](0014-visible-cells-paste-download-list.md)로 대체, 나머지 결정 유지 · 날짜: 2026-09-24 · 결정 담당: 저장소 관리

관련: 사용자 요청 — 보이는 칸 붙여넣기를 RELEASE로 게시하고 Workspace GitHub Pages에는 사용 방법만 안내하며 평가·시험 상태·시험 결과를 표시하지 않음. [정책 문서 작성 규칙](../policies/documentation.md), [Pages 운영](../delivery/pages.md).

대체 범위: [ADR-0011](0011-excel-tools-public-guides.md)의 공개 대상에 보이는 칸 붙여넣기의 사용 안내를 추가합니다. [ADR-0006](0006-public-tool-downloads.md)의 다운로드 상태 표시 규칙에는 이 도구의 공개 페이지에 한정한 사용자 지정 예외를 적용합니다.

## 맥락

보이는 칸 붙여넣기는 다른 Excel 도구와 별도로 설치하는 COM 추가 기능입니다. 사용자가 설치 파일과 사용 방법을 찾을 수 있도록 Workspace 안내 사이트에 한 페이지를 추가합니다. 사용자는 이번 공개 문서에서 개발·검증 경과 대신 설치·사용 흐름을 안내하도록 명시했습니다.

## 결정

- 공개 원본은 `docs/tools/visible-cells-paste/index.md`, 주소는 `tools/visible-cells-paste/`입니다. 홈페이지와 프로그램 받기 메뉴, 루트 README에서 연결합니다.
- 0.1.0의 ZIP과 Release 페이지를 `prozac0401/Workspace`의 `visible-cells-paste-v0.1.0`에 고정해 연결합니다. 다른 도구와 섞이는 `releases/latest/download`는 사용하지 않습니다.
- 공개 내용은 설치, 복사·붙여넣기, 값과 서식, 지원 입력, 개수 제한, 최근 한 번 되돌리기, 실패 시 행동, 업데이트·제거와 문제 해결로 구성합니다.
- 사용자 요청에 따라 이 공개 페이지와 해당 검색 항목에는 평가·시험 상태·시험 결과를 넣지 않습니다. 내부 시험 보고서, 실패·수정 이력과 배포 근거는 삭제하지 않고 저장소에 보존합니다.
- 지원하지 않는 입력, 되돌리기 제한, 코드 서명 없음과 회사의 보안 정책 적용은 사용자가 판단할 수 있도록 직접 설명합니다. 보안 승인을 얻은 것으로 표시하거나 모든 환경의 동작을 보장하지 않습니다.
- MkDocs 허용 목록·탐색 메뉴와 사이트 검사기의 명시 경로를 함께 갱신합니다. 기존 선택범위 내보내기와 File List to Excel 안내를 유지하여 공개 페이지는 19개입니다. 공개 자산은 추가하지 않습니다.
- 설치 파일은 Release 자산으로 제공하며 Pages 자산에 복사하지 않습니다. 개발 원본·검증 원문·진단·업무 기록·사용자 로그의 제외 원칙을 유지합니다.

## 검토한 대안

제품 README와 시험 보고서를 공개 페이지로 옮기면 사용자가 요청하지 않은 개발 상태와 내부 경과가 함께 게시됩니다. 사용에 필요한 내용만 별도 문서로 작성하고 실제 제약은 그 문서에 유지합니다. 공개 문구를 줄이기 위해 내부 실패 기록을 지우는 방법은 선택하지 않습니다.

## 영향과 이행

이 결정은 공개 문서의 독자와 구성, 릴리스 링크에 관한 것입니다. 이전 도구의 지원 계약을 변경하지 않으며 회사 정책 승인이나 코드 서명을 대신하지 않습니다. 소스, 최종 패키지, Release 자산과 공개 안내의 버전이 일치한 뒤 게시합니다. 사용자 요청에 따른 게시 권한은 확보됐으며 별도의 형식상 재승인을 요구하지 않습니다.

## 실패와 복구

다운로드 자산이 없거나 파일 이름·버전이 다르면 링크를 바로잡습니다. 지원 범위와 실제 동작이 다르면 제약을 정확히 고치고 다시 게시합니다. Pages 게시 실패 시 원본 변경과 실제 공개 여부를 구분해 내부 기록에 남깁니다. 복구는 이전 정상 원본을 다시 빌드하며 생성 HTML을 직접 편집하지 않습니다.

## 검증

`python -m mkdocs build --strict`와 `python scripts/check-site.py site`로 공개 경로·자산·로컬 링크·검색·사이트맵을 확인합니다. 새 페이지의 검색 내용에 공개 대상에서 제외한 상태·결과 문구가 들어가지 않도록 검사합니다. 게시 후 Release 자산과 Pages 워크플로, 공개 URL의 내용은 별도로 확인합니다. 결과는 공개 페이지가 아닌 내부 배포 기록에 남깁니다.
