# ADR-0002 · 사용자별 MSI 배포

상태: 구현에 채택 · 날짜: 2026-09-12 · 관련: 원문 01 §9, §15 / MSI 배포 요청

## 결정

Windows 11 x64용 WPF 관리 화면과 CLI를 .NET 10 자체 포함 형태로 묶습니다. WiX 4.0.6으로 사용자별 MSI를 만들고 HKCU에 탐색기 메뉴를 등록합니다. 업무파일을 다루는 custom action은 사용하지 않습니다.

.NET SDK는 global.json, MSI 도구는 도구 매니페스트로 고정합니다. 설치 위치는 LocalAppData/Programs/FolderState이며 프로그램을 일반 사용자로 실행합니다. UpgradeCode를 유지하고 버전을 증가시켜 업그레이드와 다운그레이드 차단을 관리합니다.

## 대안과 비용

MSIX는 사용자가 요청한 MSI와 설치 수명주기·서명 운영이 다릅니다. 런타임 의존 배포는 작지만 대상 PC의 추가 설치가 필요합니다. 자체 포함 배포는 크기가 커지고 런타임 보안 갱신 때 제품도 재배포해야 합니다.

Windows 11 새 메뉴의 직접 통합은 IExplorerCommand 등 후속 확장으로 분리합니다. WiX 메이저 변경은 툴체인·라이선스 검토를 거칩니다.

## 검증과 출시

패키지 테이블·사용자 범위·메뉴 인수 quoting·설치·복구·제거·업그레이드·롤백을 확인해야 합니다. 인증서 없이 서명 완료로 표시하지 않으며 미서명 산출물은 검증용으로 분류합니다.
