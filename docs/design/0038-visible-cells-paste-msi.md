# ADR-0038 · 보이는 칸 붙여넣기의 사용자별 MSI 배포

상태: 채택 · 0.2.0-rc.1 사용자별 MSI 구현. 최종 설치·게시 판정은 별도 기록<br>
날짜: 2026-10-21<br>
결정 담당: 도구 개발·검증 담당<br>
관련 요구사항·정책: [원본 작업지시](../tools/visible-cells-paste/original-specification.md), [현재 대응표](../tools/visible-cells-paste/acceptance.md), [추가 도구 개발 기준](../policies/tools.md), [정책 문서 작성 규칙](../policies/documentation.md)<br>
대체·대체됨 관계: [ADR-0010](0010-visible-cells-paste-com.md)의 독립 COM 구조와 [ADR-0037](0037-visible-cells-paste-rectangles.md)의 영역 계약을 유지한다. 이번 후속 사용자 요청은 로컬 평가판 이후 MSI 제작·릴리스를 대상으로 하며, 앞선 평가판의 미게시 기록을 소급 변경하지 않는다.

## 맥락

영역 복사·붙여넣기 구현 후 사용자가 MSI 형태의 릴리스를 요청했다. 기존 ZIP의 Install.cmd와 단일 EXE 배포는 사용자별 COM·추가 기능 등록을 자체 설치기가 관리한다. MSI는 파일과 등록의 설치·복구·업그레이드·제거 수명주기를 별도로 정의해야 한다. 기존 설치와 충돌하거나 두 설치 관리자가 같은 파일을 서로 제거하는 상태를 만들지 않아야 한다.

실제 Ctrl+C 영역 클립보드→메뉴 전체 경로는 이전 조사 환경의 클립보드 접근 제한으로 미검증이다. 로컬 엔진 시험·MSI 제작·설치 수명주기·원격 게시를 각각 증거에 따라 판정하며 MSI라는 형식만으로 검증 완료 등급을 높이지 않는다.

## 결정

- Windows Installer MSI로 완성된 COM 제품과 필요한 사용자 안내를 배포한다. 일반 사용자 설치, HKCU 등록, 제품 전용 LocalAppData 설치 경계를 유지한다.
- Excel 비트 수에 맞는 x86·x64 MSI를 각각 제작하고 CAB를 내장한다. 배포 버전은 0.2.0-rc.1, MSI ProductVersion은 0.2.0이다. 기본 위치는 `%LOCALAPPDATA%\Programs\VisibleCellsPaste`이며 기존 COM·Excel Addins 식별자를 유지한다.
- Excel이 실행 중이면 설치·제거를 거절한다. 강제 종료나 사용자 통합문서의 저장·닫기, 보안 설정 완화를 하지 않는다.
- 새 MSI 전용 UpgradeCode를 사용한다. 기존 ZIP/EXE나 다른 MSI 버전은 먼저 제거하도록 안내하고 변경 전 거절한다. 자동 이행·자동 업그레이드를 하지 않는다. 읽기 전용 native 사전 검사와 지연 실행 검사가 충돌을 확인하고 파일·등록의 실제 쓰기·제거·롤백은 표준 MSI 동작이 맡는다.
- 현재 사용자 등록은 실행 스레드의 사용자로 명시적으로 연다. 유지 관리의 제품 상태·설치 위치는 즉시 실행 사전 검사에서 Windows Installer 정보로 독립 확인하고, 확인한 인수를 비공개 CustomActionData로 지연 검사에 전달한다. 제거 도중 바뀌는 제품 상태를 지연 검사에서 다시 판정하지 않는다.
- 설치 완료와 정상 Excel 시작·메뉴 자동 로드 확인을 구분한다. 설치 성공 메시지만으로 사용 가능 판정을 내리지 않는다.
- 소유 파일 해시와 등록 값이 다르면 복구·제거를 거절한다. 비활성화된 LoadBehavior도 외부 변경에 포함하며 자동으로 원복하지 않는다. 알 수 없는 추가 파일·값은 보존한다.
- 중단된 설치에서 소유 표식이 빠졌어도 앞선 독립 MSI 제품·경로 확인이 성립하면 남아 있는 항목의 검사를 계속한다. 표식이 다른 제품을 가리키거나 남은 소유 파일·등록 값이 달라진 경우는 계속 거절한다. 표식 누락만으로 소유권을 추측하지 않는다.
- 서명·실제 검증 범위·미검증 항목은 릴리스 노트·제외 배포 기록에 남긴다. 최신 공개 문서 정책에 따라 Pages에는 기능·설치·복구 방법을 쓰고 기존 Releases 목록 진입을 유지한다.

## 검토한 대안

| 대안 | 이점 | 비용·판정 |
|---|---|---|
| ZIP/EXE만 유지 | 기존 배포 흐름 유지 | 사용자의 MSI 요청을 충족하지 못함 |
| MSI에서 기존 설치 EXE만 실행 | 기존 설치 로직 재사용 | MSI와 자체 매니페스트의 소유권·롤백·제거 관계를 검증해야 함 |
| MSI가 파일·제품 등록 수명주기를 관리 | Windows Installer의 설치 관리 흐름 활용 | 기존 설치 전환, 사용자 권한, 외부 수정 보존, 비트 수, 업그레이드·제거 시험 필요 |

MSI의 표준 파일·등록 관리와 읽기 전용 보호 검사를 채택한다. 자체 Setup.exe를 MSI 안에서 실행하지 않으며 HKLM·관리자 설치나 광범위한 등록 삭제로 바꾸지 않는다.

## 영향과 이행

사용자는 파일을 저장하고 Excel을 종료한 뒤 기존 설치가 있으면 먼저 제거하고 자신의 Office 비트 수에 맞는 MSI를 실행한다. 설치 후 평소처럼 Excel을 시작해 기존 우클릭 명령을 사용하며 VBA 편집기나 수동 초기화를 요구하지 않는다.

사용자 요청은 MSI 릴리스 작업을 허용한다. 최초 명세의 ‘별도 지시 없이 공개 릴리스를 발행하지 않는다’는 조건을 새로운 승인 요청으로 확대하지 않는다. 공개 릴리스의 최종 버전·URL·자산·검증 여부는 실제 게시 결과를 확인한 뒤 기록한다. 기존 0.1.2 다운로드와 0.2.0-eval.1 로컬 기록은 이력으로 보존한다.

## 실패와 복구

변경된 설치 동작에 필요한 실패·중단 롤백, 동일 버전 복구·제거, 기존 설치·외부 변경 차단을 검사한다. 불필요한 전체 GUI·전체 성능 시험을 반복하지 않는다. Windows Installer의 일반 기능을 제품의 실제 검증으로 대체하지 않는다. 설치기가 업무 파일·다른 추가 기능·PERSONAL.XLSB·Office 보안 설정을 변경하지 않으며, 실제 검증하지 못한 충돌·복구 경로는 미검증으로 남긴다.

2026-10-21 이 PC의 표준 쓰기 뒤 실패 주입에서는 제품 소유 파일·표식이 제거됐지만 Windows Installer 내부 제품 등록의 롤백이 접근 거부 오류5로 끝나 설치 상태가 남았다. 전체 롤백 판정은 FAIL이다. 이후 정상 설치·제거 성공 여부와 별개로 보존하며, 읽기 전용 검사 수정으로 이 내부 등록 실패가 해결됐다고 판정하지 않는다. 실제 이력과 시험 설치 정리는 아래 검증·배포 기록을 따른다.

## 검증

필수 범위는 MSI 테이블·비트 수·COM/Ribbon·파일 해시·서명 상태 정적 확인, 일반 사용자 설치, Excel 실행 중 차단, 정상 시작 자동 로드, 제거와 재설치, 기존 설치 전환·외부 수정 보존이다. 실제 실행한 항목만 PASS로 기록한다.

영역 엔진·클립보드·Undo 결과는 [이전 로컬 검증](../delivery/visible-cells-paste-rectangles-20261021.md)과 [제품 시험 보고서](../../tools/VisibleCellsPaste/docs/test-report.md)를 따른다. 새 MSI의 설치 수명주기를 이전 ZIP/EXE 결과로 대신하지 않는다. 릴리스 게시 후 자산 이름·크기·SHA-256·태그를 확인하고 공개 안내를 갱신한다.

최종 명령·자산·실기·게시 결과는 [MSI 검증·배포 기록](../delivery/visible-cells-paste-msi-020rc1-20261021.md)에 보존한다.
