# ADR-0013 · 보이는 칸 붙여넣기의 명시적 COM 참조 수명

상태: 수정 설계 채택 · 0.1.1 구현 완료, 실제 Excel 종료 재검증 대기

날짜: 2026-09-24

결정 담당: 도구 개발·검증 담당

관련 요구사항·정책: [ADR-0010](0010-visible-cells-paste-com.md), [원본 작업지시](../tools/visible-cells-paste/original-specification.md), [도구 개발 기준](../policies/tools.md)

대체·대체됨 관계: ADR-0010의 독립 COM 구조는 유지하며 COM 참조 수명과 종료 검증을 보완함.

## 맥락

0.1.0 게시 후 합성 파일에서 실제 메뉴를 사용하고 Excel을 닫는 검사에서 종료 실패가 3회 발생했다. 붙여넣기만 수행한 경우도 포함하므로 자체 Undo 실행만의 문제로 한정하지 않는다. 기본 Excel 복사·붙여넣기·실행 취소 후 닫는 제한된 대조 시나리오는 정상 종료했다.

로컬 진단은 CLR 종료의 InnerCoEEShutDownCOM, RCWCleanupList::CleanupAllWrappers, RCW::ReleaseAllInterfaces, SafeReleasePreemp 경로와 잘못된 COM 해제 호출 대상을 보여준다. 특정 Range나 이벤트 객체가 원인이라고 확정할 정보는 부족하다. 원시 덤프·진단 파일·개인 경로·실행 식별자는 공개 저장소에 포함하지 않는다.

## 결정

0.1.1은 COM 참조의 획득과 반환을 명시하는 수명 관리로 보완한다. Excel 객체는 기존처럼 Excel 호출 스레드에서 사용한다.

- 메서드 안에서 얻은 Range·Collection·열거자와 스냅샷 읽기의 임시 COM 참조는 작업 범위가 소유하고 종료 때 반환한다. 예외 경로도 같은 정리를 거친다.
- 준비된 붙여넣기 작업은 보유한 Workbook·Worksheet·Selection 참조의 소유자다. 다음 단계로의 소유권 이전과 취소·실패·Undo 교체·연결 종료의 정리를 분리한다.
- 추가 기능의 callback 인자와 연결 인자는 해당 획득 경로에서 한 번 반환한다. pending 작업을 엔진에 넘긴 뒤 추가 기능이 다시 정리하는 중복 해제를 방지한다.
- 중복 Dispose는 이미 반환한 참조를 다시 반환하지 않는다. 공유 Application을 작업마다 강제 해제하지 않는다. 참조 획득을 추적하지 않는 일괄 FinalReleaseComObject나 강제 GC를 정상 수명 계약의 대용으로 삼지 않는다.

## 검토한 대안

| 대안 | 판정 |
|---|---|
| 관리 필드 null과 자연 GC만 유지 | 이미 종료 단계의 RCW 정리에서 실패했으므로 충분한 근거가 아님 |
| 임의의 강제 GC·모든 RCW 최종 해제 | 공유 참조와 소유권을 구분하지 못해 다른 작업을 손상할 수 있음 |
| 명시적 범위·소유권 이전·한 번 반환 | 현재 수정 방향. 반복 해제와 부분 실패를 순수 시험하고 실제 종료를 별도 검증해야 함 |

## 영향과 이행

사용자의 복사·선택·우클릭 흐름, 값·타입·서식 정책과 최근 한 번 Undo의 안전 조건은 유지한다. 0.1.0 공개 릴리스는 초안으로 전환하고 최신 릴리스 표시를 해제해 보류했으며 태그는 유지했다. 이 결정은 0.1.1이 설치됐거나 공개됐다는 뜻이 아니다. 0.1.0의 게시 전 69 PASS/7 NOT RUN 표는 당시 검증 스냅샷으로 보존하며 새 종료 게이트와 구분한다.

## 실패와 복구

COM 정리가 실행됐다는 이유로 데이터 복구를 성공 처리하지 않는다. 기존 쓰기 전 검증, 전체 백업, 부분 실패 복구, 전역 상태 복원, 복구 미완료 차단을 유지한다. 설치 시 남은 Excel 프로세스가 있으면 중단하는 가드도 유지한다. 현재 그 가드 때문에 수정본의 실제 설치가 차단되어 있다.

## 검증

0.1.0 사용 후 종료 게이트는 FAIL이다. 0.1.1 수정 후 실제 Excel 설치·자동 로드·메뉴 사용·종료 검증은 아직 NOT RUN이며 설치는 BLOCKED다. 소스 변경과 순수 시험 결과를 이 실제 게이트의 통과로 바꾸지 않는다.

범위 정리·소유권 이전·중복 Dispose·부분 획득 후 실패를 순수 시험한다. 그 뒤 실제 설치에서 붙여넣기만 수행 후 종료, 붙여넣기/Undo 후 종료, 취소·거절·복구 후 종료와 반복 시작/종료를 확인한다. 기존 기능 회귀와 대상 셀 보존도 다시 기록한다. 전체 근거는 [시험 보고서](../../tools/VisibleCellsPaste/docs/test-report.md)로 연결한다.
