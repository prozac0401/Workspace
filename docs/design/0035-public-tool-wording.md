# ADR-0035 · 공개 도구 안내를 기능과 사용 방법 중심으로 정리

상태: 채택 · 날짜: 2026-10-06 · 결정 담당: 저장소 관리

후속 정리: 2026-10-07 사용자 요청에 따라 공개 경고·면책 문구와 반복적인 ‘설명용’ 표기를 그림·본문·검색에서 제거합니다. 설치·복구·보존 동작은 직접적인 사용 순서로 표현하며 실제 UI 상태명·기능 범위·회사별 미결정은 유지합니다. 이전 검증 결과와 제작 방식은 제외 기록에 보존합니다. [공개 문구 정리 기록](../delivery/public-wording-20261007.md)을 참고합니다.

관련: 사용자 요청 — Pages에 미확인 경고를 올리지 않고, 오피스 도구 소개를 MS Office Excel·PowerPoint(PPT)·Word용으로 바꾸며 정식 배포·평가용·시험용 등의 표현을 자제. [정책 문서 작성 규칙](../policies/documentation.md), [Pages 운영](../delivery/pages.md).

대체 관계: ADR-0034 및 이전 공개 안내 결정의 배포 단계·미확인 시험 경고 표시 원칙만 이 결정으로 대체합니다. 공개 범위·배포물·기능·검증 판정은 유지합니다.

## 맥락

공개 안내에 내부 시험 결과와 배포 단계가 반복되어 사용자가 기능과 실행 순서를 찾기 어려웠습니다. 사용자는 이번 변경을 GitHub Pages 전체에 적용하도록 요청했습니다.

## 결정

홈페이지와 공개 도구·교육 안내에서 정식 배포·평가·시험 배포 표시, 내부 시험 수치와 확인하지 못한 환경의 경고를 제외합니다. 오피스 도구 소개는 MS Office Excel·PowerPoint(PPT)·Word용으로 씁니다. 실제 버전·파일명·다운로드, 기능 제한·데이터 보존·오류 해결과 실제 버튼 이름은 유지합니다. 회사별 설정과 정책의 제안·미결정도 유지합니다.

배포 채널·실기 결과·미실행 항목과 과거 실패는 사이트에서 제외한 배포 기록에 남깁니다. 이전 기록을 삭제하거나 성공으로 바꾸지 않습니다. Release 상태·자산·제품 소스는 변경하지 않습니다.

## 검토한 대안

오피스 안내만 바꾸면 홈페이지와 다른 프로그램에 같은 표현이 남습니다. 공개 안내와 내부 검증 기록을 모두 삭제하면 실제 배포 근거가 사라집니다. 따라서 공개 사용 안내를 정리하고 검증 근거를 기존 제외 문서에 보존합니다.

## 영향과 이행

기존 공개 안내 21개·이동 문서 2개·자산 15개, 메뉴와 다운로드 주소를 유지합니다. 바이너리 재제작과 도구 시험은 필요하지 않습니다. 새 문구는 조직 도입이나 상용 승인 판정이 아닙니다.

## 실패와 복구

깨진 연결이나 기능 설명 누락이 발견되면 Markdown 원본을 고쳐 다시 빌드합니다. 게시 실패는 실제 결과로 기록하며 필요하면 이전 문서 커밋으로 되돌려 게시합니다.

## 검증

공개 허용 문서와 검색 출력의 대상 표현, 고정 다운로드 연결 보존을 검토합니다. `python -m mkdocs build --strict`와 `python scripts/check-site.py site`를 실행하고, Documentation 성공과 실제 공개 페이지·검색·사이트맵의 반영을 확인합니다. 결과는 [기존 배포 기록의 후속 문구 정리](../delivery/probpacker-031-publication-20261006.md)에 남깁니다.
