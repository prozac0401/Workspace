# ADR-0020 · 명시적으로 선택하는 현재 사용자 클립보드 시험

상태: 채택 · 날짜: 2026-09-27 · 결정 담당: 사용자 요청에 따른 개발·검증 담당

관련: [도구 정책](../policies/tools.md), [요구명세 v1.1](../tools/image-copy-save/ImageCopySave_Requirements_v1.1.md), [실행 절차](../tools/image-copy-save/current-session-testing.md). 기존 격리 시험의 기본 동작은 유지한다.

## 맥락

현재 PC의 private WindowStation 생성은 native183으로 막혔다. 사용자는 현재 클립보드를 사용하는 순차 시험을 승인했으며 격리 복구를 필수 선행 조건에서 제외했다. 이는 실제 제품 결함 판정과 별개다.

## 결정

현재 사용자 클립보드를 사용하는 모드를 명시적으로 선택하고 기존 복사 내용이 바뀜을 확인하는 옵션을 함께 요구한다. 일반 실행은 계속 private station을 사용하며 실패 후 자동 전환하지 않는다. 현재 모드에서는 WinSta0\Default 문맥과 세션 단위 실행 잠금을 확인하고 같은 시나리오를 순차 실행한다. 사용자 데이터의 자동 백업·완전 복원을 약속하지 않으며 기존 내용을 로그에 수집하지 않는다. 시험 fixture는 합성 데이터만 사용한다.

## 검토한 대안

- 격리 복구를 계속 필수로 유지: 설치 독립 시험까지 지연되므로 이번 순차 작업에서는 보류한다.
- 격리 실패 시 자동으로 실제 클립보드 사용: 사용자 의도가 없는 변경이 발생하므로 채택하지 않는다.

## 영향과 실패·복구

시험 동안 다른 복사 작업을 중지한다. 실행 잠금·문맥 확인 실패는 클립보드 변경 전에 중단한다. 각 worker는 자신이 만든 프로세스와 fixture만 정리한다. 시험 실패를 성공으로 바꾸지 않고, 실제 Explorer 메뉴와 외부 앱 호환성은 별도 실기로 판정한다.

## 검증

옵션 누락·잘못된 조합은 무변경으로 거절하고, 기본 격리 경로·보고서 문맥을 확인한다. 현재 사용자 모드의 사전 사례 후 전체 엔진/helper 시험을 수행한다. 실제 결과는 [후속 작업 기록](../delivery/backlog-followup-20260927.md)에 기록한다.
