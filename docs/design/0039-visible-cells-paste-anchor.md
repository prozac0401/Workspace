# ADR-0039 · 시작 셀에서 보이는 행·열로 붙여넣기 대상 확장

상태: 채택 · 0.2.1-rc.1 구현·검증 진행, 실제 게시와 별도<br>
날짜: 2026-10-21<br>
결정 담당: 도구 개발·검증 담당<br>
관련 요구사항·정책: [원본 작업지시](../tools/visible-cells-paste/original-specification.md), [현재 대응표](../tools/visible-cells-paste/acceptance.md), [추가 도구 개발 기준](../policies/tools.md), [정책 문서 작성 규칙](../policies/documentation.md)<br>
대체·대체됨 관계: [ADR-0037](0037-visible-cells-paste-rectangles.md)의 시작 셀 자동 확장 제외를 후속 사용자 요청에 따라 대체한다. 원본 명세 1.2·3.1·7절의 원래 선택 밖 쓰기 금지는 단일 시작 셀 방식에 한해 아래 확정 대상 경계로 바꾼다. 명시적 영역 선택의 경계와 [ADR-0038](0038-visible-cells-paste-msi.md)의 MSI 계약은 유지한다. 원본과 이전 릴리스 기록은 수정하지 않는다.

## 맥락

영역 붙여넣기와 MSI 게시 후 사용자는 대상 전체를 다시 드래그하지 않고 왼쪽 위 한 셀을 선택해 실행하는 방식을 요청했다. 복사한 보이는 원본이 R행×C열이면 시작 셀부터 숨김·필터 행과 숨긴 열을 건너뛰어 R개의 보이는 행과 C개의 보이는 열을 대응시켜야 한다. 이전에 요청하지 않아 제외했던 자동 확장이 이번에는 명시적으로 승인된 동작이다.

## 결정

- 현재 대상 선택이 정확히 한 셀이면 그 셀을 왼쪽 위 시작점으로 사용한다. 원본의 확정된 보이는 행 수·열 수에 맞춰 아래쪽 행과 오른쪽 열을 찾고 그 교차점을 대상 셀로 확정한다.
- 시작 셀의 행이나 열이 숨겨졌으면 같은 위치 또는 그 뒤의 첫 보이는 행·열부터 채운다. 원래 시작 셀부터 마지막 대상까지의 물리 사각형은 기존 200,000셀 한도를 지키며 보이는 대상은 최대 50,000개다.
- 첫 보이는 열은 단일 열 Hidden으로 확인한다. 이후 보이는 열·행 위의 좁은 범위에서 SpecialCells(12)와 Intersect로 얻은 가시 셀 개수로 탐색한다. 실제 Excel에서 여러 행·열의 Hidden이 첫 축 상태만 반환할 수 있으므로 이를 전체 가시 상태로 해석하지 않는다.
- 한 칸인 탐색 구간은 단일 EntireRow/EntireColumn.Hidden을 직접 확인하며, 물리 대상도 한 칸이면 대상 자체에 기존 가시성 검사를 적용해 단일 셀 SpecialCells의 UsedRange 확장을 피한다.
- 시작 셀 방식은 원본 방향을 유지한다. 한 행 원본은 가로로, 한 열 원본은 세로로 확장하며 여러 행·열을 한 줄로 펼치지 않는다.
- 둘 이상의 셀을 명시적으로 선택하면 기존 영역 방식을 유지한다. 선택 밖으로 늘리지 않고 보이는 모양 일치를 검사하며, 기존 한 행 원본→한 열 대상 호환은 이 방식에서만 허용한다.
- 확정 대상 밖과 숨긴 셀은 변경하지 않는다. 반복 채우기, UsedRange/CurrentRegion 확장, 원본 셀 다시 읽기, 필터·숨김 변경은 하지 않는다.
- 끝 행·끝 열 또는 기존 크기 한도 안에서 필요한 보이는 셀을 확보하지 못하면 쓰기 전 0개 수정으로 중단한다. 병합·보호·spill·배열·피벗·검증 규칙·표 계산 열 검사는 확정한 대상 전체에 적용한다.
- 사용자 선택과 쓰기 대상을 구분해 기록한다. 확인 창 뒤 선택·가시 상태·확정 주소를 다시 검사하며, 원래 시작 셀 또는 명시적 선택을 유지한 상태에서 확정 대상 전체를 되돌린다.
- 붙여넣기와 Undo 뒤에도 원래 시작 셀 선택을 유지한다. 영향 범위 안내에는 시작 셀만이 아니라 별도로 보관한 확정 대상 경계를 사용한다.

## 검토한 대안

| 대안 | 판정 |
|---|---|
| 계속 대상 전체를 선택하도록 요구 | 새 사용자 요청을 충족하지 못함 |
| 물리적인 R행×C열만 사용 | 숨김·필터 때문에 필요한 개수와 모양을 채울 수 없음 |
| 시작 셀에서 보이는 행·열을 각각 확보 | 채택. 원본의 행·열 관계와 숨긴 셀 보존을 함께 유지 |
| 시작 셀에서도 한 행 원본을 세로로 변경 | 원본 방향을 추측하게 되어 제외. 명시적 한 열 선택에서만 기존 동작 유지 |

## 영향과 이행

기본 흐름은 `Ctrl+C → 왼쪽 위 시작 셀 하나 선택 → 우클릭 → 보이는 칸에 붙여넣기`다. 대상 전체를 직접 선택하는 기존 방식도 유지한다. 별도 모드 선택이나 확인 절차를 추가하지 않으며 수식 덮어쓰기·내용 비우기·대량 조건의 기존 확인만 적용한다.

제품 버전은 0.2.1-rc.1, MSI ProductVersion은 0.2.1, AssemblyVersion은 0.2.1.0으로 계획한다. 기존 0.2.0-rc.1은 이미 게시된 별도 버전이며 그 파일을 수정하지 않는다. MSI 버전을 바꾸려면 기존 설치를 먼저 제거한다.

## 실패와 복구

유효한 시작점·대상 모양·한도를 확정하지 못하면 모든 셀을 유지한다. 쓰기 전 확정한 전체 대상의 값·수식·서식을 백업하고 중간 실패 시 기존 복구·검증을 적용한다. 선택 변경·구조 변경·가시 상태 변경과 기존 Undo 제한은 유지한다. 원래 한 셀 선택을 확정된 대상 전체로 잘못 해석해 되돌리기를 거절하거나, 시작 셀만 복구하지 않도록 둘을 따로 검증한다.

## 검증

[ANCHOR 수용 기준](../tools/visible-cells-paste/acceptance.md#시작-셀-확장-추가-수용-기준)으로 단일 셀·가로·세로·영역의 방향, 숨김·필터 혼합, 시트 경계·기존 한도, 명시적 선택 회귀, 확인 뒤 변경, 전체 Undo·실패 복구를 확인한다. 필요한 집중 검사와 제작 검사를 수행하며 이전 전체 GUI·설치·실패 주입 시험을 근거 없이 반복하지 않는다.

실제 결과와 새 MSI의 제작·게시 여부는 [0.2.1-rc.1 검증·배포 기록](../delivery/visible-cells-paste-anchor-021rc1-20261021.md)에 남긴다. 이전 실제 클립보드 입력 전제 FAIL, UI 미실행과 설치 실패 롤백 FAIL은 새 성공으로 바꾸지 않는다.
