# ADR-0014 · 보이는 칸 붙여넣기의 배포 목록에서 다운로드 찾기

상태: 채택

날짜: 2026-09-24

결정 담당: 저장소 관리

관련 요구사항·정책: 사용자 요청에 따른 사용 안내 중심의 공개 범위, [정책 문서 작성 규칙](../policies/documentation.md), [Pages 운영](../delivery/pages.md)

대체·대체됨 관계: [ADR-0012](0012-visible-cells-paste-public-guide.md)의 특정 버전 ZIP·Release 고정 연결 결정만 대체합니다. 공개 대상·내용·제외 범위는 유지합니다.

## 맥락

사용 안내의 특정 버전 직접 링크는 해당 릴리스가 배포 목록에서 제외되거나 다음 버전으로 바뀌어도 이전 파일을 계속 가리킬 수 있습니다. Workspace는 여러 도구를 같은 Releases 목록에 게시하므로 저장소의 최신 릴리스를 자동 선택하는 주소도 도구를 정확히 구분하지 못합니다. 사용 안내가 특정 파일의 현재 제공 여부나 최신 버전을 단정하지 않도록 다운로드 진입점을 바꿉니다.

## 결정

- 보이는 칸 붙여넣기의 공개 사용 안내는 [Workspace Releases 목록](https://github.com/prozac0401/Workspace/releases)으로 연결합니다. 공개 페이지에 특정 버전이나 ZIP 직접 주소를 고정하지 않습니다.
- 사용자는 목록에서 **보이는 칸 붙여넣기** 릴리스를 선택하고 **Assets**의 `VisibleCellsPaste_버전.zip`을 받습니다. 다른 제품의 자산이나 소스 코드 압축 파일을 선택하지 않도록 제품명과 ZIP 이름을 안내합니다.
- `releases/latest/download`와 자동 버전 선택·다운로드는 사용하지 않습니다. 설치 파일 자체는 계속 버전별 Release 자산으로 보존하며 Pages에 복사하지 않습니다.
- 이 변경은 해당 도구의 공개 다운로드 진입점에 한정합니다. 다른 도구의 고정 버전 링크, 공개 경로·자산 허용 목록, 사용에 필요한 제한·보안 안내는 유지합니다.
- 사용자 요청에 따라 평가·시험 상태·결과와 배포 보류 경과는 공개 사용 페이지와 검색 항목에 넣지 않습니다. 실제 배포 상태와 검증·실패 근거는 내부 결정·배포 기록에 보존합니다. 목록 링크 자체를 설치 파일의 게시 또는 검증 완료 근거로 사용하지 않습니다.

## 검토한 대안

특정 버전의 고정 링크는 바로 다운로드할 수 있지만 버전 교체와 배포 제외 때 사용 안내를 함께 바꿔야 합니다. 저장소 최신 릴리스 주소는 다른 도구를 선택할 수 있습니다. 제품별 릴리스를 목록에서 선택하는 방식은 한 단계가 추가되지만 제품과 자산을 사용자가 확인할 수 있습니다.

## 영향과 이행

공개 사용 안내에서 버전 문구와 고정 자산 링크를 제거하고 제품명·Assets·ZIP 이름으로 찾는 순서를 안내합니다. 다운로드 진입점 외에 설치 권한, 제품 기능, 지원 범위는 변경하지 않습니다. ADR-0012의 부분 대체 관계와 Pages 운영·문서 정책을 함께 갱신합니다.

## 실패와 복구

목록에 해당 제품의 릴리스나 ZIP이 없으면 다른 제품 파일로 대체 안내하지 않습니다. 실제 배포 상태는 내부 기록에서 확인하고 올바른 자산 제공과 안내를 바로잡습니다. Pages 게시 실패 시 원본 Markdown을 수정하거나 이전 원본으로 되돌려 다시 빌드하며 생성 HTML은 직접 편집하지 않습니다.

## 검증

`python -m mkdocs build --strict`와 `python scripts/check-site.py site`로 공개 경로·자산·검색·사이트맵과 로컬 링크를 검사합니다. 생성된 사용 안내의 다운로드 링크가 Releases 목록이며 특정 버전 직접 링크가 없는지도 확인합니다. 이 검사는 GitHub의 현재 릴리스·자산 제공 여부나 제품의 실제 동작을 검증하지 않습니다. 게시 후 공개 URL과 릴리스 자산 확인은 별도 배포 기록에 남깁니다.
