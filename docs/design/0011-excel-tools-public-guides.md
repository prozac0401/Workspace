# ADR-0011 · 선택범위 내보내기와 탐색기 Excel 도구의 공개 안내

상태: 채택 · 사용자 게시 요청에 따른 저장소 공개 범위 결정; 조직 배포 승인은 미확정
날짜: 2026-09-24
결정 담당: 저장소 소유자의 게시 요청에 따라 구현 담당이 반영
관련 요구사항·정책: [정책 문서 작성 규칙](../policies/documentation.md), [선택범위 내보내기 명세](../tools/excel-selection-export/specification.md)
대체·대체됨 관계: ADR-0006·ADR-0008의 공개 안내 범위에 두 도구 추가; 기존 결정 유지

## 맥락

사용자가 선택범위 내보내기의 GitHub 릴리스와 Workspace 도구 소개 게시를 요청했다. 앞서 제작한 탐색기에서 Excel로 보내는 도구도 안내에 포함하도록 요청했다. 선택범위 내보내기 0.1.0-rc.9는 현재 PC의 자동 로드·메뉴·내보내기를 검증했지만 전체 인수는 미완료다. 탐색기 도구는 별도 File-List-To-Excel 저장소에서 공개된 v1.1.0으로 확인했다.

## 결정

- 선택범위 내보내기 0.1.0-rc.9를 Workspace의 제품별 태그로 prerelease 게시하며 저장소의 일반 최신 릴리스를 바꾸지 않는다.
- 이미 검증한 x64/x86 설치 파일을 다시 만들지 않고 동일 해시로 게시한다. 체크섬, 빌드 manifest와 공개용 검증 요약만 동봉한다. 원시 로그·시험 문서·프로세스 정보·개인 경로는 릴리스 자산에서 제외한다.
- 동봉 README의 공개 미포함 문구는 제작 당시 기록이다. 후속 사용자 요청으로 게시 범위가 바뀌었음을 릴리스 설명에 명시하며 동결된 패키지를 고쳐 쓰지 않는다.
- 공개 사용자 안내 두 페이지를 허용 목록·메뉴·홈페이지·README에 추가한다. 공개 페이지는 16개에서 18개로 늘고 검토된 자산 8개는 유지한다.
- File List to Excel은 공개된 v1.1.0 목록 만들기·중복 찾기만 소개한다. 미게시 v1.2 기능, Excel 문서 병합을 현재 배포 기능으로 표시하지 않는다. 외부 제품의 소스·릴리스를 변경하지 않는다.
- 알려진 실패와 미실행 환경을 다운로드 앞에 설명한다. 개발 명세·ADR·평가 기록은 Git 저장소에 보존하되 Pages에서 제외한다.

## 검토한 대안

정식판으로 표시하는 방식은 Undo 소실, API 시험 후 Excel 잔존, 미실행 설치 수명주기와 맞지 않아 채택하지 않았다. 전체 작업 폴더 게시도 사용자 로그 노출 우려와 불필요한 진단 자료 때문에 제외했다. 두 도구를 하나의 설치기나 이름으로 통합하지 않고 각 제품의 고정 버전 URL을 사용한다.

## 영향과 이행

사용자는 프로그램 받기에서 제품의 역할과 실제 지원 범위를 확인한 뒤 해당 설치 파일을 받는다. 선택범위 내보내기는 Excel 비트수에 맞는 파일을 선택한다. 보안 설정·회사 정책·기존 제품의 등록을 바꾸지 않는다. 기존 설치와 실행 중인 Excel은 이번 게시 작업에서 조작하지 않는다.

## 실패와 복구

릴리스 자산의 해시가 맞지 않으면 게시하지 않는다. 문서 배포 실패 시 이전 정상 소스로 되돌려 빌드한다. 이미 공개된 버전의 바이너리를 같은 이름으로 덮어쓰지 않고 변경된 바이너리에는 새 버전을 쓴다.

## 검증

MkDocs strict 빌드, 공개 18개 페이지·검색·사이트맵·로컬 링크 검사, 독립 문서 검토, 패키지 해시·manifest 입력 13개 일치를 확인한다. 게시 후 실제 Release 자산 해시·Actions 결과·공개 URL과 내용을 확인하고 [게시 기록](../delivery/excel-tools-publication-20260924.md)에 남긴다. 문서 게시 검증으로 제품의 미실행 시험을 통과 처리하지 않는다.
