# ADR-0037 · 보이는 영역의 행·열 모양을 유지하는 붙여넣기

상태: 채택 · 로컬 0.2.0-eval.1 구현 범위. 공개 배포·조직 승인과 별도<br>
날짜: 2026-10-21<br>
결정 담당: 도구 개발·검증 담당<br>
관련 요구사항·정책: [원본 작업지시](../tools/visible-cells-paste/original-specification.md), [현재 요구사항 대응표](../tools/visible-cells-paste/acceptance.md), [추가 도구 개발 기준](../policies/tools.md), [정책 문서 작성 규칙](../policies/documentation.md)<br>
대체·대체됨 관계: [ADR-0010](0010-visible-cells-paste-com.md)의 독립 COM 구조를 유지한다. 원본 명세 3절의 한 행·한 열 원본/한 열 대상 제한과 D19의 2차원 원본 거절은 이번 영역 요구에 한해 후속 계약으로 대체한다. 원본과 과거 검증 기록은 그대로 보존한다.

## 맥락

사용자는 한 행 또는 한 열만 복사할 수 있는 제한을 해소하고, 영역을 복사하면 숨김·필터 셀을 제외한 대상 영역에 순서대로 붙여넣기를 요청했다. 기존 파서와 대상 검사는 각각 2차원 원본과 여러 열 대상을 거절하므로 메뉴 문구만 바꿔 해결할 수 없다. 값·빈칸·서식 보존과 실패 복구도 여러 열의 정확한 주소에 적용해야 한다.

## 결정

- 원본과 대상은 유한한 연속 사각형 영역이다. 한 행·한 열·한 셀을 포함하며, 전체 행·열·시트와 직접 만든 여러 영역은 계속 제외한다.
- 원본 XML Spreadsheet의 숨김 행·열 메타데이터를 해석한다. 클립보드에서 이미 제외된 필터 행은 실제 복사 구조를 따르며, 원본 셀을 다시 읽지 않는다. 날짜 숫자 보완은 동일 스냅샷의 좌표·타입·값 대조를 유지한다.
- 대상은 선택 안의 보이는 행과 보이는 열의 교차점이다. 숨김·필터·그룹 접기 행과 숨긴 열을 제외하며 스크롤 밖의 일반 셀은 포함한다.
- 원본의 보이는 행 수와 열 수가 대상과 각각 같아야 한다. 각 행 왼쪽→오른쪽, 행 위→아래 순서를 유지한다. `2×3`을 `3×2`로 재배치하지 않는다.
- 기존 한 행 원본을 한 열 대상에 넣는 동작만 같은 항목 수의 방향 변환으로 유지한다. 시작 셀 하나에서 대상 확장, 반복 채우기, 빈칸 삭제, 이름 매칭은 하지 않는다.
- 내부 계획·검증·백업·쓰기·복구는 행과 열을 모두 식별한다. 숨긴 셀을 포함한 큰 사각형에 한 번에 배열을 쓰지 않는다. 표 계산 열 등 지원 제외 검사는 대상의 모든 해당 열에 적용한다.

## 검토한 대안

| 대안 | 이점 | 선택하지 않은 이유 또는 선택 범위 |
|---|---|---|
| 영역을 한 줄로 펼쳐 같은 개수의 셀에 쓰기 | 수량 비교가 단순함 | 같은 개수라도 행·열 의미가 달라질 수 있어 제외 |
| 왼쪽 위 셀에서 자동으로 대상 확장 | 선택 동작 감소 | 사용자 선택 밖 쓰기가 생기며 요청하지 않은 동작이므로 제외 |
| 현재 원본 시트를 다시 읽고 숨김 판정 | 라이브 숨김 상태 조회 가능 | 복사 이후 변경·프로세스 혼동을 피하기 위해 클립보드 스냅샷만 사용 |
| 보이는 행·열 모양 일치 | 복사한 표의 위치 의미와 선택 경계 보존 | 채택. 기존 가로→세로 사용만 호환 예외로 유지 |

## 영향과 이행

사용자 흐름은 `Ctrl+C → 대상 영역 전체 선택 → 선택 안 우클릭 → 보이는 칸에 붙여넣기`다. 메뉴나 방향 선택 모드를 추가하지 않는다. 원본 또는 대상에 숨긴 행·열이 있어도 제외한 모양이 같으면 대응할 수 있다. 빈칸은 실제 위치에서 대응 대상 내용을 비운다.

로컬 평가판 버전은 0.2.0-eval.1이다. 기존 공개 0.1.2 설치 파일과 공개 안내의 기존 사용법은 그대로 구분한다. 현재 PC 설치본을 교체하거나 공개 릴리스를 발행하지 않는다. 독립 설치 식별자, 일반 사용자 HKCU 권한, 보안 설정 보존, 원본·대상 자동 저장 금지 조건은 유지한다.

## 실패와 복구

모양·개수 불일치, 가시 셀 없음, 모호한 복사 정보, 지원 제외 대상은 쓰기 전에 0개 수정으로 중단한다. 확인 창 뒤 선택·가시 상태·모든 대상 셀을 다시 확인한다. 쓰기 전 모든 대상의 값·수식·표시 형식을 백업하고 중간 실패 때 부분 쓰기 가능 주소까지 복구·검증한다.

최근 한 번 되돌리기는 기존 객체·선택·편집·정렬 보호를 유지한다. 영역의 모든 셀을 원래 주소로 복원하며, 숨긴 셀을 복구 대상으로 새로 추가하지 않는다. 복구를 확인하지 못하면 성공으로 표시하지 않고 후속 쓰기를 차단한다. 프로세스 종료·OS 장애·감지되지 않은 외부 동시 수정에 대한 완전한 원자성은 보장하지 않는다.

## 검증

[RECT-01–10](../tools/visible-cells-paste/acceptance.md#영역-지원-추가-수용-기준)을 추가한다. 파서의 2차원·숨김 메타데이터·빈칸·날짜 대응, 코어의 모양·순서·경계, 실제 Excel의 다중 열 쓰기·숨김 보존·Undo·실패 복구를 각각 검증한다. 기존 1차원 회귀와 과거 D19의 거절 근거를 구분한다.

실행 결과는 [로컬 검증 기록](../delivery/visible-cells-paste-rectangles-20261021.md)과 [제품 시험 보고서](../../tools/VisibleCellsPaste/docs/test-report.md#rectangle-20261021)에 기록한다. 합성 입력 시험, COM Range.Copy, 실제 Ctrl+C·우클릭 메뉴, 설치·자동 로드를 별개로 판정한다. 미실행 환경은 미검증으로 남긴다.

2026-10-21 후속 MSI 릴리스 요청은 [ADR-0038](0038-visible-cells-paste-msi.md)을 따른다. 위 로컬 평가판의 미설치·미게시 기록은 당시 상태로 보존하며, 공개 0.1.2의 수정이 반영된 통합 후보를 별도 검증한다. 로컬 초안 번호 ADR-0016은 공개 저장소의 기존 번호 충돌을 피해 ADR-0037로 이관했다.

같은 날 후속 사용자 요청에 따른 단일 시작 셀 자동 확장은 [ADR-0039](0039-visible-cells-paste-anchor.md)가 대체한다. 위 ‘시작 셀 확장 제외’는 당시 계약이며, 명시적 영역 선택의 모양·경계 규칙은 계속 유지한다.
