# ADR-0030 · 교육 업무의 설명용 예시 화면

상태: 채택
후속 문구 변경: 2026-10-07 사용자 요청과 [정책 문서 작성 규칙 v0.23](../policies/documentation.md)에 따라 아래 결정 중 그림·본문의 ‘설명용 예시 화면’ 의무 표기만 대체했습니다. 현재 공개 화면에는 작업 캡션을 쓰고 제작 방식·검증 구분은 이 기록에 보존합니다.
날짜: 2026-10-05
결정 담당: 문서 관리 담당
관련 요구사항·정책: 사용자의 교육 업무 가상 화면 일곱 개 추가 요청, [정책 문서 작성 규칙](../policies/documentation.md), [교육 업무 예시와 쉬운 공개 안내](0029-education-public-guide.md)
대체 관계: ADR-0029의 공개 자산 범위만 보완합니다. 공개 문서·기존 이동 주소·도구 동작·설치 파일은 바꾸지 않습니다.

## 맥락

교육 업무의 일곱 장면을 글과 표에 더해 화면으로 보여 달라는 요청이 있습니다. 실제 회사 자료를 쓰거나 기존 도구를 실행해 시험하는 작업은 요청 범위에 포함하지 않습니다. 처음 쓰는 사람이 선택할 곳과 기대 결과를 쉽게 찾는 설명 자료가 필요합니다.

## 결정

가짜 명단과 파일 이름으로 일곱 가상 화면을 만듭니다. 원본은 `docs/illustrations/education-examples/screens.html`에 보존하고, 브라우저에서 각 장면을 촬영한 PNG만 기존 교육 업무 안내에 넣습니다.

모든 그림과 본문 설명에 **‘설명용 예시 화면’** 표시를 둡니다. 실제 프로그램 화면을 촬영한 사진, 설치·기능 시험 결과 또는 성공 증거로 소개하지 않습니다. 화면은 현재 사용 안내의 메뉴·단축키와 연습 정답을 기준으로 구성하며, 제품의 동작을 새로 추가한 것처럼 그리지 않습니다.

새 공개 자산은 아래 일곱 파일만 허용합니다. `mkdocs.yml`과 `scripts/check-site.py`에 각각 정확한 경로를 추가하며 폴더 전체를 허용하지 않습니다.

| 장면 | 공개 파일 |
|---|---|
| 두 명단 비교 | `assets/education-examples/compare.png` |
| 보이는 칸에 값 넣기 | `assets/education-examples/paste.png` |
| 필요한 명단을 새 파일로 만들기 | `assets/education-examples/export.png` |
| 받은 파일 목록과 복사본 모으기 | `assets/education-examples/collect.png` |
| 복사한 그림 저장 | `assets/education-examples/image.png` |
| 저장한 문서 위치로 돌아가기 | `assets/education-examples/bookmark.png` |
| 폴더에 진행 상태 표시 | `assets/education-examples/state.png` |

화면 원본 HTML과 이를 만드는 추가 JavaScript·HTML·글꼴·연습 파일은 공개 사이트에서 제외합니다. 실제 명단, 회사 업무자료, 개인 폴더 경로와 로컬 진단 정보는 원본과 공개 그림에 넣지 않습니다. 기존 사이트가 사용하는 화면 표시용 파일의 허용 범위는 늘리지 않습니다.

## 검토한 대안

실제 프로그램에서 연습 자료를 실행하고 촬영하는 방법은 제품 실행과 결과 확인이 추가로 필요합니다. 이번 요청은 설명 그림이므로 가상 화면으로 만들고 실제 시험과 구분합니다.

화면 원본 HTML까지 공개하는 방법은 요청에 없는 실행 자료를 사이트에 더합니다. 공개 내용은 일곱 PNG로 한정하고 원본은 저장소에 보존합니다.

## 영향과 이행

공개 문서 **20개**, FolderState의 이전 주소 이동 문서 **2개**와 기존 메뉴를 유지합니다. 기존 교육 업무 페이지에 그림과 쉬운 설명을 넣으며 새 메뉴나 공개 HTML 페이지는 만들지 않습니다. 공개 자산만 일곱 PNG 늘어납니다.

회사별 명단 기준, 저장 위치, 담당자와 승인 방법은 계속 제안 또는 미결정으로 표시합니다. 실제 프로그램·설치 파일·업무자료는 변경하지 않습니다. 실제 제품의 설치·기능 시험을 실행하거나 사용 효과를 측정한 것으로 기록하지 않습니다. 보이는 칸 붙여넣기의 버전 비고정 설치 안내도 유지합니다.

## 실패와 복구

글자가 작거나 잘리거나 정답과 다른 부분이 있으면 가상 화면 원본을 고쳐 해당 그림을 다시 촬영합니다. 공개 범위 검사에서 원본 HTML이나 허용하지 않은 파일이 발견되면 설정을 고친 뒤 다시 확인합니다.

게시 후 문제가 확인되면 해당 문서 변경을 이전 정상 상태로 되돌려 다시 게시합니다. 제품 설치나 회사 자료를 바꾸는 복구 작업은 없습니다.

## 검증

게시 전에 `python -m mkdocs build --strict`와 `scripts/check-site.py`로 공개 문서·이동 주소·자산·검색·사이트맵·로컬 연결을 확인합니다. 일곱 PNG의 생성 여부와 교육 업무 페이지의 그림 연결을 확인합니다. 넓은 화면과 휴대전화 크기의 화면에서 글자 읽기, 잘림과 그림 배치를 살펴봅니다.

각 그림의 가짜 값·순서·개수와 현재 안내의 실제 메뉴·단축키를 대조합니다. ‘설명용 예시 화면’ 표시와 실제 명단·개인 경로·진단 정보가 없음을 확인합니다. 실제 게시 성공과 공개 페이지의 새 내용 확인은 별도 게시 기록에 남깁니다.

이 검증은 설명 그림과 문서 사이트에 한정합니다. 실제 프로그램 동작, 회사 업무 효과 또는 모든 초보 독자의 이해도를 확인한 시험이 아닙니다.
