# ADR-0008 · 업무 책갈피의 공개 사용 안내 추가

상태: 채택 · 날짜: 2026-09-22 · 결정 담당: 저장소 관리

관련: 사용자 요청 — 작업 중인 Bookmark 도구의 최신 기능과 사용 방법을 GitHub Pages에 반영. [정책 문서 작성 규칙](../policies/documentation.md), [Pages 운영](../delivery/pages.md).

대체 범위: [ADR-0006](0006-public-tool-downloads.md)의 공개 대상에 업무 책갈피(WorkBookmark)의 사용자 안내와 버전별 설치 파일 링크를 추가합니다. 기존 두 도구의 안내, 명시한 문서·자산만 공개하는 방식, 개발 자료 제외 원칙은 유지합니다.

## 맥락

업무 책갈피는 별도 `prozac0401/BookMark` 저장소에서 개발·배포합니다. Workspace 안내 사이트에서 도구를 찾고 사용하려는 요청에 따라 현재 공개 버전 0.2.0의 설치와 사용 방법을 연결할 필요가 있습니다. 최신 소스에 있는 기능과 실제 배포 파일의 기능을 구분하고, 목록과 포스트잇 스티커, 최근 삭제 복원, 데이터 형식 변경에 따른 업데이트 제한을 사용자에게 함께 안내해야 합니다.

## 결정

- `docs/tools/bookmark/index.md` 한 페이지를 공개하고 주소는 `tools/bookmark/`로 정합니다. 다운로드·설치·사용·설정·백업·복구·제거·지원 제한을 이 페이지에 모읍니다.
- 홈페이지와 프로그램 받기 메뉴에서 FolderState·Excel 명단 비교·업무 책갈피의 설치 안내로 연결합니다. 루트 README에도 업무 책갈피 안내를 추가합니다.
- MkDocs 허용 목록과 탐색 메뉴, `scripts/check-site.py`의 공개 경로를 함께 갱신합니다. 공개 페이지는 15개에서 16개로 늘리며 기존 공개 자산 8개는 유지합니다.
- 설치 파일은 `prozac0401/BookMark`의 `v0.2.0` Release에 게시한 MSI와 포터블 ZIP으로 연결합니다. 태그와 파일명을 고정하고 `releases/latest/download`는 사용하지 않습니다. 바이너리를 Workspace나 Pages 자산으로 복사하지 않습니다.
- 사용 안내는 해당 버전의 매뉴얼·변경 사항·구현에서 확인한 기능을 기준으로 작성합니다. 이전 명세의 예정 기능이나 다른 버전의 동작을 배포 파일에 포함된 기능으로 설명하지 않습니다.
- 개발 원본·명세·검증 원문·진단·업무 기록·사용자 로그는 새 공개 페이지와 사이트 검색·사이트맵에 포함하지 않습니다. 사용자가 판단하는 데 필요한 환경 제한과 미검증 사항은 안내에 직접 요약합니다.

## 검토한 대안

BookMark의 README나 매뉴얼 전체를 복사하면 개발 자료와 내부 검증 링크가 함께 공개되고 두 저장소의 중복 관리 범위가 커집니다. Workspace에는 처음 설치하고 사용하는 데 필요한 한 페이지를 작성합니다. 설치 파일을 Workspace Release에 다시 올리는 방법은 같은 버전의 배포 출처를 둘로 나누므로 선택하지 않습니다. 기존 BookMark Release의 버전별 자산을 사용합니다.

## 영향과 이행

기존 공개 문서 주소와 두 도구의 다운로드 링크는 유지합니다. 업무 책갈피 0.2.0 안내에는 스티커와 목록 전환, 프로그램별 기록·재개 범위, 삭제와 숨기기의 차이, 백업과 구버전 복귀 제한을 반영합니다. 안내 추가는 도구의 구현이나 설치 파일을 변경하지 않으며 회사 정책 승인이나 상용 출시 승인을 뜻하지 않습니다.

## 실패와 복구

Release 자산이 없거나 안내와 실제 버전이 다르면 링크와 안내를 바로잡고 다시 게시합니다. 업데이트·복구 설명이 배포 버전과 다르면 사용자가 데이터를 변경하기 전에 읽을 수 있도록 수정합니다. 사이트 게시에 실패하면 문서 원본의 수정 사항과 실제 공개 상태를 구분해 기록합니다. 되돌리기가 필요하면 이전 정상 문서 원본으로 다시 빌드하며 생성된 HTML은 직접 고치지 않습니다.

## 검증

`python -m mkdocs build --strict`와 `python scripts/check-site.py site`로 공개 페이지 16개, 자산 8개, 로컬 링크, 검색·사이트맵의 공개 범위를 확인합니다. BookMark `v0.2.0`의 MSI·ZIP 자산 이름과 다운로드 주소도 확인합니다. 게시 후 Pages 워크플로 결과와 공개 `tools/bookmark/`의 HTTP 응답·문서 내용을 확인하고, 실제 결과와 확인하지 못한 항목을 배포 기록에 남깁니다. 이 결정 문서는 해당 검사의 성공이나 프로그램의 추가 실기 검증을 주장하지 않습니다.
