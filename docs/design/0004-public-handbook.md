# ADR-0004 · 업무 안내로 GitHub Pages 공개 범위 제한

상태: 구현에 채택 · 날짜: 2026-09-12 · 관련: 사용자 공개 범위 변경 요청 / POL-005

대체 범위: ADR-0003의 사이트 게시 범위를 구체화합니다. Markdown 원본·MkDocs·GitHub Pages 사용 결정은 유지합니다.

## 문제

기존 사이트는 운영 정책과 사용법 외에도 개발 명세·설계·양식·검증 기록을 함께 노출했습니다. 메뉴에서 항목만 제거해도 MkDocs는 파일을 생성하므로 검색이나 직접 URL로 계속 접근할 수 있습니다. HTML·JSON 자산도 그대로 복사될 수 있습니다.

## 결정

사이트에는 업무 운영 정책과 FolderState 사용·설치·오류 해결 안내만 게시합니다. mkdocs.yml의 exclude_docs에서 모든 파일을 제외하고 검토한 문서와 필요한 이미지·CSS만 명시적으로 허용합니다. 개발 문서 원본은 보존합니다. 공개 페이지의 개발 문서 링크와 저장소·편집 바로가기를 제거하고, 평가판·지원 제한은 설치 안내에 직접 제공합니다.

## 영향과 대안

새 문서는 기본적으로 게시되지 않으며 공개할 때 설정·메뉴·검사 목록을 함께 갱신합니다. 메뉴 숨김만으로 처리하는 안은 직접 URL과 검색 노출을 막지 못하므로 채택하지 않습니다. 기존 개발 문서 URL은 404가 됩니다. 공개 저장소와 과거 이력의 접근권한은 바꾸지 않으며 검색엔진 캐시의 즉시 삭제를 의미하지 않습니다.

## 검증

strict 빌드 후 scripts/check-site.py가 공개 HTML 목록·로컬 링크·자산·검색 인덱스·사이트맵을 검사합니다. 실제 수행 결과와 배포 여부는 [검증 기록](../delivery/verification.md)에 남깁니다.
