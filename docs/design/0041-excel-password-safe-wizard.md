# ADR-0041 · ExcelPasswordSafe 2 단계형 화면과 설치 위치 선택

상태: 채택 · 날짜: 2026-11-17 · 결정 담당: 도구 개발
관련: [후속 요청](../tools/excel-password-safe/original-request.md), [명세](../tools/excel-password-safe/specification.md)의 REQ-EPS-017~023
대체 범위: [기존 파일 화면](0018-excel-password-safe-explorer.md)과 [폴더 화면](0040-excel-password-safe-folder-batch.md)의 항상 펼친 입력·목록, 고정 설치 위치, 사용자 화면의 평가용 표기. 암호·백업·검증·재시도·복구 계약은 유지한다.

## 맥락

기존 폴더 창은 대상 표·모든 입력·진행·결과를 한곳에 배치해 큰 공간을 차지했다. 문맥 메뉴에서 이미 고른 작업을 작은 입력 화면으로 바로 이어 주고, 입력이 끝나면 진행·결과 화면으로 바꾸라는 요청이 추가됐다. 설치 위치 선택, 자물쇠 아이콘, 빈 공간의 현재 폴더 메뉴, 정수 버전 `2`와 불필요한 평가용 문구 제거도 함께 요청됐다.

## 결정

하나의 작은 창 안에서 대상 선택, 작업 선택, 입력, 진행, 결과를 필요한 순서로 보여 준다. 최신 교정 요청에 따라 파일 메뉴도 세 작업을 펼치는 구조로 바꾼다. 파일·폴더·빈 공간의 작업 메뉴는 모두 선택된 작업의 입력으로 바로 진입한다. 일반 실행은 파일 또는 폴더 선택부터 시작하고 작업 선택을 제공한다. 기존 `--file 경로` 호출은 호환을 위해 작업 선택을 유지한다.

문맥 메뉴 입력의 `취소`는 창을 닫으며 결과의 `다른 작업`은 숨긴다. 일반 실행의 입력은 `뒤로`로 같은 대상의 작업을 다시 고르고 결과에서 `다른 작업`을 제공한다. 입력 단계를 나가거나 완료하면 암호를 지운다. 문맥 흐름에도 안전한 실패 재시도와 이미 암호가 있거나 없는 파일에 필요한 작업 전환은 남긴다.

약 480px 폭을 기본으로 단계별 높이를 제한한다. 대상 경로·폴더의 하위 포함·파일 수를 짧게 표시하고 전체 목록·실패 세부 내용은 필요할 때 펼친다. 주 버튼은 실제 작업 이름으로 표시한다. 원본 교체와 백업 보관은 버튼 근처에 짧게 설명하고 별도 동의 체크·확인 페이지만을 위한 단계를 두지 않는다.

후속 화면 검토 요청에 따라 작업 선택의 세 버튼은 작업 이름만 표시하고 부가 설명을 제거한다. 기본 창에서 세 작업과 하단 동작을 스크롤 없이 볼 수 있게 한다. 세부 대상·결과를 펼쳤을 때의 스크롤과 기본 선택 화면의 불필요한 스크롤을 구분한다.

설정은 새 암호와 확인, 해제는 현재 암호, 변경은 세 입력만 제공한다. 기본 마스킹·명시적 암호 표시, 자연스러운 Tab 순서·입력 초점·인라인 오류로 수정 경로를 짧게 한다. 진행 중에는 입력을 없애고 현재 파일·완료 수·시도 수·취소를 표시한다. 결과에는 요약과 필요한 보고서·기록·다음 동작을 보여 준다.

수동 재시도는 성공 파일을 제외한 안전한 실패 파일만 새 입력 단계로 넘긴다. 암호는 초기화하고 자동으로 다시 실행하지 않는다. `NeedsInspection` 또는 교체·정리 불확실 상태에는 재시도를 제공하지 않는다. 이미 암호가 있거나 없는 상태에는 적절한 작업으로 이동하는 버튼을 제공하고, 일반 실행의 다른 작업은 원래 범위를 새로 확인한다. 이 UI 동작은 엔진의 파일당 최대 3회와 안전 중단 계약을 우회하지 않는다.

자물쇠 아이콘을 앱·바로가기·MSI·탐색기 메뉴에 일관되게 적용한다. 빈 공간 메뉴는 `Directory\Background`의 `--folder "%V\." --mode 작업`으로 현재 폴더를 전달하고 기존 재귀 처리 경로를 사용한다. `%V`만 따옴표로 감싸면 드라이브 루트의 마지막 역슬래시가 닫는 따옴표를 이스케이프하는 문제가 재현됐다. `\.`을 더하고 UI에서 경로를 정규화하여 같은 루트를 안전하게 전달한다. 파일과 선택 폴더는 `%1`로 선택 경로를 전달한다. 파일 메뉴에 `--mode`를 추가하며 다른 도구의 메뉴는 유지한다. 이전 버전의 파일 메뉴 유지 계약은 최신 사용자 교정으로 대체한다.

신규 MSI 설치에서는 기본 위치를 보여 주고 사용자가 다른 폴더를 입력하거나 찾아볼 수 있게 한다. 업그레이드·복구는 저장된 설치 위치를 유지하며 위치 이동은 제거 후 신규 설치로 안내한다. 설치·제거가 문서·백업·보고서를 지우지 않게 한다. 사용자에게 보이는 제품 버전은 `2`이고 설치 파일명에 평가용 접미사를 붙이지 않는다. MSI·Assembly의 내부 숫자 버전은 해당 형식의 규칙을 따른다.

미서명 평가용 문구는 사용자 요청에 따라 화면·사용 안내에서 제거한다. 서명이 생긴 것처럼 표시하지 않으며 실제 서명 상태와 기존 설치 실패 제한은 검증 기록에 보존한다. 알려진 설치 실패의 제거 후 재설치 방법은 사용 안내에 남긴다.

## 검토한 대안

기존 표를 줄이기만 하면 화면마다 필요 없는 입력·결과가 계속 남는다. 여러 대화상자를 연속해서 띄우면 초점과 취소 경로가 복잡해진다. 한 창의 단계 전환과 선택적 세부 보기로 공간과 행동 수를 줄인다. 부분 성공 뒤 전체 폴더를 다시 실행하면 완료 파일을 불필요하게 처리하므로 안전한 실패 항목만 재시도한다.

## 영향과 이행

사용자는 문맥 메뉴에서 선택한 작업의 암호만 입력하고, 완료 뒤 결과와 다음 행동을 확인한다. 기존 엔진 요청 스키마와 파일·폴더의 대상 경계는 유지한다. 버전 2 문서·패키지·화면을 일치시키고 1.2.0~1.4.0 검증·게시 기록과 첨부 원본은 수정하지 않는다. 사용자는 완료 후 릴리스까지 승인했으며 검증 뒤 실제 게시 결과를 별도로 기록한다.

## 실패와 복구

잘못된 암호·확인 불일치는 입력 단계에서 수정한다. 검색·기존 Excel·접근 권한 문제에는 대상 확인이나 다시 검색 등 가능한 행동을 표시한다. 작업 결과가 불확실하면 기록·백업 확인으로 이동하며 성공으로 표시하거나 자동 재실행하지 않는다. 취소는 안전한 파일 경계와 원본 교체 상태를 따른다. 설치 위치 입력 오류·설치 실패에는 원인을 안내하고, 기존 늦은 실패 시 제품 등록 잔존 문제를 해결된 것으로 간주하지 않는다.

## 검증

진입점별 첫 단계, 필요한 입력만 표시, 뒤로·오류 수정·키보드·암호 초기화, 진행·취소·부분 결과·재시도 제외 조건, 기본 작업 선택의 스크롤 없음, 작은 창과 펼친 세부 보기를 확인한다. 최종 아이콘과 정수 버전 표시, 실제 빈 공간 메뉴의 경로·작업 전달, 사용자 지정 경로의 설치·복구·업그레이드·제거를 검사한다. 변경하지 않은 엔진 근거는 원본 패키지와의 바이트 비교로 승계하며 줄바꿈만 다른 파일은 정규화 비교 결과를 구분한다. [검증 기록](../delivery/excel-password-safe-v2-20261117.md)에 실제 결과·미실행 범위를 구분한다.
