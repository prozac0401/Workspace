FolderState 사용 안내

폴더명과 업무파일을 유지하면서 폴더 아이콘으로 업무 상태를 표시합니다.

상태 지정

탐색기에서 폴더 하나를 우클릭하고 더 많은 옵션 표시 → 업무 상태에서 미착수·진행 중·완료·이슈를 선택합니다. 시작 메뉴의 관리 화면에서도 폴더를 선택해 지정할 수 있습니다.

초기화와 복구

상태 초기화는 기존 아이콘을 복원하고 도구 상태정보를 제거합니다. 외부에서 수정한 설정은 보존합니다. 다른 PC로 복사한 뒤 표시가 없어지면 해당 PC에서 상태 아이콘 복구를 실행하세요.

아이콘 저장

이 PC 모드는 설치 리소스를 사용합니다. 폴더와 함께 이동 모드는 폴더 안에 아이콘을 저장합니다. 공유·동기화·보안 정책에 따라 표시가 달라질 수 있습니다.

오류

쓰기 권한·파일 잠금·아이콘 리소스를 확인하세요. 손상된 상태 파일과 복원 기록은 임의로 삭제하지 말고 보존하세요. 폴더 연결·자리표시자는 지원하지 않습니다.

로그와 제거

로그는 %LOCALAPPDATA%\FolderState\logs에 저장합니다. 프로그램 제거는 업무폴더를 탐색하거나 상태정보를 일괄 삭제하지 않습니다. 완전한 초기화는 제거 전에 대상 폴더에서 실행하세요.

v0.1.0은 검증용 배포입니다. 온라인 운영 기준과 검증 범위를 확인하세요.
