FolderState 사용 안내

폴더를 확인하고 현재 상태를 누르세요. 폴더 아이콘으로 진행 상황을 표시합니다. 폴더 이름과 업무 파일은 그대로입니다.

이 도움말은 2026-09-19에 0.1.3 소스에 반영한 개선 화면 기준이며 공개 미배포입니다. 현재 공개된 0.1.2 RC1 설치 파일에는 ‘폴더 확인’과 ‘아이콘 저장 위치 적용’ 등 아래 개선이 아직 없습니다. 배포본의 사용 순서는 온라인 사용 안내를 확인하세요.

폴더에 상태 표시하기

  1. Windows 시작 메뉴에서 FolderState를 엽니다.
  2. 폴더 선택으로 폴더 하나를 고릅니다. 전체 경로를 입력했다면 폴더 확인 또는 Enter를 누릅니다.
  3. 폴더명과 전체 경로, 저장된 상태를 확인합니다.
  4. 아래 네 가지 상태 중 하나를 누릅니다. 바로 저장됩니다. 결과에 나온 대상 폴더와 완료·주의·실패 안내를 확인합니다.
  5. 탐색기에서 보기로 폴더를 엽니다. 아이콘이 아직 안 바뀌면 F5를 누르거나 폴더 창을 다시 엽니다.

시작 전아직 일을 시작하지 않았습니다.
진행 중일을 하고 있거나 예정된 답변을 기다립니다.
완료필요한 결과물과 승인·전달을 확인했습니다.
확인 필요문제가 있거나 확인·결정이 필요합니다.

어떤 상태든 바로 선택할 수 있습니다. 프로그램이 일이 끝났는지 자동으로 확인하지는 않습니다. 현재 저장된 상태는 카드에 표시됩니다.

경로를 편집하면 이전 폴더의 상태·결과가 지워지고 변경 버튼을 사용할 수 없습니다. 폴더 확인 또는 Enter로 새 폴더를 확인하세요. 같은 폴더의 상태를 다시 읽을 때도 폴더 확인을 사용합니다.

탐색기에서도 바꿀 수 있습니다. 폴더 하나를 오른쪽 클릭한 뒤 더 많은 옵션 표시 → 업무 상태에서 원하는 상태를 누르세요. 저장되면 별도 창은 뜨지 않습니다. 실패하거나 확인할 일이 있으면 안내 창이 나옵니다.

표시를 지우거나 아이콘을 다시 보이게 하기

누를 버튼결과
시작 전아직 일을 시작하지 않았다는 상태를 저장합니다.
상태 표시 지우기이 폴더의 상태 표시 지우기를 펼쳐 설명을 확인한 뒤 누릅니다. 저장된 상태를 지우고 이전 아이콘 설정으로 되돌립니다. FolderState 밖에서 바뀐 설정은 그대로 둡니다.
아이콘 다시 표시저장된 상태에 맞게 아이콘을 다시 설정합니다. 상태와 마지막 변경 시각은 그대로입니다.

일을 다시 시작하려면 시작 전을 고르세요. 상태 표시 자체가 필요 없어졌을 때 상태 표시 지우기를 누릅니다.

상태가 없는 폴더는 먼저 네 가지 상태 중 하나를 저장합니다. 이전 작업이 도중에 멈췄다는 안내가 나오면 아이콘 다시 표시로 복구합니다.

다른 PC로 폴더를 옮길 때

보통은 기본 설정인 이 PC를 쓰면 됩니다. 다른 PC에서 아이콘이 안 보이면 그 PC에도 FolderState를 설치하고 아이콘 다시 표시를 누르세요.

아이콘을 폴더와 함께 복사하려면 상태를 저장한 뒤 아이콘 저장 위치 바꾸기 (선택)을 펼칩니다. 선택한 폴더 안을 고르고 아이콘 저장 위치 적용을 누르세요. 상태와 마지막 상태 변경 시각은 그대로입니다.

위치를 선택만 했다면 아직 적용되지 않은 것입니다. 상태 버튼은 기존에 저장된 위치를 유지합니다. 상태를 저장하면 선택 표시도 저장된 위치로 돌아갑니다. 위치를 바꾸려면 다시 골라 아이콘 저장 위치 적용을 누르세요. 상태가 없는 폴더의 첫 상태는 이 PC 설정으로 저장됩니다.

아이콘 파일을 함께 옮겨도 공유 폴더, 동기화 프로그램, 회사 보안 설정에 따라 표시가 달라질 수 있습니다.

오류 해결

대상 폴더와 완료·주의·실패 안내를 먼저 확인하세요. 저장 완료 뒤 상태를 다시 읽지 못했다는 안내가 함께 나오면 폴더 확인으로 다시 읽습니다. 저장 결과와 화면 조회 결과는 다를 수 있습니다.

설정 파일이 손상되었거나 다른 곳에서 바뀌었다면 반복 실행이나 파일 삭제로 해결하려 하지 마세요. 안내된 원인을 해결한 뒤 폴더 확인을 누르세요.

안내 내용할 일
파일을 읽거나 저장하지 못함폴더 접근 권한, 사용 중인 프로그램, 드라이브·네트워크 연결, 남은 저장 공간을 확인하세요.
아이콘 파일이 없거나 손상됨FolderState 설치 파일을 다시 열고 프로그램 복구를 누르세요. 복구가 끝나면 해당 폴더에서 아이콘 다시 표시를 누르세요.
이전 작업이 도중에 멈춤아이콘 다시 표시를 누르세요. 저장된 상태가 없다고 나오면 원하는 상태를 새로 고릅니다.
FolderState 밖에서 아이콘이 바뀜현재 아이콘을 확인하세요. 상태 아이콘을 쓰려면 상태 표시 지우기를 누른 뒤 원하는 상태를 고릅니다.
설정 파일이 바뀌거나 손상됨 / 이전 상태로 되돌리지 못함설정 파일과 작업 기록을 그대로 두세요. 파일 사용 중 여부와 접근 권한, 다른 프로그램이 바꾼 내용을 확인한 뒤 도움을 요청하세요.
연결된 폴더 또는 아직 내려받지 않은 폴더이 PC에 실제로 저장된 일반 폴더를 사용하세요.
같은 폴더의 다른 작업이 진행 중잠시 기다렸다가 다시 실행하세요.

.folderstate.ini, desktop.ini, .folderstate-로 시작하는 아이콘 파일, .folderstate.transaction은 상태 표시나 이전 상태로 되돌릴 때 쓰는 파일입니다. 오류가 났다고 지우지 마세요.

자세한 오류별 조치와 명령줄 사용법은 온라인 오류 해결 안내에서 확인할 수 있습니다.

작업 기록 확인하기

작업 기록 열기를 누르면 기록이 저장된 폴더가 열립니다. operations.jsonl에 작업 시각, 폴더 경로, 바꾸기 전후 상태, 성공·실패와 오류 안내가 적혀 있습니다.

기록 위치는 %LOCALAPPDATA%\FolderState\logs입니다. 이 경로를 탐색기 주소창에 붙여 넣고 Enter를 눌러도 됩니다. 기록은 자동으로 외부에 전송하지 않습니다. 도움을 요청하며 기록을 보낼 때는 사용자 이름과 실제 업무 경로를 가려 주세요.

프로그램 제거하기

  1. 폴더의 상태 표시도 지우려면 먼저 해당 폴더마다 상태 표시 지우기를 누릅니다.
  2. 설치 파일을 다시 열고 프로그램 제거를 누릅니다.

프로그램과 탐색기 메뉴, 이 PC에 설치된 아이콘, 작업 기록을 지웁니다. 업무 폴더와 파일은 그대로 둡니다. 업무 폴더를 검색하지 않으며, 폴더 안에 저장된 상태와 아이콘도 지우지 않습니다.

이 PC에 설치된 아이콘을 사용했다면 프로그램을 제거한 뒤 상태 아이콘이 보이지 않을 수 있습니다. 이 경우에도 저장된 상태와 업무 파일은 남아 있습니다.

확인한 사용 환경

Windows 11 x64용입니다. 현재 공개된 0.1.2 RC1은 아직 상용 배포 승인을 받지 않은 시험용 버전이며 전자 서명이 없습니다. 이 도움말에 설명한 소스 개선도 새 설치 파일 제작·검증·게시를 마쳤다는 뜻은 아닙니다. 회사에서 사용해도 되는지 확인한 뒤 시험용 폴더에서 시작하세요.

예전 화면에는 시작 전이 ‘미착수’, 확인 필요가 ‘이슈’, 상태 표시 지우기가 ‘상태 초기화’, 아이콘 다시 표시가 ‘상태 아이콘 복구’로 나옵니다. 설치 화면의 ‘복구’와 ‘제거’는 각각 프로그램 복구·프로그램 제거입니다.
