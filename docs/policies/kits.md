# 업무 키트와 일정

정책: 업무 키트와 일정 · 상태: 제안 · 버전: 0.2 · 책임: 표준 담당 · 근거: 원문 02 §3–7, §14–15, §19

## MASTER의 수명주기 {#master}

MASTER는 실제 업무에 직접 사용하지 않습니다. 새 회차는 복사 후 독립적으로 진행하며 Overview에 키트 이름·버전·생성일을 기록합니다. 표준 변경을 이미 진행 중인 회차에 자동으로 덮어쓰지 않습니다.

**MASTER의 단계 폴더는 항상 미착수 상태를 유지합니다.** FolderState를 사용하는 MASTER에는 `todo`만 저장하고 `doing`·`done`·`issue`는 실제 회차에서만 사용합니다. 표준을 만들거나 갱신할 때 이 기준을 확인해, 복사할 때마다 모든 단계를 다시 초기화하는 일을 줄입니다. 시연·검증은 MASTER의 시험용 복사본에서 합니다.

FolderState를 사용하지 않는 MASTER는 상태 파일 없이 준비할 수 있습니다. 이 경우 ‘미착수’는 운영상 의미이며, 도구가 상태 미지정을 `todo`로 자동 저장하거나 표시한다는 뜻은 아닙니다.

```text
MASTER_과정운영
├─ 00_운영현황.xlsx
├─ 01_과정기본정보
├─ 02_강사및일정확정
├─ 03_교육생선발
├─ 04_입과안내
├─ 05_계정및시스템
├─ 06_OT준비
├─ 07_과정운영
├─ 08_설문및수료
└─ 09_비용및종료
```

비용처리 키트는 00_현황 / 01_대상확정 / 02_증빙수집 / 03_내역작성 / 04_결재 / 05_완료를 기본으로 합니다. 계정관리와 교육생선발 키트는 필요 확인 후 추가합니다.

## 운영현황 {#overview}

| 영역 | 책임 | 중복하지 않을 것 |
|---|---|---|
| Overview | 업무명·기간·담당·원본·키트 버전 | 개별 폴더 상태의 수동 복제 |
| Schedule | 기준일·상대일정·마감·담당 | 모든 항목의 캘린더 중복 입력 |
| Checklist | 단계 내부의 세부 확인 | 폴더 완료와 동일한 체크 |
| Contacts | 역할·조직·필요 연락수단 | 불필요한 개인 정보 |
| Issues / Decision Log | 문제·결정·이유·근거 위치 | 메일 전문 복사 |

과정운영 D는 시작일, E는 종료일입니다. 기본 일정안: D-30 모집 시작, D-21 종료, D-14 선발, D-10 안내, D-7 계정, D-3 OT, D-1 장소, E+1 설문, E+3 수료, E+7 비용처리. 실제 조직 일정으로 확정한 뒤 사용합니다. 휴일·영업일 계산은 별도 결정 전 자동 가정하지 않습니다.

미팅·승인 마감처럼 시간을 점유하거나 놓치면 안 되는 일정만 캘린더로 전달합니다. 변경은 공식 일정 원본에 먼저 반영합니다.

## 업무 사건과 상태 {#events}

**정리를 위한 별도 시간을 만들기보다 업무 사건에 정리를 붙입니다.** FolderState 사용 시 담당자가 다음 시점에 해당 단계의 상태만 바꿉니다.

| 업무 사건 | 최소 행동 |
|---|---|
| 새 반복 업무 | 미착수 상태의 MASTER를 Active에 복사하고 회차명·기본정보·기준일 입력 |
| 단계 착수 | 해당 폴더를 `doing`으로 변경 |
| 진행을 막는 문제 | `issue`로 변경하고 필요한 문제·결정·이유를 기존 Issues에 기록 |
| 단계 완료 | 필요한 결과물과 해당 업무의 승인·전달을 확인한 뒤 `done`으로 변경 |
| 업무 종료 | 미완료·이슈와 보관 조건을 확인한 뒤 회차 전체를 Archive로 이동 |

FolderState는 이 사건을 자동 감지하거나 완료를 판정하지 않습니다. 회차 종료와 Archive 이동도 담당자가 수행합니다. 미해결 업무가 남았다면 종료를 보류하거나 후속 업무의 원본·담당·마감을 연결합니다.

### 기존 MASTER에 진행·완료 상태가 남았다면

기존 MASTER를 처음 채택하거나 수정할 때 잘못된 단계만 한 번 `todo`로 고칩니다. 이미 잘못된 상태를 물려받은 새 회차도 해당 단계만 바로잡습니다. 정상적인 MASTER를 복사할 때마다 전체 상태를 재입력하는 절차는 두지 않습니다.

**미착수 지정과 상태 초기화는 다릅니다.** 미착수 지정은 `todo`를 저장하고, ‘상태 초기화’는 도구의 상태정보를 제거해 기존 아이콘을 복원합니다. FolderState v0.1에는 하위 폴더 자동 초기화 기능이 없습니다. Local Mode의 복사본을 다른 PC에서 열 때 상태가 남아 있어도 아이콘은 [복구가 필요할 수 있습니다](../tools/folderstate/index.md).

## 검증과 예외

한 회차에서 WHAT·WHEN·WHO를 찾을 수 있는지 확인합니다. MASTER 작성·갱신 때 실데이터가 없는지, 저장된 단계 상태가 `todo`인지 확인합니다. 상태 표시를 사용하지 않는 키트는 상태 파일 없이 유지합니다. 단계 변경은 표준 담당의 결정과 키트 버전으로 남깁니다. 조직 승인일은 미확정입니다.
