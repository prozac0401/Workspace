# 업무 키트와 일정

정책 ID: POL-002 · 상태: 제안 · 버전: 0.1 · 책임: 표준 담당 · 근거: 원문 02 §3–7, §14–15, §19

## MASTER의 수명주기

MASTER는 실제 업무에 직접 사용하지 않습니다. 새 회차는 복사 후 독립적으로 진행하며 Overview에 키트 이름·버전·생성일을 기록합니다. 표준 변경을 이미 진행 중인 회차에 자동으로 덮어쓰지 않습니다.

```text
MASTER_과정운영
├─ 00_운영현황.xlsx
├─ 01_과정기본정보
├─ 02_강사및일정확정
├─ 03_교육생선발
├─ 04_입과안내
├─ 05_계정및시스템
├─ 06_OT준비
├─ 07_과정운영
├─ 08_설문및수료
└─ 09_비용및종료
```

비용처리 키트는 00_현황 / 01_대상확정 / 02_증빙수집 / 03_내역작성 / 04_결재 / 05_완료를 기본으로 합니다. 계정관리와 교육생선발 키트는 필요 확인 후 추가합니다.

## 운영현황

| 영역 | 책임 | 중복하지 않을 것 |
|---|---|---|
| Overview | 업무명·기간·담당·원본·키트 버전 | 개별 폴더 상태의 수동 복제 |
| Schedule | 기준일·상대일정·마감·담당 | 모든 항목의 캘린더 중복 입력 |
| Checklist | 단계 내부의 세부 확인 | 폴더 완료와 동일한 체크 |
| Contacts | 역할·조직·필요 연락수단 | 불필요한 개인 정보 |
| Issues / Decision Log | 문제·결정·이유·근거 위치 | 메일 전문 복사 |

과정운영 D는 시작일, E는 종료일입니다. 기본 일정안: D-30 모집 시작, D-21 종료, D-14 선발, D-10 안내, D-7 계정, D-3 OT, D-1 장소, E+1 설문, E+3 수료, E+7 비용처리. 실제 조직 일정으로 확정한 뒤 사용합니다. 휴일·영업일 계산은 별도 결정 전 자동 가정하지 않습니다.

미팅·승인 마감처럼 시간을 점유하거나 놓치면 안 되는 일정만 캘린더로 전달합니다. 변경은 공식 일정 원본에 먼저 반영합니다.

## 업무 사건과 상태

새 업무는 MASTER 복사와 Overview 작성, 단계 착수는 진행 중, 완료 판단은 완료, 문제 발생은 이슈와 필요한 한 줄 기록, 종료는 미완료·이슈 검토 후 전체 보관으로 연결합니다.

MASTER를 복사하면 상태 파일도 복사됩니다. 새 회차의 각 단계 상태를 확인하고 미착수로 지정합니다. FolderState v0.1에는 하위 폴더 자동 초기화가 없습니다.

## 검증과 예외

한 회차에서 WHAT·WHEN·WHO를 찾을 수 있는지 확인합니다. 단계 변경은 표준 담당의 결정과 키트 버전으로 남깁니다. v0.1 최초 제안입니다.
