# 결정이 필요한 항목

공통 설계와 회사에서 적용할 설정을 구분합니다. 실제 경로·계정·개인정보는 공개 저장소 밖의 내부 결정 기록에서 관리합니다.

DEC-020은 제품 개발에 관한 항목이어서 공개 업무 결정 대상에서 제외했던 번호입니다. 누락으로 오해하지 않도록 이관 흔적을 남기며 재사용하지 않습니다. 번호 유지는 제품 게시자·서명 결정이 완료되었다는 의미가 아닙니다.

확정 시 근거·결정일·승인자·범위·검증을 남깁니다. 미확정 항목을 회사 정책 승인으로 표현하지 않습니다.

DEC-021–025는 반복되는 불편이 있을 때 선택하는 고급 운영 항목입니다. 기본 도입의 선행 조건으로 일괄 요구하지 않습니다. 적용 방법과 우선순위는 [진행·인수인계 개선안 — 선택 적용](folder-workflow.md)에 정리합니다.

DEC-026–028은 [업무효율화의 확장 순서](work-efficiency.md)를 적용할 때 해당 단계에서만 결정합니다. Work Inbox·업무 지식·AI·Agent 도입을 기본 운영의 필수 조건으로 두지 않습니다. 실제 도구·계정·데이터·권한 값은 내부 결정 기록에서 관리합니다.

변경 이력 · 2026-09-12: DEC-020의 개발 관리 이관과 번호 유지 이유, DEC-021–025의 선택 적용 범위를 명시했습니다.

변경 이력 · 2026-09-12: 업무효율화 확장에 필요한 DEC-026–028을 미확정·선택 항목으로 추가했습니다.
