# 결정이 필요한 항목

공통 설계와 회사에서 적용할 설정을 구분합니다. 실제 경로·계정·개인정보는 공개 저장소 밖의 내부 결정 기록에서 관리합니다.

| ID | 결정 | 기본 제안 / 확인 방법 | 담당 | 상태 |
|---|---|---|---|---|
| DEC-001 | Work 루트 | 조직 승인·백업되는 저장소 | 업무·IT | 미확정 |
| DEC-002 | 기본 구조 | POL-001의 최소 6개 | 업무 책임자 | 제안 |
| DEC-003 | MASTER 종류 | 과정운영·비용처리 | 표준 담당 | 제안 |
| DEC-004 | 과정 단계 | POL-002의 9단계 | 과정 담당 | 제안 |
| DEC-005 | 비용 단계 | 대상→증빙→내역→결재→완료 | 비용 담당 | 제안 |
| DEC-006 | 일정 기준 | 시작 D, 종료 E, 휴일 규칙 별도 | 과정 담당 | 제안 |
| DEC-007 | 메일함 | Inbox / Action / Archive | 사용자 | 제안 |
| DEC-008 | 원본 시스템 | 명단·결과물·일정별 하나 | 업무 책임자 | 미확정 |
| DEC-009 | 보존기간 | 자료별 조직 기준, 자동 삭제 없음 | 기록 담당 | 미확정 |
| DEC-010 | 보안 저장소 | 권한 통제가 있는 승인 영역 | 보안 담당 | 미확정 |
| DEC-011 | 개인·공유 경계 | 초안·확정본의 원본·권한 | 팀 책임자 | 미확정 |
| DEC-012 | 백업 | 담당·주기·복구 목표·복원 시험 | IT | 미확정 |
| DEC-013 | 아이콘 방식 | Local 기본, 필요 시 Portable | 사용자 | 제안 |
| DEC-014 | 운영현황 | Overview / Schedule / Checklist / Contacts / Issues | 표준 담당 | 제안 |
| DEC-015 | Decision Log | 기존 운영현황의 Issues 또는 내부 결정 기록 중 하나 | 업무 책임자 | 제안 |
| DEC-016 | Contacts | 역할·필요 연락만 별도 영역 | 표준 담당 | 제안 |
| DEC-017 | Waiting | 회신 대기가 많을 때 | 사용자 | 선택 |
| DEC-018 | Legacy 기준일 | 실제 도입일과 기존 위치 내부 기록 | 업무 책임자 | 미확정 |
| DEC-019 | Archive 점검 | 조직 보존 규칙에 맞춤 | 기록 담당 | 미확정 |
| DEC-021 | 다음 행동과 대기 확인 | 기존 Schedule·Issues에 담당·재확인일, 전환 기준 | 업무 책임자 | 제안 |
| DEC-022 | 단계 완료 기준 | 결과물·승인 또는 전달 증거, 확인 역할 | 표준 담당 | 제안 |
| DEC-023 | 인수인계 | 대행 역할·권한 확인·다음 행동 확인 방식 | 팀 책임자 | 미확정 |
| DEC-024 | 종료·재개 | 미해결 사항 인계, 보관 경로 갱신, 재개 승인 역할 | 업무·기록 담당 | 제안 |
| DEC-025 | 기준표·키트 갱신 | 한 회차 시범 항목, 표준 담당, 점검 계기 | 표준 담당 | 제안 |

확정 시 근거·결정일·승인자·범위·검증을 남깁니다. 미확정 항목을 회사 정책 승인으로 표현하지 않습니다.

추가 항목의 적용 방법과 우선순위는 [진행·인수인계 개선안](folder-workflow.md)에 정리합니다.
