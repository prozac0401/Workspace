# 회사에서 정할 항목

상태: 제안 · 버전: 0.2 · 책임: 각 항목의 담당자 · 적용: 이 안내를 사용하는 개인과 팀

승인자·승인일·적용일: 미확정. 근거: 원문 02 §23–25와 아래에 연결한 정책.

## 이 목록을 쓰는 방법

**지금 시작할 업무에 필요한 항목만 담당자와 정합니다.** 아래 내용은 공통 제안입니다. 회사에서 승인된 설정으로 보아서는 안 됩니다.

실제 폴더 위치, 계정, 개인정보는 공개 저장소에 적지 않습니다. 회사 내부의 결정 기록에서 관리합니다. `DEC-001` 같은 번호는 각 항목을 다른 문서에서 찾을 때 쓰는 표시입니다.

## 같은 불편이 반복될 때 정할 항목

아래 항목은 처음 시작할 때 모두 정할 필요가 없습니다. [일을 이어서 하고 다른 사람에게 넘기기](folder-workflow.md)에서 필요한 방법만 선택합니다.

| 번호 | 정할 내용 | 기본 제안 또는 확인할 점 | 담당 | 상태 |
|---|---|---|---|---|
| DEC-021 | 다음 할 일과 회신 확인 | 기존 일정표·문제 기록에 담당자와 다시 확인할 날짜를 남깁니다. 언제 상태를 바꿀지도 정합니다. | 업무 책임자 | 제안 |
| DEC-022 | 완료로 표시할 기준 | 필요한 결과물, 승인·전달 기록, 확인할 담당자를 정합니다. | 표준 담당 | 제안 |
| DEC-023 | 다른 사람에게 일을 넘기는 방법 | 대신 맡을 사람, 자료를 열 권한, 다음 할 일을 확인하는 방법을 정합니다. | 팀 책임자 | 미확정 |
| DEC-024 | 업무 종료와 다시 시작하기 | 남은 일의 담당자, 보관 후 새 링크, 다시 시작해도 되는지 정할 사람을 확인합니다. | 업무·기록 담당 | 제안 |
| DEC-025 | 기본 폴더와 안내 갱신 | 업무 한 건에서 시험할 항목, 관리 담당자, 다시 확인할 시점을 정합니다. | 표준 담당 | 제안 |
| DEC-026 | 여러 곳에서 받은 요청 모아 보기 | 기존 도구 중 어느 곳에 요청의 원본 위치·다음 할 일·담당자를 연결할지 정합니다. 누가 접수를 확인할지도 정합니다. | 업무 책임자 | 미확정·선택 |
| DEC-027 | 지난 업무에서 찾아 쓰기 | 원본 링크, 이번에도 쓸 수 있는 조건, 결과를 검토할 담당자, 검색하고 열 수 있는 범위를 정합니다. | 업무·기록 담당 | 미확정·선택 |
| DEC-028 | AI나 자동 실행 도구 사용 | 쓸 도구·자료·작업 범위, 사람이 확인할 때, 멈추거나 되돌리거나 다시 실행할 기준을 정합니다. | 업무·IT·보안 담당 | 미확정·선택 |

DEC-026–028은 [반복되는 불편 줄이기](work-efficiency.md)의 해당 방법을 검토할 때 정합니다. 새 요청 목록이나 검색 도구, AI를 반드시 도입해야 하는 것은 아닙니다. 실제 도구·계정·자료·권한 설정은 내부 기록에 남깁니다.

## 제품 개발 담당자가 정하는 항목

| 번호 | 항목 | 확인할 곳 | 담당 | 상태 |
|---|---|---|---|---|
| DEC-020 | 제품 게시자와 디지털 서명 | 제품 개발 기록에서 관리합니다. 사용에 필요한 제한은 [설치 안내](../tools/folderstate/installation.md)를 보세요. | 제품 책임자 | 개발 관리로 옮김·번호 유지 |

DEC-020은 일반 업무 설정에서 제품 개발 관리로 옮긴 항목입니다. 빠진 번호로 오해하지 않도록 남겨 둡니다. 번호를 다른 항목에 재사용하지 않으며, 결정이 끝났다는 뜻도 아닙니다.

## 결정한 뒤 확인하기

정해진 내용은 내부 기록에 이유·결정일·승인자·적용 범위·확인 결과와 함께 남깁니다. 아직 정하지 않은 항목을 회사에서 승인한 것으로 표시하지 않습니다.

회사에 이미 같은 기준이 있으면 그 기준과 내부 기록을 연결합니다. 선택 항목이 필요하지 않으면 별도 절차나 기록을 추가하지 않습니다.
