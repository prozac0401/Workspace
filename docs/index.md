# 업무를 찾고, 이어가고, 넘기는 기준

업무 폴더와 이메일을 정리하는 운영 정책과 FolderState 사용법을 안내합니다. 필요한 자료를 찾고 다음 행동을 이어갈 수 있도록, 실제 업무에 적용할 기준을 확인하세요. 예시는 가상이며 실제 업무자료는 이 공개 문서에 저장하지 않습니다.

<div class="grid cards" markdown>

- **운영 정책**

    폴더의 역할, MASTER 키트, 이메일 처리와 원본 시스템의 기준을 확인합니다.

    [운영 정책 읽기](policies/workspace.md)

- **FolderState**

    폴더명은 고정하고 네 가지 아이콘으로 업무 상태를 표시합니다.

    [설치와 사용 안내](tools/folderstate/index.md)

</div>

## 기본 약속

1. 새 반복 업무는 MASTER의 복사본으로 시작합니다.
2. 현재 업무는 Active에, 종료 기록은 Archive에 둡니다.
3. 폴더 상태는 FolderState, 일정은 Schedule, 결정 이유는 Decision Log에 기록합니다.
4. 같은 정보를 여러 곳에서 각각 수정하지 않습니다.
5. 정리 자동화는 소유 범위와 복구 방법이 명확할 때 추가합니다.

## 폴더 운영 개선하기

회신 대기, 단계 완료 판단, 담당자 변경에서 반복되는 누락을 줄이기 위한 [진행·인수인계 개선안](policies/folder-workflow.md)을 확인하세요. 기존 운영현황에 필요한 항목만 더하고, 한 회차에서 효과를 확인한 뒤 적용 범위를 정합니다.

!!! info "문서 상태"
    운영 정책은 제안 단계입니다. 회사의 저장 위치·보존기간·공식 원본·백업 체계는 [결정 목록](policies/decisions.md)에서 조직별로 확정합니다. FolderState v0.1.0은 검증용 배포이며 [설치 안내](tools/folderstate/installation.md)에서 사용 환경과 제한을 확인합니다.
