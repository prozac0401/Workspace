# 업무를 찾고, 이어가고, 넘기는 기준

이 저장소는 업무 폴더와 이메일을 정리하는 정책, 그 정책을 지원하는 도구, 설계 결정의 근거를 함께 관리합니다. 원문 01·02를 출발점으로 삼으며 실제 업무자료는 이 공개 문서에 저장하지 않습니다.

    [운영 정책 읽기](policies/workspace.md)

- **01 · FolderState**

- **설계와 문서 작성**

    정책 변경과 추가 도구의 설계를 같은 형식으로 기록합니다.

## 기본 약속

1. 새 반복 업무는 MASTER의 복사본으로 시작합니다.
2. 현재 업무는 Active에, 종료 기록은 Archive에 둡니다.
3. 폴더 상태는 FolderState, 일정은 Schedule, 결정 이유는 Decision Log에 기록합니다.
4. 같은 정보를 여러 곳에서 각각 수정하지 않습니다.
5. 정리 자동화는 소유 범위와 복구 방법이 명확할 때 추가합니다.

    공통 설계 기준은 v0.1 제안입니다. 회사의 저장 위치·보존기간·공식 원본·백업 체계는 [결정 목록](policies/decisions.md)에서 조직별로 확정합니다. FolderState의 제품 상태는 [품질 기준](delivery/quality.md)에 별도로 기록합니다.
