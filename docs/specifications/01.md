# Windows Explorer 폴더 상태표시 도구 명세

버전: Draft v0.1  
목적: Windows Explorer의 폴더를 업무 체크리스트처럼 활용하되, 폴더명과 내부 업무파일은 변경하지 않고 상태만 시각적으로 표시한다.

---

## 1. 배경

반복 업무를 `MASTER 키트 → 이번 회차 복사본` 방식으로 운영할 때, 각 단계 폴더의 진행상태를 Windows Explorer에서 바로 확인하고 싶다.

예:

```text
2026-10_AWS_과정운영
├─ 01_과정기본정보
├─ 02_강사및일정확정
├─ 03_교육생선발
├─ 04_입과안내
├─ 05_계정및시스템
├─ 06_OT준비
├─ 07_과정운영
├─ 08_설문및수료
└─ 09_비용및종료
```

기존 아이디어처럼 `[ ]`, `[~]`, `[X]`, `[!]`를 폴더명에 넣을 수 있지만, 상태변경 때마다 경로가 바뀌는 문제가 있다.

따라서 **폴더명은 고정**하고 **아이콘만 상태에 따라 변경**하는 방식이 기본 설계다.

---

## 2. 핵심 원칙

1. **폴더명은 상태변경으로 수정하지 않는다.**
2. **폴더 내부의 업무파일을 스캔하거나 수정하지 않는다.**
3. 상태변경은 O(1)에 가까운 가벼운 작업이어야 한다.
4. 별도 체크리스트 프로그램을 열지 않아도 Explorer만으로 상태가 보여야 한다.
5. 도구가 설치되지 않은 PC에서도 폴더와 파일은 정상적으로 열려야 한다.
6. 상태정보와 화면표현은 분리한다.
7. 기존 `desktop.ini` 사용자 설정이 있다면 최대한 보존한다.
8. 잘못된 상태표시는 언제든 `상태 초기화`로 복구할 수 있어야 한다.

---

## 3. 상태 모델

기본 상태는 4개만 둔다.

| 상태 | 내부값 | 의미 |
|---|---|---|
| 미착수 | `todo` | 아직 시작하지 않음 |
| 진행 중 | `doing` | 현재 작업 중 |
| 완료 | `done` | 해당 단계 완료 |
| 이슈 | `issue` | 문제/확인/의사결정이 필요한 상태 |

상태 전이는 강제하지 않는다.

예:

```text
todo → doing → done
         ↓
       issue
         ↓
       doing
```

사용자가 판단한 상태를 그대로 기록한다.  
도구가 완료 여부를 자동 검증하지 않는 것이 v1의 원칙이다.

---

## 4. Explorer 컨텍스트 메뉴

폴더 우클릭 시 다음 메뉴를 제공한다.

```text
업무 상태 >
    미착수
    진행 중
    완료
    이슈
    ─────────
    상태 초기화
    상태 아이콘 복구
```

### 동작

- `미착수` → 기본 또는 TODO 아이콘
- `진행 중` → 진행 아이콘
- `완료` → 완료 아이콘
- `이슈` → 경고/이슈 아이콘
- `상태 초기화` → 본 도구가 설정한 상태정보 및 아이콘 사용자지정만 제거
- `상태 아이콘 복구` → 저장된 상태값을 읽어 현재 PC의 아이콘 경로로 재적용

---

## 5. 상태 저장 구조

권장:

```text
업무폴더
├─ desktop.ini
├─ .folderstate.ini
└─ 업무파일들...
```

두 파일은 기본적으로 Hidden/System 속성으로 사용자에게 보이지 않게 한다.

### `.folderstate.ini`

예:

```ini
[FolderState]
Version=1
Status=doing
Updated=2026-09-12T10:46:00+09:00
Mode=local
```

### 역할 분리

```text
.folderstate.ini
    └─ 실제 상태값 / 향후 확장용 메타데이터

desktop.ini
    └─ Windows Explorer 화면표현
```

`desktop.ini`만 보고 상태를 추정하지 않는다.

---

## 6. 아이콘 저장 방식

### 6.1 Local Mode — 기본 권장

아이콘은 프로그램 공용 경로에 저장한다.

예:

```text
%LOCALAPPDATA%\FolderState\icons\
├─ todo.ico
├─ doing.ico
├─ done.ico
└─ issue.ico
```

장점:
- 업무폴더 내부가 깔끔하다.
- 아이콘 업데이트가 쉽다.
- 같은 PC에서 이동할 때 사용하기 편하다.

주의:
- 다른 PC로 폴더만 복사하면 해당 아이콘 경로가 존재하지 않아 기본 폴더 아이콘으로 돌아갈 수 있다.
- 이때 `.folderstate.ini`가 남아 있으면 `상태 아이콘 복구`로 쉽게 재적용할 수 있다.

### 6.2 Portable Mode — 선택 기능

이동성을 중요하게 보는 폴더는 현재 상태 아이콘을 폴더 내부에 함께 둔다.

예:

```text
업무폴더
├─ desktop.ini
├─ .folderstate.ini
├─ .folderstate.ico
└─ 업무파일들...
```

장점:
- 다른 경로로 이동/복사 시 아이콘 유지 가능성이 높다.
- 프로그램 공용경로 의존성이 줄어든다.

주의:
- ZIP, 네트워크 공유, 보안솔루션, 다른 파일시스템을 거칠 때 Hidden/System 속성 또는 `desktop.ini` 처리 방식 때문에 표시가 달라질 수 있다.
- “어디서나 100% 동일한 표시”를 보장하는 기능으로 정의하지 않는다.

## 7. 폴더 상태 변경 처리

`완료` 선택 시 예시 흐름:

1. 선택된 대상이 폴더인지 확인
2. 경로를 Unicode/Long Path 안전하게 획득
3. `.folderstate.ini`를 임시파일로 작성
4. 원자적 교체(atomic replace)
5. 기존 `desktop.ini` 존재 여부 확인
6. 기존 사용자 설정을 보존하면서 `.ShellClassInfo`의 본 도구 소유 항목만 갱신
7. 필요한 폴더/파일 속성 적용
8. Explorer에 갱신 통지
9. 성공/실패 결과 반환

### 중요

**폴더 안의 파일 개수와 무관하게 내부 파일을 순회하지 않는다.**

파일이 3개든 10,000개든 상태변경 로직은 동일하다.

---

## 8. 기존 `desktop.ini` 보호

폴더에 이미 `desktop.ini`가 있을 수 있다.

따라서:

- 파일 전체를 무조건 덮어쓰지 않는다.
- 기존 섹션과 키를 파싱한다.
- 본 도구가 관리하는 아이콘 관련 값만 수정한다.
- `상태 초기화`에서도 본 도구가 만든 항목만 제거한다.
- 기존 사용자 폴더 아이콘이 존재했던 경우 복구 가능한 백업정보를 남기는 방안을 검토한다.

권장 백업 예:

```ini
[FolderStateBackup]
HadDesktopIni=true
OriginalIconResource=...
```

## 9. Windows 11 컨텍스트 메뉴 구현 전략

### MVP

작은 실행파일:

```text
FolderState.exe
```

명령 예:

```text
FolderState.exe set todo   "<folder>"
FolderState.exe set doing  "<folder>"
FolderState.exe set done   "<folder>"
FolderState.exe set issue  "<folder>"
FolderState.exe reset      "<folder>"
FolderState.exe repair     "<folder>"
```

사용자 범위 Registry 등록으로 Explorer 메뉴에 연결한다.

장점:
- 구현 및 디버깅이 단순하다.
- 관리자 권한 없이 설치 가능한 구성을 만들기 쉽다.

단점:
- Windows 11에서는 메뉴가 `더 많은 옵션 표시`에 나타날 수 있다.

### Native Windows 11 메뉴 — 후속 버전

필요해질 경우 `IExplorerCommand` 기반 Shell Extension으로 전환한다.

목표:

```text
우클릭
└─ 업무 상태 >
   ├─ 미착수
   ├─ 진행 중
   ├─ 완료
   ├─ 이슈
   ├─ 상태 초기화
   └─ 상태 아이콘 복구
```

**v1은 단순성과 배포 편의성을 우선한다.**

## 10. 대괄호/폴더명 상태표시 모드

기본값은 사용하지 않는다.

이유:
- 상태변경 때마다 폴더 경로가 바뀐다.
- 문서 링크, 바로가기, 스크립트, 설정파일 등에 영향을 줄 수 있다.
- `[]`는 일부 Shell/PowerShell 문맥에서 와일드카드로 해석될 수 있다.

필요 시 보조 모드로만 제공한다.

예:

```text
04__TODO__입과안내
04__DOING__입과안내
04__DONE__입과안내
04__ISSUE__입과안내
```

하지만 **권장 모드는 Icon Mode**다.

---

## 11. 다중 선택

후속 기능으로 여러 폴더를 동시에 선택해 상태를 변경할 수 있게 한다.

예:

```text
03_교육생선발
04_입과안내
05_계정및시스템
```

3개 선택 → 우클릭 → `완료`

주의:
- 한 폴더 실패가 다른 폴더 처리 전체를 롤백시키지 않는다.
- 처리결과를 `성공 N / 실패 N`으로 보여준다.
- 실패경로는 로그에서 확인 가능하게 한다.

---

## 12. 네트워크/공유폴더

v1 기본 지원대상:

- 로컬 NTFS 폴더
- 일반적인 로컬 사용자 폴더

Best-effort 지원:

- SMB 네트워크 공유
- 동기화 폴더
- 기업 문서관리/보안 솔루션 아래 폴더

네트워크/보안환경에서는:
- 폴더 사용자지정 속성
- `desktop.ini`
- Hidden/System 속성
- Shell icon refresh

동작이 다를 수 있으므로 별도 테스트가 필요하다.

---

## 13. 오류 처리

대표 오류:

- 폴더 쓰기권한 없음
- `desktop.ini` 잠김
- 읽기전용/보안솔루션 차단
- 아이콘 파일 누락
- 네트워크 연결 끊김
- 잘못된 경로
- 매우 긴 경로
- 기존 폴더 사용자지정과 충돌

사용자 메시지는 짧게:

```text
상태를 변경하지 못했습니다.
원인: 폴더에 쓰기 권한이 없습니다.
```

상세내용은 로그에 기록한다.

## 14. 로그

기본 로그 위치:

```text
%LOCALAPPDATA%\FolderState\logs\
```

로그 항목:

```text
timestamp
action
target_path
previous_status
new_status
result
error
```

업무폴더 자체에는 로그를 쌓지 않는다.

## 15. 설치/제거

### 설치

권장 목표:
- 사용자 범위 설치
- 관리자 권한 불필요
- 설치 시 아이콘 리소스 배치
- Explorer context menu 등록

### 제거

기본 제거는:
- 프로그램
- Registry 메뉴
- Local icon resource
- Local log

만 제거한다.

업무폴더 안의 `.folderstate.ini`는 기본적으로 삭제하지 않는다.

선택 옵션:

```text
[ ] 모든 업무폴더의 상태 사용자지정도 제거
```

단, 전체 업무폴더 탐색이 필요하므로 별도 정리도구로 분리하는 편이 안전하다.

## 16. 안전 원칙

v1에서 하지 않는 것:

- 업무파일 삭제
- 업무파일 이름변경
- 하위파일 내용 검사
- 완료 여부 자동판정
- 자동 Archive 이동
- 자동 메일처리
- 자동 폴더 구조 변경
- 폴더명 상태문자 강제삽입

즉 **상태표시 도구는 상태표시만 한다.**

## 17. 향후 확장 후보

필요해진 뒤에만 추가한다.

### 17.1 상태 자동복구
`.folderstate.ini`를 기준으로 손상된 아이콘을 일괄 복구

### 17.2 키트 초기화
MASTER 복사 후 모든 단계 폴더를 `todo`로 초기화

### 17.3 상위 폴더 요약
하위 단계의 상태를 읽어 상위 과정 폴더에 대표 상태 표시

예:

```text
진행 중 6
완료 2
이슈 1
```

단, 이 기능부터는 하위폴더 스캔이 필요하므로 기본 상태변경과 분리한다.

### 17.4 일정표 연계
`00_운영현황.xlsx` 또는 별도 메타파일의 마감일을 읽어:
- 기한 임박
- 기한 초과

표시

### 17.5 키트 생성기
MASTER를 복사하고:
- 과정명
- 시작일
- 종료일

만 입력하면 새 업무 컨테이너 생성

## 18. v1 완료 기준

다음이 가능하면 v1 완료로 본다.

- [ ] 폴더 우클릭으로 4개 상태 선택 가능
- [ ] 폴더명 변경 없음
- [ ] 내부 업무파일 스캔 없음
- [ ] 상태가 `.folderstate.ini`에 저장됨
- [ ] Explorer 아이콘 즉시 갱신
- [ ] Local Mode 동작
- [ ] Reset 가능
- [ ] Repair 가능
- [ ] Unicode 한글 경로 정상 지원
- [ ] 공백 포함 경로 정상 지원
- [ ] 권한오류 등 주요 실패 메시지 제공
- [ ] 기존 `desktop.ini`를 파괴하지 않음

## 19. 구현 권장 순서

### Milestone 1 — 핵심 엔진
CLI로 특정 폴더의 상태를 저장하고 아이콘 변경

### Milestone 2 — 복구/초기화
Reset / Repair 구현

### Milestone 3 — Explorer 메뉴
사용자 범위 Context Menu 등록

### Milestone 4 — 설치 패키지
설치/제거 및 icon resource 배포

### Milestone 5 — Portable Mode
폴더 내부 아이콘 방식 추가

### Milestone 6 — 다중 선택
복수 폴더 상태 일괄변경

## 20. 한 줄 정의

> **FolderState는 폴더명이나 업무파일을 건드리지 않고, Windows Explorer의 폴더 아이콘만으로 업무 진행상태를 표시하는 최소개입형 체크리스트 도구다.**
