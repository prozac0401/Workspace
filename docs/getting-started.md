## 먼저 저장할 곳을 정하세요 {#minimum}

회사에서 허용한 저장 위치에 업무용 폴더인 `Work`를 두세요. 어디에 저장해도 되는지 모른다면 담당자에게 확인하세요. 어떤 파일을 원본으로 쓸지, 누가 열어 볼 수 있는지, 누가 백업하는지도 확인해야 합니다.

이 안내는 **제안 단계**입니다. 회사별로 정할 내용은 [회사에서 정할 항목](policies/decisions.md)을 참고해 내부 기록에 남기세요.

### 용도별 폴더를 만드세요

`Work` 안에 아래 폴더를 만드세요. 오른쪽 이름은 실제 폴더 이름입니다.

| 넣을 자료 | 폴더 이름 |
|---|---|
| 어디에 쓸지 아직 정하지 못한 새 자료 | `00_Inbox` |
| 지금 하고 있는 업무 | `10_Active` |
| 반복 업무를 시작할 때 복사할 기본 폴더 | `20_Operations` |
| 여러 업무에서 참고할 매뉴얼과 자료 | `40_Reference` |
| 끝난 업무의 기록 | `80_Archive` |
| 없어져도 업무 기록에 문제가 없는 임시 파일 | `90_Temp` |

메일도 세 곳으로 나누면 됩니다. 아직 처리 방법을 정하지 않은 메일은 `Inbox`, 할 일이 남은 메일은 `Action`, 처리가 끝난 메일은 `Archive`에 둡니다. 자세한 예시는 [자료를 둘 곳 정하기](policies/workspace.md), [파일 이름과 메일 정리](policies/files-email.md)를 보세요.

예전 자료는 기존 위치에 두세요. 다시 쓸 때 필요한 것만 옮기면 됩니다. 별도 프로젝트 폴더인 `30_Projects`와 회신 대기 메일함인 `Waiting`은 필요할 때 추가하세요.

### 반복 업무의 기본 폴더를 준비하세요

**다음 업무에서 복사해 쓸 기본 폴더를 `MASTER`라고 부릅니다.** 교육 운영이나 비용 처리처럼 실제로 반복하는 업무부터 준비하세요. 필요한 빈 양식과 단계별 폴더를 넣고 `20_Operations`에 보관하세요.

이 기본 폴더에는 실제 업무 자료를 넣지 않습니다. FolderState로 상태를 표시한다면 모든 단계를 시작 전으로 유지하세요. FolderState를 쓰지 않는 폴더에 상태 파일을 미리 만들 필요는 없습니다.

만드는 예시는 [반복 업무 폴더 준비하기](policies/kits.md#master)를 보세요.

### 복사본에서 이번 업무를 시작하세요

1. 기본 폴더를 `10_Active`에 복사하세요.
2. 복사본 이름에 이번 업무의 이름과 기간을 적으세요.
3. 업무의 기본정보, 일정, 담당자를 확인하세요.
4. 이번 업무에서 만드는 자료를 복사본 안에 저장하세요.

일정이나 담당자 정보가 사내 시스템에 이미 있다면 그 위치를 연결하세요. 운영현황 파일을 사용하는 방법은 [업무 정보와 일정 적기](policies/kits.md#overview)를 보세요.

## 업무를 하면서 필요한 것만 바꾸세요 {#events}

FolderState를 쓴다면 아래 상황에서 담당자가 직접 상태를 바꾸세요.

| 지금 상황 | 할 일 |
|---|---|
| 한 단계를 시작했어요 | 그 단계의 폴더를 진행 중으로 표시하세요. |
| 문제가 생겨 일을 이어갈 수 없어요 | 확인 필요로 표시하세요. 필요한 내용과 결정 이유는 쓰고 있는 문제 기록에 적으세요. |
| 한 단계를 마쳤어요 | 필요한 자료·승인·전달을 확인한 뒤 완료로 표시하세요. |
| 이번 업무가 모두 끝났어요 | 남은 일과 문제, 보관 조건을 확인한 뒤 업무 폴더 전체를 `80_Archive`로 옮기세요. |

FolderState는 파일이 바뀌거나 메일이 왔다고 상태를 자동으로 바꾸지 않습니다. 끝난 폴더도 직접 옮겨야 합니다.

받은 자료를 매일 모두 정리하거나 매주 모든 폴더를 점검할 필요는 없습니다. 업무 마감과 회신 확인, 회사에서 정한 백업·보관 점검 일정은 지키세요.

## 한 번 마친 뒤 찾아보세요 {#review}

| 확인할 내용 | 찾아볼 곳 |
|---|---|
| 어떤 일을 했고 어떤 자료를 만들었나요? | 이번 업무 폴더의 자료와 단계별 상태 |
| 누가 언제까지 해야 하나요? | 회사에서 기준으로 정한 일정표와 담당자 정보 |
| 왜 그렇게 결정했나요? | 문제·결정 기록과 연결된 근거 자료 |
| 다른 사람이 이어서 할 수 있나요? | 업무 요약에 적힌 자료 위치, 마감일, 남은 일 |

필요한 내용을 찾을 수 있다면 지금 방식을 유지하세요. 찾기 어려웠던 내용만 쓰고 있는 기록에 보충하세요. 자주 쓰는 방법은 [자료 정리의 10가지 습관](principles.md)에 모았습니다.

## 같은 불편이 반복될 때 더해 보세요

- **어디까지 했는지 찾기 어렵다면:** 시험용 폴더에서 [FolderState 사용법](tools/folderstate/index.md)을 익힌 뒤 업무 폴더에 적용하세요.
- **파일을 못 찾거나 같은 내용을 여러 번 적는다면:** 한 회차 또는 약 한 달을 써 본 뒤, 불편했던 점을 기존 업무 돌아보기 기록에 적으세요. 쓰지 않는 칸은 줄이세요.
- **답장을 놓치거나 업무를 넘기기 어렵다면:** [일을 이어서 하고 다른 사람에게 넘기기](policies/folder-workflow.md)에서 필요한 방법만 고르세요.
- **여러 곳에서 오는 요청을 놓치거나 같은 문제를 다시 조사한다면:** [반복되는 불편 줄이기](policies/work-efficiency.md)를 보세요. 자동 처리나 AI에 맡길 일은 필요한 자료, 작업 순서, 판단 기준을 정한 뒤 검토하세요.
