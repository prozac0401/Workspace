# 처음 도입하는 순서

| 단계 | 실제 행동 | 남기는 기록 | 완료 기준 |
|---|---|---|---|
| 1. 위치 결정 | 조직이 허용한 Work 루트 선택 | 결정 목록 | 원본·권한·백업 담당 지정 |
| 2. 기본 구조 | Inbox, Active, Operations, Reference, Archive, Temp 생성 | 운영 정책 | 위치별 용도가 구분됨 |
| 3. MASTER 두 개 | 과정운영·비용처리 키트 작성 | 키트 버전 | 실데이터 없는 원본 준비 |
| 4. 한 회차 시범 | 복사본에 기본정보·일정 입력 | 운영현황 | 회차 전체를 추적 가능 |
| 5. 상태 표시 | 시험용 폴더에서 설치·초기화 확인 후 사용 | 사용 환경 확인 | 기존 아이콘 복원 확인 |
| 6. 한 달 회고 | 찾기 실패·중복 기록·불필요한 분류 기록 | 결정 기록 | 필요한 규칙만 보완 |
| 7. 운영 보완 | 회신 누락·완료 판단·인수인계 중 반복 불편 선택 | 운영현황의 해당 항목 | 한 회차에서 개선 효과 확인 |

과거 자료 전체를 다시 분류하지 않습니다. 도입 기준일 이전 자료는 기존 위치를 유지하고 실제 재사용하는 자료부터 새 구조에 편입합니다. 메일함은 Inbox / Action / Archive로 시작하고 Waiting은 필요할 때 추가합니다.

추가할 항목은 [진행·인수인계 개선안](policies/folder-workflow.md)에서 고릅니다. 처음부터 모든 항목을 도입하지 않고 다음 행동·담당자·재확인일과 단계 완료 기준부터 한 회차에 적용하는 안을 제안합니다.
