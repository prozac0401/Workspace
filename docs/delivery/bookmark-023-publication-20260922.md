# 업무 책갈피 0.2.3 창 이동 시 메모 자동저장 · 2026-09-22

## 요청과 변경

사용자가 스티커 메모를 편집하다 다른 창으로 이동하면 자동저장하고 저장 버튼은 표시하지 않도록 요청했습니다. 이전 공개 배포 요청에 이어 제품과 공개 사용 안내를 0.2.3으로 갱신합니다.

- 메모 본문이나 빈 영역을 한 번 클릭하여 같은 스티커에서 편집합니다.
- 다른 앱 창이나 다른 스티커로 이동하면 해당 메모를 자동저장합니다. 저장 버튼은 제거했습니다.
- 같은 스티커 안의 컨트롤·메뉴 이동은 저장하지 않습니다. 한글 조합이 끝난 뒤 확정된 텍스트를 저장합니다.
- Enter 즉시 저장, 저장 시작 전 취소/Esc, 한 줄 500자 제한은 유지합니다.
- 실패하면 초안을 유지하고 재시도 안내를 표시합니다. Enter 또는 다시 창을 떠날 때 재시도하며 다른 창의 포커스를 빼앗지 않습니다.
- 저장 중 중복 쓰기와 취소를 막고, 늦은 완료가 더 최신 책갈피를 덮어쓰지 않게 합니다. DB v5와 원본 파일 처리 방식은 유지합니다.

공개 페이지 16개·자산 8개를 유지합니다. 업무 기록·진단·제품 소스·설치 파일을 Pages에 복사하지 않습니다. 기존 Excel R11 변경은 이번 커밋에서 제외합니다.

## 검증

Release 전체 솔루션 빌드 경고 0·오류 0, Desktop 검사 **209개**를 통과했습니다. 일반 테스트 창·다른 스티커로의 전환 저장, 임시 SQLite의 메모별 커밋, 실패 후 초안 보존·재시도, 취소, 중복 요청, 조합 종료 대기, 다른 창의 포커스 유지와 최신 값 보존을 검사했습니다. 검사는 프로그램으로 만든 WinForms 창·이벤트와 합성 IME 메시지를 사용합니다.

렌더 8개를 생성하고 기본·편집·저장 실패·최소 크기의 100% 배율 화면 4개를 직접 확인했습니다. 최소 크기에서 오류 안내가 줄바꿈되어 잘리는 문제는 문구를 줄이고 다시 빌드·렌더하여 확인했습니다. 그 뒤 기능 로직은 바꾸지 않았습니다. 변경하지 않은 Core·IPC·어댑터 검사군은 재실행하지 않았습니다.

실제 키보드/마우스와 한글 IME, 다중 모니터, 실제 설치·업데이트·제거·재부팅 및 회사 환경 실기는 이번 자동검사와 구분합니다. 이전 검증 범위는 [0.2.2 기록](bookmark-022-publication-20260922.md)을 따릅니다.
