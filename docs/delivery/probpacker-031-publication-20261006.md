# ProbPacker 0.3.1 배포와 Workspace 안내 추가 · 2026-10-06

## 요청과 완료 기준

사용자는 저장소명을 ProbPacker로 정정하고, 로컬 `dist`의 0.3.1을 새 릴리스로 올린 뒤 Workspace 문서에 기능 소개와 사용 방법을 추가해 게시하도록 선택했습니다. 기존 Python Office 작업은 취소했습니다.

변경은 기존 EXE·ZIP의 게시와 공개 사용자 안내 한 페이지 추가입니다. 제품 기능 변경·재빌드는 하지 않습니다. 충분한 완료 근거는 기존 배포물의 버전·출처·해시 확인, Release 자산과 비인증 다운로드의 일치, 문서 strict 빌드·공개 범위 검사, Documentation 배포 성공 및 실제 공개 페이지 확인입니다. 기능·Office·GUI·전체 테스트를 새로 실행한 작업으로 설명하지 않습니다.

Workspace의 기존 작업 폴더는 원격 main보다 107개 커밋 뒤에 있었고 다른 작업의 변경이 남아 있었습니다. 최신 `fc70396`에서 별도 작업 트리를 사용하여 기존 로컬 파일과 최신 도구 안내를 보존했습니다. ProbPacker도 기존 사용자 작업 트리와 기본 index를 보존하며 배포 소스 식별을 위한 별도 Git 스냅샷을 사용합니다.

## 기존 배포물 확인

단일 EXE와 폴더형 EXE의 Windows 파일·제품 버전은 모두 0.3.1입니다. 양쪽에 포함된 제품 Python 모듈 12개를 현재 소스의 컴파일 결과와 비교했으며 파일 경로 차이를 정규화한 뒤 일치했습니다. 아이콘 13개와 포함된 0.3.1 배포 문서도 원본과 일치합니다. 기존 2026-09-20 staging 소스 digest는 `0612715ab7af1e852a432a61381492cd5f59e3cfafed979080badce596ed3f67`이며 이번 읽기 전용 대조에서 일치했습니다.

두 ZIP은 CRC 검사에 통과했습니다. 폴더형 1,216개·단일형 72개 파일의 경로와 바이트가 현재 dist 폴더와 모두 일치합니다. ZIP 경로 중복·경로 탈출·개인키 확장자·로그 경로는 없었습니다. 기존 `SHA256SUMS.txt`의 두 ZIP·단일 EXE 값과 실제 파일의 해시도 일치합니다. 이 검사는 Office·GUI를 실행하거나 원본·QA 업무 자료를 변경하지 않았습니다.

## 안내와 남은 제한

공개 안내는 [오피스 자동화 도구 받기·사용](../tools/office-automation/index.md)입니다. Excel 병합·분리, 템플릿 채우기, 원본 행 확인·분석·시험 생성·실행·결과 기록, 파일명·필드 규칙, 같은 세션의 중지·재개, 설정·업데이트·제거·문제 해결을 설명합니다. Windows x64와 Office 설치 필요 조건, 자체 서명, 출력 보호와 값·서식만 내보내는 제한을 받기 전에 안내합니다.

기존 제품 기록의 PPT-01~11 소스 시나리오 통과를 이번 신규 시험으로 합산하지 않습니다. PPT-12의 정해진 5회 반복, PPT-13 GUI·키보드·배율, PPT-14 양쪽 배포 EXE의 전체 생성·종료 흐름은 미실행입니다. 단일 EXE 임시 폴더 삭제 경고의 원인·해결 여부도 미확정입니다. 따라서 평가판·사전 릴리스로 제공하며 상용 인수·조직 도입 승인으로 표시하지 않습니다.

MkDocs 허용 목록과 공개 검사기에 새 주소를 추가했습니다. 공개 안내 21개, 기존 이동 문서 2개, 자산 15개 범위입니다. 개발 정책·ADR·이 기록·원시 진단·사용자 설정·실행 로그는 사이트에서 제외합니다.

## 소스 식별과 원본 저장소 릴리스

원본 작업 트리와 기본 index·HEAD·브랜치를 보존하며 별도 index로 소스 스냅샷 `1a3fe8e1d151f3708caeeefe262231a48f8a5f49`를 만들었습니다. 기존 소스와 공개 가능한 문서·스크린샷·빌드 레시피·Python 테스트·QA 안내 104개 파일을 정확한 바이트로 보관합니다. 빌드 산출물·원시 진단·인증서·개인 서명 설정·legacy·바이너리 QA fixture는 제외했습니다. 새 제작 전에 가짜 QA 자료를 재생성하고 서명 설정을 별도로 공급해야 합니다. 이 스냅샷은 이번 배포 EXE와 제품 모듈 12개가 일치합니다.

ProbPacker의 `v0.3.1`은 위 소스 스냅샷을 가리킵니다. 릴리스는 **2026-10-06 03:27:06 UTC**에 초안을 해제했고 사전 릴리스 상태입니다. 첨부한 네 자산의 크기·SHA-256·업로드 완료 상태가 로컬 파일과 일치했습니다. 이 저장소가 비공개인 사실을 뒤이어 확인했습니다. 인증 없이 자산을 요청하면 HTTP 404이므로 공개 사이트용 다운로드 성공으로 간주하지 않았습니다.

## 공개 배포와 문서 검증

ProbPacker를 공개로 바꾸지 않고 같은 네 파일만 Workspace의 `office-automation-tools-v0.3.1` Release 자산으로 제공합니다. 제품 원본은 ProbPacker에 남기고 Workspace 태그는 사용자 안내 커밋을 가리킵니다. 공개 페이지에는 Workspace 자산만 연결합니다. 공개 릴리스의 자동 Source code 압축은 Workspace 문서 소스이며 제품 소스가 아니라는 점을 배포 설명에 적습니다.

게시 전 `python -m mkdocs build --strict`와 `python scripts/check-site.py site`를 통과했습니다. 공개 안내 21개·이동 문서 2개·404, 자산 15개, 검색·사이트맵과 로컬 링크·제외 범위를 확인했습니다. 두 번째 읽기 전용 검토에서 Word 합본의 `한 줄 띄우기` 제한을 머리말·꼬리말의 필드 값이 항목마다 달라지는 경우로 정확히 수정했습니다. 실제 비전공자의 이해도와 좁은 화면 육안 검증은 이 작업에서 수행하지 않았습니다.
