## 제품 릴리스의 기존 검증 근거

[0.2.14 정식 릴리스](https://github.com/prozac0401/BookMark/releases/tag/v0.2.14)는 draft=false, prerelease=false이며 MSI·포터블 ZIP·Source.zip·SourceSnapshot.json·MSI 검증 JSON·SHA256SUMS.txt 6종을 게시했다. [태그 고정 소스 검증 기록](https://github.com/prozac0401/BookMark/blob/v0.2.14/docs/evidence/release-0.2.14-2026-10-15/README.md)은 Release 빌드 경고·오류 0, 전체 자동검사 981개와 별도 포커스 구성요소 검사 8개 통과(총 989개, 중복 합산 없음)를 기록한다. 실제 전경 조건 검사 6개는 NOT RUN이다.

최종 릴리스 기록은 MSI 구조 검사 54/54 통과, 관리 추출 1,129개 파일의 SHA-256 일치, 업로드한 6종 재다운로드 해시 일치를 보고한다. 최종 패키지 기준은 첨부 검증 JSON·SourceSnapshot.json·SHA256SUMS.txt이다. 이는 이번 문서 작업에서 제품 시험이나 파일 해시 검증을 재실행한 결과가 아니다.

실제 Windows 마우스·키보드·Alt+Tab·전경 창 순서, 혼합 DPI·한글 IME, MSI 실제 설치·업데이트·제거·재부팅은 미검증/NOT RUN이다. MSI 구조 검사·관리 추출과 실제 설치 시험을 구분한다. 패키지는 미서명이며 회사 도입 승인을 의미하지 않는다.
