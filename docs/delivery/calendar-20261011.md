## 검토 산출물과 다음 단계

로컬 `artifacts/calendar/calendar_2027.xlsx`와 `leap/calendar_2028.xlsx`는 **가상 검증 자료**이며 실제 공식 공휴일 달력으로 사용하지 않는다. 화면 다운로드 결과는 `browser/calendar_2027.xlsx`, 인쇄 확인은 `excel-print.pdf`, 개별 결과는 `inspection_2027.json`, `leap/inspection_2028.json`, `excel-results.json`, `browser/results.json`이다. 생성물은 Git/사이트에 포함하지 않는다.

[운영 안내](../../tools/calendar/README.md)의 로컬 명령으로 검토한다. Secret 없이 기본 빌드는 미준비 화면을 보여준다. fixture를 명시적으로 선택하면 표시된 가상 자료로 미리보기와 다운로드를 시험할 수 있다.

다음 단계는 **사용자 Secret 직접 등록 → 관리자 운영 설정 검토/승인 → 별도 병합·활성화 승인 → 최초 workflow/데이터 브랜치 생성·배포 승인 → 게시 JSON/메뉴/다운로드 확인**이다. 원격 push/PR도 별도 요청이 필요하다. API 키를 채팅이나 소스에 넣지 않는다. 일정 지연/누락, 임시공휴일의 나중 공표, 이미 받은 XLSX의 비자동 갱신은 운영 안내와 화면에 명시했다.
