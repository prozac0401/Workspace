## 요청과 작성 범위

사용자가 업무 안내에 가상의 화면을 촬영한 예시 그림을 요청했습니다. 기존 일곱 교육 장면의 가짜 자료로 HTML 설명 화면을 만들고, 브라우저에서 각 장면을 PNG로 촬영했습니다. 원본은 `docs/illustrations/education-examples/screens.html`에 보존합니다. 공개 파일은 `docs/assets/education-examples/`의 일곱 PNG로 한정합니다.

모든 그림에는 설명용 예시 화면·가짜 연습 자료 표시와 실제 화면이 다를 수 있다는 설명을 넣습니다. 본문에는 그림의 뜻과 누르면 확대되는 연결, 이미지 대신 읽을 수 있는 설명을 넣었습니다. 실제 프로그램을 실행하거나 제품 기능의 성공을 촬영한 결과가 아닙니다. 회사별 명단 기준·저장 위치·승인은 계속 제안·미결정입니다.

## 실제 확인

- Playwright와 Edge의 별도 검토 브라우저에서 외부 자료 없이 화면을 표시하고 `.scene` 장면별로 촬영했습니다. 가로는 900픽셀, 글꼴은 PC의 한글 글꼴을 사용했습니다.
- 일곱 PNG의 파일 형식·크기·그림 내용을 확인했고 숨은 텍스트나 개인 경로를 저장하는 PNG 정보 항목은 없습니다.
- 모든 장면의 경계 밖으로 잘리는 요소가 없으며 이미지 표시 오류가 없습니다.
- 입력·메뉴·단축키·예상 정답을 공개 안내와 대조했습니다. TEST003의 2↔1과 TEST006의 0↔1, A반 세 명만 수정, 내보낼 세 사람·세 열, 파일 다섯 개와 제출자 두 명을 확인했습니다. 시간표·책갈피 B4·수동 폴더 상태도 안내와 일치합니다.
- `python -m mkdocs build --strict`와 `python scripts/check-site.py site` 성공. 공개 안내 20개·이전 주소 이동 2개·404와 검색·사이트맵·로컬 연결을 확인했습니다.
- 화면 원본 HTML·내부 기록·허용하지 않은 자산은 사이트에 포함되지 않습니다. 원본 Word·실제 명단·개인 폴더·설치 진단 정보도 넣지 않았습니다.
- 교육 페이지의 1440×1000 넓은 화면과 390×844 작은 화면에서 일곱 그림의 표시·비율·확대 연결을 확인했습니다. 작은 화면에서는 그림을 눌러 원래 크기로 읽습니다.
- `git diff --check` 성공. 도구 코드·설치 파일은 변경하지 않아 제품 설치·엔진·실제 업무 효과·모든 초보자의 이해도를 새로 시험한 결과는 아닙니다.
