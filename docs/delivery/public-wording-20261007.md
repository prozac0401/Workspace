# 공개 사이트 경고·면책·그림 표기 정리

날짜: 2026-10-07 · 책임: 문서·배포 담당 · 상태: 원본 정리·로컬 검증 완료, Pages 게시 대기

## 요청과 범위

사용자가 공개 사이트의 경고성 문구와 ‘설명용 도해’ 같은 표현을 모두 빼도록 요청했다. 최신 원격 main `d11b13d030dc324e43345ce6dbf1457841acccce`와 일치하는 별도 checkout에서 이어서 작업한다. 원래 사용자 작업 사본과 제품 소스·설치 파일은 그대로 둔다.

공개 21개 페이지와 SVG·교육 PNG에서 반복 라벨, 서명·승인·시험·효과·실제 화면 여부에 대한 경고·면책 문구를 제거한다. 기능 설명·다운로드·구체적 캡션은 유지하고 설치·복구·보존 지시는 직접적인 사용법으로 정리한다. 실제 UI 상태명·오류 메시지, 지원 범위와 회사별 제안·미결정은 그대로 설명한다. 정책 문서 작성 규칙 v0.23과 관련 ADR에 최신 요청을 반영하며 과거 검증 결과는 삭제하거나 성공으로 바꾸지 않는다.

그림은 설명을 위해 만든 SVG와 가상 화면 원본에서 렌더한 PNG이며 새 제품 실행 증거가 아니다. 공개 라벨 제거는 서명·승인 상태나 제품 시험 결과를 바꾸지 않는다. 실제 제작·검증 구분은 기존 배포 기록과 이 제외 문서에 보존한다.

## 완료 기준과 검증

공개 본문·검색·SVG·교육 그림에 대상 표현이 남지 않는지 확인한다. 버전별 다운로드 링크, 9개 도구·115개 챕터·230개 SVG, 7개 교육 PNG, 공개 문서·자산 범위와 중앙 정렬을 유지한다. strict 빌드·생성 로컬 링크 검사 후 Documentation 배포 및 실제 사이트의 HTML·그림·검색 반영을 확인한다. 제품 코드나 설치 파일을 바꾸지 않으므로 제품 시험은 반복하지 않는다.

실제 검증과 게시 결과는 수행 후 아래에 기록한다. 로컬 원시 출력·화면은 `artifacts/public-wording-20261007/` 또는 별도 checkout의 `output/playwright/`에 보관하고 공개하지 않는다.

## 수행 결과

- 115개 도해의 반복 표기를 생성기에서 제거했다. 그림의 안내 문구와 본문 경고·면책 표현은 기능 중심으로 정리했다. 교육 PNG 7개에서 표시 띠와 하단 면책 문구를 제거하고 남은 여백 없이 렌더링했다.
- 교육 안내와 빠른 안내의 Bookmark 복귀 순서도 현재 본문에 맞춰 **시계 옆 아이콘 → 책갈피 보기**로 정리했다. Ctrl+Alt+J의 토글 동작을 항상 표시하는 동작으로 설명하지 않는다.
- `python -m mkdocs build --strict`와 `python scripts/check-site.py site` 통과. 공개 21개·이전 이동 2개·404 및 검색·사이트맵·자산·로컬 링크 검사 통과.
- 공개 HTML·SVG·검색 JSON 총 255개 텍스트 출력에서 대상 표기·서명 경고 0건. 초기 검사에서 File List to Excel의 잔여 ‘설명용’ 문장 1개를 찾아 수정한 뒤 재검사했다.
- 공개 21문서의 기존 Markdown 링크 집합과 버전별 Release 링크 30개가 유지됐다. 9개 도구의 H2/H3·JSON 정의·figure ID 115개가 순서까지 일치하고 SVG 230개가 생성기 출력과 일치한다.
- SVG 230개·패널 글자 2,440개 정적 배치 검사에서 영역 밖 배치·겹침 0개. 교육 PNG 7개 전체 육안 확인, 잘림·겹침 없음 및 원본 DOM overflow 0개.
- Chrome 1440·390px 폭에서 Bookmark와 교육 안내 총 4화면을 확인했다. 그림 중앙 배치·폭 맞춤·표기 제거 및 페이지 가로 넘침 없음. 실제 휴대전화 기기 시험은 아니다.
- 제품 코드·설치 파일 변경 및 제품 시험 없음. 이전 서명·시험 기록은 제외 문서에 그대로 보존했다.
- 원격 게시·Actions·공개 파일 확인은 완료 후 기록한다.
