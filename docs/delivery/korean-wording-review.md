# Excel·설치 프로그램 한국어 검수 · 2026-09-17

Excel 도구의 화면·결과표·오류·사용 안내와 두 도구의 설치 문장을 다시 검수했습니다. 개발 용어나 번역한 듯한 어순을 줄이고, 사용자가 할 일과 작업 결과를 직접 설명했습니다.

## 주요 수정

| 이전 문구 | 바꾼 문구 |
|---|---|
| 비교키 | 비교에 쓴 값 |
| 원본 예 | 원래 값 (예) |
| 잔여 | 남은 개수 / 남은 항목 |
| 개수 차이 | 개수가 다름 |
| 가시성 확인 대상 | 숨김 여부를 확인할 셀 |
| 출처 / 시점 | 위치 / 담은 시각 |
| 엔진 종료 코드 | 문제 확인용 코드 |
| 지금 로그인한 사용자만 사용 | 지금 로그인한 Windows 계정에 설치합니다. |
| 요청한 작업을 마쳤습니다 | 작업을 마쳤습니다 |

예를 들어 Excel의 ‘남은 개수’는 **같은 값이 첫 번째 목록에 2개, 두 번째에 1개 있으면 첫 번째에 1개가 남는다**고 설명합니다. 중복도 같은 값이 3개 있으면 중복은 2개라고 안내합니다. ‘첫 번째 목록 비우기’가 원본 셀을 지우는 기능으로 읽히지 않도록 설명했습니다.

설치 안내는 무엇이 설치되거나 제거되는지, 실패했을 때 무엇을 해야 하는지 순서대로 썼습니다. Excel 설치기의 기본 진행·오류·제거 메시지 67개도 검수했습니다. 파일명·내부 식별자·Windows와 Excel 자체의 오류 원문은 제품 안내와 구분합니다.

## Excel 반영 결과

수정 원본은 `ExcelE2E-20260914/upstream/tools/ExcelSmartListCompare`입니다. 예전 복사본과 과거 시험 파일은 수정하지 않았습니다. 화면 소스와 가져오기용 ASCII 파일, 설치 스크립트, 설치기, 안내 문서를 함께 고쳤습니다. 긴 설명을 읽을 수 있도록 결과표 두 행의 높이도 늘렸습니다.

- Python 기존 검사 **63개 통과**: 비교 규칙 참조 검사, 소스 검사, Windows CMD 실행기와 제거 중 실행 파일 처리 검사.
- Windows PowerShell 5.1 구문 검사 통과. 한국어 출력, 종료 코드, 인수, 기존 보안 정책과 별도 파일의 보존은 실행기 검사로 확인했습니다.
- Inno Setup 컴파일 통과. 확인용 EXE는 기존 RC8 파일을 내장했으므로 **설치·배포용이 아닙니다**.
- 문서 strict 빌드·공개 범위 검사 통과. 별도로 바꾼 Excel 문서 7개의 로컬 링크 59개도 확인했습니다.

**교정 내용을 모두 반영한 새 Excel XLAM과 배포용 EXE는 아직 만들지 않았습니다.** Excel 보안 설정을 바꾸지 않았으며, 실제 Excel 화면·설치·제거도 실행하지 않았습니다. 기존 RC8의 Esc 취소 실패와 첫 설치 실패는 해결된 것으로 표시하지 않고 배포 보류를 유지했습니다. 새 파일 제작 후 긴 문장의 줄바꿈·잘림과 실제 동작을 확인해야 합니다.

세부 범위는 [Excel 검수 기록](../../tools/ExcelSmartListCompare/docs/KOREAN_WORDING_REVIEW.md), 실제 사용 설명은 [Excel 사용 안내](../../tools/ExcelSmartListCompare/docs/QUICK_GUIDE.md)에 있습니다. 문구별 원문·수정문·출처 목록은 로컬 `artifacts/korean-wording-20260917/excel-text-review/`에 저장했습니다.

## FolderState 반영 결과

설치·복구·제거 화면과 설치 안내·오프라인 도움말을 고쳤습니다. Windows 10은 설치 조건에 맞지 않는 환경, 공유·동기화 폴더는 검증이 충분하지 않은 환경으로 구분했습니다. 설치 파일 속성의 설명과 검색어도 한국어로 바꿨습니다.

`scripts/build.ps1 -SkipTests`로 MSI를 다시 만들고 `verify-msi.ps1`, 패키지 내용 검사, 읽기 전용 MSI 감사를 통과했습니다. 사용자별 설치, HKCU 등록, 명령 6개, 메뉴 문구 7개, 포함 파일 414개를 확인했습니다. 도움말 원본과 배포본, 해시 파일의 값이 일치합니다. 대화상자 4개·컨트롤 16개의 문구가 소스와 같고, 컨트롤 경계 초과·겹침이 없습니다.

새 파일은 `artifacts/release/FolderState-0.1.0-win-x64.msi`, **50,452,971바이트**입니다. SHA-256은 `b8e7217266a8acdf2173c87e7267753762c60f46736ef1d3db8ca19d830e1d90`입니다. 요약 정보의 코드 페이지 `949`, 설명 `FolderState 설치 파일`, 검색어 `FolderState, 설치, 폴더 상태`가 실제 MSI에 들어갔습니다.

설치 동작은 바꾸지 않았습니다. 이번 추가 교정에서는 엔진 테스트와 WPF 렌더를 반복하지 않았으며, 앞선 9월 16일 결과와 구분합니다. 실제 설치·복구·제거와 설치 화면의 DPI·줄바꿈은 이번에 시험하지 않았습니다. MSI는 서명 없는 시험용이며 상용 승인된 배포본이 아닙니다.

빌드 로그와 검사 결과는 로컬 `artifacts/korean-wording-20260917/folderstate-*`에 있습니다. 문서 strict 빌드와 생성 링크·공개 범위 검사도 통과했습니다.

이번 변경은 로컬 소스·산출물에만 반영했습니다. 커밋·푸시·공개 게시를 하지 않았습니다. 학력이나 사용 경험이 다른 사람들을 대상으로 이해도를 시험한 결과는 아니므로, ‘누구나 이해한다’고 검증한 것으로 표시하지 않습니다.
