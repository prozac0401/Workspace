## FolderState 0.1.3 RC1

- 공개 시각: 2026-09-19T23:01:10Z
- 파일: FolderState-0.1.3-win-x64.msi
- 크기: 50,465,413바이트
- SHA-256: `27a63645375988aa31dc53ae537f6f01d7a466788812e377807ddfdbe2a79bbf`
- 엔진 47/47, WPF 상호작용 12/12 및 렌더 통과
- MSI 구성 검사: 버전 0.1.3, 파일 414개, 메뉴 명령 6개, 사용자별 설치, HKCU 전용
- 서명: NotSigned · 사전 릴리스 · 상용 승인 아님

MSI, SHA-256 파일, 공개 검증 요약의 세 자산을 다시 내려받아 업로드된 SHA-256과 일치함을 확인했습니다. [게시 증거](evidence/folderstate-0.1.3-rc.1.json)에 버전·소스·CI·자산 정보를 기록했습니다. 원시 사용자 로그와 로컬 진단은 게시 자산에 포함하지 않았습니다.

이 MSI의 실제 설치·복구·업데이트·제거, .NET이 없는 새 Windows 11 PC, 키보드·Narrator·고대비·150/200% DPI, 공유·동기화·보안 환경은 추가 검증 대상입니다. CI의 windows-2025 시험을 Windows 11 사용자 환경의 설치 수명주기 시험으로 바꾸어 표시하지 않습니다.

이미 공개된 [Excel 명단 비교 RC10](https://github.com/prozac0401/Workspace/releases/tag/excel-smart-list-compare-v0.2.0-rc.10)의 원격 변경 두 커밋을 가져왔습니다. 비교 기능과 실제 배포 자산을 다시 변경하지 않았습니다. [RC10 게시 기록](../../tools/ExcelSmartListCompare/docs/RC10_PUBLICATION_20260920.md), [전체 흐름 판정](../../tools/ExcelSmartListCompare/docs/RC10_END_TO_END_REPORT.md)의 기존 결과를 유지합니다.

공개 설치 파일 ExcelSmartListCompare-0.2.0-rc.10-Setup.exe를 다시 내려받아 2,230,652바이트와 SHA-256 `d14334fc5c5ad5c4cdf9cc602e953defa70252ba00d09dad32313c55be4ef3a8`이 기존 게시 기록과 일치함을 확인했습니다.

루트 README·홈페이지·도구별 안내가 FolderState 0.1.3 RC1과 Excel RC10을 가리키도록 맞췄습니다. FolderState의 이전 화면과 ‘다음 버전’ 설명을 현재 사용 순서로 교체하고 0.1.3 WPF 화면을 다시 렌더했습니다. Excel의 개발 인계 안내도 RC10 기준으로 갱신했습니다.

## 저장소 정리

- 작업 중 변경을 임시 보관한 뒤 main을 원격 최신 커밋으로 fast-forward했습니다. 이미 원격에 반영된 Excel 변경과 이전 게시 준비 문구를 중복 반영하지 않고 FolderState 변경을 보존했습니다.
- 루트의 최초 Excel 검증 지시와 v0.2 소스 ZIP을 tools/ExcelSmartListCompare/archive로 옮겼습니다. 두 파일의 원본 내용은 유지하고 관련 문서 링크를 갱신했습니다.
- 현재 버전과 과거 증거를 찾는 [배포·검증 안내](index.md)를 추가했습니다. 원문 명세와 과거 실패 기록은 보존했습니다.
- 로컬 ExcelE2E-* 사본을 공통 .gitignore에 명시했습니다. 생성 디렉터리·사용자 기록·인증서는 Git에 추가하지 않았습니다. 이전 로컬 시험 자료를 삭제하지 않았습니다.
- Windows CI에 MSI 구성 검사를 추가했습니다. 검사 결과도 빌드 산출물과 함께 보관합니다.

- MkDocs strict 빌드 통과. 공개 페이지 15개와 404, 검색·사이트맵의 공개 범위, 생성된 로컬 경로·자산 연결을 확인했습니다.
