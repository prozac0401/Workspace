# 보이는 칸 붙여넣기 · 영역 지원 로컬 검증

## 사용자 요구와 변경 범위

사용자는 한 행·한 열만 복사할 수 있는 제한을 확인하고 영역 복사·붙여넣기를 요청했다. 여러 행·열 원본을 복사하고 대상 영역 전체를 선택하면 숨김·필터 행과 숨긴 열을 제외한 교차점에 같은 모양으로 값을 넣도록 변경한다. 원본의 숨김 여부는 클립보드 메타데이터로 판단하고 원본 셀을 다시 읽지 않는다.

원본과 대상의 보이는 행 수·열 수를 각각 비교한다. `2×3`→`3×2`는 같은 여섯 칸이어도 거절한다. 기존 한 행 원본→한 열 대상의 방향 변환은 유지한다. 시작 셀에서 자동 확장, 반복 채우기, 빈칸 삭제는 하지 않는다. 일반 사용자 설치·보안·원본 보호 조건은 유지한다.

이 기록은 [도구 명세 양식](../forms/tool.md)의 검증·지원 및 명세 대응표·배포 기록 구분을 따르며, 설계 결정은 [ADR 양식](../forms/adr.md)을 적용한 ADR-0037에 보관한다. 최초 명세와 0.1.0 당시 거절·성공 결과는 수정하지 않는다.

문서 검증 명령은 `.tools/docs-venv/Scripts/python.exe -m mkdocs build --strict`와 `.tools/docs-venv/Scripts/python.exe scripts/check-site.py site`다. 요약은 artifacts/visible-cells-paste/rectangle-docs-20261021/validation.json에 보관한다. 숨김 메타데이터 파일 관찰은 artifacts/visible-cells-paste/rectangle-clipboard-unit/saved-visibility-probe.json, 클립보드 접근 제한은 같은 디렉터리의 clipboard-access-diagnostic.json에 기록했다. 내부 진단 자료는 공개 사이트에 포함하지 않는다.

클립보드 접근 진단 자체는 읽기·쓰기를 하지 않았다. 그보다 앞선 별도 프로브는 합성 자료의 COM Range.Copy를 시도했으므로 이번 조사 전체에서 클립보드를 바꾸지 않았다고 주장하지 않는다. 합성 복사 시도는 실제 사용자 Ctrl+C나 성공한 클립보드 해석의 증거가 아니다.

## 후보 시험과 수정

첫 실제 Excel 후보는 15 PASS / 1 FAIL이었다. 필터 자료가 `0.00` 형식의 숫자에 숫자 `1` 조건을 적용해 의도한 가시 행을 만들지 못했다. `yes/no` 자료와 실행 전 가시 행 사전 검사를 추가했다. 후보 결과는 artifacts/visible-cells-paste/rectangle-excel/RectangleTests.txt에 보존하며 최종 시험으로 덮어쓰지 않는다.

표 검사는 실제 보이는 대상과 겹치는 열에 적용하도록 조정했다. 수정하는 표 열은 숨긴 행을 포함한 데이터 열 전체의 수식을 검사한다. 수정하지 않는 숨긴 계산 열 때문에 별도 보이는 값 열을 거절하지 않도록 두 가지 표 회귀를 추가했다. 시험 재컴파일에서 이전 출력 DLL의 잠금을 만나 별도 안전한 출력 경로를 사용할 수 있게 했으며, 이 잠금은 제품 컴파일 오류나 기능 시험 실패로 집계하지 않는다.

최종 실행 결과는 artifacts/visible-cells-paste/rectangle-excel-final/RectangleTests.txt의 18 PASS / 0 FAIL이다. 테스트가 직접 만든 타입 스냅샷을 제품 엔진에 전달한 시험으로, 실제 Ctrl+C·우클릭 메뉴 전체 경로를 대신하지 않는다. 과거 0.1.0의 자동 로드·수명주기·실제 복사 통과는 이번 영역 평가판에 소급하지 않는다.

## 산출물과 재현 명령

로컬 제작 명령은 `powershell -NoProfile -File tools/VisibleCellsPaste/build/build.ps1 -Version 0.2.0-eval.1`이다. artifacts/visible-cells-paste/0.2.0-eval.1에 x86/x64 제품 DLL과 설치/제거 런처를 포함한 VisibleCellsPaste_0.2.0-eval.1.zip, SHA256SUMS.txt, 제작·검증 로그를 생성한다. 문서와 소스를 동기화한 최종 ZIP의 해시는 같은 디렉터리의 SHA256SUMS.txt를 기준으로 확인한다. 초기 후보 해시를 최종 해시로 고정하지 않는다.

설치·공개 릴리스·사이트 게시를 수행하지 않았으며 기존 설치본은 그대로다. 서명 없는 로컬 평가판이고 조직 배포 승인을 뜻하지 않는다. 기존 사용자 Excel이나 업무 파일을 시험 정리 대상으로 사용하지 않았다.

## 미검증과 후속 배포 조건

클립보드 형식은 Excel 버전과 복사 방식에 따라 다를 수 있다. 지원 형식으로 모양·타입·좌표를 확정할 수 없으면 아무 셀도 바꾸지 않고 중단한다. XML 원본의 물리적 행×열은 숨김 제거 전에도 50,000칸 이하여야 한다. 상한 설정은 모든 크기의 실제 Excel 성능 보증을 뜻하지 않는다.

전체 수명주기·미실행 플랫폼·회사 정책은 별도 검증이 필요하다. 빌드 완료를 설치 성공이나 공개 배포로 표현하지 않는다. 공개 안내의 0.1.2 링크를 새 평가판 링크로 바꾸지 않으며, 로컬 소스 변경만으로 현재 설치본의 1차원 제한이 해소됐다고 안내하지 않는다.
