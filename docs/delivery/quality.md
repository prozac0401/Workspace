# 상용 배포 품질 기준

현재 안내 버전은 FolderState 0.1.3 RC1과 Excel 명단 비교 RC10입니다. 파일 게시와 상용 인수 승인을 구분하며, 자동 시험이나 패키지 생성만으로 상용 정식판으로 분류하지 않습니다. 버전별 실제 결과는 [배포·검증 안내](index.md)에서 확인합니다. 아래 증거를 갖춰 제품 책임자가 상용 출시를 승인해야 합니다.

| 게이트 | 필요한 증거 | 실패 시 |
|---|---|---|
| 요구 충족 | 원문 요구와 구현·시험의 대응표 | 누락·차이를 수정 |
| 데이터 보존 | 원본 INI·업무파일 불변, 외부 편집 보존 | 배포 중단 |
| 실패 복원 | 잠금·권한·중단·동시 요청·부분 실패 | 복구 경로 보완 |
| MSI 수명주기 | 일반 사용자 설치·수리·제거·업그레이드·다운그레이드 차단 | 패키지 수정 |
| 깨끗한 PC | .NET 없는 Windows 11 x64에서 실행 | 의존성 보완 |
| 사용성 | 실제 Explorer 메뉴·아이콘 갱신, 키보드, 100/150/200% DPI, 화면 읽기 | 사용성 결함 해결 |
| 배포 신뢰 | 게시자·코드 서명·서명 검증·해시 | 검증용으로 유지 |
| 운영 준비 | 지원 연락처·라이선스·변경 이력·지원 OS | 정식 출시 보류 |
| 문서 | strict 빌드·실제 게시 URL·제약 공개 | 게시·문서 수정 |

## 지원 범위

로컬 일반 폴더가 우선입니다. 네트워크·OneDrive 자리표시자·DRM·다른 파일시스템·ARM64·Windows 10은 별도 환경별 검증 결과 없이 지원 완료로 표기하지 않습니다. v0.1은 재분석 지점이 있는 경로를 보수적으로 거부합니다.

## 수명주기 시험

새 사용자 프로필에서 이전 설치가 없는지 확인합니다. MSI 설치와 CLI 실행, 네 상태 메뉴, 원래 아이콘 초기화, MSI 복구, 상위 버전 업그레이드, 구버전 설치 차단, 제거 후 업무 상태 보존을 순서대로 확인합니다. 테스트 경로만 사용하고 실제 업무자료는 시험 대상으로 삼지 않습니다.

자동 회귀 테스트의 통과 결과와 별개로 전원 손실, 보안 제품 차단, Explorer 캐시, UI 접근성은 환경별 수동 시험을 기록합니다.
