# 다운로드 안내와 한국어 문구 통합 · 2026-09-17

사용자의 요청에 따라 이전 문구 교정과 최신 원격 기능을 통합하고, 홈페이지와 메뉴에 **프로그램 받기**를 추가했습니다. Excel 전용 설치·사용 안내를 신설했으며 설치 파일은 GitHub Release에서 받도록 연결합니다. 사이트에는 개발 기록·업무 자료·원시 진단 파일을 넣지 않습니다.

## 포함한 변경

통합 기준은 원격 `ec74662`와 그 이후 로컬 RC8 기록 `a5edfd8`입니다. FolderState 0.1.1의 아이콘 갱신·상태 형식·중단 복원 기능을 유지하면서 이번 한국어 교정과 화면 배치를 반영했습니다. 이전 작업 폴더의 0.1.0 MSI를 새 버전처럼 배포하지 않고 **0.1.2를 다시 제작**했습니다.

Excel 화면·결과표·설치·제거 문구와 안내 문서의 수정 소스도 포함합니다. VBA 프로젝트 접근 설정은 바꾸지 않았고, 새 XLAM은 아직 제작하지 않았습니다. 공개 다운로드는 **기존 RC7의 정확한 EXE·ZIP**입니다. 새 한국어 문구가 포함되지 않았음을 버튼 주변과 사용 안내에 적었습니다. RC7의 취소·첫 제거 실패, RC8의 취소·첫 설치 실패도 숨기지 않습니다. RC8의 배포 보류와 고정 파일 해시는 유지합니다.

공개 문서는 15페이지로 늘었습니다. 허용 목록·메뉴·검사기·공개 정책·Pages 운영 기록과 [ADR-0006](../design/0006-public-tool-downloads.md)을 함께 맞췄습니다. 실제 다운로드할 RC7 화면의 열 이름은 쉬운 말로 풀이하고, 새 소스의 열 이름과 구분했습니다.

최종 MSI는 `FolderState-0.1.2-win-x64.msi`, 50,461,317바이트, SHA-256 `67fb49e9a01046da7da7e5fc11673ba98b07edb12ad4c6cbf05c33b3a9f2242a`입니다. 코드 서명은 없습니다. 공개용 검증 요약에는 계정·로컬 경로·원시 로그를 넣지 않았습니다.

브라우저 검사 첫 실행은 페이지 수 기대값이 이전 14페이지 기준(28화면)으로 남아 있어 집계가 실패했습니다. 검사기를 현재 공개 경로 수에 맞춰 고친 뒤 다시 실행해 통과했습니다. 첫 실행도 30화면에서 넘침·링크·브라우저 오류는 없었습니다.

기존 배포와 달라진 문구·검사 자료는 [한국어 검수 기록](korean-wording-review.md)에 연결합니다. 작업 폴더의 검증 로그와 화면은 로컬 `artifacts`에 보관합니다. 실제 설치·복구·업그레이드·제거·재부팅과 여러 DPI 시험을 이번 버전에서 다시 했다고 표시하지 않습니다.

## 게시 상태

이 기록을 작성할 때는 로컬 제작과 검증을 마쳤으며 원격 게시 전입니다. Git 반영, Release 파일 업로드와 실제 Pages 응답을 확인한 뒤 후속 기록을 추가합니다. 기존 릴리스의 실행 파일·태그·검증 자료는 덮어쓰지 않습니다.
