# File List to Excel의 AI 대화 기반 정리 사용 예 반영

날짜: 2026-10-06 · 범위: 기존 공개 안내의 사용 예와 연결 문구

## 요구와 변경 범위

사용자는 재귀적으로 만든 파일 목록 Excel을 백데이터로 두고, AI와 대화하며 분류 기준·업무별 폴더 구조의 초안을 검토한 뒤 확정한 파일 목록의 BATCH 복사 스크립트를 요청·실행하는 루틴을 Pages에 반영하도록 요청했습니다. 일회성 AI 자동 분류가 아니라 질문·설명·예외 조정을 통한 초안 작성이 핵심입니다.

- 기존 [File List to Excel 안내](../tools/file-list-to-excel/index.md#ai-organization)에 목록 준비, 대화 요청문, 분류 기준 수정 예, Work 구조와의 연결, 별도 검토 시트, 확정한 목록의 스크립트 요청·실행·결과 확인을 추가합니다.
- 첫 화면, 지금 할 일 찾기, 자료를 둘 곳 정하기에서 같은 사용 예로 연결합니다. 기존 정책의 선택 적용·원본 보존·기준 위치 하나 유지와 보관한 업무의 맥락을 유지합니다.
- v1.2.0의 기본 Excel 파일 복사와 별도 BATCH의 역할을 구분합니다. 기존 결과표의 숨김 정보는 보존하며 새 분류 시트를 기본 복사의 입력으로 설명하지 않습니다.
- 공개 문서·자산·다운로드·제품 소스·설치 파일은 추가하거나 변경하지 않습니다. 공개 안내 21개, 이전 주소 이동 문서 2개, 자산 15개의 기존 범위 안에서 수정합니다.

현재 원본 작업 폴더는 최신 원격보다 오래됐고 다른 작업의 변경이 있어 `origin/main`의 `106ca15` 기준 별도 관리 작업 공간에서 수정합니다. 원본 작업 폴더의 변경을 게시에 포함하지 않습니다.

## 근거와 완료 기준

File-List-To-Excel 원본 v1.2.0의 최초 명세·목록 작성 소스·WorkbookWriter 및 기존 Workspace 안내를 대조했습니다. 표시 열 12개, 폴더 행 포함, 65,000행 시트 분할, 링크 미탐색과 Errors, 목록의 본문 비열람, 기본 Excel 복사의 한 폴더 수집 범위를 확인했습니다. 분류 기준과 회사의 AI 자료 제공 여부는 확정된 조직 설정으로 표시하지 않습니다.

필요한 완료 근거는 문구 검토, `python -m mkdocs build --strict`, `python scripts/check-site.py site`, 변경의 공백 검사와 게시 후 Documentation 성공·공개 사용 예·연결·검색 확인입니다. 제품 코드 변경이 없으므로 엔진·GUI·설치 시험은 반복하지 않습니다.
