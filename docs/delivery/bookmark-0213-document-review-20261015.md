# 업무 책갈피 0.2.13 호환성·다운로드 안내 갱신

날짜: 2026-10-15 · 상태: PR 준비, Pages 미반영

## 요청과 완료 근거

정식 추천 버전과 DB 호환성·복원 절차의 불일치를 문서만 수정한다. 제품 코드·사용자 데이터는 변경하지 않는다. 기존 0.2.8·0.2.9·0.2.10 게시 기록은 보존한다. 완료 근거는 태그 고정 릴리스·소스·검증 기록 확인, MkDocs strict 빌드, 공개 출력 범위·로컬 링크 검사와 새 외부 링크 확인이다.

## 추천 버전과 검증 범위

[0.2.13 정식 릴리스](https://github.com/prozac0401/BookMark/releases/tag/v0.2.13)는 draft=false, prerelease=false이며 MSI·ZIP·SHA256SUMS.txt를 포함한 배포 자산 6종이 있다. [제품 검증 기록](https://github.com/prozac0401/BookMark/blob/v0.2.13/docs/evidence/folder-interaction-2026-10-14/README.md)에 Release 빌드 경고·오류 0, 자동검사 970개 통과가 기록되어 있다. 릴리스 기록은 MSI 검사 54/54, 관리 추출 1,112개 파일 해시 일치 및 업로드 자산 6종 재다운로드 해시 일치를 보고한다. 이는 이번 작업에서 Windows 제품 검사를 재실행한 결과가 아니다.

실제 마우스 클릭·드래그, 혼합 DPI·한글 IME, MSI 실제 설치·업데이트·제거·재부팅은 NOT RUN이다. MSI 관리 추출을 실제 설치 검증으로 표시하지 않는다. 공식 정식 채널에 따라 추천 다운로드를 0.2.13으로 갱신하며 회사 도입 승인·모든 환경의 동작 보증으로 해석하지 않는다.

[0.2.14-test.2](https://github.com/prozac0401/BookMark/releases/tag/v0.2.14-test.2)는 prerelease=true인 별도 ZIP 시험판이다. 정식 0.2.13의 목록 전개 시 숨김·설정 닫기 문제를 다루며 DB 형식은 유지한다. 정식 다운로드 버튼을 시험판으로 교체하지 않는다.

## 데이터와 설치 정책

0.2.10(v5) → 0.2.11(v7: 트리·색상) → 0.2.12(v8: 폴더·열림 상태) → 0.2.13(v8 유지)를 구분했다. v5에서 바로 v8로 이전 가능하며 이전 실행 파일의 순차 설치는 필요하지 않다. 기존 스티커 부모를 폴더로 감싸는 변환과 보존되는 데이터·다음 표시 시 배치 정리를 안내했다.

태그 v0.2.13의 `SqliteBookmarkRepository.Initialize`는 기존 DB 형식·열을 확인한 뒤 `BackupDatabase`로 이전 직전 `.bak`를 만들고 트랜잭션으로 이전한다. 현재 v8은 이전 없이 열며 더 높은 스키마는 거부한다. `.bak`는 DB만 포함하므로 데이터 폴더 전체 백업과 구분한다. 복귀 시 앱 종료, 현재 데이터 전체 보존, 호환 형식 백업 선택, MSI 다운그레이드 제한, 백업 복사본 복원, 현재 DB 보조 파일과 혼합 금지, 이후 변경 미포함을 안내했다. 기존 사용자 지정 설치 경로와 표시 규칙 설명은 유지한다.
