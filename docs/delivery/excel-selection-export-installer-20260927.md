## 대상과 결과

기존 Inno Setup EXE의 현재 사용자 설치 경로를 검증했다. 제품 DLL과 공개 패키지를 수정하지 않았다. T06에서 만든 시험 설치를 정상 제거한 뒤 각 수명주기의 미설치·Excel 0개 사전검사를 통과했다. 기존 사용자 설치를 임의로 제거하지 않았다.

설치 활성화 실패는 자동 rollback하지 않으며, 실패 상태와 제거/정상 설치 파일 재실행 경로를 명확히 제공한다. 시험 전용 잘못된 패키지는 `artifacts`에만 보관하며 배포 후보가 아니다. 정상 rc.10 설치 EXE의 바이트는 바꾸지 않았다.

## 시험 도구 보완과 제한

Test-Package에 명시적인 이전 버전 패키지 인자와 파일 잠금 실패 검사를 추가했다. Test-ActivationFailure는 미설치·Excel 0개 사전검사 후 시험 전용 잘못된 payload를 만들고 종료30·복구·제거·타 설정 보존을 확인한다.

활성화 실패 시험의 첫 준비는 컴파일러 기본 환경 경로가 없어 설치 전에 실패했다. 다음 실행은 복구·제거까지 성공했으나, 제거 launcher 반환 직후 임시 helper의 자기 정리가 끝나기 전에 디렉터리 부재를 검사해 실패했다. 로그에서 뒤이은 정상 정리를 확인하고, 10초 이내의 실제 부재 관찰을 추가한 최종 실행은 통과했다. 시험이 설치 디렉터리를 직접 삭제하지 않는다.

증거는 로컬 `artifacts/selection-export/t07-lifecycle`, `t07-upgrade`, `t07-locked-upgrade`, `activation-failure-*` 및 `artifacts/audit/backlog-20260926`에 보관한다. 각 시험 결과·설치 로그·보안 지문·합성 UI 화면은 공개 사이트에서 제외한다.

등록 ACL 거부·전원 차단·강제 중단은 주입하지 않았다. 파일 잠금 rollback과 COM 로드 실패의 명시적 복구 경로를 확인한 범위를 전체 중단 원자성으로 확대하지 않는다. x86 Office 실기·새 프로필·재로그인/재부팅은 미실행이며 네 Excel 제품의 전체 대표 기능 공존은 T12에서 별도로 확인한다. 제품은 서명 없는 로컬 평가판이며 공개 배포·조직 승인은 별도다.
