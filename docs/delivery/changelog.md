# 변경 이력

## 업무효율화 확장 지도 · 2026-09-12

- 기존 10대 원칙 본문을 유지하고 홈에 ‘05 / 다음 단계 — 정리에서 업무효율화로’를 추가.
- [업무효율화의 확장 순서](../policies/work-efficiency.md)에 정리 → 흐름 → 표준화 → 기록 → 지식화 → 자동화 → Agent의 지도, Work Inbox, 업무 지식 재사용, AI·Agent 운영 원칙을 선택 적용 제안으로 정리.
- 홈·도입 안내·기본원칙·README에서 새 장으로 연결하고 조직별 미확정·선택 항목 DEC-026–028을 추가.
- 공개 14개 페이지에 맞춰 메뉴·허용 목록·검사기·Pages 운영 문서를 갱신. PPTX 공개 제외와 자체 자산 8개는 유지.
- strict 빌드, 공개 범위·로컬 링크·309개 내부 앵커, Edge의 홈 → 새 장 이동과 Work Inbox 검색 확인 완료. 이번 변경은 로컬 반영이며 커밋·푸시·Pages 배포는 수행하지 않았습니다. 상세 범위는 [검증 기록](verification.md)을 따릅니다.

## PPTX 이미지 확장 및 게시 · 2026-09-12

- PPTX 고유 이미지 6종을 홈·10대 기본원칙·도입 순서·진행 및 인수인계 안내의 문맥에 맞게 배치.
- 동일한 슬라이드 8·12 이미지는 하나의 자산으로 통합하고, 전체 WebP 용량을 약 297 KiB로 최적화.
- 13개 공개 페이지와 자체 자산 8개에 맞춰 공개 허용목록·검사기·운영 기록 갱신.
- 기존 사이트 개선을 함께 main에 반영하고 GitHub Pages 배포 성공. 공개 페이지 13개와 원본 자산이 일치하는 이미지 6개를 실제 URL에서 확인. 상세 결과는 [검증 기록](verification.md)의 최신 절을 따릅니다.

## PPTX 콘셉트 기반 웹 디자인 · 2026-09-12

- 제공된 14장 PPTX의 크림·갈색·황동색과 원본 이미지 3개로 홈과 공통 스타일을 개선.
- 10대 기본원칙 페이지에 적용 예시와 기존 정책 링크를 추가하고, 빠른 판단·도입 안내 동선을 보완.
- 이미지 해상도를 유지한 WebP 3개의 합계 약 154 KiB. PPTX 원본은 Pages에서 제외.
- 공개 13개 페이지와 자체 자산 5개에 맞춰 허용 목록·검사기·운영 문서 갱신.
- strict 빌드·공개 범위·로컬 링크·내부 앵커·정적 색상 대비 검사 통과. 이번 변경은 로컬 반영이며 원격 배포는 수행하지 않음. 화면별 브라우저 시험은 미실행.

상세 출처·결과·제한은 [검증 기록](verification.md)을 따릅니다.

## main 통합 · 2026-09-12

- 문서 개선과 기존 FolderState 구현을 원격 main의 공개 안내 이력과 병합.
- 저장소 전체 소스를 내려받아 빌드할 수 있도록 개발 안내를 갱신.
- 엔진 27개 시험·WPF 렌더링·MSI 생성과 구조 검사·문서 strict 빌드·공개 범위 검사 통과.
- 새 패키지는 미서명 검증용이며 실제 해시와 검증 범위는 [검증 기록](verification.md)에 기록.

## 기획 대비 평가 반영 · 2026-09-12

- 홈·README에 ‘정리가 일이 되지 않는다’는 원칙과 업무 사건 중심 흐름을 배치.
- [빠른 판단 기준](../quick-reference.md)에 19개 상황별 행동과 상세 정책 링크를 추가.
- 도입을 최소 시작·업무 사건·필요 시 보완으로 나누고, 고급 진행·인수인계 개선안은 선택 메뉴로 이동.
- MASTER의 미착수 유지, 상태 미지정·미착수 지정·초기화의 차이를 정책·양식·사용법에 일치시킴.
- FolderState의 경로 보호 설계와 기존 업무파일 보존 시험 근거를 공개 사용 안내에 설명.
- DEC-020은 제품 개발 관리로 이관된 번호임을 표시하고 기존 번호를 유지.
- 공개 문서 12개에 맞춰 MkDocs 허용 목록·내비게이션·사이트 검사 목록과 운영 문서를 갱신.

[실제 검증과 배포 상태](verification.md): strict 빌드·공개 범위·링크·브라우저 확인 완료. 이번 변경은 로컬에 반영했으며 원격 배포는 수행하지 않았습니다.
