## Excel·설치 프로그램 한국어 검수 · 2026-09-17

- Excel 결과표와 안내에서 ‘비교키·잔여·가시성’을 ‘비교에 쓴 값·남은 개수·숨김 여부’로 풀고, 개수 계산 예시를 붙였습니다.
- Excel 설치·제거·오류 안내, CMD 실행 안내, 설치기 기본 메시지 67개를 자연스러운 한국어로 다듬었습니다. 안내 문서와 검사 기대값을 함께 맞췄습니다.
- FolderState 설치·복구·제거 문구와 도움말을 추가 교정하고 MSI를 다시 만들었습니다.
- Excel은 소스 반영이며 새 XLAM·배포용 EXE는 만들지 않았습니다. 기존 실패 기록과 배포 보류를 유지합니다.

[추가 검수 기록](korean-wording-review.md)과 [검증 기록](verification.md)에 범위·한계·새 MSI 정보를 남겼습니다. 커밋·푸시·공개 게시를 하지 않았습니다.

## 쉬운 문구와 사용 순서 · 2026-09-16

- 공개 안내 14개 페이지를 상황과 행동 순서 중심으로 수정했습니다. 영어 폴더·시트 이름에는 쉬운 뜻을 붙이고 회사별 미확정 조건은 유지했습니다.
- FolderState 상태명을 ‘시작 전 / 진행 중 / 완료 / 확인 필요’로 통일하고, 상태 표시 지우기·아이콘 다시 표시·작업 기록 열기의 결과를 설명했습니다. 화면, 탐색기 메뉴, 설치, 명령줄, 도움말에 함께 반영했습니다.
- 처음 화면을 폴더 선택 → 상태 선택으로 안내하고, 선택 설정은 접어 두었습니다. 작은 화면의 줄바꿈과 문서의 바로가기 간격을 확인했습니다.
- 문구별 목록과 변경 전후 비교를 만드는 `scripts/review-wording.py`, 작성 기준, [문구 점검 기록](wording-review.md)을 추가했습니다.
- 저장 값·명령·파일 형식·업무자료 보호·설치 권한은 유지합니다. 명령줄의 사람용 출력 문구와 줄 수는 바뀌었고 JSON 필드는 유지합니다.

테스트와 제한, 패키지 상태는 [검증 기록](verification.md)을 따릅니다. 로컬 수정이며 원격 게시를 하지 않았습니다.

## PPTX 콘셉트 기반 웹 디자인 · 2026-09-12

- 제공된 14장 PPTX의 크림·갈색·황동색과 원본 이미지 3개로 홈과 공통 스타일을 개선.
- 10대 기본원칙 페이지에 적용 예시와 기존 정책 링크를 추가하고, 빠른 판단·도입 안내 동선을 보완.

## 기획 대비 평가 반영 · 2026-09-12

- 홈·README에 ‘정리가 일이 되지 않는다’는 원칙과 업무 사건 중심 흐름을 배치.
- [빠른 판단 기준](../quick-reference.md)에 19개 상황별 행동과 상세 정책 링크를 추가.
- 도입을 최소 시작·업무 사건·필요 시 보완으로 나누고, 고급 진행·인수인계 개선안은 선택 메뉴로 이동.
- MASTER의 미착수 유지, 상태 미지정·미착수 지정·초기화의 차이를 정책·양식·사용법에 일치시킴.
- FolderState의 경로 보호 설계와 기존 업무파일 보존 시험 근거를 공개 사용 안내에 설명.
- DEC-020은 제품 개발 관리로 이관된 번호임을 표시하고 기존 번호를 유지.
- 공개 문서 12개에 맞춰 MkDocs 허용 목록·내비게이션·사이트 검사 목록과 운영 문서를 갱신.

[실제 검증과 배포 상태](verification.md): strict 빌드·공개 범위·링크·브라우저 확인 완료. 이번 변경은 로컬에 반영했으며 원격 배포는 수행하지 않았습니다.
