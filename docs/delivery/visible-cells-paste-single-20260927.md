## 실제 UI 검증과 한계

처음에는 설치 완료 창을 UI 도구가 잘못 식별해 조작하지 못했다. 사용자가 완료 사진과 확인 클릭을 제공한 뒤 시험을 재개했다. Excel 접근성 요소 인덱스 입력도 실패해 최신 화면을 확인한 좌표 입력으로 전환했다. 메뉴 텍스트가 접근성 트리에 같은 요소 번호로 두 번 노출되는 경우에는 고유 요소 번호와 실제 화면으로 메뉴 수를 판정했다. 이 도구 제약을 제품 실패로 분류하지 않는다.

합성 파일만 사용했다. 실제 동작은 UI로 수행했고 `UiSmokeProbe.cs`는 정확한 파일·시트에 한정해 값을 읽었다. 각 단계의 13개 검사는 공통 항목을 반복한 것으로 독립 사례 수로 합산하지 않는다. 컴파일된 검사 프로세스가 획득한 COM 참조를 반환한 후 실제 UI 종료와 프로세스 부재를 확인했다. 파일을 저장하지 않았으며 디스크 해시가 처음과 같았다. 시험 설치는 제거했다.

최초 직접 실행 어댑터는 4초 제한으로 호출됐고 이후 Excel 프로세스가 없어 검증 근거에서 제외했다. 이후에는 기다리거나 종료하지 않는 일반 Process.Start 실행기로 새 세션을 시작했다. 위 PASS는 이 실행기로 시작한 세션에서만 얻은 결과다. 마지막 두 설치 상태 세션과 제거 후 세션은 강제 종료 없이 UI로 닫혔다.

T05의 현재 PC 단일 EXE 전환 범위를 완료했다. T12의 네 제품 공존, x86 Office·새 프로필·재부팅·등록 ACL/전원 차단은 이 결과에 포함하지 않는다. 서명 없는 로컬 평가 후보이며 공개 게시·조직 배포 승인은 별도다.

상세 자동 검사·설치 증거는 `artifacts/visible-cells-paste/single-lifecycle-2203bd556c81406dbdd709ee8b39959f`와 `single-0.1.1`에, UI 장애 기록·공개 ZIP·`t05-ui-*` 검증 기록은 로컬 감사 디렉터리에 보관한다. 재현용 검사 도구 빌드도 종료0을 확인했다. 문서 strict 빌드와 공개 19페이지·404·생성 링크 검사는 통과했다. 개인 경로·원시 로그는 공개 사이트에 포함하지 않는다.
