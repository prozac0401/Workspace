# 검증 기록

## 현재 확인

- 핵심 엔진과 WPF 관리 화면의 Release 빌드 성공.
- 실제 Windows 파일시스템 통합 테스트 24건 통과.
- 한글·공백·260자 초과 경로, 원본 desktop.ini 바이트·속성 복원 확인.
- 외부 아이콘 변경 보호, Portable 충돌 보호, 중복·미래 형식 거부 확인.
- 변경 단계별 오류 주입과 실패한 초기화의 복원 확인.
- 동시 요청 12개 직렬화, 파일 잠금, 명시 목록의 부분 성공 확인.
- 파일 10,000개가 있는 폴더에서 업무파일 개수와 표본 내용 유지 확인. 상태변경 28ms는 이 환경의 한 번 측정이며 성능 보장이 아닙니다.

## 진행 중

MSI 빌드·설치 검증과 GitHub Pages 게시 결과는 작업 완료 시 이 페이지를 갱신합니다.

## 별도 환경에서 필요한 확인

깨끗한 일반 사용자 PC, Explorer 실제 시각 갱신, DPI·접근성, 실제 인증서 서명, 조직 보안·공유 저장소, 전원 손실 시험은 자동 테스트 통과로 대체하지 않습니다.
