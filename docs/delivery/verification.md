정책 개선 아이템의 실제 업무 효과는 측정하지 않았으며 POL-007과 DEC-021–025는 제안·미확정입니다. 엔진·WPF·MSI 변경은 없어 해당 제품 검증은 재실행하지 않았습니다. 이 표는 문서 검증 결과이며 제품의 상용 출시 승인을 의미하지 않습니다. Pages 게시 결과는 해당 main 커밋의 Documentation 워크플로와 실제 공개 URL에서 별도로 확인합니다.

검증일: 2026-09-12 · 제품: FolderState 0.1.0 · 환경: Windows 11 x64, OS 10.0.22631.0.

## 데이터 보존과 실패 복원

- 네 상태, 한글·공백·260자 초과 경로, 원본 desktop.ini 바이트·속성 복원을 확인했습니다.
- 외부의 다른 설정 편집을 보존하고, 외부 아이콘 변경·Portable 충돌·손상·미래 형식·중복 INI를 보호했습니다.
- 각 변경 단계의 오류 주입, 실패한 초기화 복원, 실제 프로세스 강제 종료 후 다음 실행에서의 복구를 확인했습니다.
- 동시 요청 12개 직렬화, 파일 잠금, 하드링크 보호, 손상된 복구 기록 보존, 명시 목록의 부분 성공을 확인했습니다.
- 업무파일 10,000개가 있는 폴더의 파일 개수와 표본 내용이 유지되는지 확인했습니다. 상태 엔진은 하위 항목을 열거하지 않으며 이 시험은 전체 환경의 성능 보장을 뜻하지 않습니다.

## 설치 수명주기

기존 FolderState 메뉴가 없는 개발 PC의 **권한 상승 없는 세션**에서 저장소 내부의 전용 시험 폴더를 사용했습니다. 실행 기록의 `elevated`는 `false`입니다.

1. MSI 설치 후 HKCU 메뉴, 자체 포함 CLI 실행과 상태 저장을 확인했습니다.
2. 설치된 아이콘 하나를 삭제한 뒤 MSI 복구로 같은 설치 경로에 복원되는지 확인했습니다.
3. 동일 최종 프로그램과 설치 정의로 만든 **0.1.1 시험 전용 패키지**를 사용해 MSI 상위 버전 교체를 확인했습니다. 실제 차기 제품의 데이터 형식 변경 시험은 아닙니다.
4. 0.1.0 재설치가 최신 버전 존재를 이유로 차단되는지 확인했습니다. 종료 코드 1603과 해당 버전 오류 문구를 함께 검사했습니다.
5. 제거 후 메뉴·프로그램이 없어지고 업무파일·폴더 상태정보의 바이트가 유지되는지 확인했습니다.

설치·복구·업그레이드·제거는 모두 종료 코드 0이었습니다. 이 시험은 개발 PC에서의 실제 동작 근거이며 깨끗한 별도 PC의 검증을 대체하지 않습니다.

## 남은 상용 출시 검증

.NET이 설치되지 않은 깨끗한 일반 사용자 PC, Explorer 실제 메뉴 조작·아이콘 갱신, 설치 마법사의 대화형 조작, 100/150/200% DPI·키보드·화면 읽기, 실제 게시자 인증서 서명, 조직 보안·공유 저장소, 전원 손실은 별도 검증이 필요합니다. 실제 프로세스 종료 시험은 전원 손실 시험과 구분합니다. 게시자·라이선스·지원 연락처와 조직 운영값도 확정해야 합니다.
