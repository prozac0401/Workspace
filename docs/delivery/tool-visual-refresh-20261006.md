# 도구 삽화·그림·표 시각 구성 개편 · 2026-10-06

## 요청과 완료 기준

사용자는 Bookmark의 최근 기능을 기록에 따라 안내에 추가하고, 기존 삽화 전체를 사이트의 룩앤필에 맞추며, 각 도구 설명 페이지의 그림과 표를 본문 가운데 배치하도록 요청했습니다. 원래 사용자 작업 폴더는 유지하고 최신 원격 `143465471c46293c3f353d2731e3093e19c2c61a`의 별도 복사본에서 작업했습니다.

완료 근거는 공개 버전·사용법 대조, 모든 챕터와 도해 정의의 일치, SVG 글자 배치, strict 빌드·공개 링크 검사, PC·모바일 브라우저에서 중앙 배치와 넘침 확인, Documentation 배포 및 공개 반영입니다. 제품 코드·설치 파일을 바꾸거나 새로운 제품 실기를 수행하지 않습니다.

## 변경 내용

- Bookmark 0.2.10의 고정 다운로드와 0.2.9의 전체 표시·숨김, 자석·일괄 정렬, 0.2.10의 숨김·편집 중 정렬 수정은 [Bookmark 기록](bookmark-0210-publication-20261006.md)을 따릅니다.
- 기존 113개 챕터의 가로·모바일 SVG를 모두 다시 생성하고 Bookmark의 두 챕터를 추가합니다. 총 115개 챕터, SVG 230개입니다.
- 기존 사이트의 종이색(`#fffdf9`), 갈색(`#2c2622`), 황동색(`#8a622f`)과 같은 글꼴·얇은 테두리·작은 모서리를 적용했습니다. 순서는 번호·화살표로, 비교는 구분선으로 표현하며 기존 설명·대체텍스트를 보존합니다.
- 교육 예시 PNG 7개는 원본 HTML의 종이색·갈색·황동색 틀을 맞춰 같은 크기로 다시 렌더링했습니다. 기능을 구분하는 Excel 녹색·선택 표시·스티커 색은 유지하고, 공개 문구 정책에 따라 오래된 평가판 문구 한 곳을 제거했습니다. 소개 WEBP 6개는 이미 사이트 색상과 일치함을 확인했으며 실제 FolderState 화면 PNG는 원래 제품 색상을 보존합니다. 모든 그림의 공통 테두리·여백·캡션을 맞추며, 설명용 그림을 실제 제품 시험 증거로 바꾸지 않습니다.
- 그림과 표는 본문 가운데 배치하며 표의 셀 안 정렬은 유지합니다. 좁은 화면에서 도해는 세로형으로, 넓은 표는 가로 스크롤로 읽습니다. 캡션은 가운데 배치합니다.
- 공개 페이지 21개·이전 주소 이동 2개는 유지합니다. 기존 자산 15개와 SVG 230개를 명시적으로 허용하며 생성기·JSON·검증 기록·로컬 화면 캡처는 Pages에서 제외합니다.
