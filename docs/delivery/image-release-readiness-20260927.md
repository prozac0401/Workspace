# 그림 복사·저장 0.1.1 · 배포 준비 판정

## 후속: 0.2.0 외부 전체 보존 시험 32/32 PASS

외부 호스트에서 같은 0.2.0 MSI의 전체 보존 시험 **32 PASS / 0 FAIL / 0 NOT RUN**을 확인했습니다. HKLM·HKCU 충돌 차단, 외부 수정 보존, 복구·업데이트·제거와 실패 롤백을 통과했고 합성 시험 등록을 정리하며 업무 자료 역할의 fixture는 보존했습니다. 기본 위치 최종 설치도 msiexec 0으로 PASS했으며 재시작 요구와 Explorer 강제 재시작은 없었습니다. 기본 설치본의 실제 탐색기 복사·저장 대표 확인도 PASS했으며, 저장 후 최종 행 선택은 미확인입니다. 정식 게시는 아직 미완료입니다. [0.2.0 후속 작업 기록](image-020-release-20260927.md)에서 최신 실제 결과와 앞선 실패 이력을 구분합니다. 아래는 0.1.1의 당시 판정입니다.

날짜: 2026-09-27 · 책임: 도구 개발·검증 담당 · 상태: **공개 배포 보류**

적용: [도구 정책](../policies/tools.md), [문서 정책](../policies/documentation.md), [v1.2 변경 계약](../tools/image-copy-save/ImageCopySave_Requirements_v1.2.md).

사용자의 순차 배포 요청에 따라 최신 별도 작업본과 기존 검증 산출물을 확인했다. 이전 MSIX 설치 신뢰 오류를 현재 MSI의 차단 사유로 재사용하지 않는다. 현재 후보는 관리자 설치·일반 사용자 실행을 분리한 Windows 11 x64 무서명 자체 포함 MSI다.

## DEP-06: MSI와 시험기의 보호 차이

[Product.wxs](../../tools/ImageCopySave/installer/Product.wxs)의 기존 설치 검사는 두 COM InprocServer32 기본값을 검사한다. 같은 이름의 기존 verb 등록만 있는 경우와 알 수 없는 설치 폴더에 대한 보호는 별도 [시험 스크립트](../../tools/ImageCopySave/installer/test-msi-lifecycle.ps1)에 있으며 제품 MSI 직접 실행에는 적용되지 않는다.

복구 화면은 REINSTALLMODE=amus를 사용하며 외부에서 바꾼 제품 소유 파일·레지스트리 값을 비교해 보존하는 동작이 없다. 일반 제거 또한 작성된 레지스트리 값을 제거하는 Windows Installer 동작을 사용한다. [Microsoft REINSTALLMODE](https://learn.microsoft.com/en-us/windows/win32/msi/reinstallmode), [RemoveRegistryValues](https://learn.microsoft.com/en-us/windows/win32/msi/removeregistryvalues-action)의 동작을 참고한다.

이는 v1.2 DEP-06과 정적 설계상 차이가 있다는 판정이다. 실제 사용자 자원의 손실을 관찰한 시험은 아니다. 기존 시험의 설치 폴더 밖 합성 PNG 보존을 이 요구의 통과로 확대하지 않는다. 요구를 약화하거나 시험기 보호를 제품 기능으로 설명하지 않는다.

필요한 회귀는 기존 메뉴 값만 있는 등록·설치 대상 파일 충돌, 정상 설치 후 외부 변경, 복구·업데이트·제거 시 보존 또는 안전한 중단, 알 수 없는 파일·값·타사 등록 보존, 기존 설치의 업데이트 실패 롤백, 검사와 작업 사이의 외부 변경이다. 보호 방식은 별도 설계 결정·패키지 변경으로 연결한다. 이번에 사용자 설치 자원을 바꾸어 재현하지 않았다.

## 후보 출처와 게시 경계

관리·native 소스 입력 23개와 Product.wxs는 보존된 빌드 메타데이터와 일치한다. build-msi.ps1·verify-msi.ps1은 단순 줄바꿈·BOM 차이를 제외해도 일치하지 않는다. Git에 최초 보존된 스크립트는 MSI 제작 이후의 내용이며 이전 사본이 없어 정확한 변경 줄은 확정하지 못했다. 이 차이는 MSI 자체 변조의 증거가 아니며, 현재 스크립트로 재현 빌드까지 확인했다고 표현하지 않는다.

최신 MSI·클래식 메뉴 구현과 이 판정을 함께 보존한다. README·배포 색인·현재 실기 안내의 과거 MSI 부재·첫 메뉴 필수·20회 반복 문구를 현행 계약에 맞췄다. 이전 명세와 실패·실기 기록은 유지한다.

검증한 MSI·체크섬·경로/로그를 제외한 후보 요약은 로컬 배포 검토 폴더에 준비한다. 같은 버전의 이전 후보와 실패 주입 MSI는 제외한다. G0와 DEP-06이 해소되기 전에는 공개 Release의 설치 자산이나 Pages 다운로드로 제공하지 않는다. 소스·문서 게시를 제품 배포 완료로 표현하지 않으며 상용 승인·다른 PC 지원도 미확정이다.
