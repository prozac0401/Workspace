# 업무 책갈피 0.2.9·0.2.10 사용 안내 반영

날짜: 2026-10-06 · 책임: 문서·배포 담당 · 상태: 문서·삽화 및 통합 검증 완료, Pages 게시 대기

## 요청과 필요한 변경

사용자는 Bookmark의 작은 기능 추가를 기록에 따라 기존 설명에 보충하도록 요청했다. 현재 공개 안내의 기준은 0.2.8이고, BookMark의 최신 공개 릴리스는 [0.2.10](https://github.com/prozac0401/BookMark/releases/tag/v0.2.10)이다. 0.2.9의 스티커 표시·숨기기, 자석 정렬, 일괄 정렬과 0.2.10의 메모 읽기·편집 중 정렬 수정을 설치·사용 안내에 반영한다.

범위는 업무 책갈피 안내 한 페이지와 홈페이지 소개, 현재 배포 색인, 설명용 삽화 정의, 이 기록이다. 제품 소스·설치 파일·사용자 설정과 기존 작업 사본은 바꾸지 않는다. 별도 checkout의 최신 원격 main 기준 파일에서 작업하며, 이전 0.2.8의 [공개 안내 기록](bookmark-028-publication-20260927.md)과 [일반 배포 전환 기록](stable-tools-release-20261005.md)은 당시 근거로 보존한다.

완료 근거는 변경 동작과 기록·소스의 일치, 고정 다운로드 자산 확인, 설명용 삽화의 본문 대응, MkDocs strict 빌드와 로컬 링크·공개 범위 검사, GitHub Actions 성공 및 실제 공개 페이지 반영이다. 문서 변경이므로 제품의 설치·GUI 시험은 반복하지 않는다.

## 자료 근거와 반영 내용

BookMark 로컬 main `18d118e`의 README, 0.2.9·0.2.10 릴리스 노트, 관련 검증 기록을 읽고 스티커 메뉴·토글·정렬·메모 읽기 구현과 대조했다. 제품 저장소의 작업 트리는 이 대조 당시 깨끗했다. 제품의 빠른 시작·사용 매뉴얼 일부는 0.2.9 다운로드 안내를 유지하고 있으므로 현재 버전은 최신 README와 0.2.10 릴리스 노트를 기준으로 삼았다.

| 근거 | 반영한 사용자 행동 |
|---|---|
| [0.2.9 릴리스 노트](https://github.com/prozac0401/BookMark/blob/v0.2.10/docs/release-notes-v0.2.9.md) | Ctrl+Alt+J와 사용자 지정 보기 키의 토글, 트레이의 항상 전체 표시, 자석 정렬과 Alt 자유 이동, 격자·가로·세로 정렬 |
| [0.2.10 릴리스 노트](https://github.com/prozac0401/BookMark/blob/v0.2.10/docs/release-notes-v0.2.10.md) | 전체 숨김 이전에 요청한 메모의 늦은 읽기가 다시 표시·활성화하지 않음, 편집 중 정렬 후 저장·취소 시 새 위치 유지 |
| [최신 README](https://github.com/prozac0401/BookMark/blob/v0.2.10/README.md) | 0.2.10 설치 파일명과 보존 계약, 기존 한 줄 스티커·자동 저장·Whale 안내 유지 |
| `BookmarkApplicationContext.cs`, `StickerManager.cs`, `StickerSnap.cs`, `StickerArrangement.cs`, `UI/StickerForm.cs`, `UI/SettingsForm.cs` | 실제 메뉴명, 일부 숨김 상태 판정, 같은 모니터의 보이는 자석 대상, 커서가 있는 모니터로 일괄 정렬, 편집 복원 위치·초안 보존 |

처음 책갈피를 다시 여는 연습은 **시계 옆 아이콘 → 책갈피 보기**로 안내한다. 이미 스티커가 보일 때 Ctrl+Alt+J를 누르면 숨기는 동작으로 바뀌었으므로, 이를 언제나 표시하는 키처럼 설명하지 않는다. 일부만 숨긴 상태에서 첫 입력은 나머지도 숨기고 다음 입력은 전체를 표시함을 명시한다.

일괄 정렬은 숨긴 스티커까지 마우스가 있는 모니터에 최근 저장 순으로 모은다. 한 화면에 모두 들어가지 않으면 어긋나게 겹쳐 놓는다. 자석 정렬은 같은 모니터의 보이는 주변 스티커만 대상으로 하며 기본 켜짐, 100% 배율의 범위 12픽셀·간격 8픽셀, Alt 임시 해제와 설정 저장을 설명한다.

메모 편집 중 정렬은 저장을 강제하거나 초안을 버리지 않는다. 저장 실패 시 초안과 편집 상태를 유지하며, 이후 저장 성공이나 Esc 취소 후 정렬한 위치와 편집 전 크기·접힘 상태로 돌아간다. Esc의 편집 취소와 일반 상태의 스티커 숨기기도 구분한다. 두 문제의 최초 발생 버전은 확정되지 않았으므로 0.2.9에서 새로 생겼다고 단정하지 않는다.

기존 H2/H3 13개에 표시·숨기기와 자석·일괄 정렬 H3 두 개를 추가하고 각 설명용 SVG의 원본 정의를 만든다. 업무 책갈피는 15개 챕터이며 각 가로·모바일 그림은 실제 프로그램 화면이나 제품 시험 증거가 아니다. 생성·화면 확인 결과는 아래 통합 검증에 별도로 기록한다.

## 다운로드와 보존 범위

공개 안내의 MSI·ZIP·배포 태그·체크섬은 `v0.2.10` 고정 주소로 연결한다. `releases/latest`를 사용하거나 설치 파일을 Workspace와 Pages에 복사하지 않는다.

- `WorkBookmark-0.2.10-win-x64.msi`
- `WorkBookmark-0.2.10-win-x64.zip`
- `SHA256SUMS.txt`

DB v5·설정 파일 버전 1·스티커 표시 규칙 버전 3은 유지된다. 0.2.0~0.2.9에서 새 DB 이전 없이 업데이트하며 기존 메모·삭제 기록·사용자 크기·선택 모드·단축키·자동 실행 설정을 보존한다. 0.2.9의 선택 항목 `StickerSnapEnabled`가 없으면 켜짐으로 읽는다. 이전 표시 규칙의 최초 적용, 0.1.7 복귀 시 업그레이드 전 백업 필요, 0.2.3 이하 사용자 지정 MSI 경로 이행 안내를 유지한다.

전자 서명 없음과 데이터 보존에 필요한 제한은 공개 안내에 남긴다. 내부 시험 수치·배포 단계·미실행 경고는 [정책 문서 작성 규칙](../policies/documentation.md)과 [ADR-0035](../design/0035-public-tool-wording.md)에 따라 이 제외 기록에 보존한다. 문구 반영은 새 제품 검증이나 회사의 사용 승인을 뜻하지 않는다.

아래 수치는 BookMark의 기존 기록을 대조한 것이며 이번 문서 작업에서 제품 시험을 실행한 결과가 아니다.

| 기록 | 실제 근거와 한계 |
|---|---|
| [0.2.9 정렬 검증](https://github.com/prozac0401/BookMark/blob/v0.2.10/docs/evidence/sticker-alignment-2026-10-06/README.md) | 전체 자동검사 746개 통과에 최종 Desktop 351개가 포함된다. 앞선 345개 대신 351개를 사용하며 반복 실행을 합산하지 않았다. Release 빌드 경고·오류는 0개다. |
| 0.2.9 전역 단축키 실기 | 커밋 전 검증 DLL의 격리 앱에서 사용자 지정 Ctrl+Alt+Shift+F16 입력으로 2개 표시 → 모두 숨김 → 2개 표시와 위치·크기·메모 보존, 종료 코드 0을 확인했다. 기본 Ctrl+Alt+J 직접 입력이나 최종 Commit 모드 패키지 실기와 같지 않다. |

| 패키지 확인 구분 | 최종 패키지 검사 수와 결과는 릴리스의 `validation.json`, 소스 기준은 `SourceSnapshot.json`, 해시는 `SHA256SUMS.txt`를 기준으로 한다. EXE 기동·MSI 구조·해시 검사는 실제 UI나 설치 시험을 대신하지 않는다. |

## 이번 수행과 게시 상태

| 단계 | 현재 상태 |
|---|---|
| 원본 기록·소스 대조 | 완료. 앞서 적은 메뉴·동작·보존 조건을 확인했다. |
| 공개 본문·홈 소개·배포 색인·삽화 정의 작성 | 작성. 0.2.10 고정 다운로드와 두 추가 챕터를 반영했다. |
| 원본 형식·챕터 대응·공백 | JSON 파싱 통과, 정의 15개와 H2/H3 15개가 일치하고 누락·중복 ID는 0개다. 수정 대상의 `git diff --check`를 통과했다. |
| 삽화 생성·화면 확인 | Bookmark 15개 챕터·SVG 30개 생성. 전체 115개 챕터 통합 검사 및 Chrome 1440·390px의 9개 도구 18개 화면 검사 통과. Bookmark는 320·601px도 확인. 상세 결과는 [시각 구성 개편 기록](tool-visual-refresh-20261006.md)을 따른다. |
| MkDocs strict·생성 로컬 링크·검색·사이트맵 | `python -m mkdocs build --strict`와 `python scripts/check-site.py site` 통과. 공개 21개·이전 주소 2개·404 및 제외 자산 확인. |
| 문서 커밋·원격 main 반영 | 대기. 이 작성 시점에는 완료를 주장하지 않는다. |
| GitHub Actions·실제 Pages | 대기. 워크플로 성공과 실제 공개 내용 확인 후 완료로 갱신한다. |

이 문서와 원본 JSON·소스·로컬 진단은 공개 사이트에 포함하지 않는다. 원래 사용자의 작업 사본과 BookMark 제품·사용자 데이터는 이번 문서 편집에서 수정하지 않았다.
