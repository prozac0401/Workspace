## 요청과 반영 범위

사용자는 최신 Release의 각 도구를 확인하고 두 첨부 문서의 내용을 쉬운 말로 작성해 GitHub Pages에 게시하도록 요청했습니다. 추가 범위 질문에서 Workspace 업무 안내와 교육 업무 예시부터 게시하는 것으로 선택했습니다. 별도 WebSim은 이번 수정·게시에서 제외합니다.

「GitHub Pages·Workspace 문서 리뷰와 수정안」과 「교육 운영 업무별 도구 활용 시나리오」의 본문·표·근거 링크를 읽었습니다. 첨부 문서의 할 일은 검토 자료로 취급하고, 실제 사용자 요청과 현재 저장소 규칙을 우선했습니다. 원문 Word 파일과 추출본은 공개 사이트에 복사하지 않습니다.

첫 화면·README·배포 색인의 최신 버전을 맞추고, 여덟 도구의 설치·사용 안내를 일상말로 고쳤습니다. 교육 활용안은 [교육 업무에 도구 써 보기](../education-operations.md) 한 페이지에 일곱 장면으로 작성했습니다. 가짜 자료 준비, 사용 순서, 기대 결과와 핵심 제한을 설명합니다. 책갈피는 작은 메모창과 목록 표시 모두를 안내합니다.

자료 보호 안내의 공개 범위를 현재 도구 안내에 맞췄습니다. 옛 SmartList 안내 7개에는 당시 버전과 현재 안내를 먼저 표시하고 기존 본문을 보존했습니다. FolderState 도움말 원본의 옛 0.1.2·미배포 표기를 현재 0.1.3에 맞췄습니다. **이미 게시한 MSI를 다시 만들거나 그 안의 도움말을 바꾼 것은 아닙니다.**

업무 책갈피 0.2.8은 10월 5일 07:48:26에 기존 파일의 시험용 표시를 해제한 것입니다. 새 파일 공개일로 바꾸어 쓰지 않습니다. FolderState 0.1.3도 기존 RC1과 같은 설치 파일이라는 기존 제작 기록을 따릅니다. 이번에는 설치 파일의 내용을 새로 실행하거나 해시를 다시 계산하지 않았습니다.

선택범위 내보내기에는 32·64비트 EXE가 있고 MSI는 없습니다. 보이는 칸 붙여넣기는 EXE와 ZIP이 있습니다. 그 밖의 파일 이름·시각·크기·공개 주소는 로컬 검토용 Release 목록에 보관했습니다. 공개 설치 안내의 버전 비고정 예외는 유지합니다.

## 쉬운 말과 결과 검토

공개 문장은 중등교육 수준의 비전공자를 기준으로 고쳤습니다. 개발 용어와 불필요한 영어를 줄이고 실제 메뉴·버튼·파일 이름과 단축키만 필요한 곳에 보존했습니다. 기존 다운로드 주소와 문단 주소는 보존했습니다. 상세 시험 수치는 사용에 필요한 제한 뒤에서 읽도록 정리했습니다.

명단 예시의 TEST003은 첫 목록 2개·둘째 1개, TEST006은 0개·1개입니다. 보이는 칸 예시는 A반 세 명만 바뀌고 B반은 그대로입니다. 내보내기는 TEST001·003·004의 세 열과 제목만 남습니다. 파일 목록은 다섯 파일과 과제 세 개·제출자 두 명입니다. 나머지 그림·책갈피·상태 표시의 기대 결과도 현재 기능 설명과 대조했습니다.

교육 대상자, 최종 자료, 미제출자와 업무 완료는 사람이 판단합니다. 실제 회사 설정을 확정하지 않았으며, 업무 효과나 비전공자의 실제 이해도를 측정한 결과도 아닙니다. 다운로드 이름 유지의 알려진 설치 실패 복구 문제를 유지하고 일상 교육 업무 추천에서 제외합니다.

## 실제 수행한 검사

| 확인 | 결과 |
|---|---|
| python -m mkdocs build --strict | 성공, 종료 0 |
| python scripts/check-site.py site | 성공, 공개 안내 20개·이전 주소 이동 2개·404 확인 |
| 검색·사이트맵·공개 자산·로컬 링크 | 허용한 목록만 포함, 깨진 연결 없음 |
| GitHub 자산 주소 대조 | 현재 안내의 서로 다른 주소 16개 모두 최신 Release의 실제 첨부 파일과 일치 |
| 해당 주소의 HTTP HEAD 확인 | 16개 모두 200, 파일 본문은 내려받지 않음 |
| git diff --check | 성공, 공백 오류 없음 |
| 화면 검토 | 교육 안내 1440×1000·390×844, 첫 화면 다운로드 표를 확인. 본문·표 읽기와 작은 화면의 표 스크롤 확인 |
| 브라우저 검색 | 한국어 ‘교육’과 ‘FolderState’로 새 교육 안내가 결과에 나타남 |
| 브라우저 화면 오류 | 확인 중 pageerror 없음 |
| 별도 검토 | 공개 문서·메뉴·검사 목록 20개 일치, 가짜 자료 정답과 기능 제한 대조 |

로컬 빌드에는 저장소의 고정된 mkdocs 1.6.1과 mkdocs-material 9.7.7을 사용했습니다. 도구 코드·상태 저장 방식·WPF 화면·설치 파일을 변경하지 않았으므로 제품 엔진·설치 수명주기를 새로 시험하지 않았습니다. 이번 결과는 문서와 공개 연결 확인이며 이전 제품 확인 범위를 넓힌 증거가 아닙니다.

원래 작업 폴더의 기존 수정 파일과 새 파일은 그대로 둡니다. 원격 최신 main을 별도 작업 폴더에서 수정했습니다. 생성한 site·화면·검사 출력과 첨부 추출본은 변경에 넣지 않습니다.

## GitHub 반영과 실제 게시

검사한 문서 변경을 PR로 제출하고 CI 통과 후 main에 반영합니다. 실제 게시 결과와 공개 URL 내용은 이 절의 후속 기록으로 남깁니다. 아직 확인하기 전에는 게시 완료로 표시하지 않습니다.
