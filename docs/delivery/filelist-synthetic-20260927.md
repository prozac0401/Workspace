## 재현 및 증거

Workspace의 `scripts/test-filelist-synthetic.ps1`은 정확한 공개 MSI 해시를 고정하고 기존 설치나 Excel이 있으면 시작하지 않는다. `Prepare`가 합성 자료를 생성하며, 실제 UI 복사를 마친 뒤 `Remove`가 자신의 설치만 제거한다. UI 조작은 스크립트가 대신 수행하지 않는다.

`scripts/check-filelist-synthetic.py <evidence> --verify-copy`로 최종 결과를 읽기 전용 검증한다. `--verify-copy` 사용 전 이번 작업의 보고서를 evidence의 `copy-report.json`에 복사한다. 결과는 `workbook-checks.json`에 남는다. 설치 로그, 원본 manifest, 통합문서, 작업 보고서와 UI 텍스트는 local-only artifacts에 보관하고 공개 사이트에 싣지 않는다.

초기 검사기의 원본 종류(`directory`) 및 첫 시트 표 관계 해석 오류는 제품 오류와 구분해 보존했다. 추가 보존 검사에서는 폴더 생성 직후 열거 정보의 캐시된 수정 시각이 기준에 들어간 사실을 발견했다. 해당 폴더 시각의 전후 보존을 주장하지 않으며, 이후 fixture 생성에는 `Refresh()`를 추가했다. 현재 증거에서는 폴더 이름/목록/속성 및 모든 파일의 수정 시각·내용을 확인했다. 수정 후 최종 246개 검사가 통과했다.
