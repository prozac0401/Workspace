## 요청과 완료 기준

사용자는 폴더의 하위 폴더까지 모든 지원 Excel 파일을 설정·해제·변경하고, 기존 파일 메뉴는 유지하기를 요청했다. 안전한 실패는 최초 포함 최대 3회 시도하고 최종 실패의 파일·경로·이유·시도 수를 보여 주며, 실패가 있을 때만 XLSX를 남긴다. 정상 경로의 중간 파일은 정리하고 원본 백업은 보존한다. 안전성이 불확실한 결과에서는 재시도를 멈추고 필요한 복구 자료와 안내를 남긴다.

완료 근거는 폴더 미리보기·순차 처리·재시도·실패 보고서·정리의 관련 자동 시험, 합성 Excel 일괄 처리, 실제 폴더/파일 메뉴와 화면, MSI 설치·업그레이드·제거 결과다. 관련 없는 전체 환경 시험을 새로 확대하지 않고 이전 결과는 해당 버전에 귀속한다.

## 실제 시험 환경

`batch-excel-001/environment.json`은 시험 후 등록된 COM 실행 파일과 운영체제에서 읽은 정보다. Windows 11 Pro 23H2 x64, 빌드 22631.6199, Windows PowerShell Desktop 5.1.22621.6133 x64 STA, 등록된 EXCEL.EXE 파일·제품 버전 16.0.20527.20196 x64를 확인했다. 환경 수집은 Excel을 새로 실행한 COM 속성 조회와 구분한다. 실제 Excel 처리·보고서 열기는 아래 50개 검사에서 별도로 수행했다.

## 독립 검토와 보완 추적

폴더 실행·정리 코드를 읽고 암호 전달 파일 삭제 실패를 숨기던 경로, JSON 쓰기 실패 시 pending 정리 경계, 검색 오류만 있는 목록의 보고서 생성, 진행 중 완료 행 갱신, 전체 경로·긴 실패 이유 노출과 최소 창 크기를 확인 대상으로 전달했다. 후속 소스에서 secret 삭제 실패 경고·재시도 중지, JSON outer finally 정리, 검색 오류만 있는 경우 암호 검증 생략, 진행 시 items.json 읽기, 전체 경로·이유 툴팁과 작업 영역에 맞춘 최소 크기 제한을 확인했다. 검토 범위와 3개 화면 해시는 `artifacts/excel-password-safe/review-1.4-20261116/review.json`에 보관한다. 실제 실행 결과와 육안 검토를 구분한다.

최초 full build 후 독립 검토에서 UI가 미리보기에 없는 backend 정리 오류 행을 빠뜨리고, 목록 새로고침 시 이전 실행 폴더를 유지하는 결함을 발견했다. 두 경로를 수정하고 위 12개 회귀 검사를 수행했다. 첫 후보 MSI는 설치 시험 전에 대체했다.

## 빌드 이력과 증거 승계

첫 full build는 `build-1.4.0-20261116-231139-0c1e79a7`이다. 이후 UI만 보완한 `build-1.4.0-20261116-231710-4a6f55ba`는 WiX 내장 파일 추출의 IOException으로 실패했다. 이 실패 기록을 보존하고 소스를 변경하지 않은 재실행 `build-1.4.0-20261116-231740-77c3129c`에서 최종 MSI 제작·7개 내장 payload 해시 검사를 통과했다. 이는 설치 중 오류나 업무 파일 처리 실패가 아니다.

최종 제작은 `SkipTests`로 수행하여 원래 `build-result.json`의 `tests=NotRun`을 유지한다. 이후 실행한 최종 EXE 앱 43개·렌더 44장과 변경하지 않은 runtime의 기존 코어 63·장애 6·배치 45 근거를 `verification-carryforward.json`에 따로 연결했다. 최종 MSI 설치·실제 GUI 결과는 해당 파일의 해시를 기준으로 아래 기록에 추가하며, 이전 후보 시험을 최종 파일에서 다시 수행한 것처럼 표시하지 않는다.

## 이전 결과와 남은 제한

[1.3.0 UI·실제 사용 기록](excel-password-safe-ui-20261116.md)과 [1.2.0 엔진·설치 기록](excel-password-safe-20261116.md)은 당시 결과로 보존한다. 이전 버전의 검사 수를 1.4.0 통과 수로 합산하지 않는다.

1.2.0의 제품 등록 이후 설치 실패 주입에서 파일·메뉴는 제거됐지만 Windows Installer 등록이 남았다. 같은 MSI를 열어 프로그램 제거 후 재설치하는 복구 안내를 유지한다. 이번 폴더 기능 추가를 이 문제의 수정으로 표시하지 않는다.

원본 백업·필요한 복구 자료에는 평문이 남을 수 있다. 파일별 검증은 모든 그림 픽셀·OLE 내부·매크로 동작·외부 연결의 동일성 보장이 아니다. 공통 암호와 다른 파일은 실패할 수 있으며 도구는 암호를 추측하지 않는다. 실제 시험 환경·확인한 보존 항목과 미검증 항목을 최종 결과에 구분한다.
