# Workspace 도구 백로그 · 2026-09-26

상태: 로컬 대조 후 순차 처리 중 · 책임: 개발·검증 담당

첨부 GitHub 잠정안의 T01~T12 식별자를 유지한다. 최신 사용자 요청에 따라 구현·검증·항목별 Git 커밋까지 수행한다. 한 번에 한 항목만 실행하고 Excel 시험·설치·빌드의 동시 실행을 금지한다. 완료 항목마다 이 문서를 같은 커밋에 갱신한다. 사이트 공개 대상이 아닌 개발 기록이다.

## 기준과 보존

- 최초 로컬 main: 89219d0. origin/main은 fetch 후 d157090으로 확인했다. 17개 커밋 차이와 미추적 소스가 함께 있었다.
- 원본 작업 폴더의 사용자 변경을 보존하고, origin/main 기반 codex/backlog-20260926 작업 트리에서 진행한다. 최신 원격 VisibleCellsPaste 0.1.1 종료 수정은 로컬 0.1.0으로 되돌리지 않는다.
- ExcelSelectionExport rc.10의 Undo 후속 작업과 ImageCopySave 0.1.1 후보는 원본 로컬에서 발견했다. 각 작업 차례에 필요한 소스·근거를 연결한다.
- BookMark와 File-List-To-Excel은 Workspace의 하위 프로젝트가 아니라 인접한 별도 저장소다. 두 저장소 작업 트리는 최초 확인 시 깨끗했다.
- 공개 릴리스 6개의 실제 자산 이름·크기·해시를 GitHub API로 확인했다. ImageCopySave 공개 배포는 확인되지 않았으며 다운로드 주소를 만들지 않는다.
