## 사용자와 목적

Windows Excel에서 연속 영역을 복사한 뒤 대상 영역의 보이는 행·열에 같은 모양으로 값을 넣는다. 숨김·필터 행과 숨긴 열을 제외하고 빈칸과 순서를 유지한다. 기존 한 행 원본을 한 열 대상에 순서대로 넣는 방식도 유지한다. 설치·제거·메뉴·Undo 기록은 다른 제품과 독립한다. 사용자 VBA 실행과 문서 코드 삽입을 요구하지 않는다.

## 요구사항

이 표의 구현 경로는 검토 대상이다. 파일 존재와 빌드 성공을 실제 Excel 통과로 해석하지 않는다. 시험 결과의 단일 기록은 [시험 보고서](../../../tools/VisibleCellsPaste/docs/test-report.md)다. 원본 명세의 D/R/U/I/P ID는 당시 요구사항의 근거로 보존하며 영역 지원은 아래 RECT ID로 추가한다. 과거 D19의 2×2 거절 PASS를 이번 영역 지원 PASS로 바꾸지 않는다.

## 범위와 금지 동작

수정 대상은 사용자가 선택한 연속 사각형 영역 안에서 가시 상태가 확인된 셀의 내용이다. 숨김·선택 밖 셀, 원본 통합문서, 다른 제품, 사용자 설정·신뢰 센터와 일반 문서를 설치기가 수정하지 않는다. 자동 저장·원본 재계산·네트워크·텔레메트리는 없다. 이름·사번 매칭, 정렬, 빈칸 제거, 개수 맞추기, 전체 행·열 자동 축소, TSV로의 모호한 자동 강등을 하지 않는다.

## 데이터 계약

Empty / String / Number / Boolean / Error를 구분하며 실제 빈칸도 한 항목이다. 수식은 복사 시점 계산 결과만 사용한다. 숫자 123에 표시 형식 00000을 적용한 값은 문자열 00123과 다르다. 날짜 체계 자동 보정은 하지 않는다. 최대 50,000항목·선택 200,000셀·페이로드 32 MiB·20,000가시 구간은 초기 설계 제한이며 검증된 처리 속도를 뜻하지 않는다.

원본의 숨김 행·열은 클립보드 메타데이터로 제외하며 원본 셀을 다시 읽지 않는다. 영역은 보이는 행 수와 열 수가 각각 같아야 한다. `2×3`과 `3×2`는 같은 여섯 항목이어도 다르다. 예외는 기존 한 행 원본을 같은 항목 수의 한 열 대상에 넣는 방식뿐이다. 여러 행·열 원본을 임의로 펼치지 않는다.

## UX와 복구

복사 → 범위 선택 → 우클릭 → 보이는 칸에 붙여넣기. 수식 덮어쓰기·내용 비우기·대량 조건은 한 확인 창에 모은다. 실패 전에 수정하지 않았는지, 수정 후 복구를 확인했는지, 복구가 불완전한지를 구분해 알린다. 최근 한 번 되돌리기의 안전 조건과 한계는 [되돌리기 안전성](../../../tools/VisibleCellsPaste/docs/undo-safety.md)에 기록한다.

## 설치·검증·배포 기록

MSI 기본 위치는 %LOCALAPPDATA%\Programs\VisibleCellsPaste이며 HKCU의 자기 등록만 소유한다. 이전 EXE·ZIP의 기본 위치는 %LOCALAPPDATA%\VisibleCellsPaste다. 기존 설치·다른 MSI 버전은 먼저 제거하고 설치한다. 개발 도구는 제작 환경에만 필요하다. 서명과 조직 승인은 미결정이며 서명 없는 배포물을 승인된 상용 배포로 표현하지 않는다. 정상 시작 증거 없이 자동 로드 PASS를 부여하지 않는다. 원본 명세의 변경 없는 사본은 [원본 작업지시](original-specification.md)다.

## 현재 요구사항 차이와 조치

- 2026-10-21 사용자 요청으로 원본 명세 3절의 한 행·한 열 원본/한 열 대상 제한을 영역 지원으로 확장한다. 원본 문서는 변경하지 않으며 ADR-0037과 RECT 기준을 추가한다. 기존 공개 0.1.2 설치본의 변경이나 설치 완료를 뜻하지 않는다.
- REQ-VCP-007의 날짜·시간: XML DateTime만으로 숫자를 추정하지 않고 같은 sequence의 제한적 Biff12 숫자 보완을 사용합니다. XML/native의 비날짜 항목·타입·좌표가 일치해야 하며 날짜 체계 자동 보정은 없습니다. 실제 시험 범위는 D17/D18에 기록하며 확정 못하는 형식은 거절합니다.
- REQ-VCP-004/007의 최신 오류 종류: 8개 고전 Excel 오류 외의 오류는 지원 제외입니다. 알 수 없는 오류를 문자열로 강등하지 않습니다.
- REQ-VCP-001/018의 자동 로드·설치 수명주기: 비승격 설치 후 정상 Excel 시작·자동 연결·실제 우클릭 붙여넣기/Undo, 특수문자 경로 업그레이드·제거·제거 재실행과 기본 경로 재설치를 확인했습니다. 같은 기본 설치의 두 번 정상 시작도 확인했습니다. 다른 제품 동작·32비트 등은 시험 보고서의 개별 근거로 판정하며 COM DLL 제작만으로 통과 처리하지 않습니다.
- REQ-VCP-012의 Undo: 즉시 원래 선택, 이벤트 감지 가능, 기본 Undo 비활성 기준, 워크시트와 표의 기존 SortFields가 모두 비어 있어야 하는 보수적인 추가 제한이 있습니다. 기존 정렬 설정이 있으면 즉시 Undo도 비활성화됩니다. 감지되지 않은 외부 동시 자동화는 보장하지 않습니다.
