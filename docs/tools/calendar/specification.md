# 정적 달력 · 제품 명세

도구 ID: Calendar · 버전: 1.4.2 · 상태: 입력 정렬·높이 통일과 미리보기 너비 맞춤
제품 책임: 저장소 관리 담당(운영 담당자 미결정)
적용: [개발 기준](../../policies/tools.md), [문서 규칙](../../policies/documentation.md), [ADR-0036](../../design/0036-static-calendar.md)

## 사용자와 목적

기존 Workspace에서 다음 해 달력을 준비하는 사용자에게 연도·공식/수동 휴일 설정, 12개월 미리보기와 편집 가능한 XLSX를 제공한다. 원본 초안 명세의 달력 계산·인쇄·입력 계약을 유지하고 서버 proxy/메모리 캐시를 Actions와 정적 JSON으로 대체한다. 첨부 XLSX는 형식 참고이며 최신 명세의 A:G·무수식 계약을 우선한다.

## 좌표·출처·입력 계약

사용자의 인쇄 상단 정리 요청에 따라 최초 연간 제목·출처·범례 셀을 제거한다. 기존 좌표 호환을 위해1~4행은 숨김 빈행이며 인쇄영역은A5:G마지막행이다. 출처·수집/생성 시각·모드·fixture 구분은 OOXML 문서 속성에 보존한다. 월 시작 s=5, 요일 s+1, 날짜 s+2+4q, 작성 r+1~r+3, 다음 월 s+3+4w, w=ceil((offset+days)/7). 월제목12개 외 병합 없음. 2027년1월1일 F7, 작성 F8:F10,1월31일 A27,2월제목32행. 인쇄 마지막 구분행 제외.

공식/일요일 빨강,토요일 파랑,평일 수동 보라. 같은 이름은 표시만 정리하고 model.sources에는 각 출처를 유지한다. 날짜행 이름은 자르지 않으며409pt 초과 시 명시적 오류다. 수식 모양 이름도 inline string이다. 시트 보호·매크로·수식·외부링크·데이터연결은 없다.

2026-10-11 사용자 요청으로 공식 휴일 이름의 ‘기독탄신일’을 ‘크리스마스’로 표시한다. ‘대체공휴일(기독탄신일)’도 ‘대체공휴일(크리스마스)’로 표시한다. 미리보기·XLSX는 공통 `holidayDisplayName` 규칙을 사용한다. 원본 JSON과 불변 snapshot/sources의 이름·sourceId·수집 시각은 유지하고 개인/회사 수동 이름은 바꾸지 않는다. 날짜 행은 변환된 표시 이름으로 공식 우선·이름 정렬·동일 이름 표시 중복 정리를 수행하며 출처 항목을 삭제하지 않는다.

## 화면과 서식

정상 상태는 연도 범위1983~2099년만 안내하고 공휴일 읽기·출처 설명·전체 연도별 준비 목록·별도 공식 목록·상시 주의사항은 표시하지 않는다. 공식 휴일은 달력 날짜 안에서 확인한다. 미제공·오류·35일 초과와32일 이상 stale는 필요한 순간에만 안내하고 공식 다운로드 차단·동의를 유지한다. 수동 모드는 ‘공휴일 없이 내 일정만 사용’으로 명시적으로 선택한다. 연도 변경의 일정 폐기 확인과 빈 수동 달력 재확인은 유지한다. 개인·회사 입력은 브라우저 메모리만 사용한다.

‘내 일정 추가’의 날짜·일정 이름·구분·추가 버튼은 한 가로 행이다. 작은 화면은 입력 행만 가로 스크롤하고 키보드로 이동할 수 있다. 서식과 색상은 접을 수 있는 영역이며 기본 서식 복원 버튼을 제공한다. 글꼴(맑은 고딕/Arial/바탕), 날짜·일정 글자8~16pt, 월 제목14~24pt, 작성칸 높이16~32pt와 평일·일요일/공휴일·토요일·일정·제목 글자, 제목·요일·날짜/작성칸·날짜 없는 칸 배경, 테두리 색상을 지정한다. 색상은 검증된6자리HEX, 숫자는 범위 내 정수만 허용한다. 날짜 행 높이는 선택 글꼴 크기와 긴 이름에 맞춰 계산하고 초과 시 차단한다.

연도 안내는 `(범위 : 1983~2099)`이며 연도·날짜·이름·선택값·서식 입력과 버튼의 텍스트를 가운데 정렬한다. 일정 입력행의 날짜·이름·구분·추가 버튼은 동일한 2.7rem 높이와 줄 높이를 사용한다. 미리보기 영역이 기존 달력 최소 너비 780px보다 좁으면 테두리를 포함한 종이 전체를 비례 축소하여 처음부터 일~토 모든 열을 표시한다. 창 크기 변경과 페이지 재진입 때 다시 맞추며 기존 인스턴스의 ResizeObserver는 페이지 이탈 때 해제한다. 이 화면 배율은 모델·XLSX의 글자 크기·셀 높이·인쇄 설정에 영향을 주지 않는다.

서식은 같은 불변 CalendarModel에 포함하며 변경하면 기존 미리보기와 다운로드를 무효화한다. 미리보기에는 XLSX와 같은 색상·글꼴·크기·행높이를 사용하며 사이트의 밝은/어두운 테마 색상은 달력 종이에 전파하지 않는다. Excel과 브라우저의 글꼴 렌더링·인쇄 축소 비율까지 픽셀 단위 일치를 약속하지 않는다. 높은 글자·작성칸 설정은 A4 높이 자동 정책에 따라 한 달이 여러 페이지가 될 수 있다.

## 음력 날짜 선택

음력 표시는 기본 끔이며 켜면 양력 날짜 바로 오른쪽에 `1 (MM.DD)` 형식으로 넣는다. 두 자리 월·일을 사용하고 휴일·일정 이름은 다음 줄을 유지한다. 윤월도 요청한MM.DD표시를 유지하며 내부 lunar.isLeapMonth와 미리보기 날짜의 접근성 설명에 구분을 보존한다. 음력값·서식·날짜는 동일 불변 model에 포함하여 미리보기와 XLSX가 일치한다. 옵션을 바꾸면 새 미리보기를 만들기 전까지 다운로드를 막는다.

음력 글자는 기본 7pt·회색 `#777777`으로 양력 기본 10pt보다 작게 표시한다. 서식 설정에서 `lunarFontSize`(6~16pt 정수), `lunarColor`(6자리 HEX)를 따로 지정하며 양력·휴일·일정의 크기와 색상은 기존 설정을 유지한다. 사용자가 더 큰 음력 크기를 선택하는 것도 허용한다. 불변 `displayRuns`가 양력·음력·휴일별 텍스트·크기·색상을 함께 담고 미리보기 span과 OOXML inline rich text가 같은 값을 사용한다. 괄호에도 음력 서식을 적용하고 줄바꿈·텍스트·날짜 좌표는 유지한다. 큰 음력 설정도 행 높이 추정에 반영하며 작성칸에 문자를 넣지 않는다. 음력을 끄면 기존 단일 문자열 셀을 유지한다. 기본 서식 복원과 설정 변경의 미리보기·다운로드 무효화는 음력 전용 설정에도 동일하게 적용한다.

사용자는 한국 음력 기준으로 대조 가능한 범위만 제공하기로 명시적으로 선택했다. 따라서 달력 선택은1983~2099년을 유지하지만 음력은1983~2050년까지만 제공한다. 2051년 이후로 바꾸면 음력 선택을 해제·비활성화하고 해당 옵션 옆에 지원 범위를 짧게 표시한다. 중국음력이나 브라우저Intl의 근삿값으로 조용히 대체하지 않는다.

한국천문연구원 기준임을 명시한 고정 버전 변환표에서 생성한 정적 월시작표를 사용한다. 생성 도구·정확한 버전·라이선스·원출처와 검증 한계는 tools/calendar/LUNAR-DATA.md에 기록한다. 매월 공휴일 Actions수집과 음력표는 별개이며 브라우저가 API나 외부서비스를 호출하지 않는다. 재현생성 검사와 전체 지원 일자의 독립 변환 비교, 2017/2033 차이·윤월·연도경계·옵션on/off를 검증한다.

## 경계·실패·운영

2026-10-11 배포 후 요청으로 정기 수집은 일일에서 월 1회로 변경한다. 수동 수집은 GitHub Actions의 collect 실행으로 진행하며 프런트엔드는 공개 JSON을 자동으로 읽고 선택 연도를 반영한다. 사용자가 32일 이상 경고·35일 초과 차단을 선택했다. 가장 긴 월간 간격 31일과 하루의 지연 여유를 포함하며, 수집 실패로 보존한 자료는 경과 시간과 관계없이 명시적 동의를 요구한다. 새로고침 또는 연도 선택은 KASI 수집을 실행하지 않는다.

2026-10-11 후속 요청에서 사용자가 1983~2099년 선택과 완료 후 원격 반영·최초 실수집·배포를 승인했다. 이 범위가 최초의 올해/다음 해 공식 조회 범위를 대체한다. 117개 연도의 자료 제공을 보장하지 않으며 미제공 연도는 명시적 수동 모드만 허용한다. 정상 0건의 선택 연도가 있더라도 현재 해 수집 성공과 실제 오류 없음이 확인되면 준비/미준비 상태를 함께 게시한다. 기존 완전 자료가 0건으로 바뀌거나 현재 해 0건, HTTP·업무·검증 오류가 있으면 이 예외에 포함하지 않고 배포를 건너뛴다. 기존 XLSX 형식과 수동 입력·날짜 계산 규칙은 유지한다.

상시 서버·계정·저장·개인 일정 전송·기존 XLSX 재업로드는 없다. 사용자가 선택하는 로컬 일정 JSON 백업·가져오기를 지원한다. 공식 자료 원문과 오류 객체를 로그/브라우저/커밋으로 보내지 않는다. 12개월 완료는 향후 임시공휴일 확정과 다르며 다운로드 파일은 자동 갱신되지 않는다. 연도 변경은 수동목록 폐기를 확인하고 빈 수동 모드는 별도 재확인한다.

버전 schema와 영속 복구, 설치 없는 사용, 환경변수·권한·활성화 순서는 [운영 안내](../../../tools/calendar/README.md), 실제 결과·미실행은 [검증 기록](../../delivery/calendar-20261011.md)을 따른다. 최초 원본 명세 텍스트는 `original-specification.txt`로 보존하며 공개 사이트에 싣지 않는다.

2026-10-13 후속 요청: 일정 JSON 파일은 format/version/year/entries만 담으며 최대128KiB·100개다. 전체 검증 후 대체 확인하며 취소·오류는 목록·편집 입력·미리보기를 보존한다. 성공은 새 미리보기를 요구한다. 서버 저장·자동 저장은 없으며 상세 계약은 운영 README를 따른다.
