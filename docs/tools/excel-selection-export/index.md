# 선택범위 내보내기 설치·사용

**선택범위 내보내기 0.1.0-rc.10 · 서명 없는 평가판** · 2026-09-27

Excel에서 선택한 범위의 **보이는 행과 열만 저장 전 새 통합문서**로 만듭니다. 필터와 숨김을 반영하고, 남은 셀의 순서·빈칸·기본 서식을 유지합니다. 수식은 현재 계산 결과로 내보냅니다. 명단 비교와 설치·메뉴·제거 항목이 별도인 제품입니다.

한 번 설치하면 Excel을 평소처럼 시작할 때 메뉴가 준비됩니다. 자동 실행은 메뉴 준비뿐이며 **사용자가 메뉴를 눌렀을 때만** 내보냅니다.

[자주 묻는 질문 바로 보기](#faq) · [선택한 범위를 내보내는 순서](#export)

## 다운로드 전에 확인하세요 {#limits-before-download}

현재 PC의 Windows 11·Excel x64에서 실제 설치, 자동 메뉴 준비, 우클릭 내보내기, 결과 창 표시와 정상 UI 종료를 확인했습니다. **전체 인수와 조직 배포 승인은 완료되지 않았습니다.** 다음 제한을 확인한 뒤 평가 용도로 사용하세요.

| 확인할 점 | 이번 버전의 실제 결과·제한 |
|---|---|
| **원본의 실행 취소 기록** | rc.10에서 출력 생성 경로를 분리했습니다. 실제 메뉴 실행 후 원본 편집 3단계의 Undo 3회·Redo 3회를 확인했습니다. 모든 추가 기능·문서 조합에서의 보존을 보장하는 것은 아닙니다. |
| **API 시험 뒤 Excel 종료** | 과거 시험에서는 창 없는 Excel 잔존이 관찰됐습니다. 후속 시험에서 시험 도구의 COM 참조 반환과 실제 종료 판정을 보완했고, 현재 PC의 설치 전후·API 기능 실행 후 자연 종료를 확인했습니다. 기존 도구 대조에서도 재현되지 않아 과거 원인은 확정하지 않았습니다. |
| **설치 전후 설정 비교** | 개발 중 rc.5 설치 전후 비교는 **33개 범위 중 29개 동일, 4개 변경**으로 전체 실패입니다. 바뀐 곳은 사용자 Excel의 Options·Resiliency 설정의 32/64비트 보기이며 원인은 특정하지 못했습니다. 보안·정책·다른 추가 기능 등록·기존 제품 파일은 비교 범위에서 동일했습니다. 이를 모든 설정의 무변경 보장으로 해석하지 마세요. |
| **아직 실행하지 않은 시험** | Excel x86 실제 실행, 새 사용자·격리 VM, 재로그인·재부팅, 모든 취소·실패 단계, ACL·강제 중단은 미실행입니다. 현재 PC의 제거와 네 도구 대표 기능·순차 제거 공존을 확인했지만 전체 환경·모든 업데이트 조합을 검증한 것은 아닙니다. |
| **서명과 회사 정책** | 설치 파일에 코드 서명이 없습니다. 회사의 설치 허용·서명 조건·배포 승인은 미확정입니다. 보안 설정을 낮추거나 차단을 해제하는 방식으로 사용하지 마세요. |

셀 안에 글꼴이나 첨자 상태가 섞인 서식과 그라데이션 배경은 현재 지원하지 않아 중단합니다. Arial에 한글을 입력한 셀도 Excel의 자동 대체 글꼴 때문에 혼합 상태가 될 수 있습니다.

## 한 번 설치하고 메뉴 사용하기 {#install}

1. 필요한 작업을 저장하고 Excel 창을 모두 닫습니다.
2. Excel 비트수에 맞는 **ExcelSelectionExport-0.1.0-rc.10-x64-Setup.exe** 또는 **ExcelSelectionExport-0.1.0-rc.10-x86-Setup.exe**를 실행합니다.
3. 설치를 마친 뒤 Excel을 평소처럼 엽니다.
4. 셀을 우클릭해 **선택범위 내보내기 → 새 Excel로** 메뉴를 확인합니다.

현재 Windows 계정에 설치하며 관리자 권한·Python·개발 SDK가 필요하지 않습니다. 이후 Excel을 시작할 때 메뉴가 자동으로 준비됩니다. **Alt+F8·Alt+F11, VBA 코드 등록·실행, VBS 실행, 매크로 허용, 추가 기능 수동 체크는 사용 단계가 아닙니다.**

회사 정책이 설치나 추가 기능 로드를 차단하면 회사의 승인된 설치 절차를 따르세요. 설치기는 정책·Trust Center·매크로 보안을 낮추거나 Office가 비활성화한 추가 기능을 강제로 되살리지 않습니다.

## 선택한 범위를 새 Excel로 만들기 {#export}

1. 한 시트에서 필요한 **직사각형 셀 범위 하나**를 선택합니다. 제목이나 합계가 필요하면 함께 선택하세요.
2. 선택한 셀 안에서 우클릭합니다.
3. **선택범위 내보내기 → 새 Excel로**를 누릅니다.
4. 자동으로 열린 결과 통합문서를 확인합니다.
5. 보관하려면 Excel의 **저장**을 사용해 위치와 파일 이름을 정합니다.

한 셀과 가로·세로 목록도 선택할 수 있습니다. 결과는 같은 Excel 인스턴스의 **저장 전 통합문서·시트 한 개**입니다. 최종 결과의 저장 위치는 사용자가 정하며 원본 파일은 자동 저장하지 않습니다.

처리 중 별도 작업용 Excel과 사용자 임시 폴더의 제품 전용 경로에 중간 XLSX를 사용합니다. 정상 완료와 확인한 취소 경로에서는 정리하지만, 강제 종료하면 중간 파일이 남을 수 있습니다. 이 파일은 사용자가 저장한 최종 결과가 아닙니다.

필터와 수동 숨김으로 가려진 행·열은 제외하고 나머지를 원래 순서대로 연결합니다. 포함된 빈칸·빈 행·빈 열은 유지하며, 제목을 추정하거나 내용을 정렬하지 않습니다. 화면 밖으로 스크롤된 셀은 숨긴 셀이 아니므로 포함됩니다.

수식은 Excel이 보유한 계산 결과로 바뀝니다. 재계산이나 외부 연결 갱신을 강제하지 않습니다. 수동 계산 모드에서는 아직 재계산하지 않은 이전 결과가 나올 수 있으므로 결과가 최신인지 확인하세요. 다른 시트·매크로·외부 연결·정의 이름·메모·댓글·하이퍼링크·입력 제한 규칙은 가져오지 않습니다.

## 자주 묻는 질문 (FAQ) {#faq}

아래 답변은 **0.1.0-rc.10 평가판** 기준입니다. 알려진 실패와 미실행 시험은 [다운로드 전 제한](#limits-before-download)과 [실제 확인 범위](#verification)를 함께 보세요.

### 여러 시트 탭을 선택해도 새 파일로 만들어 주나요? {#faq-tabs}

현재는 **한 시트에서 선택한 직사각형 범위 하나**만 지원합니다. 여러 탭을 함께 선택하면 “시트를 하나만 선택한 뒤 내보내 주세요.”라는 안내와 함께 중단합니다. 결과에도 시트 한 개만 만들어집니다.

### 시트 탭 자체를 별도 파일로 저장하는 기능은 Excel에도 있나요? {#faq-excel-copy}

네. Windows 데스크톱 Excel의 기본 **이동/복사** 기능을 사용할 수 있습니다.

1. 복사할 탭을 선택합니다. 여러 탭은 **Ctrl을 누른 채 클릭**합니다.
2. 선택한 탭을 우클릭하고 **이동/복사**를 누릅니다.
3. 대상 통합문서에서 **(새 통합 문서)**를 고릅니다.
4. 원본 시트를 유지하도록 **복사본 만들기**를 체크한 뒤 확인합니다. 체크하지 않으면 원본에서 시트가 이동합니다.
5. 열린 새 통합문서를 확인하고 저장합니다.

여러 탭을 고르면 **하나의 새 파일 안에 여러 시트**로 들어갑니다. 탭마다 각각 다른 파일이 필요하면 한 탭씩 이 작업을 반복하세요. [Microsoft의 시트 별도 저장 안내](https://support.microsoft.com/en-us/excel/save-a-worksheet)

Excel 기본 기능은 수식과 숨긴 행·열을 포함한 **시트 전체**를 복사합니다. 선택범위 내보내기는 **지정한 범위의 보이는 행·열과 현재 값, 지원하는 기본 서식**을 새 시트 하나로 만듭니다.

### 필터를 걸거나 행·열을 숨긴 상태에서도 내보낼 수 있나요? {#faq-visible}

네. 필터로 제외된 행과 수동으로 숨긴 행·열을 빼고, 남은 셀을 원래 순서대로 이어 붙입니다. 예를 들어 선택한 A1:C10에서 1·4·7행만 보이고 B열을 숨겼다면 결과는 **3행 × 2열**이 됩니다. 숨김으로 빠진 자리는 압축되지만, 남은 셀 안의 빈칸은 유지됩니다.

원본의 필터 조건이나 숨김 설정을 결과에 복사하지는 않습니다. 결과에는 내보낸 행·열이 모두 보입니다. 필요한 제목·합계도 직접 선택 범위에 포함하세요.

### 화면 밖으로 스크롤된 셀은 제외되나요? {#faq-scroll}

아닙니다. 여기서 ‘보이는 셀’은 **필터나 행·열 숨김으로 가려지지 않은 셀**을 뜻합니다. 선택 범위에 포함돼 있다면 스크롤 때문에 화면 밖에 있는 셀도 내보냅니다. 현재 화면에 보이는 부분만 필요하면 그 셀들로 선택 범위를 줄이세요.

### 수식은 값으로 복사하나요? 수식을 유지하는 옵션도 있나요? {#faq-values}

**항상 현재 계산 결과 값으로 내보냅니다. 수식 유지 옵션은 없습니다.** 숫자·날짜·백분율 등의 표시 형식과 기본 셀 서식은 유지합니다.

예를 들어 **수식의 숫자 결과 1500이 표시 형식 때문에 `1,500원`으로 보인다면**, 결과에는 숫자 1500과 해당 표시 형식이 들어갑니다. `TEXT` 함수나 문자 결합으로 만든 `1,500원`은 문자열로 유지합니다. 수식은 남지 않으므로 원본의 값이 나중에 바뀌어도 내보낸 결과는 자동으로 바뀌지 않습니다.

재계산이나 외부 연결 갱신을 강제하지 않습니다. **수동 계산 모드에서는 이전 계산 결과가 나올 수 있으므로**, 최신 값이 필요하면 원본에서 계산이 완료된 상태인지 확인한 뒤 내보내세요.

### 원본과 똑같은 모양으로 나오나요? {#faq-format}

글꼴·크기·색·배경·테두리·정렬·줄바꿈·숫자 표시 형식·행 높이·열 너비 같은 **기본 서식이 보존 대상**입니다. 화면을 그림처럼 완전히 복제하는 기능은 아닙니다.

조건부 서식은 현재 보이는 글자색·배경색 등의 효과를 고정된 서식으로 옮기며, 조건부 규칙은 가져오지 않습니다. 아이콘·데이터 막대는 제외 안내 후 진행할 수 있습니다. 도형·차트·이미지·스파크라인도 내보내는 대상이 아닙니다.

**셀 전체에 같은 상태로 적용된 위 첨자·아래 첨자는 지원합니다.** 셀 안에서 글꼴이나 첨자가 섞인 경우와 그라데이션 배경은 지원하지 않아 중단합니다. 한글의 자동 대체 글꼴 때문에 혼합 상태로 감지되는 경우도 있습니다. 세부 항목의 실기 검증 여부는 [이번 버전에서 확인한 범위](#verification)를 보세요.

### 떨어진 셀들을 Ctrl로 고르거나 전체 행·열을 선택해도 되나요? {#faq-selection}

한 셀이나 이어진 직사각형 범위는 가능합니다. **Ctrl로 고른 떨어진 여러 범위, 전체 행·열·시트 선택은 지원하지 않습니다.** 필요한 셀 범위를 한정해 선택하세요.

필터나 숨김이 적용돼 있어도 필요한 직사각형 범위를 그대로 선택하면 됩니다. 도구가 숨긴 행·열을 판별하므로 별도로 ‘보이는 셀만 선택’을 먼저 할 필요는 없습니다.

### 빈칸·제목·합계·병합 셀은 어떻게 되나요? {#faq-layout}

선택 범위에 포함되고 숨기지 않은 빈칸·빈 행·빈 열은 유지합니다. 제목과 합계는 사용자가 포함한 경우에만 가져오며 자동으로 추가하거나 정렬하지 않습니다.

병합 셀은 **병합 영역 전체가 선택되고 그 행·열이 모두 보일 때** 다시 병합합니다. 일부만 포함하거나 숨김 때문에 잘리면 중단합니다. 필요한 병합 영역 전체가 들어가도록 선택 범위를 확인하세요.

### 결과 파일은 어디에 저장되나요? 원본 파일을 덮어쓰나요? {#faq-save}

메뉴를 누르면 같은 Excel 인스턴스에 **아직 저장하지 않은 새 통합문서**가 열립니다. 저장 위치를 자동으로 정하거나 원본 파일을 덮어쓰지 않습니다.

결과를 확인한 뒤 **Ctrl+S 또는 파일 → 저장**에서 원하는 위치와 이름으로 저장하세요. 보관하지 않을 결과라면 저장하지 않고 닫으면 됩니다.

### 원본의 수식이나 필터가 바뀌나요? 실행 취소도 유지되나요? {#faq-original}

원본의 값·수식·기본 서식·필터·숨김 상태를 변경하거나 원본을 자동 저장하지 않도록 구현했고, 실제 시험에서도 해당 전후 동일 검사를 통과했습니다.

rc.9에서는 내보내기 후 원본 Undo가 비활성화됐습니다. rc.10은 출력 작성 경로를 분리했으며 실제 메뉴 실행 후 원본 편집 3단계를 Undo·Redo로 각각 되돌리는 검사를 통과했습니다. 내보낸 결과의 값은 원본을 되돌려도 바뀌지 않습니다. 다른 추가 기능과 모든 문서 조합까지 확인한 것은 아니므로 중요한 편집은 저장해 두세요.

### 큰 범위는 어디까지 처리하나요? 중간에 취소할 수 있나요? {#faq-limits}

입력은 숨긴 셀을 포함해 **1,000,000칸**, 결과는 보이는 셀 **100,000칸**, 원문 문자열 합계는 **10,000,000자**까지입니다. 숨긴 셀이 많아 결과가 작더라도 입력 한도를 넘으면 중단합니다. 한도를 넘는 데이터를 조용히 잘라내지 않으므로 범위를 나누어 실행하세요.

보이는 셀이 20,000개를 넘으면 시작 전에 확인합니다. 오래 걸리는 작업은 진행 창의 **취소**를 누른 뒤 종료될 때까지 기다리세요. 미완성 결과만 정리하도록 구현했습니다. 정확한 상한의 성공·성능과 모든 단계의 취소를 실제로 검증한 것은 아닙니다.

### Excel을 열 때마다 매크로나 추가 기능을 따로 실행해야 하나요? {#faq-startup}

아니요. 한 번 설치하면 Excel 시작 시 메뉴가 자동으로 준비됩니다. **내보내기는 사용자가 메뉴를 눌렀을 때만** 실행합니다. Alt+F8·Alt+F11, VBA·VBS 실행, 매크로 허용, 추가 기능 수동 체크는 사용 단계가 아닙니다.

설치 파일은 Windows가 아닌 **Excel의 32/64비트**에 맞춰 고르세요. 메뉴가 없거나 회사 정책에 의해 차단된 경우에는 [설치 안내](#install)와 [문제 해결](#troubleshooting)을 확인하세요. 보안 설정을 낮추는 방식으로 해결하지 않습니다.

## 서식·선택 범위와 처리 한도 {#supported-range}

| 항목 | 처리 방식 |
|---|---|
| 값과 기본 서식 | 문자열의 앞자리 0, 숫자·날짜 기준·표시 형식, 글꼴·색·배경·테두리·정렬·줄바꿈·행 높이·열 너비를 유지하도록 구현했습니다. |
| 첨자 | 셀 전체에 같은 상태로 적용된 위 첨자·아래 첨자는 유지합니다. 셀 안에서 상태가 섞이면 중단합니다. |
| 조건부 서식 | 현재 보이는 글자색·배경색 등의 효과를 정적 서식으로 옮기고 규칙은 옮기지 않습니다. 데이터 막대·아이콘은 제외 안내를 확인한 뒤 진행할 수 있습니다. |
| 병합 | 병합 영역 전체가 선택되어 있고 해당 행·열이 모두 보일 때 재구성합니다. 일부만 포함되거나 숨김으로 잘리면 중단합니다. |
| 선택할 수 없는 대상 | Ctrl로 떨어진 여러 범위, 전체 행·열·시트, 여러 시트 동시 선택, 차트·개체, 보호된 보기입니다. 필요한 셀 범위 하나를 선택하세요. |
| 입력 범위 | 숨긴 셀을 포함해 **1,000,000칸**까지입니다. |
| 결과 범위 | 보이는 셀 **100,000칸**, 원문 문자열 합계 **10,000,000자**까지입니다. |

한도를 넘으면 범위를 나누어 다시 선택해야 합니다. 데이터를 조용히 잘라내지 않습니다. 한도 값까지 모든 데이터 조합의 완료 시간과 응답성을 검증한 것은 아닙니다.

보이는 셀이 20,000개를 넘으면 시작 전에 한 번 확인합니다. 오래 걸리는 작업에는 진행 단계와 **취소** 버튼이 나타납니다. 취소를 누른 뒤 종료될 때까지 기다리세요. 실패·취소 시에는 이번에 만든 미완성 결과만 정리하도록 구현했습니다.

## 업데이트·제거하기 {#maintenance}

새 버전 설치 파일을 실행하면 별도 버전 폴더에 설치됩니다. 이미 열린 Excel은 기존 코드를 계속 사용하므로 작업을 저장하고 Excel을 모두 닫았다가 다시 열어야 새 버전이 적용됩니다.

같은 버전을 다시 설치하거나 제거하려면 먼저 모든 Excel 창을 닫으세요. Excel 실행이 감지되면 설치·제거를 중단하고 종료 안내를 표시합니다. 설치기가 열린 문서를 강제로 닫거나 저장하지 않습니다.

제거는 **Windows 설정 → 앱 → 설치된 앱 → 선택범위 내보내기 → 제거**를 사용합니다. 원본과 사용자가 저장한 결과 파일은 제거 대상이 아닙니다. 명단 비교의 메뉴·설치·제거 항목도 별도입니다. 현재 PC에서 제거 후 소유 파일·등록·메뉴 정리와 기존 명단 비교 메뉴 보존을 확인했습니다.

## 메뉴가 없거나 작업이 중단될 때 {#troubleshooting}

| 증상 | 확인할 일 |
|---|---|
| 설치 후 메뉴가 없어요 | Excel 비트수에 맞는 파일인지 확인하고, 작업을 저장한 뒤 모든 Excel 창을 닫았다가 다시 여세요. 정책 차단 안내가 있으면 회사 담당자에게 승인 절차를 확인하세요. |
| 범위를 다시 선택하라고 해요 | 한 시트의 직사각형 셀 범위 하나로 줄이세요. 병합이 있으면 전체 병합 영역과 그 행·열이 모두 보이는지 확인하세요. |
| 혼합 글꼴·서식을 처리할 수 없다고 해요 | 셀 안의 글꼴·첨자 혼합이나 그라데이션이 포함됐을 수 있습니다. 지원하지 않는 셀을 제외한 범위로 다시 선택하세요. 한글 자동 대체 글꼴도 해당할 수 있습니다. |
| 계산 중이거나 Excel 이벤트가 꺼져 있다고 해요 | 계산이 끝난 뒤 시도하세요. 이벤트 관련 안내가 계속되면 작업을 저장하고 Excel을 정상 종료한 뒤 다시 여세요. |
| Excel 창을 닫았는데 설치·제거가 계속 막혀요 | 과거 API 시험에서 창 없는 Excel이 남았으며 후속 시험에서는 재현되지 않았습니다. 다른 작업이나 자동화가 있는지 확인하고 담당자에게 문의하세요. 열려 있는 업무 문서나 소유권을 모르는 프로세스를 강제 종료하지 마세요. |

문의할 때는 제품 버전, Excel 버전·비트수, 실행 순서와 안내 문구를 적어 주세요. 원본 문서·개인 경로·설치 로그를 그대로 공개하지 마세요.
