# FolderState · 대상 확인과 결과 안내 개선 명세

도구 ID: FolderState  
버전·상태: 0.1.3 RC1 · 사용성 개선 구현
제품 책임: 제품·개발 담당  
적용 정책: [추가 도구 개발 기준](../../policies/tools.md), [정책 문서 작성 규칙](../../policies/documentation.md)  
관련 ADR: [ADR-0007](../../design/0007-folderstate-usability.md)

## 사용자와 목적

관리 화면에서 폴더를 바꾸거나 아이콘 저장 위치를 바꾸는 사용자가 대상과 저장 결과를 확실하게 알 수 있도록 합니다. A 폴더를 조회한 뒤 경로만 B로 편집하면 A의 상태를 보면서 B에 적용할 수 있었고, 상태 없는 B에도 A의 아이콘 저장 방식과 작업 결과가 남았습니다. 이 문제는 소스 검토에서 확인했으며 실제 사용자 시험으로 빈도를 측정한 것은 아닙니다.

[최초 명세](../../specifications/01.md)의 상태·화면 표현 분리와 기존 설정 보존 원칙을 구체화합니다. 조직의 업무 상태 판단 기준은 새로 정하지 않습니다.

## 범위와 금지 동작

관리 화면의 단일 폴더 흐름과 Core의 `ChangeMode`를 추가합니다. 업무 폴더를 이동하거나 이름을 바꾸지 않습니다. 선택한 폴더의 고정 메타데이터와 아이콘만 다루며 하위 목록 검색·업무 파일 내용 열람·외부 전송을 추가하지 않습니다.

여러 폴더 선택·끌어놓기, 실행 취소, Windows 11 첫 메뉴 통합, 탐색기 성공 알림, 작업 기록 전용 화면은 구현하지 않은 후속 검토 대상입니다. 기존 CLI의 명시 목록 처리와 탐색기 단일 폴더 메뉴는 유지합니다.

## 데이터 계약

`.folderstate.ini`의 형식 2와 기존 상태값을 유지합니다. `ChangeMode(folder, mode)`는 기존 상태가 있을 때만 실행하며 Status와 Updated를 보존합니다. 로그의 action에는 `change-mode`를 기록합니다. UI의 상태 버튼은 저장된 모드를 유지하고, 상태가 없는 폴더의 첫 상태는 Local로 저장합니다.

외부 메타데이터, 기존 사용자 아이콘과 알 수 없는 정보의 보존 규칙은 [구조와 데이터 계약](architecture.md)을 따릅니다. 별도 모드 변경도 기존 소유 확인·잠금·트랜잭션을 사용합니다.

## UX

- 시작·경로 편집: 확인 필요를 표시하고 이전 폴더에 대한 정보와 작업 결과를 지웁니다.
- 읽는 중·적용 중: 중복 동작과 대상 편집을 막고 진행 사실을 알립니다.
- 빈 상태: 네 상태 중 하나를 바로 저장할 수 있습니다. 아이콘 위치 변경은 첫 상태를 저장한 뒤 가능합니다.
- 현재 상태: 폴더명·전체 경로·저장된 상태·상태 변경 시각·아이콘 위치를 함께 보여줍니다.
- 성공·주의·실패: 대상과 작업 결과를 표시하고 ‘탐색기에서 보기’·‘문제 해결 안내’로 이어집니다. 추가 조회 실패는 저장 결과와 구분합니다. ‘문제 해결 안내’는 동봉 도움말 전체를 열며 오류별 페이지 자동 선택은 구현하지 않습니다.
- 미적용 위치 선택: 상태 저장·아이콘 다시 표시·폴더 확인 후 읽기에 성공하면 선택 표시를 저장된 위치로 갱신합니다. 미적용 선택을 이후 작업까지 보관하지 않습니다.
- 상태 지우기: 설명을 펼쳐 결과를 확인한 뒤 ‘상태 표시 지우기’를 누릅니다. ‘시작 전’으로 바꾸는 기능과 구분합니다.
- 취소: 폴더 선택 창을 취소하면 기존 확인 대상이 유지됩니다. 시작한 저장 작업의 중간 취소 기능은 추가하지 않습니다.
- 접근성: 키보드 Enter와 명시적인 확인 버튼, 색 이외의 결과 문구·기호, 화면 읽기 이름·안내를 제공합니다. 실제 키보드·화면 읽기·배율 검증 결과와는 구분합니다.

## 동시 실행과 복구

폴더별 잠금과 외부 변경 충돌 검사를 유지합니다. 확인한 뒤 폴더 내용이 달라져도 엔진이 실제 변경 시점에 다시 검사합니다. `recovery_pending`은 일반적인 읽기 실패와 구분하여 복구 버튼을 제공하며, 복구 후 저장 상태가 없으면 새 상태를 고를 수 있게 합니다.

아이콘 저장 위치 변경 중 중단·오류가 나면 기존 트랜잭션 기록으로 복원합니다. 외부에서 바뀐 파일은 강제로 덮어쓰지 않습니다. 별도의 UI 실행 취소는 제공하지 않습니다.

## 설치·업그레이드·제거

일반 사용자 실행, HKCU 메뉴, 자체 포함 Windows MSI와 기존 설치·제거 방식을 유지합니다. 현재 안내 버전은 **0.1.3 RC1**이며 이 사용성 변경을 포함합니다. [배포 기록](../../delivery/releases-20260920.md)에서 검증 결과와 게시 상태를 확인합니다.

## 검증·지원

필수 검증은 FolderState 엔진 테스트, UI 회귀 시험, WPF smoke 렌더, 문서 strict 빌드와 생성된 로컬 링크 검사입니다. 새 `ChangeMode`에는 중단 쓰기, 롤백, 동시 작업, reset 호환성 검증이 필요합니다.

실제 최초 사용자 시험, 화면 읽기, 고대비, 150/200% 배율, 공유·동기화·회사 보안 환경, 새 설치 파일의 설치 수명주기는 별도 검증 대상입니다. 이 문서 작성만으로 통과로 표시하지 않습니다.
