# FolderState 사용 안내

폴더명과 업무파일을 유지하면서 Explorer의 폴더 아이콘에 진행상태를 표시합니다.

| 상태 | 내부값 | 표시 | 판단 |
|---|---|---|---|
| 미착수 | todo | 회색 원 | 아직 시작하지 않음 |
| 진행 중 | doing | 파란 진행 표시 | 현재 작업 중 |
| 완료 | done | 초록 체크 | 담당자가 단계 완료 판단 |
| 이슈 | issue | 빨간 느낌표 | 문제·확인·결정 필요 |

상태 전이를 강제하지 않으며 완료를 자동 판정하지 않습니다. 색상과 함께 서로 다른 기호를 사용합니다.

## 왜 폴더명이 아닌 아이콘인가요?

`04_[X]_입과안내`처럼 상태를 이름에 넣으면 상태를 바꿀 때마다 경로도 달라집니다. 문서 링크·바로가기·스크립트·프로그램 설정에 영향을 줄 수 있으므로 FolderState는 폴더명을 고정하고 아이콘으로 상태를 표현합니다.

상태 변경은 선택 폴더의 고정 메타데이터만 다루며, 하위 항목을 열거하거나 업무파일의 내용을 읽고 수정하지 않습니다. 2026-09-12 검증 기록에는 업무파일 10,000개가 있는 시험 폴더에서 파일 수와 표본 내용이 유지된 결과가 있습니다. 이 결과가 모든 저장 환경의 성능이나 Explorer 표시를 보장하지는 않습니다.

## 탐색기에서 사용

1. [MSI 설치](installation.md)를 완료합니다.
2. 업무 단계 폴더 하나를 우클릭합니다.
3. Windows 11에서 **더 많은 옵션 표시 → 업무 상태**를 엽니다.
4. 원하는 상태를 선택합니다. 성공 시 별도 창을 띄우지 않습니다. 실패 시 원인을 표시합니다.

메뉴에는 미착수 / 진행 중 / 완료 / 이슈 / 상태 초기화 / 상태 아이콘 복구가 있습니다. 새 Windows 11 메뉴의 첫 화면에 직접 표시하는 확장은 후속 범위입니다.

## 관리 화면에서 사용

![FolderState 관리 화면: 대상 폴더 선택, 네 가지 상태, 초기화와 복구](../../assets/folderstate.png)

시작 메뉴의 FolderState를 열고 폴더를 선택하거나 전체 경로를 입력한 뒤 Enter를 누릅니다. 현재 상태를 확인하고 네 가지 버튼 중 하나를 누릅니다. “폴더와 함께 이동”을 선택하면 Portable Mode로 적용합니다.

Local은 설치된 아이콘 경로를 사용합니다. 다른 PC에 복사한 뒤 표시가 없어지면 그 PC에 설치하고 **상태 아이콘 복구**를 실행합니다. Portable은 선택 폴더 안에 아이콘을 함께 둡니다. 복사 도구·공유 저장소·보안 정책에 따른 표시 차이가 있을 수 있습니다.

## 초기화와 복구

**미착수 지정**은 `todo`를 저장합니다. **상태 초기화**는 도구의 상태정보를 제거하고 기존 아이콘을 복원합니다. 외부에서 수정한 다른 설정은 유지합니다. 복구는 저장된 상태를 기준으로 현재 PC의 아이콘을 재적용하며 업무 상태의 갱신 시각은 바꾸지 않습니다.

## MASTER를 복사해 사용하는 경우

상태를 표시하는 MASTER의 단계 폴더는 항상 **미착수(`todo`)**로 유지합니다. 진행·완료·이슈는 Active의 실제 회차에서만 사용하고, MASTER를 시험할 때는 시험용 복사본을 사용합니다. 정상적인 MASTER의 복사본을 매번 전체 초기화할 필요는 없습니다.

FolderState 미사용 MASTER에는 상태 파일이 없어도 됩니다. 상태 미지정이 자동으로 `todo`가 되지는 않으며 하위 폴더 자동 초기화 기능도 없습니다. 이전 상태가 남은 예외 처리와 다른 PC에서의 표시는 [업무 키트와 일정](../../policies/kits.md#events)을 참고하세요.

## 업무에서 상태를 판단하는 기준

완료는 필요한 결과물과 해당 업무에 필요한 승인·전달이 확인된 뒤 담당자가 선택합니다. 통상적인 회신 대기는 진행 중으로 유지하고, 기한 초과나 결정 없이는 진행할 수 없는 문제는 이슈로 판단하는 안을 제안합니다. [빠른 판단 기준](../../quick-reference.md#work)에서 기본 흐름을 확인할 수 있습니다.

회신 누락이나 인수인계 문제가 반복될 때만 기존 일정에 다음 행동·재확인일 등 필요한 항목을 보완합니다. 자세한 예시는 [진행·인수인계 개선안 — 선택 적용](../../policies/folder-workflow.md)을 참고하세요.

이 기준은 업무 운영 제안입니다. FolderState가 마감·승인을 확인하거나 상태를 자동 변경하지는 않습니다.
