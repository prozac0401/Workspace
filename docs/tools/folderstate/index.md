# FolderState 사용 안내

폴더명과 업무파일을 유지하면서 Explorer의 폴더 아이콘에 진행상태를 표시합니다.

| 상태 | 내부값 | 표시 | 판단 |
|---|---|---|---|
| 미착수 | todo | 회색 원 | 아직 시작하지 않음 |
| 진행 중 | doing | 파란 진행 표시 | 현재 작업 중 |
| 완료 | done | 초록 체크 | 담당자가 단계 완료 판단 |
| 이슈 | issue | 빨간 느낌표 | 문제·확인·결정 필요 |

상태 전이를 강제하지 않으며 완료를 자동 판정하지 않습니다. 색상과 함께 서로 다른 기호를 사용합니다.

## 탐색기에서 사용

1. [MSI 설치](installation.md)를 완료합니다.
2. 업무 단계 폴더 하나를 우클릭합니다.
3. Windows 11에서 **더 많은 옵션 표시 → 업무 상태**를 엽니다.
4. 원하는 상태를 선택합니다. 성공 시 별도 창을 띄우지 않습니다. 실패 시 원인을 표시합니다.

메뉴에는 미착수 / 진행 중 / 완료 / 이슈 / 상태 초기화 / 상태 아이콘 복구가 있습니다. 새 Windows 11 메뉴의 첫 화면에 직접 표시하는 확장은 후속 범위입니다.

## 관리 화면에서 사용

시작 메뉴의 FolderState를 열고 폴더를 선택하거나 전체 경로를 입력한 뒤 Enter를 누릅니다. 현재 상태를 확인하고 네 가지 버튼 중 하나를 누릅니다. “폴더와 함께 이동”을 선택하면 Portable Mode로 적용합니다.

Local은 설치된 아이콘 경로를 사용합니다. 다른 PC에 복사한 뒤 표시가 없어지면 그 PC에 설치하고 **상태 아이콘 복구**를 실행합니다. Portable은 선택 폴더 안에 아이콘을 함께 둡니다. 복사 도구·공유 저장소·보안 정책에 따른 표시 차이가 있을 수 있습니다.

## 초기화와 복구

초기화는 도구의 상태정보를 제거하고 기존 아이콘을 복원합니다. 외부에서 수정한 다른 설정은 유지합니다. 복구는 저장된 상태를 기준으로 현재 PC의 아이콘을 재적용하며 업무 상태의 갱신 시각은 바꾸지 않습니다.
