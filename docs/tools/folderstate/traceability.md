# 명세 대응표

원문은 [01 전체 명세](../../specifications/01.md)에 보존합니다. “구현”은 실제 운영 환경의 수동 검증 완료를 뜻하지 않습니다.

| 원문 절 | 요구 | 구현·결정 | 확인 방식 |
|---|---|---|---|
| 1–2 | 이름 고정, 업무파일 미접근, 상태·표현 분리 | 고정 파일 엔진 | 소스 점검·10,000파일 시험 |
| 3 | todo/doing/done/issue, 전이 자유 | 네 상태 모델 | 상태별 통합 테스트 |
| 4 | 네 상태·초기화·복구 메뉴 | HKCU 단일 폴더 메뉴 | MSI 구성·설치 시험 |
| 5 | .folderstate.ini와 desktop.ini | 소유·백업 필드 포함 | 메타데이터·속성 시험 |
| 6.1 | Local | 설치 폴더의 공용 아이콘 | 상태·복구 시험 |
| 6.2 | Portable 선택 | 관리 화면·CLI --mode | 전환·충돌·초기화 시험 |
| 7 | Unicode, 원자적 교체, 순회 없음 | 제한 읽기·동일 경로 교체·복원 기록 | 긴 경로·오류 주입 |
| 8 | 기존 desktop.ini 보존 | 원본 백업·소유 키 조건부 복원 | 원본 바이트·외부 수정 시험 |
| 9 | Windows 11 MVP 메뉴 | 더 많은 옵션 표시 | 새 메뉴 직접 확장은 후속 |
| 10 | 폴더명 모드 기본 제외 | 이름변경 기능 없음 | 소스 점검 |
| 11 | 다중 선택 후속 | CLI 명시 목록, 폴더별 결과 | 혼합 성공·실패 시험; Explorer 다중선택 후속 |
| 12 | 로컬 기본, 공유 best effort | Windows 11 x64 일반 폴더 | SMB·동기화·DRM 미검증 |
| 13 | 짧은 오류·상세 로그 | 한국어 메시지·구조화 코드 | 잠금·경로·형식 실패 시험 |
| 14 | 사용자 로컬 로그 | 두 파일 순환 | 로컬 로그 시험 |
| 15 | 사용자 설치·제거 | MSI, HKCU, 시작 메뉴 | 설치 수명주기 게이트 |
| 16 | 삭제·자동 이동·메일·스캔 금지 | 엔진 소유 범위 제한 | 코드 검토 |
| 17 | 후속 확장 | 별도 도구 정책으로 관리 | 현재 구현 범위 제외 |
| 18 | v1 완료 기준 | 표준 Shell 갱신·내용별 Portable 경로 | 로컬 실제 Explorer 전환·초기화 확인; 다른 OS·저장소는 미검증 |
| 19 | 구현 단계 | 엔진·복구·메뉴·MSI·Portable·CLI 일괄 | 자동 검증과 MSI 산출물 |
| 20 | 최소 개입 정의 | 공통 도구 정책에 반영 | [추가 도구 개발 기준](../../policies/tools.md) |

## 평가 반영 보완

2026-09-12: MASTER 미착수 유지 원칙은 원문 02의 실업무 분리·중복 기록 최소화를 구체화한 운영 제안입니다. 상태를 표시하는 MASTER는 `todo`, 미사용 MASTER는 상태 파일 없이 유지할 수 있습니다. 원문 01 §17.2의 키트 자동 초기화는 여전히 후속 범위이며 이번 문서 개선으로 구현되지 않았습니다. 원본 명세는 수정하지 않았습니다.
