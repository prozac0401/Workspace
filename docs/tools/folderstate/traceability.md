# 원본 요구와 구현을 비교한 표

처음 정한 요구는 [01 전체 명세](../../specifications/01.md)에 그대로 보관합니다. 아래 표에서 “구현”은 코드를 만들었다는 뜻입니다. 실제 업무 환경에서 사람이 사용해 확인을 마쳤다는 뜻은 아닙니다.

## 평가 반영 보완

2026-09-12: 복사해서 쓰는 기본 폴더(MASTER)를 시작 전으로 두는 기준은 운영 제안입니다. 원문 02의 “실제 업무와 기본 폴더를 구분하고 같은 내용을 여러 번 기록하지 않는다”는 뜻을 구체화했습니다. 상태를 표시하는 MASTER는 `todo`, 표시하지 않는 MASTER는 상태 파일 없이 둘 수 있습니다. 원문 01 §17.2의 키트 자동 초기화는 아직 만들지 않은 기능입니다. 원본 명세는 수정하지 않았습니다.

## 2026-09-16 · 사용자에게 보이는 말 바꾸기

요청: 방법론과 개발 용어를 몰라도 다음 행동과 결과를 알 수 있게 바꿉니다. 원본 요구는 보존하고 화면·탐색기 메뉴·설치 안내·오류 안내·명령줄 설명을 같은 말로 맞춥니다.

| 원본·이전 화면 | 새 화면 | 바꾼 이유 | 유지하는 내부 값·명령 |
|---|---|---|---|
| 미착수 | 시작 전 | 아직 일을 시작하지 않았다는 뜻을 바로 알 수 있음 | `todo` |
| 진행 중 | 진행 중 | 일상적으로 쓰는 말이므로 유지 | `doing` |
| 완료 | 완료 | 끝낸 일이라는 뜻 유지 | `done` |
| 이슈 | 확인 필요 | 문제·확인·결정이 필요한 상태를 한국어로 설명 | `issue` |
| 상태 초기화 | 상태 표시 지우기 | ‘시작 전으로 바꾸기’와 구분하고 실제 결과를 설명 | `reset` |
| 상태 아이콘 복구 | 아이콘 다시 표시 | 저장된 상태의 아이콘을 다시 설정하는 결과를 설명 | `repair` |
| 폴더와 함께 이동 | 선택한 폴더 안 | 프로그램이 폴더를 이동하는 기능으로 오해하지 않도록 저장 위치를 표시 | `portable` |
| 로컬 로그 열기 | 작업 기록 열기 | 이 PC에 저장된 성공·실패 기록을 여는 기능임을 설명 | 기존 기록 위치·형식 |
| 설치 화면의 복구 / 제거 | 프로그램 복구 / 프로그램 제거 | 폴더의 아이콘 다시 표시·상태 표시 지우기와 구분 | 기존 MSI 동작 |

프로그램 화면은 “폴더를 고르기 → 상태 누르기”로 나눴습니다. 버튼을 누르면 바로 저장된다고 알립니다. 아이콘 저장 위치는 선택 항목으로 접어 두고, 위치를 고른 뒤 상태 버튼을 누를 때 적용된다고 설명합니다. 결과와 오류 안내는 줄바꿈을 허용하며 화면 읽기 프로그램용 이름도 맞췄습니다.

파일 이름, 상태값, 명령 이름, 오류 코드, JSON 필드, 저장 방식, 되돌리기 절차는 바꾸지 않았습니다. 명령줄에서 사람이 읽는 출력 문구와 줄 수는 바뀌므로 자동 처리는 기존 `--json` 출력을 사용합니다. 다른 곳에서 설정이 바뀌었거나 되돌리기에 실패한 경우에는 무조건 다시 실행하라고 안내하지 않습니다. 파일을 남겨 두고 원인을 확인하도록 설명합니다.

이 변경은 문구와 화면 배치 수정입니다. 새 환경의 동작 확인이나 상용 배포 승인을 뜻하지 않습니다. 실제 시험 결과와 남은 확인은 아래 검증 기록에 남깁니다.

### 설치 안내 추가 교정 · 2026-09-17

후속 요청에 따라 설치 화면과 설치·복구·제거 안내를 다시 읽고 어색한 표현을 다듬었습니다. ‘지금 로그인한 사용자만 사용’은 사용 제한처럼 읽힐 수 있어 ‘지금 로그인한 Windows 계정에 설치’로 고쳤습니다. ‘기존 설치를 교체’는 ‘설치된 프로그램을 새 버전으로 바꾸기’로 풀어 썼습니다. 설치할 수 없는 Windows 10과 아직 충분히 확인하지 못한 공유·동기화 환경도 구분했습니다.

버튼 이름은 **프로그램 복구 / 프로그램 제거**를 유지합니다. 설치 파일의 복구와 폴더의 **아이콘 다시 표시**가 각각 무엇을 하는지 설명했습니다. 설치 조건, 사용자별 설치 범위, 복구·제거 동작은 바꾸지 않았습니다. 시험용 버전이라는 점과 상용 배포 승인·전자 서명·지원 방법이 아직 준비되지 않았다는 안내도 유지합니다. 문구 교정만으로 추가 환경을 지원하거나 실제 설치 시험을 마친 것으로 표시하지 않습니다.

2026-09-17 추가 점검: 기존 MSI를 읽기 전용으로 열어 확인했습니다. 화면 문구가 들어 있는 `Control` 표는 한국어이며, 별도의 `ActionText`, `Error`, `UIText` 표는 없습니다. 진행 중 안내와 기본 오류는 Windows Installer가 제공하는 문구이므로 제품에서 작성한 문구와 구분합니다. `ActionText`를 작성하지 않으면 설치 파일의 언어 설정에 맞는 기본 문구를 사용하며, 이 설치 파일의 언어 설정은 한국어(`1042`)입니다. [Microsoft ActionText 표 설명](https://learn.microsoft.com/en-us/windows/win32/msi/actiontext-table)을 확인했습니다.

설치 파일 속성의 설명과 검색어도 한국어로 바꾸고, 요약 정보의 코드 페이지를 한국어 `949`로 지정했습니다. 설치 데이터베이스 본문의 코드 페이지는 기존 `65001`을 유지합니다. 이 둘은 별도 설정입니다. [Microsoft 코드 페이지 설명](https://learn.microsoft.com/en-us/windows/win32/msi/codepage-summary), [한국어 코드 페이지 식별자](https://learn.microsoft.com/en-us/windows/win32/intl/code-page-identifiers), [WiX 요약 정보 속성](https://docs.firegiant.com/wix/schema/wxs/summaryinformation/)을 참고했습니다. WiX 4가 자동으로 넣는 요약 정보의 제목과 설명문(`Comments`), 도구 이름은 그대로입니다. 설치 화면에서 표시하는 문장과는 별개이며, 이 변경에서 Windows나 Windows Installer 자체의 시스템 메시지를 새로 번역하지는 않았습니다. 새 MSI를 만든 뒤 문구와 한글 요약 정보를 읽기 전용으로 확인했습니다. 코드 페이지 949, 한국어 설명·검색어와 화면 문구가 소스와 일치합니다. 자세한 결과와 실제 화면 시험의 한계는 [추가 검수 기록](../../delivery/korean-wording-review.md)을 따릅니다.
