# 다시 받은 파일의 원래 이름 유지하기

DownloadVersionManager는 Chrome·Edge에서 방금 받은 파일에 원래 이름을 주고, 내용이 달라진 이전 파일만 `_history`에 보관하는 Windows 도구입니다.

**현재 0.1.0은 개발 평가 후보입니다. 공개 설치 파일은 아직 게시하지 않았습니다.** MSI 하나에 프로그램과 확장이 들어가지만 브라우저 확장 활성화에는 사용자 작업이 필요합니다. 일반 PC의 완전 자동 통합 설치를 완료한 정식판으로 안내하지 않습니다.

## 같은 파일을 다시 받으면

`보고서.xlsx`가 있는 폴더에서 같은 이름으로 다시 다운로드합니다. 브라우저가 신규 파일을 먼저 다른 이름으로 저장한 뒤, 도구가 두 파일을 비교합니다.

- **바이트가 같으면:** 방금 받은 파일 자체가 `보고서.xlsx`가 됩니다. 이전 파일을 History에 넣지 않습니다.
- **바이트가 다르면:** 이전 파일은 `_history/보고서_20260930_094512.xlsx`처럼 보관하고, 방금 받은 파일이 `보고서.xlsx`가 됩니다.

History 이름의 날짜와 시간은 이전 파일을 옮기는 로컬 시각입니다. 같은 초에 이름이 겹치면 `_001`, `_002`를 붙입니다. 확장자는 유지합니다. 다른 저장 폴더를 선택했다면 그 폴더의 `_history`를 사용합니다.

## 평가용 설치 마무리

평가용 MSI를 받은 경우 한 파일을 설치합니다. 사용자별 설치이며 개발 SDK나 별도 runtime을 요구하지 않습니다. 설치 파일에는 코드 서명이 없습니다.

1. 시작 메뉴의 **DownloadVersionManager 설치 마무리**를 엽니다.
2. 안내에 따라 평가용 Chrome 또는 Edge의 확장 관리에서 개발용 **압축 풀린 확장 로드**를 선택합니다.
3. 설치 폴더의 `extension`을 선택합니다. 기본 위치는 `%LOCALAPPDATA%\Programs\DownloadVersionManager\extension`입니다.
4. 확장에서 **설치 연결 확인**을 눌러 연결됐는지 확인합니다.

이 과정은 스토어 심사·배포 전의 평가용 방법입니다. 회사 정책이 개발용 확장을 허용하지 않으면 담당자의 공식 배포 절차를 따릅니다. 도구가 기업 정책이나 브라우저 profile을 변경하지 않습니다.

## 파일이 사용 중일 때

안전하게 바꿀 수 없으면 작업을 중단하고 남아 있는 파일을 확인하도록 안내합니다. 앱이나 브라우저를 강제로 닫지 않습니다. 자동 재시도도 없습니다. 복구를 마치지 못했다는 안내가 나오면 현재 폴더와 `_history`의 이전 파일을 직접 확인하세요.

작업 도중 PC가 꺼지면 `_history` 또는 `.dvm-…pending`에 이전 파일이 남을 수 있습니다. 확인 없이 일괄 삭제하지 마세요. 이 도구는 restore 화면을 제공하지 않습니다.

## 제거와 지원 범위

Windows의 설치된 앱에서 DownloadVersionManager를 제거하고, 각 브라우저에서 확장도 제거합니다. 다운로드와 `_history`는 사용자 데이터이며 제거하지 않습니다.

현재 확인 대상은 Windows 11 x64와 고정 로컬 NTFS입니다. Windows 10·ARM64·네트워크·클라우드 경로·모든 기업 정책은 지원 인증하지 않았습니다. 다른 확장이 다운로드 이름을 변경하는 경우와 저장 대화상자의 직접 덮어쓰기는 보장하지 않습니다. 원래 이름과 다른 이름을 직접 선택하면 이를 보존하고 자동 처리하지 않습니다. 브라우저 다운로드 목록은 이동 전 경로를 표시할 수 있어 최종 파일은 저장 폴더에서 확인합니다.

기존 suffix 파일 일괄 정리, Outlook·Teams 직접 감시, Explorer 복사, Office/PDF 의미 비교는 하지 않습니다. 동시에 같은 파일에 대한 완료 요청은 처리 순서로 이름을 승계하며 브라우저 전체 완료 시각 순서를 보장하지 않습니다.

평소 상주 프로그램·서비스·tray·watcher·polling을 만들지 않습니다. 파일을 처리할 때만 Host를 실행하고 즉시 종료합니다. 파일 내용·hash·사용 통계를 외부에 보내지 않습니다.
