## 사용자 요청

아래는 첨부 파일과 함께 받은 요청이다. 원문의 표현을 보존한다.

> 탐색기에서 마우스 오른쪽 클릭으로 나오는 context 메뉴에서 trigger 되는 기능을 개발하려 합니다. 위 excel 암호 를 거는 프로그램을 탐색기 컨텍스트 메뉴에 추가하고, 암호가 걸린 excel 의 경우 복호화도 지원가능해야해여. 암호가 걸려있을 경우, 암호를 변경하는것도 가능해야하고요. 위 기능을 지원하는 간결한 ux 를 구성하고, 암호화 복호화 기능 설치를 위한 msi 설치 프로그램도 만들어야합니다.

요청의 결과물은 탐색기에서 실행하는 암호 관리 창, 암호 설정·해제·변경 기능, MSI 설치 프로그램이다. 지원 파일 형식·암호 길이·복구 조건은 첨부 원본의 계약을 검토한 뒤 [현재 명세](specification.md)에 구체화한다. 조직 배포 승인이나 인터넷 게시를 요청한 것으로 해석하지 않는다.

## 폴더 처리 후속 요청 · 2026-11-16

아래 후속 요청은 최초 요청을 대체하지 않고 폴더 일괄 처리·재시도·실패 기록·정리 요구를 추가한다. 사용자 원문을 보존한다.

> 폴더를 선택하면, **Excel 암호 관리** 메뉴 안에 (폴더 내 모든) **암호 설정·암호 해제·암호 변경** ... 엑셀 파일 하나에서 오른쪽 클릭을 하면, **기존과 동일한 동작** ... 이 되어야 해요 이 동작이 지원되나요?

범위 선택 답변:

> 하위 폴더의 파일까지 모두 처리

실패 처리 요청:

> 암호화에 실패한 것에 대한 재시도가 필요해요. 3회 수행 후, 안된 것은 안된 것으로 기입하고.. 암호화하지 못한것을 사용자가 볼 수 있게끔 기록으로 보여줄수 있어야해요 (실패한 건이 있을 경우, 엑셀 파일을 남겨줘요)

중간 파일 정리 요청:

> 그리고 맨 처음 전달드린 배치파일의 경우 중간 파일을 남깁니다. 이러한 중간파일이 남지 않도록 합니다.

실행 계약은 안전한 실패를 최초 시도 포함 최대 3회 처리하고, 최종 실패의 파일·경로·이유·시도 수를 화면과 XLSX에 남기는 것이다. 정상 경로의 작업 복사본·임시 결과는 정리하며 원본 백업은 보존한다. 불확실한 교체나 정리에는 재시도를 멈추고 필요한 복구 근거와 안내를 남긴다. 보고서는 검색에서 제외한 제품 전용 실행 폴더에 생성한다. 구체적인 안전 경계는 [현재 명세](specification.md), [폴더 설계](../../design/0040-excel-password-safe-folder-batch.md), 실제 결과는 [1.4.0 검증 기록](../../delivery/excel-password-safe-folder-20261116.md)에 기록한다.

## 버전 2 후속 요청 · 2026-11-17

사용자는 다음 여섯 항목을 요청했다. 원문을 보존한다.

> 1. MSI 에서 설치위치 커스터마이즈 기능 추가 및 서명되지 않은 평가용 패키지라는 워딩은 빼줘요. 버전 표기는 단일 숫자로 해주시기 바랍니다.
> 2. 아이콘이 없어요. 아이콘을 제작해줘요. 암호 자물쇠 아이콘 같은걸로요
> 3. 탐색기 빈공간에서 우클릭 할 경우, 현재 폴더를 루트로 한 암호화로 인식이 되어 컨텍스트 메뉴가 떠야해요.
> 4. 전반적으로 UI 가 화면 영역을 너무 많이 잡아먹어요. 현재UI 자체가 컨텍스트 메뉴로 부터 시작하는 공통 UI 로 구현이 되어 있어 필연적으로 화면의 영역을 많이 차지할 수 밖에 없어보입니다. 특정 기능 선택 -> 입력할 최소 데이터 입력란. 그리고 입력이 끝나고 오류나 메시지 -> 출력창 방식의 위자드 형태로 만들어주세요.
> 5. 현재 컨셉을 기반으로 상업용 어플리케이션 수준의 UI/UX 수준으로 디자인 해줘요.
> 6. 실사용자. 사람이라 생각을 하고 이것을 사용해봤을때 걸림 포인트가 없어야 합니다.

버전 확인 답변:

> 정수 하나로 표시: 버전 2

완료 후 게시 요청:

> 완료되면 릴리즈도 함께 부탁합니다.

확정한 흐름은 문맥 메뉴에서 선택한 작업의 최소 입력→진행→결과이며, 파일 메뉴는 작업 선택부터 시작한다. 폴더 세부 목록은 선택적으로 펼친다. 사용자 화면의 평가용 표현을 제거하되 실제 서명 상태를 검증 기록에서 바꾸거나 인증을 주장하지 않는다. [버전 2 설계](../../design/0041-excel-password-safe-wizard.md)와 [검증·게시 기록](../../delivery/excel-password-safe-v2-20261117.md)에 구현과 실제 결과를 연결한다.

### 작업 선택 화면 후속 조정

> 어떤작업을 할까요? 에서 스크롤 바는 나오지 않게 조정해줘요.

> 버튼 부가설명도 불필요해보여요.

기본 작업 선택 화면에서 세 작업 버튼을 모두 스크롤 없이 보이게 하고 버튼에는 작업 이름만 남긴다. 대상과 백업 등 필요한 정보는 대상·입력 단계에서 안내한다.

### 문맥 메뉴의 작업 선택 교정

> 아니. 그보다.. 어떤작업을 할지는 컨텍스트 메뉴에서 이미 정한것 아닌가요?

이 최신 교정에 따라 기존 파일 메뉴 동작 유지 계약을 바꾼다. Excel 파일에도 `Excel 암호 관리` 아래 암호 설정·해제·변경을 제공하고, 파일·선택 폴더·빈 공간 모두 메뉴에서 선택한 작업의 암호 입력으로 바로 진입한다. 일반 실행과 기존 작업 인수 없는 파일 실행만 작업 선택을 제공한다. 문맥 입력에서는 취소로 닫고 작업을 다시 고르게 하지 않는다.

### 우선 릴리스 요청

> 우선 릴리즈 해주세요. 사용해보고 추가 피드백 드리겠습니다

사용자는 현재 검증된 버전 2 패키지를 우선 릴리스하도록 명시적으로 요청했다. 남은 실제 설치 화면·탐색기 클릭·최종 설치 앱의 암호 실행·수동 재시도는 미실행 상태로 기록하고 실사용 피드백을 받는다. 기존 검증 결과를 확대하거나 게시 완료를 미리 기록하지 않는다.
