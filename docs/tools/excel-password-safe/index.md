# Excel 파일·폴더의 암호 설정·해제·변경

ExcelPasswordSafe 2는 탐색기에서 Excel의 열기 암호를 관리합니다. 선택한 작업에 필요한 암호를 입력하면 진행 상황과 결과를 차례로 보여 줍니다.

## 설치 위치 선택하기

MSI를 실행하고 설치할 폴더를 확인합니다. 기본 위치는 `%LocalAppData%\Programs\ExcelPasswordSafe`이며 신규 설치에서 다른 위치를 입력하거나 찾아볼 수 있습니다. 현재 사용자에게 설치하며 Excel은 함께 설치하지 않습니다.

업그레이드와 복구는 기존 설치 위치를 유지합니다. 설치 위치를 옮기려면 프로그램을 제거한 뒤 원하는 위치에 다시 설치하세요. 문서·백업·실패 보고서는 제거되지 않습니다.

Windows 10 버전 2004 이상 또는 Windows 11 x64, .NET Framework 4.8, Windows PowerShell 5.1과 데스크톱 Microsoft Excel이 필요합니다. 실행 전 열려 있는 Excel을 모두 정상 종료하세요.

## 탐색기에서 시작하기

| 시작점 | 방법 |
|---|---|
| 파일 하나 | Excel 파일 오른쪽 클릭 → **Excel 암호 관리 → 암호 설정 / 암호 해제 / 암호 변경** |
| 폴더 | 폴더 오른쪽 클릭 → **Excel 암호 관리 → 암호 설정 / 암호 해제 / 암호 변경** |
| 열린 폴더의 빈 공간 | 빈 공간 오른쪽 클릭 → **Excel 암호 관리**의 작업 선택. 현재 폴더가 대상 |
| 시작 메뉴 | **Excel 암호 관리** 실행 → 파일 또는 폴더 선택 → 작업 선택 |

Windows 11에서는 **더 많은 옵션 표시** 안에 메뉴가 있습니다. 파일·폴더·빈 공간 모두 메뉴에서 고른 작업의 암호 입력 화면으로 바로 이어집니다. 폴더는 모든 하위 폴더의 지원 Excel 파일을 포함합니다. 표시된 경로·파일 수를 확인하고 필요하면 대상 목록을 펼쳐 보세요. 목록에 없던 새 파일은 이번 작업에 자동 추가하지 않습니다.

## 암호 입력하고 실행하기

| 작업 | 입력할 내용 |
|---|---|
| 암호 설정 | 새 암호와 확인 |
| 암호 해제 | 현재 암호 |
| 암호 변경 | 현재 암호, 새 암호와 확인 |

새 암호는 1~15자이며 대소문자를 구분합니다. 암호는 기본적으로 가려지고, 필요할 때 표시하도록 선택할 수 있습니다. 오류가 있으면 입력 화면의 안내에 따라 수정하세요. 탐색기 메뉴에서 시작한 입력의 **취소**는 창을 닫습니다. 앱을 직접 실행한 흐름의 **뒤로**는 같은 대상의 작업 선택으로 돌아갑니다. 입력 단계를 나가거나 작업을 마치면 암호를 지웁니다.

원본을 교체하고 백업을 보관한다는 안내를 확인한 뒤 **암호 설정 / 암호 해제 / 암호 변경** 버튼을 누릅니다. 원본을 백업하고 Excel에서 복사본을 저장·다시 열어 검증한 다음 같은 경로의 파일을 교체합니다.

폴더에는 같은 암호를 적용합니다. 현재 암호가 서로 다른 파일은 실패할 수 있습니다. 암호 찾기와 셀·시트·통합문서 구조·쓰기 보호 해제는 제공하지 않습니다.

## 진행과 결과

진행 화면에서 현재 파일·완료 수·시도 수를 확인합니다. **취소**는 현재 Excel 호출이 끝날 때까지 기다릴 수 있습니다. 이미 성공한 파일은 다른 파일의 실패나 취소 때문에 되돌리지 않습니다.

결과 화면은 완료·건너뜀·실패·취소/미처리를 구분합니다. 세부 내용은 필요할 때 펼치며 실패가 있으면 **실패 보고서 열기**로 파일명·전체 경로·이유·시도 수가 담긴 XLSX를 엽니다. 보고서는 `%LocalAppData%\ExcelPasswordSafe\Runs\배치ID\failure-report.xlsx`에 저장하고 다음 폴더 작업에서 제외합니다. 실패가 없으면 보고서를 만들지 않습니다.

안전한 실패의 **실패 N개 다시 시도**는 실패한 파일만 암호 입력으로 돌려보냅니다. 암호를 다시 입력하고 실행해야 하며 성공한 파일은 제외합니다. 폴더의 한 실행 안에서는 안전한 실패를 최초 포함 최대 3회 처리합니다. 교체·정리 상태가 불확실하면 재시도하지 말고 **백업·기록 보기**에서 먼저 확인하세요.

이미 암호가 있거나 없는 파일은 결과에 안내된 적절한 작업으로 이동할 수 있습니다. 앱을 직접 실행한 흐름의 **다른 작업**은 원래 대상 범위를 다시 확인합니다. 보고서에는 파일 경로가 포함되므로 전달 전에 내용을 확인하세요. 암호는 보고서에 기록하지 않습니다.

## 원본 백업과 중간 파일

**백업·기록 보기**로 실행 폴더를 엽니다. 파일 작업의 백업은 `%LocalAppData%\ExcelPasswordSafe\Runs\실행ID\original.확장자`, 폴더 작업은 배치 폴더 아래 각 시도 폴더의 `original.확장자`입니다.

정상 완료·안전한 실패·취소 뒤에는 이 실행의 작업 복사본·임시 결과·암호 전달 파일과 확인된 중복 recovery를 정리합니다. **원본 백업은 남깁니다. 암호 없는 원본의 백업도 암호가 없습니다.** 필요가 끝난 백업은 확인한 뒤 직접 정리하세요.

교체나 Excel 종료가 불확실하면 필요한 복구 파일을 보존하고 경로를 안내합니다. 정리 오류가 있으면 중간 파일이 남을 수 있습니다. 복원하려면 Excel을 닫고 현재 파일도 별도로 보관한 뒤, 실행 기록의 원본 해시와 백업을 대조하여 복사합니다. 자동으로 외부 변경을 덮어쓰는 복구는 하지 않습니다.

## 지원 범위와 문제 해결

`.xls`(BIFF8)·`.xlsx`·`.xlsm`·`.xlsb`를 지원하며 형식을 자동 변환하지 않습니다. 처리할 문서는 로컬 고정 NTFS 경로에 있어야 합니다. 네트워크·이동식·링크·오프라인·읽기 전용 파일은 제외합니다. 동기화 폴더는 별도 로컬 복사본으로 작업하세요. 서명된 문서·VBA, 공유·쓰기 예약 파일과 발견된 Excel 4.0 매크로 시트는 지원하지 않습니다.

`.xls`의 구형 RC4 암호화는 보안상 한계가 있어 민감한 자료 보호용으로 권장하지 않습니다. [Microsoft 암호화 명세](https://learn.microsoft.com/en-us/openspecs/office_file_formats/ms-offcrypto/78b227ba-bb55-49d0-aa41-83644ca1963b)

파일을 열지 못하면 현재 암호와 파일 손상·보안 제한을 확인하세요. 파일이 바뀌었거나 잠겨 있으면 다른 앱에서 닫고 대상을 다시 선택합니다. 도구는 사용자 Excel을 강제 종료하지 않습니다. 내용 비교는 그림 픽셀·삽입 개체 내부·매크로 동작·외부 참조의 완전한 동일성 보장이 아니므로 대표 파일의 복사본으로 확인하고 결과를 Excel에서 검토하세요.

설치 실패 후 앱 항목만 남거나 재설치해도 메뉴가 없으면 **같은 MSI를 다시 열어 프로그램 제거 후 재설치**하세요. 레지스트리나 Windows 보안 설정을 직접 바꾸지 마세요. 제거는 **Windows 설정 → 앱 → 설치된 앱 → ExcelPasswordSafe 2 → 제거**를 사용합니다. 프로그램과 자기 메뉴만 제거하며 문서·기본 연결·백업·보고서는 보존합니다.
