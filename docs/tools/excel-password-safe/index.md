# Excel 파일의 암호 설정·해제·변경

ExcelPasswordSafe 1.3.0 · 로컬 평가 후보. Windows 10 버전 2004 이상 또는 Windows 11의 x64 PC와 데스크톱 Microsoft Excel, Windows PowerShell 5.1, .NET Framework 4.8이 필요합니다. 서명과 조직 배포 승인을 마친 제품으로 표시하지 않습니다. 현재 버전의 화면과 실제 동작을 확인한 범위는 [1.3.0 검증 기록](../../delivery/excel-password-safe-ui-20261116.md)을 따릅니다.

**설치 실패 복구에 확인된 제한이 있습니다.** 이전 버전의 시험에서 설치가 중간에 실패하면 파일·메뉴가 없어져도 Windows의 설치 정보가 남는 사례가 확인됐습니다. 이 제한을 해결했다고 판정하지 않습니다. 이때 같은 MSI를 다시 열어 **프로그램 제거**를 선택하고, 제거가 끝난 뒤 다시 설치하세요. 모든 설치 실패의 자동 복구가 검증된 것은 아닙니다.

## 설치하고 시작하기

1. 제공된 MSI를 실행하여 현재 사용자에게 설치합니다.
2. 열려 있는 Excel을 모두 정상 종료합니다.
3. 탐색기에서 작업할 Excel 파일 **하나**를 오른쪽 클릭하고 **Excel 암호 관리**를 선택합니다. Windows 11에서는 **더 많은 옵션 표시** 안에 있습니다.
4. 창에 표시된 파일 경로와 작업을 확인합니다.

시작 메뉴의 ExcelPasswordSafe로 실행한 뒤 파일을 선택할 수도 있습니다. `.xls`, `.xlsx`, `.xlsm`, `.xlsb`를 지원합니다. 폴더 전체나 여러 파일을 한 번에 처리하지 않습니다.

1.3.0 화면은 흰색·회색 바탕과 남색·파란색 강조를 사용합니다. 파일, 작업 선택, 암호 입력을 나누어 보여줍니다. 선택한 작업 이름과 안내를 확인한 뒤 입력하세요. 암호 처리와 원본 백업 절차는 이전 버전과 같습니다.

## 원하는 작업 선택하기

| 작업 | 입력할 내용 | 결과 |
|---|---|---|
| 암호 설정 | 새 암호, 새 암호 확인 | 다음에 파일을 열 때 암호가 필요함 |
| 암호 해제 | 현재 암호 | 다음에 파일을 열 때 암호가 필요하지 않음 |
| 암호 변경 | 현재 암호, 새 암호, 새 암호 확인 | 새 암호로 파일을 열 수 있음 |

새 암호는 1~15자이며 대소문자를 구분합니다. 현재 암호를 모르는 파일의 암호 찾기·해제는 지원하지 않습니다. 셀·시트 보호나 통합문서 구조 보호를 푸는 기능도 아닙니다.

`.xls`의 구형 RC4 암호화는 보안상 한계가 있어 민감한 자료 보호용으로 권장하지 않습니다. 이 도구는 형식을 자동 변환하지 않습니다. [Microsoft 암호화 명세](https://learn.microsoft.com/en-us/openspecs/office_file_formats/ms-offcrypto/78b227ba-bb55-49d0-aa41-83644ca1963b)

대상과 백업 안내를 확인한 뒤 선택한 작업을 실행합니다. 원본을 백업한 다음 임시 결과를 저장하고 다시 열어 검증합니다. 검증을 통과하면 같은 경로의 파일을 교체합니다. 취소를 누른 경우 현재 Excel 호출이 끝날 때까지 기다릴 수 있습니다.

## 백업과 결과 확인하기

결과 창에서 성공·건너뜀·실패·취소를 확인합니다. 백업은 현재 사용자에게 접근을 제한한 `%LocalAppData%\ExcelPasswordSafe\Runs\실행ID`에 남깁니다. **백업·기록 보기**를 누르면 이 폴더가 열립니다. `original.확장자`는 작업 전 원본이며 같은 파일 폴더의 `.eps-…recovery`도 교체 전 원본입니다.

원본이 암호 없는 파일이었다면 **백업과 recovery도 암호 없는 파일**입니다. 필요가 끝난 자료는 경로와 내용을 확인한 뒤 직접 정리하세요. 앱 제거는 백업을 삭제하지 않습니다. 작업용 파일 정리가 끝나지 않았다는 안내가 나오면 기록의 임시 경로도 확인하세요.

암호를 걸거나 바꾸기 전에 대표 파일의 복사본으로 확인하세요. 파일 형식·수식·값·시트·도형 목록을 비교하지만 그림의 모든 픽셀, 삽입 개체 내부, 매크로 동작과 외부 참조까지 동일하다고 보증하지 않습니다. 결과를 Excel에서 열어 실제 업무에 필요한 내용도 확인하세요.

## 작업이 끝나지 않을 때

| 상황 | 다음 행동 |
|---|---|
| Excel이 열려 있음 | 작업을 저장하고 Excel을 정상 종료한 뒤 다시 실행 |
| 파일을 열지 못함 | 현재 암호를 확인하고 Excel에서 파일 상태 확인. 암호·손상·보안 제한을 오류 하나로 단정하지 않음 |
| 파일이 바뀌었거나 잠겨 있음 | 다른 앱에서 파일을 닫고 파일을 다시 선택 |
| 지원하지 않는 위치·형식 | 로컬 고정 NTFS 폴더에 복사하여 확인. 네트워크·이동식·링크 경로와 구형 XLS는 제외 |
| 서명·공유·쓰기 예약·Excel 4.0 매크로 파일 | 해당 문서의 관리 절차 사용. 이 도구로 강제 처리하지 않음 |
| 시간 초과 또는 Excel이 남아 있음 | Excel과 결과에 표시된 기록·임시 경로 확인. 사용자 Excel을 강제 종료하지 않음 |
| 교체 상태 확인 필요 | 자동으로 다시 실행하지 말고 현재 파일·백업·recovery와 해시 기록 확인 |

복원할 때는 Excel을 닫고 현재 파일도 별도로 보관합니다. 실행 기록에 남은 원본 SHA-256과 백업을 대조한 뒤, 복원할 경로를 확인하여 백업을 복사합니다. 도구는 외부에서 바뀐 파일을 자동으로 덮어쓰는 복구를 하지 않습니다.

## 제거하기

Windows **설정 → 앱 → 설치된 앱 → ExcelPasswordSafe → 제거**를 사용합니다. 프로그램과 이 도구의 탐색기 메뉴가 제거됩니다. Excel 파일·기본 파일 연결·다른 앱 메뉴와 백업은 보존합니다.
