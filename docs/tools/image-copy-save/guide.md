# 그림 파일로 저장하고 이미지로 복사하기

**그림 복사·저장(ImageCopySave)**은 탐색기에서 복사한 이미지를 PNG 파일로 저장하고, 그림 파일 한 개를 다른 프로그램에 붙여넣을 이미지로 복사하는 도구입니다. 이 안내는 **0.2.0** 기준입니다.

!!! warning "배포 준비 중"
    이 문서는 0.2.0 정식 릴리스를 위한 초안입니다. 아래 다운로드는 게시 예정 주소이며, 최종 MSI 검증과 실제 자산 게시가 끝나기 전에는 배포 완료를 뜻하지 않습니다.

## 설치 전에 확인하세요

**Windows 11 x64용 무서명 MSI입니다.** 설치·업데이트·복구·제거에는 Windows의 관리자 승인이 필요합니다. 평소 복사·저장은 일반 사용자 권한으로 실행합니다. 필요한 .NET 실행 환경이 포함되어 있어 따로 설치하지 않아도 됩니다. 회사 PC에서는 허용된 설치 절차를 따르세요.

Windows 10·ARM64, 네트워크 드라이브와 온라인 전용 파일은 지원 대상이 아닙니다. Word·PowerPoint·메일·메신저의 모든 붙여넣기 형식과 투명도는 확인하지 않았습니다. 사용하는 프로그램에 따라 이미지가 압축되거나 투명 배경이 달라질 수 있습니다.

이전 0.1.1의 Windows 11 기본 메뉴 경로에서 복사·저장 두 기능은 사용자가 직접 확인했습니다. 클래식 직접 메뉴와 그림판의 대표 동작도 확인했습니다. 전체 앱 호환성이나 모든 창·탭 전환을 확인했다는 뜻은 아닙니다. 과거 메뉴 시험 중 탐색기가 잠시 응답하지 않았다가 회복한 사례는 원인이 확정되지 않았습니다. 최종 0.2.0의 확인 범위와 남은 제한은 게시 시 릴리스 안내에 구분합니다.

## 설치하기

1. **ImageCopySave-0.2.0-x64.msi**를 실행합니다.
2. 설치 안내와 관리자 승인 화면을 확인하고 설치합니다.
3. 실제 로컬 폴더를 탐색기로 열어 아래 두 메뉴를 사용합니다.

프로그램은 이 PC의 프로그램 폴더에 설치합니다. 별도 설정 화면이나 시작프로그램은 만들지 않습니다. 탐색기 강제 종료나 자동 재부팅도 수행하지 않습니다. Windows가 사용 중인 파일 때문에 재시작을 요청하면 작업을 저장한 뒤 직접 재시작하세요.

## 복사한 이미지를 PNG로 저장하기

1. 캡처 도구나 그림 프로그램에서 이미지를 복사합니다.
2. 저장할 **폴더 안 빈 곳을 우클릭 → 더 많은 옵션 표시 → 복사한 그림 저장**을 누릅니다.
3. 같은 폴더에 만들어진 **그림_날짜_시간.png**를 확인합니다.

Windows 11에서 클래식 메뉴를 바로 여는 설정을 사용한다면 우클릭한 메뉴에서 **복사한 그림 저장**을 바로 고릅니다. 명령은 **새로 만들기** 안이 아닌 독립 항목입니다. 메뉴 표시 방식을 바꿀 필요는 없습니다.

저장 위치나 파일명을 다시 묻지 않습니다. 같은 이름이 있으면 번호를 붙여 새 파일을 만들며 기존 파일을 덮어쓰지 않습니다. 저장 후에도 복사한 내용은 유지됩니다.

텍스트·주소·HTML만 복사했거나 클립보드가 비어 있으면 저장 메뉴가 나타나지 않습니다. 탐색기에서 그림 파일을 일반 **Ctrl+C**로 복사한 경우도 파일 목록만 제공하면 저장 메뉴가 나타나지 않습니다. 아래 **그림으로 복사**를 사용하세요. 복사한 내용을 바꿨다면 메뉴를 닫고 다시 엽니다.

## 그림 파일을 이미지로 복사하기

1. 탐색기에서 **PNG, JPG/JPEG 또는 BMP 파일 한 개**를 선택합니다.
2. **우클릭 → 더 많은 옵션 표시 → 그림으로 복사**를 누릅니다. 클래식 메뉴가 바로 열리는 환경에서는 **그림으로 복사**를 바로 고릅니다.
3. 복사 완료 안내를 확인한 뒤 사용할 프로그램에서 **Ctrl+V**를 누릅니다.

파일 경로나 첨부 목록 대신 이미지 데이터를 복사합니다. 원본 파일은 수정·이동·삭제하지 않습니다. 복사 후 작업 프로그램이 종료되어도 붙여넣을 수 있습니다. 여러 파일·폴더·지원하지 않는 확장자를 선택하면 메뉴를 표시하지 않습니다.

## 처리할 수 있는 이미지와 위치

| 항목 | 지원 범위 |
|---|---|
| 그림 파일 | 일반적인 8비트 화면용 PNG·JPG/JPEG·BMP의 정지 이미지 한 개 |
| 저장 형식 | PNG 고정. 크기·비율을 임의로 줄이지 않으며 같은 이름은 번호를 붙임 |
| 투명도 | 지원 PNG 또는 알파 정보가 명시된 비트맵 표현에서 유지. 받는 앱의 처리 방식은 별도 |
| 이미지 크기 | 가로·세로 각각 16,384픽셀 이하이며 총 50,000,000픽셀 이하 |
| 데이터 크기 | 입력 파일·압축 이미지 데이터 128MiB 이하. 메모리 부족이나 안전 상한 초과 시 거절 |
| 파일 위치 | 접근 권한이 있는 실제 고정 로컬 디스크의 파일·폴더 |

GIF·TIFF·WebP·HEIC·AVIF·SVG·PDF, 애니메이션, HDR·고비트 이미지와 특수 색상 프로파일은 지원하지 않습니다. PNG의 ICC 프로파일과 비표준 감마, JPEG의 CMYK·ICC·MPO, 팔레트·압축 BMP 등도 거절할 수 있습니다. PNG로 다시 인코딩하므로 원본의 모든 메타데이터나 파일 바이트를 그대로 복제하는 기능은 아닙니다.

홈·갤러리·검색 결과·휴지통·ZIP 내부와 바탕화면 자체의 빈 곳은 저장 위치로 지원하지 않습니다. 바탕화면 **폴더를 탐색기로 연 경우**에는 실제 로컬 폴더 조건을 따릅니다. 네트워크·가상 드라이브, 연결·정션 경로와 온라인 전용 파일은 제외합니다. 내려받은 클라우드 파일도 연결 속성이 남아 있으면 처리하지 않을 수 있습니다.

## 업데이트·복구·제거하기

- **업데이트:** 새 버전 MSI를 실행합니다. 자동 업데이트 서비스는 없습니다.
- **복구:** 설치한 버전의 MSI를 다시 열어 **복구**를 선택합니다. 설치 파일이 없어진 경우 다시 채울 수 있습니다.
- **제거:** **Windows 설정 → 앱 → 설치된 앱 → ImageCopySave → 제거**를 누르거나 같은 MSI에서 **제거**를 선택합니다.

설치기가 관리하는 프로그램 파일과 두 기능의 메뉴 등록을 대상으로 처리합니다. 원본 그림·저장한 PNG·업무 파일·다른 프로그램의 메뉴·기본 연결 프로그램은 보존합니다. 설치 폴더에 따로 추가한 파일이 남아 있으면 제거 후 폴더가 남을 수 있습니다.

0.2.0 설치기는 이 PC의 제품 등록 또는 설치를 실행한 사용자의 등록과 같은 이름으로 충돌하거나 알 수 없는 설치 폴더가 있으면 설치를 중단하도록 보완합니다. 설치 후 외부에서 바꾼 제품 파일이나 등록 값이 발견되면 복구·업데이트·제거도 중단하여 변경 내용을 보존합니다. 이 보호 기능의 최종 확인은 0.2.0 릴리스 검증에 포함합니다.

**기존 등록 또는 변경된 파일 때문에 중단된 경우:** 오류 문구와 사용 중인 버전을 확인해 [제품 문의](https://github.com/prozac0401/Workspace/issues)에 전달하세요. 회사 PC라면 설치 담당자에게 확인을 요청하세요. 기존 폴더나 등록을 한꺼번에 지우지 마세요. 담당자가 충돌 항목의 소유자와 필요한 변경을 확인하고, 보관할 사본을 확보한 뒤 해당 항목의 복구 방법을 결정해야 합니다. 설치 파일을 다시 실행하는 것만으로 외부 변경을 강제로 덮어쓰지는 않습니다.

## 메뉴가 없거나 작업이 실패할 때

| 상황 | 확인할 내용 |
|---|---|
| 메뉴가 보이지 않음 | Windows 11에서는 **더 많은 옵션 표시**를 여세요. 실제 로컬 폴더인지, 지원 파일 한 개 또는 지원 이미지 데이터인지 확인한 뒤 메뉴를 다시 여세요. 설치 직후라면 새 탐색기 창에서도 확인하세요. |
| 그림 파일을 복사했는데 저장 메뉴가 없음 | 일반 파일 복사와 이미지 복사는 다릅니다. 파일의 **그림으로 복사**를 먼저 실행하세요. |
| 저장·복사 중 오류 | 원본 이동·손상, 폴더 쓰기 권한, 남은 디스크 공간, 이미지 상한을 확인하세요. 저장 위치를 임의로 바꾸거나 관리자 권한으로 다시 실행하지 않습니다. |
| 처리 중 다른 내용을 복사함 | 새 복사 내용을 덮어쓰지 않도록 작업이 중단될 수 있습니다. 필요한 그림을 다시 선택해 실행하세요. |
| 저장 파일은 있지만 선택되지 않음 | 원래 호출한 폴더에서 생성된 PNG를 확인하세요. 저장 성공과 탐색기의 파일 선택은 별개입니다. |
| 탐색기가 일시적으로 응답하지 않음 | 작업이 회복되는지 확인하고 반복 실행을 멈추세요. 재현 순서와 Windows 버전을 문의에 남기세요. 원인 확인 없이 다른 메뉴 확장이나 업무 파일을 삭제하지 마세요. |

제품은 이미지나 클립보드 내용을 서버로 보내지 않으며 클립보드 기록을 따로 모으지 않습니다. Windows나 다른 프로그램의 클립보드 기록·동기화 설정은 그대로 유지됩니다. 문의에는 업무 이미지·개인 정보·전체 경로·진단 로그 원문을 공개하지 마세요.
