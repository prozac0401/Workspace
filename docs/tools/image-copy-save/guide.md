# 그림 파일로 저장하고 이미지로 복사하기

**그림 복사·저장(ImageCopySave)**은 탐색기에서 복사한 이미지를 PNG 파일로 저장하고, 그림 파일 한 개를 다른 프로그램에 붙여넣을 이미지로 복사하는 도구입니다. 이 안내는 **0.2.1** 기준입니다.

## 설치 전에 확인하세요

**64비트 Windows 11용 설치 파일입니다. 제작자를 확인하는 전자 서명은 없습니다.** 설치·업데이트·복구·제거에는 Windows의 관리자 승인이 필요합니다. 평소 복사·저장은 관리자 권한 없이 사용합니다. 실행에 필요한 파일도 포함되어 있습니다. 회사 PC에서는 허용된 설치 절차를 따르세요.

Windows 10, ARM64 방식의 PC, 네트워크 저장장치와 온라인에만 있는 파일은 지원하지 않습니다. Word·PowerPoint·메일·메신저의 모든 붙여넣기 형식과 투명도는 확인하지 않았습니다. 사용하는 프로그램에 따라 이미지가 압축되거나 투명 배경이 달라질 수 있습니다.

0.1.1에서는 Windows 11에서 마우스 오른쪽 버튼을 누르면 처음 열리는 메뉴로 복사·저장을 할 수 있음을 사용자가 직접 확인했습니다. 0.2.0에서는 오른쪽 클릭 메뉴가 바로 열리도록 설정한 PC에서 복사·PNG 저장을 확인했습니다. 모든 프로그램과 탐색기 창·탭에서 확인한 결과는 아닙니다. 과거 시험 중 탐색기가 잠시 멈췄다가 다시 움직인 사례가 있으며, 원인은 아직 알지 못합니다.

0.2.1은 작업이 끝나기 전에 취소됐을 때 안내하는 문장을 고쳤습니다. 관련 기능과 설치 파일 검사는 마쳤습니다. 설치와 탐색기 사용에 관한 확인은 0.2.0에서 얻은 결과를 사용합니다. **0.2.1에서 설치와 탐색기의 모든 기능을 다시 확인한 것은 아닙니다.**

## 설치하기

1. **ImageCopySave-0.2.1-x64.msi**를 실행합니다.
2. 설치 안내와 관리자 승인 화면을 확인하고 설치합니다.
3. 이 PC에 실제로 저장된 폴더를 탐색기로 열어 아래 두 메뉴를 사용합니다.

프로그램은 이 PC의 프로그램 폴더에 설치합니다. 따로 설정할 화면은 없습니다. Windows를 시작할 때 자동으로 실행하지 않습니다. 탐색기를 강제로 닫거나 PC를 자동으로 다시 시작하지 않습니다. Windows가 사용 중인 파일 때문에 재시작을 요청하면 작업을 저장한 뒤 직접 재시작하세요.

## 복사한 이미지를 PNG로 저장하기

1. 캡처 도구나 그림 프로그램에서 이미지를 복사합니다.
2. 저장할 **폴더 안 빈 곳에서 마우스 오른쪽 버튼 → 더 많은 옵션 표시 → 복사한 그림 저장**을 누릅니다.
3. 같은 폴더에 만들어진 **그림_날짜_시간.png**를 확인합니다.

Windows 11에서 **더 많은 옵션 표시**를 거치지 않고 이전 방식의 메뉴를 바로 여는 설정을 사용한다면 마우스 오른쪽 버튼으로 연 메뉴에서 **복사한 그림 저장**을 바로 고릅니다. **복사한 그림 저장**은 **새로 만들기**와 별도로 보이는 메뉴입니다. 메뉴 표시 방식을 바꿀 필요는 없습니다.

저장 위치나 파일명을 다시 묻지 않습니다. 같은 이름이 있으면 번호를 붙여 새 파일을 만들며 기존 파일을 덮어쓰지 않습니다. 저장 후에도 복사한 내용은 유지됩니다.

글·웹 주소·웹페이지 내용만 복사했거나 복사한 내용이 없으면 저장 메뉴가 나타나지 않습니다. 탐색기에서 그림 파일을 일반 **Ctrl+C**로 복사한 경우도 그림 자체가 아닌 파일 이름만 복사됐다면 저장 메뉴가 나타나지 않습니다. 아래 **그림으로 복사**를 사용하세요. 복사한 내용을 바꿨다면 메뉴를 닫고 다시 엽니다.

## 그림 파일을 이미지로 복사하기

1. 탐색기에서 **PNG, JPG/JPEG 또는 BMP 파일 한 개**를 선택합니다.
2. **마우스 오른쪽 버튼 → 더 많은 옵션 표시 → 그림으로 복사**를 누릅니다. 이전 방식의 메뉴가 바로 열리도록 설정한 PC에서는 **그림으로 복사**를 바로 고릅니다.
3. 복사 완료 안내를 확인한 뒤 사용할 프로그램에서 **Ctrl+V**를 누릅니다.

파일의 위치나 첨부 파일 목록을 복사하는 대신 그림 자체를 복사합니다. 원본 파일은 수정·이동·삭제하지 않습니다. 복사 후 작업 프로그램이 종료되어도 붙여넣을 수 있습니다. 여러 파일·폴더·지원하지 않는 확장자를 선택하면 메뉴를 표시하지 않습니다.

## 처리할 수 있는 이미지와 위치

| 항목 | 지원 범위 |
|---|---|
| 그림 파일 | 각 색을 256단계까지 구분하는 일반 화면용 PNG·JPG/JPEG·BMP의 움직이지 않는 그림 한 개 |
| 저장 형식 | PNG 고정. 크기·비율을 임의로 줄이지 않으며 같은 이름은 번호를 붙임 |
| 투명도 | 지원하는 PNG 또는 투명한 부분을 알려 주는 정보가 있는 그림에서 유지합니다. 붙여넣는 프로그램에 따라 달라질 수 있습니다. |
| 이미지 크기 | 가로·세로 각각 16,384픽셀 이하이며 총 50,000,000픽셀 이하 |
| 데이터 크기 | 입력 파일과 압축된 그림 데이터는 각각 128MiB 이하입니다. PC가 한 번에 처리할 수 있는 용량이 부족하거나 안전한 처리 한도를 넘으면 중단합니다. |
| 파일 위치 | 접근할 수 있는 PC 내부 저장장치의 실제 파일·폴더 |

GIF·TIFF·WebP·HEIC·AVIF·SVG·PDF와 움직이는 그림은 지원하지 않습니다. 밝고 어두운 부분이나 색상을 특별한 방식으로 저장한 고화질 그림도 지원하지 않습니다. 별도 색상 설정이나 기본 방식과 다른 밝기 설정을 쓰는 PNG, 별도 색상 설정·인쇄용 색상·여러 사진을 담은 JPEG, 색상 목록을 따로 저장하거나 압축한 BMP도 처리하지 못할 수 있습니다.

그림을 PNG 형식으로 다시 저장합니다. 원본에 들어 있는 설명·색상 정보 등을 모두 그대로 보관하는 기능은 아닙니다.

홈·갤러리·검색 결과·휴지통·ZIP 내부와 바탕화면 자체의 빈 곳은 저장 위치로 지원하지 않습니다. 바탕화면 **폴더를 탐색기로 연 경우**에는 PC에 실제로 저장된 폴더 조건을 따릅니다. 네트워크 저장장치, 실제 저장장치가 아닌 위치, 다른 곳에 연결된 파일·폴더, 온라인에만 있는 파일은 제외합니다. PC에 내려받은 온라인 저장소의 파일도 연결 표시가 남아 있으면 처리하지 못할 수 있습니다.

## 업데이트·복구·제거하기

복구·제거에는 **현재 설치된 버전의 설치 파일**을 사용하세요. 아래 절차의 실제 설치 확인은 **0.2.0**에서 했습니다. 이전 버전 업데이트가 기존 설정과 겹치거나 바뀐 파일 때문에 중단되면, 구버전으로 먼저 제거하지 말고 아래 충돌 안내를 따르세요.

- **업데이트:** 새 버전 설치 파일을 실행합니다. 자동으로 새 버전을 설치하지는 않습니다.
- **복구:** 현재 설치된 버전의 설치 파일을 다시 열어 **복구**를 선택합니다. 설치된 프로그램 파일이 없어진 경우 다시 채울 수 있습니다.
- **제거:** **Windows 설정 → 앱 → 설치된 앱 → ImageCopySave → 제거**를 누르거나 현재 설치된 버전의 설치 파일에서 **제거**를 선택합니다.

설치기가 관리하는 프로그램 파일과 두 기능의 메뉴 설정을 처리합니다. 원본 그림·저장한 PNG·업무 파일·다른 프로그램의 메뉴·기본 연결 프로그램은 보존합니다. 설치 폴더에 따로 추가한 파일이 남아 있으면 제거 후 폴더가 남을 수 있습니다.

0.2.0 설치기는 PC 전체나 현재 사용자의 기존 프로그램 설정과 같은 이름이 겹치거나 누구의 것인지 알 수 없는 설치 폴더가 있으면 설치를 중단합니다. 설치 후 외부에서 바꾼 프로그램 파일이나 설정값이 발견되면 복구·업데이트·제거도 중단하여 변경 내용을 보존합니다. 보호 기능의 확인 범위는 [0.2.0 배포 안내](https://github.com/prozac0401/Workspace/releases/tag/image-copy-save-v0.2.0)를 확인하세요.

**기존 설정과 겹치거나 파일이 바뀌어서 중단된 경우:** 오류 문구와 사용 중인 버전을 확인해 [제품 문의](https://github.com/prozac0401/Workspace/issues)에 전달하세요. 회사 PC라면 설치 담당자에게 확인을 요청하세요. 기존 폴더나 설정을 한꺼번에 지우지 마세요. 담당자가 겹친 항목이 누구의 것인지 확인해야 합니다. 필요한 사본을 먼저 보관한 뒤 되돌릴 방법을 정합니다. 설치 파일을 다시 실행하는 것만으로 외부 변경을 강제로 덮어쓰지는 않습니다.

## 메뉴가 없거나 작업이 실패할 때

| 상황 | 확인할 내용 |
|---|---|
| 메뉴가 보이지 않음 | Windows 11에서는 **더 많은 옵션 표시**를 여세요. PC에 실제로 저장된 폴더인지, 지원 파일 한 개 또는 복사한 내용이 지원하는 그림인지 확인한 뒤 메뉴를 다시 여세요. 설치 직후라면 새 탐색기 창에서도 확인하세요. |
| 그림 파일을 복사했는데 저장 메뉴가 없음 | 일반 파일 복사와 이미지 복사는 다릅니다. 파일의 **그림으로 복사**를 먼저 실행하세요. |
| 저장·복사 중 오류 | 원본 이동·손상, 폴더 쓰기 권한, 남은 디스크 공간, 그림 크기와 파일 크기가 한도 안에 있는지 확인하세요. 저장 위치를 임의로 바꾸거나 관리자 권한으로 다시 실행하지 않습니다. |
| 처리 중 다른 내용을 복사함 | 새 복사 내용을 덮어쓰지 않도록 작업이 중단될 수 있습니다. 필요한 그림을 다시 선택해 실행하세요. |
| 저장 파일은 있지만 선택되지 않음 | 메뉴를 눌렀던 폴더에서 생성된 PNG를 확인하세요. 저장 성공과 탐색기의 파일 선택은 별개입니다. |
| 탐색기가 일시적으로 응답하지 않음 | 작업이 회복되는지 확인하고 반복 실행을 멈추세요. 재현 순서와 Windows 버전을 문의에 남기세요. 원인 확인 없이 다른 프로그램의 메뉴나 업무 파일을 삭제하지 마세요. |

제품은 이미지나 복사한 내용을 외부로 보내지 않습니다. 복사한 내용의 기록도 따로 모으지 않습니다. Windows나 다른 프로그램이 복사한 내용을 기록하거나 다른 PC와 함께 쓰도록 한 설정은 그대로 둡니다. 문의에는 업무 이미지·개인 정보·실제 폴더 위치·문제 확인용 기록 전체를 공개하지 마세요.
