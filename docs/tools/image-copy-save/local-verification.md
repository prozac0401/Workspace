# 그림 복사·저장 · 이 PC에서 마지막으로 확인하기

도구 ID: ImageCopySave · 기록일: 2026-09-25 · 상태: **설치 전 검증 안내**

현재 요구는 [v1.1](ImageCopySave_Requirements_v1.1.md)이며, 저장 메뉴는 실제 폴더 빈 공간의 **첫 우클릭 메뉴**에 있어야 합니다. 이미지가 없으면 완전히 사라져야 합니다. 아래 항목을 실행하기 전에는 제품 출시 완료로 판정하지 않습니다. 자동시험 결과는 [시험 기록](../../../tools/ImageCopySave/TEST_RESULTS.md)을 확인하세요.

## 설치할 수 있는 파일부터 준비합니다

unsigned MSIX는 내용 검사와 개발 검토를 위한 파일입니다. 일반 사용자에게 배포할 설치 완료본이 아닙니다. 먼저 게시자와 일치하는 코드서명 인증서로 패키지를 서명하고, 대상 PC에서 그 서명을 신뢰하는지 확인해야 합니다. 기존 인증서의 존재만으로 신뢰·배포 승인을 뜻하지 않습니다.

개발자 모드, 인증서 가져오기, 레지스트리 편집을 일반 사용자의 정상 설치 절차로 요구하지 않습니다. 조직 PC라면 기존 앱 설치·서명 정책에 맞는 인증서/배포 경로를 결정해야 합니다. 이 결정이 없으면 메뉴 시험 전에 멈춥니다. 서명과 설치용 개발 스크립트는 [설치 안내](../../../tools/ImageCopySave/installer/README.md)에 있습니다.

신뢰되는 서명의 패키지가 준비되면 MSIX를 더블클릭하고 **설치**를 누릅니다. 설치가 차단되면 표시된 오류를 기록합니다. Explorer를 강제로 종료하지 마세요. 메뉴 갱신에 로그아웃이 필요한 경우 작업을 저장한 뒤 직접 로그아웃하고 다시 로그인합니다.

## 첫 사용 확인 — 약 5분

이번 작업 폴더의 `artifacts/image-copy-save/manual-test/A`와 `B`에 시험 공간을 준비했습니다. A에는 투명도 시험 PNG와 텍스트가 있습니다. 다른 PC라면 업무 자료가 없는 로컬 시험 폴더 A와 B를 만듭니다. 네트워크·온라인 전용 폴더는 사용하지 않습니다. 아래 시험은 실제 클립보드를 바꾸므로 보관할 복사 내용이 있다면 먼저 붙여넣어 두세요.

1. 작은 PNG 하나를 A에 넣고 그 파일을 우클릭합니다. **그림으로 복사**를 누릅니다. 짧은 완료 안내가 표시되고 원본 파일은 그대로 있어야 합니다.
2. A의 빈 공간을 우클릭합니다. 첫 메뉴에 **복사한 그림 저장**이 보여야 합니다. 누르면 `그림_날짜_시각.png`가 생기고 가능하면 같은 보기에서 선택돼야 합니다. 저장 대화상자와 새 탐색기 창은 뜨지 않아야 합니다.
3. 같은 초에 반복해서 저장합니다. 이름이 겹치면 `_2`, `_3`가 붙고 이전 파일은 그대로 남아야 합니다. B에도 저장할 수 있어야 합니다.
4. 메모장에서 글자만 복사하고 폴더의 메뉴를 다시 엽니다. **복사한 그림 저장**과 빈 앱 하위 메뉴가 모두 없어야 합니다. 회색 항목이 남는 것도 실패입니다.
5. PNG 파일을 일반 **Ctrl+C**로 복사합니다. 이것은 파일 목록 복사이므로 저장 메뉴가 없어야 합니다. **그림으로 복사**로 복사한 상태와 구분합니다.
6. 그림 파일 두 개·폴더·TXT를 각각 선택합니다. **그림으로 복사**가 없어야 합니다.

## 창·탭·붙여넣기 확인

1. A와 B를 서로 다른 창·탭에 열고 각각 저장합니다. 항상 메뉴를 호출한 폴더에만 파일이 생겨야 합니다.
2. 저장을 누른 직후 다른 탭으로 이동하거나 원래 탭을 닫습니다. 다른 탭의 선택·포커스를 바꾸거나 새 창을 열지 않아야 합니다. 저장 성공과 선택 실패를 혼동하는 오류가 없어야 합니다.
3. 그림으로 복사한 뒤 안내가 사라질 때까지 기다립니다. 그림판에 Ctrl+V로 붙여넣습니다. 파일 첨부가 아니라 그림이 붙어야 합니다.
4. 실제 사용하는 Word·PowerPoint·메일·메신저에도 붙여넣습니다. 초안 화면에서만 확인하며 메시지는 보내지 않습니다. 앱 이름·버전과 투명도/배경 처리 결과를 기록합니다.
5. 시험용 원본을 옮긴 뒤에도 붙여넣기가 되는지 확인합니다. 업무 원본으로 이동·삭제 시험을 하지 않습니다.

정식 G0에서는 **이미지 → 텍스트 → 빈 클립보드 → 이미지** 전환을 20회 반복하고 매번 새 메뉴의 표시·숨김과 잔재 여부를 기록합니다. 빈 상태는 Windows 클립보드 설정의 지우기를 사용하면 기존 내용·기록이 지워질 수 있으므로, 필요한 내용을 보관한 뒤 직접 수행합니다. 자동시험의 private clipboard는 이 실제 메뉴 시험을 대신하지 않습니다.

## 제거·재설치 확인

Windows 설정의 설치된 앱에서 **그림 복사·저장 평가 후보**를 제거합니다. 만든 PNG가 그대로 남고 두 명령이 사라지는지 확인합니다. 다시 설치해 메뉴가 중복되지 않는지 확인합니다. 기존 PNG/JPEG/BMP 연결 프로그램과 일반 Ctrl+C/Ctrl+V도 유지되어야 합니다. 업데이트 검증은 버전이 더 높은 서명된 같은 identity 패키지로 별도 수행합니다.
