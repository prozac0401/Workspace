# 그림 복사·저장 · 남은 실기 확인

도구 ID: ImageCopySave · 기준: 2026-09-27 · 상태: 배포 전 확인

현재 요구는 [v1.2 변경 계약](ImageCopySave_Requirements_v1.2.md)입니다. Windows 11 x64의 자체 포함 무서명 MSI를 관리자 승인으로 설치하고 평소 명령은 일반 사용자로 실행합니다. 기본 메뉴에서는 **더 많은 옵션 표시**를 거치고 클래식 직접 표시 모드에서는 바로 접근합니다. 실제 Windows 10 운영체제는 지원 검증 대상에 포함하지 않습니다.

[기존 실기](../../delivery/image-classic-msi-20260927.md)의 MSI 설치·복구·업데이트·제거·실패 롤백·재설치와 클래식 메뉴 PNG 복사·저장 결과는 유지합니다. 아래 미확인 기능과 관련 수정의 영향만 추가 확인합니다. 최신 차단 조건은 [배포 준비 판정](../../delivery/image-release-readiness-20260927.md)을 따릅니다.

## 시험 전

업무 자료가 없는 로컬 시험 폴더 A와 B, 작은 PNG·JPEG·BMP와 TXT를 준비합니다. 클립보드의 필요한 내용은 먼저 다른 곳에 보관하세요. 시험은 클립보드를 바꾸며 이전 내용을 완전히 복원한다고 보장하지 않습니다. 버전·해시를 확인하고 별도 설치가 필요한 경우 [설치 안내](../../../tools/ImageCopySave/installer/README.md)를 따릅니다. 다른 제품의 등록이나 알 수 없는 설치 폴더가 있으면 설치 시험을 시작하지 않습니다.

인증서·개발자 모드·보안 설정을 변경하지 않습니다. 메뉴 설정 전환이나 Explorer 재시작은 이 체크리스트의 기본 동작이 아닙니다. 기본 메뉴를 관찰할 수 없으면 미확인으로 기록합니다.

## 기본 Windows 11 메뉴의 대표 확인

1. PNG 하나를 우클릭하고 **더 많은 옵션 표시 → 그림으로 복사**를 누릅니다. 원본은 유지되고 완료 안내가 보여야 합니다.
2. A의 빈 공간을 우클릭하고 **더 많은 옵션 표시 → 복사한 그림 저장**을 누릅니다. A 안에 PNG가 생겨야 하며 저장 대화상자나 새 탐색기 창은 뜨지 않아야 합니다.
3. 텍스트, 빈 상태, URL/HTML, 일반 Ctrl+C로 복사한 파일 목록에서는 저장 명령이 완전히 없어야 합니다. 지원 이미지가 있으면 보여야 합니다. 각 미확인 조건의 대표 사례만 수행합니다.
4. 지원 JPEG·BMP 한 개, PNG 두 개, PNG와 TXT 혼합, 폴더 선택을 각각 확인합니다. 지원 이미지 한 개에만 복사 명령이 있어야 합니다.

상태 전환 15회·46개 관찰의 기존 PASS는 클래식 직접 표시의 당시 결과입니다. 16~20회는 사용자 지시에 따라 반복 생략했으며 필수 잔여가 아닙니다. 기본 메뉴 경로를 기존 클래식 PASS로 대신하지 않습니다.

## 창·탭·붙여넣기 확인

1. A와 B를 서로 다른 창·탭에서 열어 저장합니다. 호출한 폴더에만 파일이 생기는지 확인합니다.
2. 저장 직후 다른 탭으로 이동하거나 호출 탭을 닫는 대표 사례를 확인합니다. 다른 탭의 포커스·선택을 바꾸거나 새 창을 열지 않아야 하며 저장 성공과 선택 실패가 구분돼야 합니다.
3. 복사 후 helper가 종료된 상태에서 외부 앱에 붙여넣습니다. 그림판의 이전 대표 결과는 유지하고 Word·PowerPoint·메일·메신저는 실제 수행한 앱·버전과 투명도 결과만 기록합니다. 메시지는 보내지 않습니다.
4. 취소·오류·지연 안내의 미확인 대표 사례를 확인합니다. Explorer 무응답이 생기면 상황과 결과를 기록하고 반복 입력을 멈춥니다. 기존 무응답 원인은 미확정입니다.

## 설치 자원 보존 확인

기존 정상 수명주기는 통과했지만 같은 이름의 기존 메뉴 등록과 외부 수정 자원 보존은 별도 미완료입니다. [DEP-06 검토](../../delivery/image-release-readiness-20260927.md)의 보호를 구현한 후보에서 충돌·수정·복구·제거 시험을 수행합니다. 사용자의 실제 설치 파일이나 등록을 바꾸어 재현하지 않습니다.

## 결과 기록

| 항목 | 현재 판정 | 추가 기록 |
|---|---|---|
| MSI 설치·복구·업데이트·제거·롤백·재설치 | 이전 지정 시나리오 PASS | 같은 결과를 새 시험으로 집계하지 않음 |
| 클래식 직접 표시 PNG 복사·저장 | 이전 대표 실기 PASS | 당시 버전과 범위 유지 |
| 기본 메뉴 → 더 많은 옵션 표시 | 복사·저장 사용자 직접 확인 PASS | 비이미지 조건별 숨김 등 나머지 대표 조건은 별도 |
| JPEG·BMP·혼합·폴더 선택 | 미확인 범위 남음 | 원본 불변·표시/숨김 |
| A/B 창·탭·결과 선택·포커스 | 미확인 범위 남음 | 호출 폴더와 생성 위치 |
| 외부 앱·취소·오류 안내 | 일부만 확인 | 앱·버전·실제 결과 |
| 기존·외부 수정 설치 자원 보존 | 설계 보완·실기 필요 | 충돌 거절·원본 보존 |

수행한 결과만 PASS로 기록합니다. 화면에는 시험 자료만 담고 원시 사용자 경로·진단·로그는 공개 사이트에 게시하지 않습니다.
