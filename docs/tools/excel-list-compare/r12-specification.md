## 사용자와 목적

차이 결과와 **담은 목록 확인**의 문구가 어렵다는 피드백에 따라, 처음 읽어도 값·개수·원본 위치를 구분할 수 있게 고친다. 긴 설명과 비교 전의 불필요한 두 번째 목록 칸을 줄인다.

## 요구사항과 구현

| ID | 요구 행동 | 반영 내용 |
|---|---|---|
| REQ-EXCEL-032 | 차이를 쉬운 말로 설명한다 | ‘상태’ → ‘차이’, ‘남은 수’ → ‘더 많은 개수’, ‘대표 주소’ → ‘원본 셀 (예)’ |
| REQ-EXCEL-033 | 결과표를 간결하게 보여준다 | A:F의 주요 6열을 표시. G:J의 추가 개수·원본 셀은 숨김 열로 보존. 제목 8행·데이터 9행과 기존 데이터 열 순서는 유지 |
| REQ-EXCEL-034 | 담은 첫 목록을 명확히 보여준다 | 요약을 3열·20항목에서 2열·14항목으로 정리. 출처·시각·전체 개수·제외 개수·일부 표시 한도 유지 |
| REQ-EXCEL-035 | 위치 안내를 쉽게 읽게 한다 | ‘제외·발생위치’ 시트를 ‘값과 위치’로 변경. ‘표본’은 ‘표시한/표시하지 않은 위치’로 설명. 같은 목록 이름이 반복되는 B열은 숨김 |
| REQ-EXCEL-036 | 로직을 유지하고 R12 설치본을 배포한다 | 비교·수집·정규화·설정·취소·복구는 R11 그대로. 사용자 요청에 따라 기존 테스트를 실행하지 않으며 제작 확인과 구분해 기록 |

## 데이터 계약과 UX

결과표의 ‘비교한 값’은 현재 비교 설정을 적용한 값이다. ‘원본 값 (예)’와 ‘원본 셀 (예)’는 처음 발견한 셀 하나의 예이며, 잘못된 셀을 특정하는 판정이 아니다. G:J를 보려면 F~K열 머리글을 선택하고 우클릭 → **숨기기 취소**를 누른다. 숨김은 화면 표시만 바꾸며 값·개수·주소를 삭제하지 않는다.

**담은 목록 확인**은 현재 선택을 다시 읽지 않는다. 이전에 담아 둔 첫 목록을 보여준다. **값과 위치**에는 목록당 최대 1,200개·같은 비교값당 5개, 오류 위치는 최대 200개를 표시하고 생략 수를 알린다. 비교와 개수 집계는 전체 대상으로 수행한다. 요약의 읽은 영역 수 등 내부 처리 지표와 반복 설명은 표시하지 않는다.

빈칸·오류·표 제목·합계 제외, 숨김·필터 제외, 원본 보존, 수식 실행 방지, 일치 시 결과 미생성, 성공 후 비우기/유지는 기존 계약을 따른다. 입력 제한·수집 표본 한도·출력 순서·비교 설정 저장 형식도 유지한다. 결과와 확인용 파일은 사용자가 직접 저장한다.

## 동시 실행·복구·설치

현재 계정 설치, 설정 보존, 잠금, 오류·취소 시 이전 목록 복구와 설치·업데이트·제거 동작은 바꾸지 않는다. 설치 버전과 도움말 버전만 `0.2.0-rc.12`로 올린다. 조직의 서명·배포 승인 설정은 미결정 상태다.

## 검증·지원과 배포 기록

이번 사용자 요청은 기존 테스트 없이 문구를 반영하고 R12를 릴리즈하는 것이다. Python 회귀, Excel 기능·UI·성능·취소 및 설치 수명주기 시험은 **NOT_RUN**으로 남긴다. 빌드 중 소스 가져오기·저장, 소스의 버전 확인, 저장한 파일의 소스 대조, 패키지 제작·해시 확인, 문서 strict 빌드·링크 확인은 제작 작업이며 기능 시험 통과를 의미하지 않는다. 최종 BuildOnly 경로는 저장한 XLAM을 재개방하거나 매크로를 실행하지 않는다.

실제 결과는 [R12 배포 기록](../../../tools/ExcelSmartListCompare/docs/RC12_RELEASE_REPORT.md)에 보존한다. R11의 테스트 통과를 R12에 재사용하지 않는다.
