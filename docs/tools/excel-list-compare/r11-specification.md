# Excel 명단 비교 · R11 제품 명세

도구 ID: ExcelSmartListCompare / EXCEL-LIST-COMPARE

명세 버전·상태: 0.3 · 2026-09-20 · **R11 구현·필수 검사·GitHub 배포 완료. 전체 인수 상태는 검증 기록 참조**

제품 책임: 도구 개발·검증 담당

적용 정책: [추가 도구 개발 기준](../../policies/tools.md), [정책 문서 작성 규칙](../../policies/documentation.md)

원래 요구·이전 버전: [실제 Excel 검증 작업 지시](../../../tools/ExcelSmartListCompare/archive/CODEX_EXCEL_E2E_TEST_PROMPT.md), [기존 제품 명세와 검증 기록](specification.md)

관련 ADR·인수: [ADR-0018 · R11 비교 설정과 완료 동작](../../../tools/ExcelSmartListCompare/docs/ADR-0018-R11-comparison-options.md), [R11 인수 요구사항](../../../tools/ExcelSmartListCompare/docs/ACCEPTANCE_TESTS.md#r11-2026-09-20)

이 문서는 R11의 구현 기준이다. 설정 경로가 현재 배포된 RC10에 이미 있다는 뜻이 아니다. 아래 변경과 충돌하는 이전 버전의 비교 규칙·결과 생성·첫 목록 유지 요구는 R11에서 이 명세를 따른다. 나머지 데이터 보존·설치 계약과 과거 버전의 실제 검증 판정은 유지한다. 개발 명세는 저장소에 보존하며 공개 사용 안내는 구현·검증한 배포 버전에 맞춰 갱신한다.

## 사용자와 목적

두 목록의 값과 중복 개수가 같은지 빠르고 가볍게 확인한다. 기본 사용 흐름은 첫 목록 담기 → 두 번째 목록과 비교 → 성공하면 첫 목록 비우기다. 메일 비교 범위, 대소문자 처리, 첫 목록 재사용이 필요한 사용자는 **비교 설정**에서 바꾼다. 비교할 때마다 설정을 묻지 않는다.

## 범위와 금지 동작

기존 Selection 전체를 목록 하나로 읽고 같은 Excel 프로세스 안에서 비교하는 계약을 유지한다. 가로·세로·부분·사각형·단일 셀·Ctrl 다중·겹친 선택, 필터·숨김·제목·합계 제외 규칙은 바꾸지 않는다. 다른 셀의 같은 값은 중복으로 세고, 겹쳐 선택한 같은 셀은 한 번만 센다.

원본 값·수식·서식·필터와 이전 결과를 변경하지 않는다. 스냅샷을 자동으로 다시 읽거나 영구 저장하지 않으며 외부 전송·다른 Excel 프로세스와의 공유를 추가하지 않는다. 결과는 필요한 경우 새 통합문서로 만들고 사용자가 직접 저장한다. 설정 접근을 위해 전역 단축키·관리자 권한·보안 정책 변경을 요구하지 않는다.

## 데이터 계약

### 기본값과 비교 의미

| 설정 이름 | 기본값 | 변경했을 때 |
|---|---|---|
| 메일 비교 범위 | **`@` 앞부분만 비교** | **전체 주소 비교**를 선택하면 `@` 뒤 도메인까지 비교 |
| 대소문자 무시 | **꺼짐** — 대문자와 소문자를 구분 | 켜면 대문자와 소문자를 같은 문자로 비교 |
| 비교 후 첫 목록 유지 | **꺼짐** — 성공하면 첫 목록 비우기 | 켜면 첫 목록을 남겨 다음 목록과 이어 비교 |

설정이 아직 없는 최초 상태의 기본값이다. Excel을 다시 열 때 마지막으로 적용한 세 설정을 자동 복원하며 기본값으로 되돌리기도 제공한다. 메일 범위와 대소문자 설정은 서로 독립적이며, 첫 목록 유지 설정은 비교 결과 자체를 바꾸지 않는다.

| 비교 예 | 앞부분만 / 무시 꺼짐 | 앞부분만 / 무시 켜짐 | 전체 주소 / 무시 꺼짐 | 전체 주소 / 무시 켜짐 |
|---|---|---|---|---|
| `User@a.test`와 `User@b.test` | 같음 | 같음 | 다름 | 다름 |
| `User@a.test`와 `user@a.test` | 다름 | 같음 | 다름 | 같음 |
| `User@A.test`와 `User@a.test` | 같음 | 같음 | 다름 | 같음 |

일반 텍스트 `ABC`와 `abc`도 대소문자 무시가 꺼져 있으면 다르고 켜져 있으면 같다. 기존 숫자 정규화는 별도로 유지하여 숫자 `123`과 텍스트 `123`·`123.0`·`1.23e2`는 같고, `1E3`·`1e3`·숫자 `1000`도 같다. 텍스트 `00123`의 앞자리 0은 보존한다. 기존 공백 처리와 메일 주소 인식 범위는 유지하며 복수 주소나 `이름 <주소>`를 새로 분해하지 않는다.

### 결과 생성 조건

- 선택한 비교 규칙을 적용한 뒤 **값과 그 값의 개수가 모두 같으면** 일치 안내만 표시한다. 결과를 잠깐 생성했다 닫는 방식도 사용하지 않는다.
- A와 B가 각각 `[a, a]`이면 중복이 있어도 결과를 만들지 않는다. A가 `[a, a]`, B가 `[a]`이면 개수가 다르므로 결과를 만든다. 순서는 결과에 영향을 주지 않는다.
- 도메인이나 대소문자를 무시하도록 선택했다면 그 차이만으로 결과를 만들거나 별도 상세 시트를 작성하지 않는다. **규칙으로 같아진 값**의 자동 작성과 그 시트만을 위한 상세 원문 변형 수집·대조를 기본 처리에서 제거한다.
- 오류 셀을 제외한 뒤 비교값과 개수가 같으면 결과 파일 없이 제외 개수를 알리고 **오류를 제외한 비교 대상이 같습니다**라고 안내한다. 원본 전체가 완전히 같다고 표현하지 않는다. 비교할 유효 값이 없는 경우는 기존의 **비교할 값 없음**으로 처리하며 성공 일치로 간주하지 않는다.
- 실제 값·개수 차이가 있을 때는 필요한 비교값·개수·원문 예·출처·제외 집계를 보존한다. 차이 결과는 `명단비교_결과` 시트 하나, 8행 제목·9행 데이터와 RC9 열 순서를 사용한다. 같은 개수의 중복은 출력하지 않는다. 기존 결과의 자동 덮어쓰기나 저장은 하지 않는다.

## UX

### 설정에 접근하는 경로

1. **Excel → 추가 기능 탭 → 비교 설정**
2. **셀 우클릭 → 명단 비교 → 비교 설정**

두 경로는 같은 세 체크 항목과 현재값을 사용한다. 메일 전체 주소 비교 체크가 꺼져 있으면 앞부분만 비교한다. 같은 Excel 프로세스의 창을 바꾸어도 설정과 첫 목록 상태가 일치해야 한다. 설정은 가벼운 체크 메뉴로 제공하며 필요할 때 직접 연다. 첫 목록 담기나 매 비교 전에 자동으로 띄우지 않는다. 세 옵션의 현재 선택과 기본 동작을 쉬운 문구로 표시하고, 비활성화된 옵션에는 이유를 안내한다. 실제 메뉴 표시·클릭·키보드 이동·화면 잘림을 별도로 확인한다.

### 설정을 바꿀 수 있는 시점

| 상태 | 메일 비교 범위·대소문자 무시 | 비교 후 첫 목록 유지 |
|---|---|---|
| 첫 목록 없음, 작업 대기 | 변경 가능 | 변경 가능 |
| 첫 목록 있음, 작업 대기 | 변경 불가. **비교 기준을 바꾸려면 첫 목록을 비워 주세요** 안내 | 다음 비교 시작 전까지 변경 가능 |
| 첫 목록 담기·바꾸기 또는 비교·결과 작성 중 | 변경 불가 | 변경 불가 |
| 작업 종료 후 | 남아 있는 첫 목록 유무에 따라 위 규칙 적용 | 변경 가능 |

첫 목록은 담을 때 적용한 메일 범위·대소문자 규칙과 함께 보관한다. 두 번째 목록은 반드시 그 규칙으로 비교한다. **첫 번째 목록 비우기**는 스냅샷을 지워 규칙 변경을 가능하게 하며 원본 셀을 지우지 않는다. **첫 번째 목록 바꾸기**도 보유 중인 규칙을 임의로 바꾸지 않는다.

### 비교 완료 후 흐름

| 작업 결과 | 첫 목록 유지 꺼짐 — 기본 | 첫 목록 유지 켜짐 |
|---|---|---|
| 일치 판정 완료, 결과 파일 없음 | 첫 목록을 비우고 **첫 번째 목록 담기**로 돌아감 | 같은 첫 목록을 유지하고 **두 번째 목록 담아 비교**로 대기 |
| 차이 판정과 결과 작성 모두 성공 | 첫 목록을 비우고 **첫 번째 목록 담기**로 돌아감 | 같은 첫 목록을 유지하고 **두 번째 목록 담아 비교**로 대기 |
| 경고 거절·취소·오류·비교할 값 없음·결과 작성 실패 | 이전 첫 목록과 비교 규칙 유지 | 이전 첫 목록과 비교 규칙 유지 |

유지 설정이 켜져 있으면 출처·항목 수·담은 시각이 바뀌지 않아야 한다. 원본 파일을 닫거나 수정해도 자동 갱신하지 않으며 사용자가 **첫 번째 목록 바꾸기 / 비우기**로 직접 관리한다. 꺼져 있어도 실패한 작업 때문에 첫 목록을 다시 담게 만들지 않는다.

## 동시 실행과 복구

담기·바꾸기·비교 작업을 시작할 때 그 작업에서 사용할 설정을 고정하고 완료까지 변경을 막는다. 같은 프로세스의 다른 메뉴·창에서 설정을 바꾸거나 작업을 중복 시작해도 진행 중인 값과 스냅샷을 바꿀 수 없어야 한다.

일치 판정 또는 차이 결과 작성이 정상적으로 확정된 후에만 첫 목록 비우기를 적용한다. 확정 전 오류·취소·경고 거절은 이전 첫 목록의 값·출처·시각·개수·비교 규칙을 보존하고 이번 작업의 미완성 결과만 정리한다. 바꾸기 실패도 이전 스냅샷을 유지한다. 기존 결과와 사용자가 편집한 파일을 닫거나 지우지 않는다.

Excel 설정과 상태표시줄의 값·형식을 복원하는 기존 요구를 유지한다. 취소 요청과 실제 취소·정상 완료·시간 초과를 구분하며 기존 미해결 동작을 해결됐다고 표시하지 않는다.

## 설치·업그레이드·제거

현재 계정의 제품 파일과 HKCU만 관리하는 기존 설치·보존 계약을 유지한다. 이번 설정 기능을 위해 설치 권한이나 보안 설정 요구를 늘리지 않는다. 설정은 현재 계정의 제품 전용 레지스트리 값 하나로 저장하고 업데이트·재설치·제거 후에도 보존한다. 사용자는 기본값으로 되돌리기로 초기화한다.

설치 패키지와 일반 설치 안내는 제품명과 버전으로 안내하며 **시험판** 문구와 시험 실패 목록을 넣지 않는다. 실제 실패·부분 검증·미실행은 별도 검증 기록에 그대로 보존한다. 이 문서 반영은 설치 파일 제작·게시 요청이나 검증 완료 판정이 아니다.

## 구현 순서와 후속 결정

1. 세 설정의 단일 상태와 기본값, 첫 목록의 비교 규칙 보관·잠금을 구현한다.
2. 두 설정 메뉴와 체크 상태를 연결하고 작업 중 변경을 막는다.
3. 두 목록의 규칙을 일치시키고, 일치 시 출력 생략과 불필요한 원문 변형 수집 제거를 적용한다.
4. 성공 후 비우기·선택적 유지와 취소·실패 복구를 연결한다.
5. 빠른 필수 검사와 동일 XLAM의 실제 Excel 검증 후 패키징·GitHub 배포를 진행한다.

사용자의 구현·GitHub 배포 요청과 직전 권장안에 따라 **마지막 설정 자동 기억 + 기본값으로 되돌리기**, **RC9의 단일 시트·열 순서**를 적용한다. 설정 메뉴는 매 비교에 앞서 자동으로 열지 않는다. 이행·저장·검증 범위 결정은 [ADR-0019](../../../tools/ExcelSmartListCompare/docs/ADR-0019-R11-release-scope.md)를 따른다.

### 설정 저장과 재시작

`HKCU\Software\VB and VBA Program Settings\ExcelSmartListCompare\Preferences`의 `OptionsV1`에 `1|전체주소|대소문자무시|첫목록유지` 형식으로 저장한다. 세 플래그는 `0` 또는 `1`이며 최초 기본값은 `1|0|0|0`이다. 한 값에 함께 저장하고 실패하면 메모리의 기존 설정도 유지한다. 저장값이 없거나 읽기 실패·형식 오류면 기본값을 사용하며 읽기만으로 저장값을 덮어쓰지 않는다.

같은 PC·Windows 계정에 옵션만 저장한다. 첫 목록의 내용·출처·시각은 저장하지 않으므로 Excel 완전 종료 뒤에는 첫 목록을 다시 담아야 한다. 같은 프로세스의 창은 현재 설정을 공유하고, 별도 프로세스는 시작 시 저장값을 읽는다. 마지막으로 성공한 설정 저장이 다음 실행에 적용되며 이미 담은 목록의 규칙은 바꾸지 않는다.

기본값 복원은 먼저 첫 목록을 비워야 하며 작업 중에는 실행하지 못한다. 업데이트·재설치·제거는 사용자 비교 설정을 보존한다. 조직별 배포·서명 정책은 아직 미결정이며 이 개인 사용자 설정의 채택과 구분한다.

### 필수 검사와 배포 후 검증

사용자 요청에 따라 대용량 시간·메모리 비교, 실제 취소 반복, 전체 메뉴·창·배율 조합과 설치 수명주기 반복은 이번 선배포 검사에서 제외한다. 빠른 비교·설정·상태·출력 복구, 동일 XLAM 소스 대조와 실제 내장 기능, 패키지 무결성과 문서 검사는 필수다. 장시간 항목의 재현 경로와 기대값은 [사용자 검증 안내](../../../tools/ExcelSmartListCompare/docs/RC11_USER_VALIDATION.md)에 제공하고 미실행을 통과로 표시하지 않는다.

## 검증·지원

[R11 인수 요구사항](../../../tools/ExcelSmartListCompare/docs/ACCEPTANCE_TESTS.md#r11-2026-09-20)의 R11-01~R11-12로 요구 ID와 실제 증거를 연결한다. 기본값, 네 가지 비교 규칙 조합, 두 설정 경로, 설정 잠금, 일치 시 통합문서 미생성, 두 완료 흐름과 실패 복구를 확인한다. 기존 선택·숫자·앞자리 0·원본·수식 방지 회귀도 유지한다.

성능은 RC9·RC10·R11을 같은 환경과 합성 입력으로 비교하여 입력량·고유값·문자 길이·출력량, 처리 시간과 메모리를 기록한다. 경고 대기 시간을 처리 시간과 구분한다. 기존 안전 상한을 높이거나 100,000개 고유값의 정상 완료를 가정하지 않는다. 실제 Excel의 메뉴·키 입력·화면과 설치 수명주기는 참조 모델·정적 검사와 구분한다.
