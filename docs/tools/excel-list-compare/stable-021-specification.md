# Excel 명단 비교 0.2.1 · 상태표시줄 보존 요구

도구 ID: ExcelSmartListCompare  
버전·상태: 0.2.1 정식 배포 준비  
적용 정책: [도구 정책](../../policies/tools.md)

## 요구사항

| ID | 요구 행동 | 완료 기준 | 근거 |
|---|---|---|---|
| SLC-021-01 | Excel의 기존 상태표시줄을 보존한다 | 담기·비교·취소 요청 후 원시 종류와 값이 같다 | 실제 저장 후보의 세 상태 회귀 검사 |
| SLC-021-02 | 진행·취소 결과를 확인할 수 있다 | 기존 제품 도구 모음의 진행·지속 결과 사용 | UI 초기화·기존 취소 경로 유지 |
| SLC-021-03 | 기존 데이터·설치 계약을 유지한다 | 비교·설정·결과 로직과 설치 동작을 바꾸지 않는다 | 소스 대조·실제 usability·기존 설치 보존 |

StatusBar에 False를 대입해 복원하지 않는다. 제품의 상태표시줄 쓰기 경로를 제거하고 기존 도구 모음에 진행 내용을 표시한다. 비교·취소 처리와 설치 형식은 유지한다. 보안 설정 완화나 다른 추가 기능 수정은 하지 않는다.

[구현·검증·제한](../../../tools/ExcelSmartListCompare/docs/STABLE_RELEASE_REPORT.md)에서 실제 시험과 재사용 근거를 구분한다. 일반 릴리스 채널과 코드 서명·회사 도입 승인을 구분하며 이전 평가판의 FAIL과 미실행 기록은 보존한다.
