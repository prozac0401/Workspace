# Excel 명단 비교 설치·사용

**두 목록에서 다른 값과 중복된 값을 찾으세요.** 첫 번째 목록을 담고 두 번째 목록을 선택하면 비교 결과를 새 Excel 파일에 보여 줍니다. 원본 파일은 그대로 둡니다. 이름과 메일 주소뿐 아니라 일반 텍스트도 비교할 수 있습니다.

## 설치하기

1. Excel에서 작업 중인 내용을 저장하고 모든 Excel 창을 닫습니다.
2. 받은 EXE 파일을 실행하고 **설치**를 누릅니다. ZIP을 받았다면 압축을 모두 풀고 `Release` 폴더의 `Install.cmd`를 실행합니다.
3. 설치가 끝나면 Excel을 엽니다.
4. **추가 기능** 탭에 **첫 번째 목록 담기**가 있는지 확인합니다. 셀을 마우스 오른쪽 버튼으로 클릭한 뒤 **명단 비교** 메뉴에서도 사용할 수 있습니다.

지금 로그인한 Windows 계정에 설치하며 관리자 권한은 필요하지 않습니다. 설치 과정에서 제품 폴더를 Excel의 **신뢰할 수 있는 위치**에 등록합니다. 이 폴더 안의 매크로는 별도 확인 없이 실행될 수 있으므로 Excel 명단 비교 파일만 보관하세요. 회사의 보안 정책을 끄고 설치하지 마세요.

## 두 목록 비교하기

1. 첫 번째 목록의 셀을 선택하고 **첫 번째 목록 담기**를 누릅니다.
2. 두 번째 목록의 셀을 선택하고 **두 번째 목록 담아 비교**를 누릅니다.
3. 결과 파일이 열리면 내용을 확인하고 필요한 위치에 직접 저장합니다.

한 번에 선택한 셀 전체가 **목록 하나**입니다. 가로, 세로, 여러 영역을 선택해도 됩니다. 같은 Excel에서 연 다른 파일과도 비교할 수 있습니다. 두 열을 한꺼번에 선택했다고 자동으로 두 목록으로 나누지는 않습니다.

`첫 번째 목록: 42개 항목`은 빈칸 등 비교에서 뺄 셀을 제외하고 값 42개를 담았다는 뜻입니다. 같은 값이 여러 셀에 있으면 각각 셉니다. 담은 뒤 원본을 고쳐도 이미 담은 값은 바뀌지 않습니다.

| 하고 싶은 일 | 누를 버튼 |
|---|---|
| 담아 둔 목록을 비우기 | **첫 번째 목록 비우기**. 원본 셀은 지우지 않습니다. |
| 현재 선택한 셀로 다시 담기 | **첫 번째 목록 바꾸기** |
| 간단한 사용법 보기 | **사용 안내** |

## 결과 읽기

모두 같고 중복·오류도 없으면 같다는 안내만 나옵니다. 차이·중복·오류가 있으면 새 결과 파일을 만듭니다. 결과는 자동으로 저장하지 않습니다.

아래 표는 **다운로드할 수 있는 RC7 화면의 열 이름**을 설명합니다. 새 문구가 들어간 파일을 공개하기 전까지는 화면에 이 이름이 나타납니다.

| RC7 화면에 보이는 말 | 뜻 |
|---|---|
| 비교키 | 공백 등을 정리한 뒤 실제로 비교한 값 |
| 첫 번째 목록 / 두 번째 목록 개수 | 각 목록에서 같은 값이 나온 횟수 |
| 첫 번째 목록 / 두 번째 목록 잔여 | 같은 값끼리 하나씩 짝지은 뒤 남는 개수 |
| 원본 예 / 주소 | 각 목록에서 해당 값이 처음 나온 셀의 내용과 위치 |
| 첫 번째 목록에만 있음 / 두 번째 목록에만 있음 | 다른 목록에는 없는 값 |

예를 들어 같은 값이 첫 번째 목록에 2개, 두 번째 목록에 1개라면 첫 번째 목록에 1개가 남습니다. 오류가 있는 셀은 비교에서 빼므로, 오류가 제외됐다면 원본 전체가 완전히 같은지는 알 수 없습니다.

## 비교할 때 알아 두세요

- 숨긴 셀과 필터로 가려진 셀, 빈칸, 오류 셀, 표의 제목·합계 셀은 비교에서 뺍니다. 일반 범위의 제목은 직접 빼고 선택하세요.
- 값의 순서는 무시하고, 같은 값이 몇 번 나오는지를 비교합니다.
- 메일 주소는 `@` 앞부분만 비교합니다. `user@a.com`과 `user@b.com`이 같다고 나올 수 있습니다.
- 영문 대소문자와 일부 공백·숫자 표기 차이는 무시합니다. 문자로 입력한 `00123`과 숫자 `123`은 다르게 봅니다.
- 병합된 셀은 비교할 수 없습니다. 수동 계산을 쓰고 있다면 먼저 수식을 계산해 주세요.
- 한 목록의 셀 수 제한은 빈칸을 포함해 100,000개입니다. 그 크기의 목록이 항상 끝까지 비교된다는 뜻은 아닙니다. 시간이 오래 걸리면 중단될 수 있습니다.
- Excel을 완전히 종료하면 담아 둔 목록이 사라집니다. 별도로 실행한 Excel끼리는 목록을 공유하지 않습니다.

## 프로그램 제거하기

1. 작업 중인 내용을 저장하고 모든 Excel 창을 닫습니다.
2. EXE로 설치했다면 **Windows 설정 → 앱 → 설치된 앱 → Excel 명단 비교 → 제거**를 선택합니다.
3. ZIP으로 설치했다면 압축을 풀었던 `Release` 폴더의 `Uninstall.cmd`를 실행합니다.

업무 파일, 다른 추가 기능, 설치 폴더에 사용자가 따로 넣은 파일은 남깁니다. 제거가 실패하면 오류 내용과 코드를 보관하고 반복해서 파일을 지우지 마세요. RC7의 첫 제거 실패 원인은 아직 확정하지 못했습니다.

설치 기록에는 사용자 이름과 폴더 경로가 들어갈 수 있으므로 그대로 공개하지 마세요.
