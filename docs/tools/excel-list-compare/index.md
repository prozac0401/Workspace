## 설치하기

1. 작업 중인 파일을 저장하고 Excel 창을 모두 닫습니다.
2. EXE를 실행하고 **설치**를 누릅니다. ZIP은 모두 푼 뒤 `Release` 폴더의 **Install.cmd**를 실행합니다.
3. Excel을 열어 **추가 기능** 탭의 명단 비교 버튼을 확인합니다.

다음은 설치 방법이며 새 EXE로 실제 검증한 절차는 아닙니다. 현재 Windows 계정에 설치하며 관리자 권한·Python·VBA 편집기는 필요하지 않습니다. 제품 폴더 한 곳을 Excel의 **신뢰할 수 있는 위치**에 등록합니다. 이곳의 매크로는 별도 확인 없이 실행될 수 있으므로 제품 파일만 보관하세요. 회사의 보안 정책은 바꾸지 않습니다.

## 두 목록 비교하기

1. 첫 번째 목록의 셀을 선택하고 **첫 번째 목록 담기**를 누릅니다.
2. 두 번째 목록을 선택하고 **두 번째 목록 담아 비교**를 누릅니다.
3. 새 결과 파일을 확인하고 필요한 위치에 직접 저장합니다.

셀을 오른쪽 클릭한 **명단 비교** 메뉴에서도 실행할 수 있습니다. 가로·세로·사각형·여러 영역을 선택해도 전체가 목록 하나입니다. 두 열을 골랐다고 자동으로 두 목록으로 나누지는 않습니다. 같은 Excel에서 연 다른 파일과도 비교할 수 있습니다.

`첫 번째 목록: 42개 항목`은 빈칸 등 제외한 셀을 뺀 값의 수입니다. 같은 값이 여러 셀에 있으면 각각 셉니다. 담은 뒤 원본을 고쳐도 이미 담긴 값은 유지됩니다.

| 하고 싶은 일 | 누를 버튼 |
|---|---|
| 기억한 목록 비우기 | **첫 번째 목록 비우기**. 원본 셀은 지우지 않습니다. |
| 현재 선택으로 다시 담기 | **첫 번째 목록 바꾸기** |
| 사용법 보기 | **사용 안내** |

## 결과 읽기

모두 같고 중복·오류도 없으면 같다는 안내만 나옵니다. 차이·중복·오류가 있으면 새 결과 파일을 만듭니다. 원본과 이전 결과는 바꾸지 않으며 결과는 직접 저장해야 합니다.

| 화면에 보이는 말 | 뜻 |
|---|---|
| 비교에 쓴 값 | 공백 등 비교 규칙을 적용한 값 |
| 첫 번째 목록 / 두 번째 목록 개수 | 각 목록에서 같은 값이 나온 횟수 |
| 남은 개수 | 같은 값을 하나씩 짝지은 뒤 남는 수 |
| 원래 값 (예) / 셀 주소 | 해당 값이 처음 나온 셀의 값과 위치 |

같은 값이 첫 번째 목록에 2개, 두 번째에 1개라면 첫 번째에 1개가 남습니다. 오류 셀은 비교에서 빼므로 오류가 제외된 결과만으로 원본 전체가 완전히 같다고 볼 수는 없습니다.

## 비교 규칙과 크기 제한

- 숨긴 셀·필터로 가려진 셀·빈칸·오류·표의 제목과 합계는 비교에서 뺍니다. 일반 범위의 제목은 직접 빼고 선택하세요.
- 순서는 무시하며 같은 값의 개수를 비교합니다.
- 메일 주소는 `@` 앞부분만 비교합니다. `user@a.com`과 `user@b.com`이 같다고 나올 수 있습니다.
- 영문 대소문자와 일부 공백·숫자 표기 차이를 정리합니다. 문자로 입력한 `00123`과 숫자 `123`은 다르게 봅니다.
- 병합 셀은 비교할 수 없습니다. 수동 계산 중이면 먼저 수식을 계산하세요.
- Excel을 종료하면 담긴 목록이 사라집니다. 별도 Excel 프로세스끼리는 목록을 공유하지 않습니다.

한 목록의 입력 상한은 숨기지 않은 선택 셀 **100,000개**이며 빈칸도 포함합니다. 이 크기까지 항상 비교를 완료한다는 보장은 없습니다.

| 실제 시험한 입력 | 결과 |
|---|---|
| 서로 다른 48자 값 20,000개씩 | 40,000행 결과 완료 |
| 같은 48자 값 100,000개씩 | 1행 결과 완료 |
| 서로 다른 4,096자 값 1,000개씩 | 2,000행 결과 완료 |
| 중복 위주 1,221셀, 원문 합계 각 5,000,000자 | 1행 결과 완료 |
| 서로 다른 48자 값 50,000개씩·100,000개씩 | 약 30초 처리 제한으로 중단, 결과 없음 |

이는 해당 PC와 입력에서의 관찰입니다. 값 길이·고유값 수·필터·PC 부하에 따라 달라지므로 모든 같은 크기의 선택이나 처리 속도를 보장하지 않습니다.

취소를 시도할 때는 작업 중인 Excel 창을 앞에 두고 **Esc를 누른 채 유지**하세요. 첫 목록 바꾸기의 100ms 유지 요청 두 시험은 이전 목록을 보존했고, 같은 조건에서 키를 누르지 않으면 교체를 완료했습니다. 이는 대조 실험에 근거한 부분 확인이며 취소 안내는 관찰하지 못했습니다. 짧은 입력·모든 작업·일정 시간 내 취소는 보장하지 않습니다. 작업 종료와 목록 항목 수를 확인하세요. 경고창에서 **아니요**를 누르면 시작하지 않습니다.

부분 취소와 원본 파일 보존의 확인을 모든 Excel 설정·복구 동작의 통과로 보지 마세요. 상태표시줄 복원 실패와 미검증 기능은 이 제한 평가판에 남아 있습니다.

## 프로그램 제거하기

1. 작업 중인 내용을 저장하고 Excel 창을 모두 닫습니다.
2. EXE 설치는 **Windows 설정 → 앱 → 설치된 앱 → Excel 명단 비교 → 제거**를 선택합니다.
3. ZIP 설치는 `Release` 폴더의 **Uninstall.cmd**를 실행합니다.

업무 파일·다른 추가 기능·설치 폴더에 따로 넣은 파일은 남깁니다. 제거 오류가 나면 오류 내용을 보관하고 반복해서 파일을 지우지 마세요. 설치 기록에는 사용자 경로가 들어갈 수 있으므로 그대로 공개하지 마세요.
