# 파일 목록을 Excel로 만들기

**File List to Excel**은 탐색기에서 고른 파일·폴더의 목록을 Excel 표로 만들고, 내용이 같은 파일을 찾는 도구입니다. 여러 폴더의 자료를 이름·크기·날짜·경로로 모아 보고, Excel의 필터와 정렬로 필요한 항목을 찾을 수 있습니다. 이 안내는 공개된 **v1.2.0** 기준입니다.

## 설치 전에 확인하세요

## 탐색기에서 목록 만들기

1. 내려받은 **FileListToExcel-1.2.0-win-x64.msi**를 실행합니다. 지금 로그인한 Windows 계정에 설치합니다. 관리자 권한은 필요하지 않습니다. 실행에 필요한 프로그램을 따로 설치하지 않아도 됩니다.
2. 탐색기에서 파일이나 폴더를 고르고 **마우스 오른쪽 버튼 → 더 많은 옵션 표시**를 누릅니다.
3. 아래에서 필요한 목록 메뉴를 고릅니다.
4. 열린 Excel에서 필터·정렬로 결과를 살펴보고 **다른 이름으로 저장**합니다. 처음 만든 파일은 임시 파일이므로 보관할 위치에 따로 저장하세요.

| 고른 대상 | 메뉴와 범위 |
|---|---|
| 파일 한 개 또는 여러 개 | **파일 목록을 Excel로**: 고른 파일만 포함합니다. |
| 폴더 | **폴더 내용 목록을 Excel로**: 바로 안의 항목을 모읍니다. **하위 폴더까지 Excel로**: 안쪽 폴더도 탐색합니다. |
| 파일·폴더를 함께 선택 | **선택 항목을 Excel로**: 선택한 항목 자체를 나열합니다. **선택 폴더 + 하위 폴더를 Excel로**: 선택 파일과 폴더 안쪽 항목을 모읍니다. |
| 폴더 안 빈 공간 | **현재 폴더 목록을 Excel로** 또는 **현재 폴더 + 하위 폴더를 Excel로**를 고릅니다. |

결과에는 이름·종류·크기·날짜·경로 등이 들어갑니다. 숫자와 날짜는 Excel 값으로 기록하며, 표·필터·첫 행 고정·원본 링크를 제공합니다. 목록 만들기는 파일 본문을 읽지 않습니다. 검색 결과처럼 실제 저장 폴더가 아닌 곳과 압축파일 안은 대상이 아닙니다.

## 같은 내용의 파일 찾기

목록과 같은 **더 많은 옵션 표시** 메뉴에서 실행합니다.

| 고른 대상 | 메뉴와 비교 범위 |
|---|---|
| 파일 한 개 | **같은 파일 찾기**: 해당 폴더와 하위 폴더에서 찾습니다. |
| 파일 여러 개 | **선택 파일 중 중복 찾기**: 고른 파일끼리 비교합니다. |
| 폴더 한 개 또는 여러 개 | **중복 파일 찾기**: 고른 폴더들의 하위 항목까지 함께 비교합니다. |
| 폴더 안 빈 공간 | **현재 폴더 중복 파일 찾기**를 누릅니다. |

이름이나 확장자만 비교하지 않고 파일 크기로 후보를 좁힌 뒤 내용을 읽어 실제 내용이 같은지 확인합니다. 결과의 **Duplicates / Matches**에서 같은 파일 묶음을 봅니다. **Summary**는 요약, **Errors**는 실패한 항목, **Skipped**는 검사에서 뺀 항목입니다. 원본 파일을 자동으로 삭제·이동·수정하지 않습니다.

온라인에만 있는 파일은 내려받지 않습니다. 중복 검사에서는 다른 위치나 온라인 저장소에 연결된 파일·폴더를 제외합니다. **PC에 내려받은 OneDrive 파일도 연결 표시가 남아 있으면 검사에서 빠질 수 있습니다.** 접근할 수 없거나 검사 중 바뀐 파일도 기록하고 나머지를 검사합니다.

## Excel에서 선택한 실제 파일 복사

1. 설치 화면에서 **Excel에서 선택한 파일 복사 (선택)**를 선택합니다. 기본 선택은 꺼져 있으며 사용자 선택 없이 이전 설치를 새 버전으로 바꿀 때는 자동으로 추가하지 않습니다. PC에 설치된 Excel이 필요합니다.
2. Excel을 저장·종료한 뒤 다시 엽니다. 이 버전으로 새로 만든 **Files / Duplicates / Matches** 표에서 필요한 행을 선택합니다. 필터와 직접 숨긴 행은 제외합니다.
3. **셀 우클릭 → 파일목록 → 선택한 파일 복사…**를 누릅니다.
4. 대상 폴더와 개수·예상 크기·제외 수를 확인하고 **여기에 복사**를 누릅니다.
5. 새 **모은파일_날짜_시간_식별자** 하위 폴더와 **작업 결과 보기**에서 결과를 확인합니다.

원본을 이동·삭제·이름 변경하거나 기존 파일을 덮어쓰지 않습니다. 같은 이름은 번호를 붙입니다. 예전 버전의 결과표에는 필요한 행 정보가 없어 목록을 새로 만들어야 합니다. 연동을 설치하지 않아도 목록과 중복 찾기는 사용할 수 있습니다.

한 번에 보이는 데이터 행 10,000개까지 선택할 수 있습니다. 목록을 만든 뒤 바뀌거나 삭제된 원본은 제외합니다. 온라인에만 있거나 열 때 내려받는 파일, 다른 위치에 연결된 파일·폴더도 제외합니다. **PC에 내려받은 OneDrive 파일도 제외될 수 있습니다.** 복사할 저장장치는 파일에 딸린 추가 정보와 사용자별 접근 권한을 보관할 수 있어야 합니다. **원본 파일에 접근할 수 없는 다른 PC에서는 목록 파일만 받아도 복사할 수 없습니다.** 취소하면 완료된 복사본을 유지하고 자체 미완료본만 정리합니다.

## 결과 확인·제거

- 오래 걸리는 작업은 진행 상황과 **취소**를 표시합니다. 네트워크 응답을 기다리는 중에는 취소 반영이 늦을 수 있습니다.
- 큰 목록은 시트당 65,000행으로 나눕니다. 실패한 항목은 **Errors**를 확인하세요. 한 셀의 글자가 32,767자를 넘으면 뒤쪽 글자는 잘립니다.
- Excel이 없으면 기본 .xlsx 앱으로 열기를 시도하고, 연결 앱도 없으면 생성 위치를 안내합니다.
- 설치 후 메뉴가 보이지 않으면 새 탐색기 창에서 확인하거나 다음 로그인 후 다시 확인하세요. 계속 안 보이면 위 릴리스의 알려진 문제를 확인하세요.
- 제거는 **Windows 설정 → 앱 → 설치된 앱 → File List to Excel → 제거**에서 합니다. 만든 Excel 파일과 이전에 한 중복 검사의 저장 정보는 남습니다.
