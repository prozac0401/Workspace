# 파일 목록을 Excel로 만들기

**File List to Excel**은 탐색기에서 고른 파일·폴더의 목록을 Excel 표로 만들고, 내용이 같은 파일을 찾는 도구입니다. 여러 폴더의 자료를 이름·크기·날짜·경로로 모아 보고, Excel의 필터와 정렬로 필요한 항목을 찾을 수 있습니다. 이 안내는 공개된 **v1.2.0** 기준입니다.

자료가 여러 작업 폴더에 뒤섞여 있다면 [파일 목록 Excel을 보며 AI와 정리 초안 만들기](#ai-organization)를 따라 해 보세요. 목록을 대화의 근거 자료로 두고, 분류 기준과 폴더 구조를 함께 다듬은 뒤 확정한 파일을 복사하는 사용 예입니다.

## 탐색기에서 목록 만들기

1. 내려받은 **FileListToExcel-1.2.0-win-x64.msi**를 실행합니다. 지금 로그인한 Windows 계정에 설치합니다. 관리자 권한은 필요하지 않습니다. 실행에 필요한 프로그램을 따로 설치하지 않아도 됩니다.
2. 탐색기에서 파일이나 폴더를 고르고 **마우스 오른쪽 버튼 → 더 많은 옵션 표시**를 누릅니다.
3. 아래에서 필요한 목록 메뉴를 고릅니다.
4. 열린 Excel에서 필터·정렬로 결과를 살펴보고 **다른 이름으로 저장**합니다. 처음 만든 파일은 임시 파일이므로 보관할 위치에 따로 저장하세요.

| 고른 대상 | 메뉴와 범위 |
|---|---|
| 파일 한 개 또는 여러 개 | **파일 목록을 Excel로**: 고른 파일만 포함합니다. |
| 폴더 | **폴더 내용 목록을 Excel로**: 바로 안의 항목을 모읍니다. **하위 폴더까지 Excel로**: 안쪽 폴더도 탐색합니다. |
| 파일·폴더를 함께 선택 | **선택 항목을 Excel로**: 선택한 항목 자체를 나열합니다. **선택 폴더 + 하위 폴더를 Excel로**: 선택 파일과 폴더 안쪽 항목을 모읍니다. |
| 폴더 안 빈 공간 | **현재 폴더 목록을 Excel로** 또는 **현재 폴더 + 하위 폴더를 Excel로**를 고릅니다. |

결과에는 이름·종류·크기·날짜·경로 등이 들어갑니다. 숫자와 날짜는 Excel 값으로 기록하며, 표·필터·첫 행 고정·원본 링크를 제공합니다. 목록 만들기는 파일 본문을 읽지 않습니다. 검색 결과처럼 실제 저장 폴더가 아닌 곳과 압축파일 안은 대상이 아닙니다.

## 같은 내용의 파일 찾기

목록과 같은 **더 많은 옵션 표시** 메뉴에서 실행합니다.

| 고른 대상 | 메뉴와 비교 범위 |
|---|---|
| 파일 한 개 | **같은 파일 찾기**: 해당 폴더와 하위 폴더에서 찾습니다. |
| 파일 여러 개 | **선택 파일 중 중복 찾기**: 고른 파일끼리 비교합니다. |
| 폴더 한 개 또는 여러 개 | **중복 파일 찾기**: 고른 폴더들의 하위 항목까지 함께 비교합니다. |
| 폴더 안 빈 공간 | **현재 폴더 중복 파일 찾기**를 누릅니다. |

이름이나 확장자만 비교하지 않고 파일 크기로 후보를 좁힌 뒤 내용을 읽어 실제 내용이 같은지 확인합니다. 결과의 **Duplicates / Matches**에서 같은 파일 묶음을 봅니다. **Summary**는 요약, **Errors**는 실패한 항목, **Skipped**는 검사에서 뺀 항목입니다. 원본 파일을 자동으로 삭제·이동·수정하지 않습니다.

온라인에만 있는 파일은 내려받지 않습니다. 중복 검사에서는 다른 위치나 온라인 저장소에 연결된 파일·폴더를 제외합니다. **PC에 내려받은 OneDrive 파일도 연결 표시가 남아 있으면 검사에서 빠질 수 있습니다.** 접근할 수 없거나 검사 중 바뀐 파일도 기록하고 나머지를 검사합니다.

## Excel에서 선택한 실제 파일 복사

1. 설치 화면에서 **Excel에서 선택한 파일 복사 (선택)**를 선택합니다. 기본 선택은 꺼져 있으며 사용자 선택 없이 이전 설치를 새 버전으로 바꿀 때는 자동으로 추가하지 않습니다. PC에 설치된 Excel이 필요합니다.
2. Excel을 저장·종료한 뒤 다시 엽니다. 이 버전으로 새로 만든 **Files / Duplicates / Matches** 표에서 필요한 행을 선택합니다. 필터와 직접 숨긴 행은 제외합니다.
3. **셀 우클릭 → 파일목록 → 선택한 파일 복사…**를 누릅니다.
4. 대상 폴더와 개수·예상 크기·제외 수를 확인하고 **여기에 복사**를 누릅니다.
5. 새 **모은파일_날짜_시간_식별자** 하위 폴더와 **작업 결과 보기**에서 결과를 확인합니다.

원본을 이동·삭제·이름 변경하거나 기존 파일을 덮어쓰지 않습니다. 같은 이름은 번호를 붙입니다. 예전 버전의 결과표에는 필요한 행 정보가 없어 목록을 새로 만들어야 합니다. 연동을 설치하지 않아도 목록과 중복 찾기는 사용할 수 있습니다.

한 번에 보이는 데이터 행 10,000개까지 선택할 수 있습니다. 목록을 만든 뒤 바뀌거나 삭제된 원본은 제외합니다. 온라인에만 있거나 열 때 내려받는 파일, 다른 위치에 연결된 파일·폴더도 제외합니다. **PC에 내려받은 OneDrive 파일도 제외될 수 있습니다.** 복사할 저장장치는 파일에 딸린 추가 정보와 사용자별 접근 권한을 보관할 수 있어야 합니다. **원본 파일에 접근할 수 없는 다른 PC에서는 목록 파일만 받아도 복사할 수 없습니다.** 취소하면 완료된 복사본을 유지하고 자체 미완료본만 정리합니다.

## 사용 예 파일 목록 Excel을 보며 AI와 정리 초안 만들기 {#ai-organization}

저장해 둔 작업 폴더에서 자료를 찾기 어렵거나 업무별로 넘길 파일을 모아야 할 때 쓰는 방법입니다. **파일 목록 Excel을 바탕으로 AI와 대화하며 분류 기준의 초안을 잡고, 사람이 확인한 목록으로 일괄 복사합니다.** AI의 첫 답을 보고 바로 파일을 옮기지 않고, 실제 업무에 맞는 기준이 될 때까지 질문과 수정을 이어갑니다.

흐름은 **하위 폴더까지 목록 만들기 → Excel을 보며 분류 기준 논의 → 대표 파일로 초안 수정 → 복사할 목록 확정 → BATCH 스크립트 요청·실행 → 결과 확인**입니다. File List to Excel로 목록을 만들고, AI와의 대화와 스크립트 작성은 별도로 진행합니다.

### 정리할 폴더의 목록을 Excel로 저장하기

1. 정리가 필요한 작업 폴더 하나를 고릅니다. 이미 잘 보관한 자료 전체를 다시 정리할 필요는 없습니다.
2. **하위 폴더까지 Excel로**를 눌러 안쪽 폴더의 파일도 목록으로 만듭니다.
3. **다른 이름으로 저장**으로 `파일목록_정리검토.xlsx`처럼 보관합니다. 이 Excel이 대화와 분류의 근거 자료가 됩니다.
4. **Files**와 **Files_2** 등 나뉜 목록 시트를 모두 확인합니다. 복사할 파일을 고를 때는 **종류가 폴더인 행을 제외**합니다. **Errors**에 나온 접근 실패와 다른 위치에 연결된 폴더도 확인하세요. 연결된 폴더 안쪽은 탐색하지 않으므로 목록에 없는 자료가 있을 수 있습니다.

목록에는 **이름·상대경로·전체경로·크기·수정일** 등이 들어 있습니다. 파일 본문은 읽지 않으므로 문서 내용이나 업무 완료 여부는 담당자가 설명해 줘야 합니다. 파일명과 경로에도 회사 정보가 들어갈 수 있습니다. AI에 제공할 수 있는 범위는 회사 기준을 따르세요.

이름과 경로를 가려야 한다면 AI에 제공할 별도 파일을 만드세요. 전체경로·원본 링크·숨겨진 정보에도 실제 경로가 들어 있으므로 함께 빼야 합니다. 화면에 보이는 이름만 가리는 것으로는 충분하지 않습니다. 항목번호와 실제 경로의 대응, 원래 파일 목록 Excel은 로컬에 보존합니다.

### AI와 질문을 주고받으며 분류 기준 잡기

파일 목록 Excel과 현재 업무 상황을 함께 제시합니다. 처음에는 전체 파일의 목적지를 확정하기보다 **어떤 기준으로 나눌지, 무엇을 더 알아야 할지**를 논의합니다. 아래 요청문은 회사에서 허용한 AI에 자료를 제공할 때 쓸 수 있습니다.

```text
첨부한 파일 목록 Excel을 근거 자료로 삼아 작업 폴더를 정리하려고 합니다.
목록에 있는 이름·경로·크기·날짜와 내가 설명하는 업무 상황을 함께 보면서
분류 기준과 새 폴더 구조의 초안을 대화로 다듬어 주세요.

우선 진행 중인 업무, 끝나서 보관할 업무, 반복해서 쓸 양식,
공통 참고자료, 확인이 필요한 자료를 어떻게 구분할지 제안해 주세요.
대표 파일 몇 개에 적용한 예와 애매한 항목을 보여 주세요.
필요한 질문을 해 주면 내가 답하겠습니다. 답을 반영해 초안을 고쳐 주세요.
파일명이나 수정일만으로 업무 완료·보관 기간·삭제 여부를 확정하지 마세요.
아직 전체 파일의 분류를 확정하거나 복사 스크립트를 만들지는 마세요.
```

대화는 다음처럼 이어갈 수 있습니다. 아래 파일명과 업무 상황은 설명용 예시입니다.

| 대화 | 초안에 반영할 내용 |
|---|---|
| AI: “작년 교육 파일은 끝난 업무인가요? 올해도 고쳐 쓰는 양식이 있나요?” | 날짜만으로 보관 여부를 정하지 않고 실제 쓰임을 확인합니다. |
| 사용자: “작년 교육은 끝났지만 신청서 양식은 올해도 씁니다. 정산은 아직 진행 중입니다.” | 끝난 교육 기록은 업무별 보관 후보, 재사용할 양식은 기본 양식 후보, 정산은 진행 중인 업무 후보로 나눕니다. |
| AI: “교육별 폴더를 먼저 만들고 그 안에서 안내·접수·결과를 나누면 어떨까요?” | 파일 형식보다 업무를 먼저 나누는 초안을 검토합니다. |
| 사용자: “안내와 접수는 함께 두세요. 어느 교육인지 모르는 파일은 확인 필요로 남겨 주세요.” | 불필요한 하위 폴더를 줄이고 판단이 어려운 파일은 보류합니다. |

대표 파일의 분류가 실제 업무와 맞으면 같은 기준을 나머지 목록에 적용하도록 요청합니다. 예외가 나오면 이유를 묻고 기준을 고칩니다. AI가 제안한 분류와 사람이 확정한 분류를 구분해 두세요.

### Workspace 안내의 폴더 구조에 맞춰 초안 다듬기

[자료를 둘 곳 정하기](../../policies/workspace.md)의 `Work` 구조를 출발점으로 삼을 수 있습니다. `Work`는 업무자료를 둘 폴더이며 이 프로그램을 개발하는 `Workspace` 저장소와는 다른 곳입니다. 아래 연결은 제안이며 실제 업무와 회사의 보관 기준에 맞춰 정합니다.

| 대화에서 확인한 쓰임 | 복사할 위치의 초안 |
|---|---|
| 진행 중인 업무의 파일 | `10_Active\업무명\` |
| 다음 업무에서 복사해 쓸 빈 양식과 안내 | `20_Operations\업무명_MASTER\` |
| 여러 업무가 함께 참고하는 자료 | `40_Reference\주제\` |
| 끝났다고 확인한 업무의 기록 | `80_Archive\연도\업무명\` |
| 어느 업무인지 또는 보관할지 확인이 필요한 파일 | 목적지를 비워 두고 복사 목록에서 보류 |

끝난 업무는 결과물과 근거를 같은 업무 폴더로 모아 맥락을 유지합니다. 이미 폴더째 보관한 업무를 파일 종류별로 흩어 놓지 않습니다. 오래됐거나 중복으로 보인다는 이유만으로 삭제 대상으로 정하지 않습니다.

### Excel에 분류 초안과 확정한 복사 목록 남기기

원래 결과표를 보존하고 같은 Excel의 별도 **분류 초안** 시트에 검토 내용을 모읍니다. 대화에서 기준을 바꿨다면 해당 시트도 최신 초안으로 맞춥니다. 원래 표와 숨겨진 정보는 그대로 두어야 기본 Excel 복사 기능도 사용할 수 있습니다.

검토표에는 다음 칸을 두면 원래 목록과 대화의 결과를 대조하기 쉽습니다. 이 칸은 사용자가 추가하는 검토용 칸입니다.

| 칸 | 적을 내용 |
|---|---|
| 항목번호·원본 전체경로 | 파일마다 고정 번호를 붙이고 원래 경로와 연결합니다. 이름이 같아도 서로 다른 파일을 구별합니다. |
| 업무·분류 초안·이유 | AI와 논의한 쓰임, 그 분류를 제안한 이유를 적습니다. |
| 확인할 것 | 업무 완료 여부나 다른 자료와의 관계처럼 아직 답이 필요한 내용을 적습니다. |
| 확정한 목적지 | 사람이 확인한 뒤 대상 폴더 안의 경로를 적습니다. 같은 이름이 부딪히면 하위 경로를 구분합니다. |
| 복사 확정 | 이번에 복사할 파일만 표시합니다. 보류한 항목은 표시하지 않습니다. |

복사 전에 확정한 원본·목적지·개수·예상 크기를 살펴봅니다. 누락과 같은 목적지로 겹치는 파일을 확인한 뒤 스크립트 작성을 요청합니다. 실행용 CSV 목록이 필요하다면 **확정한 Excel 행에서만** 만듭니다. 분류의 근거는 계속 파일 목록 Excel에 남습니다.

### 확정한 목록으로 BATCH 복사 스크립트 요청하기

업무별로 서로 다른 폴더에 복사하려면 확정한 목록과 원본·대상 폴더를 제시해 별도 BATCH 스크립트를 요청할 수 있습니다. BATCH는 여러 파일의 복사 명령을 한 번에 실행하는 `.bat` 파일입니다. 다음 요청문에서 폴더 위치는 실제 작업에 맞게 적으세요.

```text
파일 목록 Excel의 '분류 초안' 시트에서 '복사 확정'한 행만 사용해
확정한 목적지로 일괄 복사하는 Windows BATCH 스크립트를 만들어 주세요.
분류 기준을 새로 추측하거나 보류 항목을 포함하지 마세요.

원본 폴더: [실제 원본 폴더]
대상 폴더: [원본 폴더 밖에 마련한 새 폴더]

- 기본 실행은 원본·목적지·개수·예상 크기를 보여주는 미리보기로 해 주세요.
  실제 복사는 별도의 실행 명령을 사용하게 하고 두 명령을 설명해 주세요.
- 확정한 파일 경로만 처리하고 원본을 이동·삭제·이름 변경하지 마세요.
  폴더를 다시 재귀 검색해 파일을 추가하지 마세요.
- 원본·목적지가 지정한 폴더 범위 안에 있는지 확인해 주세요.
  다른 위치로 이어지는 파일·폴더와 온라인에만 있거나 열 때 내려받는
  파일은 건너뛰고 기록해 주세요. 온라인 파일을 내려받지 마세요.
- 기존 파일을 덮어쓰지 마세요. 같은 목적지에 겹치는 항목은 복사 전에
  알려 주세요. 재실행해도 성공한 파일을 중복 복사하지 않게 해 주세요.
- 없거나 목록 작성 뒤 바뀐 원본, 접근 실패, 중단된 복사를 기록하고
  성공·실패·건너뛴 항목을 구분해 주세요. 미완료본을 성공으로 처리하지 마세요.
  원래 목록에 기록된 크기·수정일을 복사 계획에 포함하고 비교해 주세요.
  수정일을 변환한다면 원래 값의 시간대와 정밀도를 유지해 주세요.
- 한글·공백·특수문자가 있는 경로를 안전하게 처리해 주세요.
  필요하면 .bat에서 PowerShell 보조 파일을 실행하고,
  확정한 Excel 행으로 만든 UTF-8 CSV를 읽는 방식으로 작성해 주세요.
- 일반 사용자 권한으로 실행하고 소량 시험·취소·재실행 방법도 설명해 주세요.
```

AI가 만든 스크립트의 미리보기에서 Excel의 확정 목록과 경로·개수가 맞는지 확인합니다. 대표 파일 몇 개를 먼저 복사해 보고, 결과가 맞으면 확정 목록 전체를 실행하세요. 완료 후 성공·실패·건너뛴 목록과 복사된 파일의 개수·크기를 비교하고 대표 파일이 열리는지도 확인합니다. 실패한 항목은 원인을 확인한 뒤 다시 처리합니다.

복사 결과를 확인할 때까지 기존 폴더를 보존합니다. 검토가 끝나면 앞으로 수정할 기준 위치를 하나 정하고 다른 위치에는 그곳으로 연결하세요. 원본 정리와 보관 기간에 따른 처리는 [끝난 업무 보관과 자료 보호](../../policies/archive-security.md)를 따릅니다. 파일 목록 Excel과 실제 경로가 담긴 실행 기록은 내부에 보관하고 공개 페이지에 올리지 않습니다.

### 파일을 한곳에 모으기만 하면 기본 복사 기능 쓰기

필요한 파일을 한 폴더에 모으는 작업은 위의 **Excel에서 선택한 실제 파일 복사** 기능으로 할 수 있습니다. 분류 초안에서 고른 파일을 원래 **Files** 표의 행과 대조한 뒤 선택하세요. 기본 기능은 하나의 새 폴더로 모으며, 행마다 다른 업무 폴더로 나누는 작업은 별도 스크립트로 진행합니다.

## 결과 확인·제거

- 오래 걸리는 작업은 진행 상황과 **취소**를 표시합니다. 네트워크 응답을 기다리는 중에는 취소 반영이 늦을 수 있습니다.
- 큰 목록은 시트당 65,000행으로 나눕니다. 실패한 항목은 **Errors**를 확인하세요. 한 셀의 글자가 32,767자를 넘으면 뒤쪽 글자는 잘립니다.
- Excel이 없으면 기본 .xlsx 앱으로 열기를 시도하고, 연결 앱도 없으면 생성 위치를 안내합니다.
- 설치 후 메뉴가 보이지 않으면 새 탐색기 창에서 확인하거나 다음 로그인 후 다시 확인하세요. 계속 안 보이면 위 릴리스의 알려진 문제를 확인하세요.
- 제거는 **Windows 설정 → 앱 → 설치된 앱 → File List to Excel → 제거**에서 합니다. 만든 Excel 파일과 이전에 한 중복 검사의 저장 정보는 남습니다.
