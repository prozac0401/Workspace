Excel 명단 비교 0.2.0 RC9 제한 평가판
LIMITED EVALUATION

코드 서명이 없는 평가용 파일입니다. 전체 인수 기준을 통과하지 못했습니다. 별도의 자료 복사본으로 확인해 주세요.

확인된 문제와 미검증 범위
- 일부 진단에서 Excel 상태표시줄의 원래 값과 형식 복원이 실패했습니다.
- 첫 번째 목록 바꾸기의 약 100ms Esc 유지 입력만 대조 실험에서 상태 보존을 확인했습니다. 취소 안내는 관찰하지 못했고, 순간 입력이나 다른 작업의 취소는 보장하지 않습니다.
- 이 EXE의 실제 설치, 재설치, 업데이트, 제거와 전체 자동 로드, 창 전환, 다른 Excel 프로세스와의 격리는 검증하지 못했습니다.
- 진단 중 Excel이 비정상 종료하고 창 없는 시험 프로세스가 남은 환경에서는 설치가 차단됩니다. 창만 닫아 해결된다고 보장하지 않습니다. 보호를 끄거나 막힌 설치를 반복하지 마세요.

확인한 비교 범위
Windows 11과 Excel 16.0.20326.20144 64비트에서 서로 다른 48자 값은 목록마다 20,000개, 동일한 48자 값은 목록마다 100,000개 비교를 완료했습니다. 이는 모든 같은 크기 목록의 완료 보장이 아닙니다.
서로 다른 48자 값 50,000개 또는 100,000개씩은 약 30초 제한으로 결과 생성에 실패했습니다. 큰 목록은 나누어 비교하세요. 32비트 Office와 조직별 매크로 API 차단 환경은 미검증입니다.

실제 파일 해시와 자세한 검증 범위는 배포 페이지와 동봉한 README를 확인해 주세요.
