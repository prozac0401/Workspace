# Excel 명단 비교

**첫 번째 목록을 담고, 두 번째 목록을 선택해 비교하세요.** 이름, 메일 주소, 일반 텍스트를 비교하는 Windows 데스크톱 Excel 추가 기능입니다. 원본 파일은 그대로 두고 차이가 있으면 새 파일에 결과를 보여 줍니다.

> **현재 상태:** RC9 candidate-07에서 용량 14조건·선택 14조건·실제 메뉴 5동작·보호 안내 7조건을 확인했습니다. 48자 고유값 각 20,000개는 결과 40,000행을 만들었지만 각 50,000·100,000개는 시간 초과로 중단됐습니다. 바꾸기 중 Esc 유지 입력은 대조군과 비교해 이전 목록 보존을 확인했으며, 남은 기능·취소·설치 인수와 릴리즈는 아직 미확정입니다. [허용 후 RC9 진행 결과](docs/RC9_APPROVED_RETEST_20260917.md) · [이전 RC9 기록](docs/RC9_STABILITY_REPORT.md) · [RC8 실제 실패 기록](docs/RC8_COMPLETION_REPORT.md)

2026-09-17 후속 재실험에서 공개 RC7의 정상 완료 범위와 실패를 다시 측정했고, 상속된 PowerShell 모듈 경로 때문에 생기는 설치 준비 오류를 실행기 소스에서 수정했습니다. 실제 파일별 결과와 미완료 항목은 [재실험 보고서](docs/RETEST_20260917.md), 요구사항과 지원 범위는 [제품 명세](../../docs/tools/excel-list-compare/specification.md)를 따릅니다. RC7의 측정값을 새 RC9 바이너리의 검증으로 사용하지 않습니다.

## 처음 사용하기

1. 비교할 첫 번째 목록의 셀을 선택합니다.
2. Excel의 **추가 기능** 탭에서 **첫 번째 목록 담기**를 누릅니다.
3. 두 번째 목록의 셀을 선택합니다. 같은 Excel에서 연 다른 파일도 비교할 수 있습니다.
4. **두 번째 목록 담아 비교**를 누릅니다.
5. 결과 파일이 열리면 내용을 확인하고 필요한 위치에 저장합니다.

셀을 마우스 오른쪽 버튼으로 클릭한 뒤 **명단 비교** 메뉴에서도 같은 기능을 쓸 수 있습니다. 화면 예시는 [사용 안내](docs/QUICK_GUIDE.md)에 있습니다. 이전 버전의 화면은 캡션으로 구분했습니다.

**목록**은 한 번에 선택한 셀 전체를 말합니다. **항목**은 그 안의 값 하나입니다. `첫 번째 목록: 42개 항목`은 빈칸 등 비교에서 제외할 셀을 빼고 값 42개를 담았다는 뜻입니다. 같은 값이 서로 다른 셀에 있으면 각각 셉니다.

| 버튼 | 누르면 어떻게 되나요? |
|---|---|
| 첫 번째 목록 담기 | 선택한 셀의 값을 기억합니다. |
| 두 번째 목록 담아 비교 | 현재 선택한 셀과 기억해 둔 첫 번째 목록을 비교합니다. |
| 첫 번째 목록 비우기 | 기억해 둔 목록을 비웁니다. 원본 셀은 지우지 않습니다. |
| 첫 번째 목록 바꾸기 | 현재 선택한 셀로 첫 번째 목록을 다시 담습니다. |

비교가 끝나면 담아 둔 목록을 비우고 **첫 번째 목록 담기**로 돌아갑니다. 첫 번째 목록을 담은 뒤 원본을 고쳐도 이미 담은 값은 바뀌지 않습니다. 바뀐 값을 비교하려면 다시 담으세요.

다른 파일을 같은 Excel에 열어 둔 상태라면 첫 번째 파일을 닫아도 담아 둔 목록은 남습니다. Excel을 완전히 종료하면 사라집니다. 별도로 실행한 Excel끼리는 목록을 공유하지 않습니다. 다른 파일로 옮겼을 때 첫 번째 목록의 개수가 보이지 않으면 비교를 진행하기 전에 메뉴 상태를 확인하세요. [메뉴의 확인 범위](docs/RC8_COMPLETION_REPORT.md)

## 어떤 셀을 선택하나요?

가로, 세로, 사각형, 한 셀 모두 가능합니다. Ctrl 키로 여러 곳을 선택해도 전체를 하나의 목록으로 읽습니다. 방향이나 비교 모드를 따로 고를 필요는 없습니다.

예를 들어 `A1:B20`을 선택하면 **40개 셀로 된 목록 하나**를 담습니다. 두 열을 자동으로 나눠 비교하지 않습니다. 같은 셀을 겹쳐 선택하면 한 번만 읽습니다.

| 선택한 셀 | 비교할 때의 처리 |
|---|---|
| 필터에서 제외된 셀, 숨긴 행·열 | 읽지 않습니다. 화면을 스크롤해 지금 보이는 셀만 읽는다는 뜻은 아닙니다. |
| Excel 표의 제목·합계행, 자동 필터의 제목 | 해당 셀만 뺍니다. 같은 행의 다른 일반 데이터는 그대로 읽습니다. |
| 일반 범위의 첫 행 | 제목인지 자동으로 판단하지 않습니다. 제목을 빼고 선택하세요. |
| 빈칸, 공백만 있는 셀, 수식 결과가 빈 문자열인 셀 | 비교에서 뺍니다. |
| 오류가 표시된 셀 | 개수를 따로 표시합니다. 오류 셀이 있으면 두 원본이 완전히 같다고 안내하지 않습니다. |
| 병합된 셀 | 작업을 중단합니다. 병합되지 않은 셀만 선택하세요. |

행이나 열 전체를 선택하면 Excel이 사용 중이라고 판단한 범위 안에서만 확인합니다. 값이 없어도 서식이 남아 있으면 범위가 커질 수 있습니다. 이 때문에 제한에 걸리면 실제 값이 있는 셀만 다시 선택하세요. 프로그램이 원본을 자동으로 정리하지는 않습니다.

## 무엇을 같다고 보나요?

**같은 값이 몇 개씩 있는지도 확인합니다.** 순서는 비교하지 않지만, `김철수`가 두 번 있는 목록과 한 번 있는 목록은 다릅니다.

| 첫 번째 목록 | 두 번째 목록 | 비교 결과 |
|---|---|---|
| 숫자 `123` | 텍스트 `123`, `123.0`, `1.23e2` | 같음 |
| 텍스트 `00123` | 숫자 `123` | 다름 |
| `USER@a.com` | `user@b.com`, `user` | 같음 |
| ` mailto:user@a.com ` | `user` | 같음 |
| `ＡＢＣ１２３` | `abc123` | 같음 |
| ` 홍길동 ` | `홍길동` | 같음 |
| `홍 길동` | `홍길동` | 다름 |
| 텍스트 `1,234` | 숫자 `1234` | 다름 |

메일 주소는 `@` 앞부분만 비교합니다. 주소 뒷부분이 다르면 서로 다른 사람이어도 같다고 나올 수 있습니다. 이름과 주소가 함께 적힌 `이름 <user@domain>`이나 여러 주소가 들어 있는 셀을 개별 메일 주소로 나누지는 않습니다.

앞뒤 공백, 반복 공백, 탭·줄바꿈, 일부 보이지 않는 문자와 전각 영숫자를 정리한 뒤 비교합니다. 모든 문자 표기 차이를 같게 처리하지는 않습니다. 한글 자모가 나뉘어 저장된 값도 강제로 합치지 않습니다.

셀에 보이는 서식보다 **실제로 저장된 값**을 읽습니다. 숫자 `123`을 서식으로만 `00123`처럼 보이게 했다면 `123`으로 비교합니다. Excel에서 이미 반올림된 숫자는 되살릴 수 없습니다. 앞자리 0이나 긴 사번·ID를 보존하려면 원본부터 텍스트로 입력하세요. 날짜·통화 서식의 뜻을 별도로 판단하지는 않습니다.

Excel이 계산 중이면 실행하지 않습니다. 수동 계산을 쓰는 파일은 먼저 계산을 마친 뒤 비교하세요. 이 도구가 수식을 강제로 다시 계산하지는 않습니다.

## 결과 읽기

차이·중복·오류가 없으면 같다는 안내만 보여 줍니다. 그 밖의 경우에는 원본과 별개의 새 결과 파일을 만듭니다. 결과를 자동으로 저장하지는 않습니다.

| 결과표에서 볼 것 | 뜻 |
|---|---|
| 비교에 쓴 값 | 공백 등 비교 규칙을 적용한 값입니다. |
| 원래 값 (예) | 그 값에 해당하는 첫 번째 셀의 원래 값입니다. |
| 각 목록의 개수 | 해당 값이 목록에 몇 개 있는지 나타냅니다. |
| 남은 개수 | 두 목록에서 같은 값을 하나씩 짝지은 뒤 남는 수입니다. 첫 번째에 2개, 두 번째에 1개라면 첫 번째에 1개가 남습니다. |
| 셀 주소 | 그 값이 처음 나온 셀의 위치입니다. 해당하는 모든 셀을 나열하지는 않습니다. |

결과에는 각 목록을 가져온 파일·범위와 담은 시각, 제외한 빈칸·오류·제목·합계행의 개수도 표시합니다. **첫 번째 목록에만 있음 / 두 번째 목록에만 있음**은 해당 목록에만 있는 값입니다.

원본의 값·수식·서식·필터와 이전 결과 파일은 바꾸지 않습니다. 결과에 적힌 `=...` 등의 문자열이 수식으로 실행되지 않도록 텍스트로 기록합니다. 외부 서비스로 명단을 보내지 않습니다. 다만 VBA를 실행한 뒤 Excel의 기본 **실행 취소** 기록까지 유지된다고 보장하지는 않습니다.

## 큰 목록과 취소

큰 범위는 값을 읽기 전에 진행 여부를 묻습니다. 기본 선택은 **아니요**입니다. 아니요를 누르면 이미 담아 둔 첫 번째 목록은 남습니다.

**RC8에서는 Esc를 눌러도 취소되지 않은 사례가 있습니다.** 실제 시험에서 비교는 시간이 오래 걸려 중단됐고, 첫 번째 목록 바꾸기는 취소되지 않은 채 끝났습니다. Esc를 눌렀다는 이유만으로 멈췄다고 판단하지 마세요. 처리 중에는 원본을 편집하지 말고, 큰 목록은 범위를 나누어 비교하세요. [자세한 실패 기록](docs/RC8_COMPLETION_REPORT.md)

다음 수치는 처리량을 제한하기 위한 값이며 속도나 완료를 보장하는 수치는 아닙니다.

| 항목 | 제한 또는 안내 |
|---|---|
| 한 목록에서 숨기지 않은 선택 셀 | 100,000개까지. 빈칸·제목을 빼기 전의 수입니다. |
| 큰 목록 안내 | 이번 선택과 담아 둔 목록의 셀이 합계 20,000개 이상일 때 |
| 필터 등으로 나뉜 영역 | 500개부터 안내, 5,000개 초과 시 중단 |
| 숨긴 셀인지 확인할 범위 | 200,000셀부터 안내, 2,000,000셀 초과 시 중단 |
| 한 셀의 글자 수 | 4,096자 초과 시 중단 |
| 한 목록 전체의 글자 수 | 5,000,000자 초과 시 중단 |
| 작업 시간 | 중간 점검 시 실제 처리 시간이 약 30초를 넘으면 중단 |

긴 글을 잘라서 비교하지 않습니다. 여러 선택 범위가 겹치면 실행 전 크기 계산에는 중복이 포함될 수 있지만, 실제 값을 읽을 때는 같은 셀을 한 번만 셉니다. Excel 내부 처리가 끝날 때까지 기다려야 하는 경우가 있어 정확히 30초에 멈추지는 않습니다. 설정 화면에서 위 제한을 바꾸는 기능은 없습니다.

## 설치와 제거

설치 방법은 [설치 안내](docs/ONEFILE_INSTALLATION.md)를 확인하세요. 지금 로그인한 Windows 계정에 설치하며 관리자 권한을 요청하지 않습니다. 일상적인 사용에는 Python이나 VBA 편집기가 필요하지 않습니다. 설치·제거에는 Windows PowerShell을 사용합니다.

이 제품 폴더만 Excel의 **신뢰할 수 있는 위치**에 등록합니다. 이곳에 둔 매크로는 알림 없이 실행될 수 있으므로 업무 파일을 보관하지 마세요. 기존의 다른 신뢰 위치와 회사 정책은 유지합니다. 설치·제거는 열려 있는 Excel을 강제로 닫지 않습니다.

이전 v0.1을 직접 추가 기능으로 등록했다면 직접 해제해야 합니다. `PERSONAL.XLSB`에 넣은 코드, 다른 추가 기능, 기존 단축키 등록은 이 설치기가 지우지 않습니다.

## 제작·검증 담당자 안내

- 수정 원본: `src/*_utf8.*`, `src/ThisWorkbook_events.txt`, `src/customUI14.xml`
- VBA 가져오기 파일 생성: `python tests/export_ascii.py`
- Python 참조·소스 검사: `python -m unittest discover -s tests -p "test_*.py" -v`
- 실제 제작: VBA 프로젝트 접근이 허용된 개발 환경에서 `Build_Release.cmd`
- 실제 Excel 검사: `Test_Excel.cmd`, `SLC_TestAll`. Python 검사만으로 Excel 실행을 확인했다고 판단하지 않습니다.

빌드는 별도로 시작한 Excel의 소유 프로세스를 확인하고 빈 추가 기능에 ASCII 소스를 가져옵니다. 저장한 XLAM을 다시 열어 버전·비교 규칙·통합 검사·메뉴 등록을 확인한 뒤에만 `dist/`와 `Release/`를 만듭니다. `Release/EXCEL_TEST_RESULT.txt`에 해당 빌드의 실행 결과가 남습니다. 일반 설치는 완성된 XLAM을 사용하므로 VBA 프로젝트 접근 권한이 필요하지 않습니다.

설치기는 자체 파일과 현재 계정의 Excel 자동 실행 등록(`HKCU`, `Options/OPEN[n]`)을 관리합니다. 설치 실패 시 처리 가능한 변경은 되돌리며, 외부에서 바뀐 파일·등록은 보존합니다. 그룹 정책이나 `AllSigned`가 있으면 그대로 따릅니다. 그렇지 않은 경우 CMD 실행기는 같은 폴더의 `Setup.ps1`만 다운로드 차단을 해제하고 해당 PowerShell 실행에만 `RemoteSigned`를 적용합니다. 영구 실행 정책은 바꾸지 않습니다. 파일 한 개의 차단 해제는 유지됩니다.

신뢰 위치 등록이 정책으로 금지되거나 설치 파일의 실제 저장 경로가 예상과 다르면 중단합니다. 제거는 자신이 만든 변경되지 않은 등록과 파일만 지우며 별도로 추가된 파일을 남깁니다. 실행 중에는 같은 작업을 다시 시작하지 못하게 하고, 계산 모드·클립보드·전역 단축키를 바꾸지 않습니다. 메뉴도 이 제품의 식별자가 붙은 항목만 관리합니다.

이벤트를 끈 상태에서는 기존 추가 기능 도구 모음의 개수가 늦게 갱신될 수 있습니다. 우클릭 메뉴는 열 때마다 담긴 목록으로 구성합니다. 모든 Excel 버전과 타사 추가 기능에서의 동작을 확인한 것은 아닙니다.
