# Excel 명단 비교 0.2.0 R11

두 목록의 값과 개수가 같은지 확인합니다. 같으면 짧게 알려주고, 차이가 있을 때만 새 Excel 결과 파일을 만듭니다.

## 설치하기

64비트 Windows와 PC에 설치된 데스크톱 Excel이 필요합니다. Mac과 브라우저용 Excel은 지원하지 않습니다.

1. 작업 중인 파일을 저장하고 Excel 창을 모두 닫습니다.
2. **ExcelSmartListCompare-0.2.0-rc.11-Setup.exe**를 실행하고 **설치**를 누릅니다.
3. Excel을 열어 **추가 기능** 탭의 명단 비교 버튼을 확인합니다. 셀을 마우스 오른쪽 버튼으로 눌러도 사용할 수 있습니다.

ZIP은 모두 푼 뒤 `Release` 폴더의 **Install.cmd**를 실행합니다. 현재 Windows 계정에 설치하며 관리자 권한·Python·VBA 편집기는 필요하지 않습니다. 제품 폴더 한 곳을 Excel의 신뢰할 수 있는 위치로 등록하므로 이곳에는 제품 파일만 보관하세요. 회사 정책으로 설치가 차단되면 승인된 설치 절차를 따르세요.

## 두 목록 비교하기

1. 일반 범위의 제목을 빼고 첫 목록의 셀을 선택한 뒤 **첫 번째 목록 담기**를 누릅니다.
2. 필요하면 **담은 목록 확인**으로 출처·담은 시각·항목 수와 표본을 확인합니다.
3. 같은 Excel에서 두 번째 목록의 셀을 선택하고 **두 번째 목록 담아 비교**를 누릅니다.

값과 개수가 같으면 결과 파일을 만들지 않습니다. 같은 값이 양쪽에 두 번씩 있어도 같습니다. 한쪽에 두 번, 다른 쪽에 한 번 있으면 차이가 있습니다.

차이가 있으면 **명단비교_결과** 시트 하나가 열립니다. 8행에 제목, 9행부터 차이 내역이 표시됩니다. 비교에 쓴 값, 원래 값의 예, 각 목록의 개수와 남은 개수, 대표 셀 주소를 확인하고 원하는 위치에 직접 저장하세요. 같은 개수의 중복은 차이 내역에 표시하지 않습니다.

기본 설정에서는 비교가 성공하면 첫 목록을 비우고 **첫 번째 목록 담기**로 돌아갑니다. 원본 값·수식·서식과 이전 결과 파일은 그대로입니다. 오류·취소·경고 거절에는 이전 첫 목록을 유지합니다.

## 비교 설정 바꾸기

**Excel → 추가 기능 탭 → 비교 설정** 또는 **셀 우클릭 → 명단 비교 → 비교 설정**을 엽니다. 두 경로에서 같은 설정을 바꿉니다. 체크된 항목이 켜진 상태입니다.

| 체크 항목 | 꺼짐 — 최초 기본값 | 켜짐 |
|---|---|---|
| 메일 전체 주소 비교 (@ 뒤 포함) | `@` 앞부분만 비교 | 도메인까지 전체 주소 비교 |
| 대소문자 무시 | `ABC`와 `abc`를 다르게 봄 | `ABC`와 `abc`를 같게 봄 |
| 비교 후 첫 목록 유지 | 성공하면 첫 목록 비우기 | 같은 첫 목록으로 다음 목록과 이어 비교 |

기본 상태에서 `User@a.com`과 `User@b.com`은 같고, `User@a.com`과 `user@a.com`은 다릅니다. 전체 주소 비교를 켜면 다른 도메인도 차이로 봅니다.

첫 목록을 담은 동안에는 메일·대소문자 설정이 잠깁니다. 변경하려면 **첫 번째 목록 비우기**를 누른 뒤 설정하고 다시 담으세요. 첫 목록 유지 여부는 비교 시작 전까지 바꿀 수 있습니다. 작업 중에는 설정을 바꿀 수 없습니다.

설정은 같은 PC·Windows 계정에서 다음 Excel 실행에도 자동으로 기억합니다. **기본값으로 되돌리기**는 세 항목을 모두 끄고 그 값을 기억합니다. 먼저 첫 목록을 비워야 합니다. 설정을 기억해도 **명단 내용은 Excel을 완전히 종료하면 사라집니다.**

## 첫 목록 확인·바꾸기·비우기

담긴 값은 원본과 분리해 보관합니다. 원본을 수정하거나 닫아도 자동으로 바뀌지 않습니다. 새로운 범위를 선택하고 **첫 번째 목록 바꾸기**를 누르면 새 값을 담습니다. **첫 번째 목록 비우기**는 기억한 목록만 지우고 원본 셀을 지우지 않습니다.

**담은 목록 확인**은 필요할 때 직접 여는 확인용 파일입니다. 요약과 제외·발생위치 시트에서 출처와 표본을 볼 수 있습니다. 발생 위치는 목록당 최대 1,200개·같은 비교값당 5개, 오류는 최대 200개의 표본이며 생략 수를 표시합니다. 표본 한도와 관계없이 비교 대상 전체의 개수를 셉니다.

## 비교 규칙과 큰 목록

- 순서와 가로·세로 방향을 무시하고 선택 전체를 목록 하나로 비교합니다. Ctrl로 선택한 여러 범위도 목록 하나입니다.
- 숨긴 셀·필터로 가려진 셀·빈칸·오류·표 제목과 합계는 뺍니다. 일반 범위의 제목은 직접 빼고 선택하세요. 오류를 제외하고 같으면 제외 개수를 함께 알립니다.
- 숫자 `123`과 문자 `123.0`·`1.23e2`는 같습니다. 문자 `00123`의 앞자리 0은 보존합니다. 대소문자 설정은 이 숫자 규칙을 바꾸지 않습니다.
- 병합 셀은 비교할 수 없습니다. 계산 중이면 계산이 끝난 뒤 실행하세요.
- 한 목록의 가시 선택 셀 상한은 **100,000개**, 한 셀은 **4,096자**, 원문 합계는 **5,000,000자**입니다. 입력 상한은 정상 완료 보장량이 아니며 값 길이·고유값·PC 부하에 따라 시간 제한으로 중단될 수 있습니다.
- **작업 취소**나 Esc는 취소 요청입니다. 종료 안내와 남은 첫 목록을 확인하세요. 큰 선택 경고에서 **아니요**를 누르면 작업을 시작하지 않습니다.

두 목록을 같은 행 수로 나누면 다른 구간으로 이동한 같은 값을 차이로 볼 수 있습니다. 나누려면 같은 비교값의 모든 항목이 양쪽에서 같은 묶음에 포함되어야 합니다. 별도 Excel 프로세스끼리는 목록을 공유하지 않습니다. VBA 실행 후 Excel의 기본 실행 취소 기록은 유지되지 않을 수 있습니다.

명단은 외부 서비스로 보내지 않습니다. 결과와 확인용 파일에는 원래 값 표본이 있으므로 저장·공유할 때 내용을 확인하세요.

## 다시 설치하거나 제거하기

파일을 저장하고 Excel을 닫은 뒤 EXE 또는 **Install.cmd**로 업데이트·재설치할 수 있습니다. EXE 설치는 **Windows 설정 → 앱 → 설치된 앱 → Excel 명단 비교 → 제거**, ZIP 설치는 **Uninstall.cmd**로 제거합니다. 업무 파일과 다른 추가 기능은 유지합니다.

비교 설정은 업데이트·재설치·제거 후에도 같은 계정에 남습니다. 초기화하려면 설치된 Excel의 **비교 설정 → 기본값으로 되돌리기**를 사용하세요. 설치 오류를 문의할 때는 사용자 경로가 들어간 로그를 그대로 공개하지 마세요.
