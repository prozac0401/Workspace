# Windows Excel 인수 테스트

이 표는 인수 요구사항입니다. 현재 RC8 파일의 실행 결과는 [RC8 검증 기록](RC8_COMPLETION_REPORT.md)을 따릅니다. 이전 RC7의 Esc·최초 GUI 제거 실패는 [잠금 해제 기록](UNLOCKED_UI_REPORT.md)에 보존합니다. 아래 기대값 자체는 통과 증거가 아닙니다.

## 한국어 문구 후속 교정 · 2026-09-17

현재 소스의 결과표는 **비교에 쓴 값 / 원래 값 (예) / 남은 개수 / 셀 주소**를 사용합니다. 요약의 `목록 잔여`는 `목록 남은 항목`으로 바뀌었습니다. 중복 수와 남은 개수는 예시로 설명하며, Esc 취소를 보장하는 안내는 하지 않습니다. 실행 검사 7개 파일의 결과 문구 기대값도 새 표현에 맞췄습니다.

이번 소스는 실제 Excel에서 새로 제작·실행하지 않았습니다. 결과표의 긴 문장과 사용 안내 창이 잘리지 않는지, 설치 화면의 문장이 자연스럽게 이어지는지 실제 화면에서 확인해야 합니다. 기존 RC8 통과·실패 기록을 새 소스의 결과로 사용하지 않습니다. [문구 검수와 확인 범위](KOREAN_WORDING_REVIEW.md)

I12~I15는 명시적 후속 요청에 따라 RC2에서 추가했다. [ADR-0003](ADR-0003-Product-trusted-location.md)과 [실제 실행·격리 시험·미실행 구분](WINDOWS_TRUST_LOCATION_REPORT.md)을 따른다. 회사 정책 실기는 이번 시험에서 실행하지 않았다.

I16~I20은 수동 설치 준비를 실행기에 포함해 릴리즈해 달라는 후속 요청이다. [ADR-0005](ADR-0005-Process-scoped-launchers.md)와 [RC4 검증 기록](WINDOWS_LAUNCHER_REPORT.md)에 실제 프로세스 시험과 정책 모의 시험을 구분한다.

I21~I25는 설치 시 이전 버전을 감지해 제거한 뒤 설치해 달라는 요청이다. [ADR-0007](ADR-0007-Replace-previous-installation.md)과 [RC6 업데이트 검증](UPGRADE_REPORT.md)에 격리 시험, 실제 설치, 중단 복구의 검증 범위를 구분한다.

I26~I30은 동일 로직의 단일 EXE 제작·배포 요청이다. [ADR-0009](ADR-0009-Single-file-installer.md)와 [단일 EXE 검증 기록](ONEFILE_REPORT.md)을 따른다.
