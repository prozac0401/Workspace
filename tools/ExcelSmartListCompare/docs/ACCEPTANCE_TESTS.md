# Windows Excel 인수 테스트

이 표는 인수 요구사항입니다. 2026-09-14 후속 Windows 실행에서 실제 XLAM 빌드·제품 기능·설치 수명주기를 검증했습니다. 항목별 통과 범위와 남은 미실행 항목은 [Windows E2E 보고서](WINDOWS_E2E_REPORT.md)를 따릅니다. 아래 기대값 자체는 통과 증거가 아닙니다.

## 값과 선택

| ID | 시나리오 | 기대 결과 |
|---|---|---|
| S01 | B2:K2 → 다른 파일 C10:C19 | 방향·파일과 무관하게 10개 값 비교 |
| S02 | C10:C19 → B2:K2 | 반대 방향도 같은 판정 |
| S03 | B2:D4 → H10:H18 | 9셀을 하나의 명단으로 비교 |
| S04 | 한 셀만 선택, 주변에 다른 값 존재 | 선택한 한 셀만 읽음 |
| S05 | Ctrl 다중 선택 / 겹친 영역 | 선택 전체가 한 명단; 같은 주소는 한 번 |
| S06 | A1:B20 선택 | 자동 두 열 비교 없이 하나의 기준 |
| S07 | 기준을 담고 원본 파일 닫음 | 두 번째 파일과 비교 가능 |
| S08 | 기준 범위 내용/필터 변경 후 같은 범위 재실행 | 자동 취소하지 않고 이전 스냅샷과 비교 |
| S09 | 서로 다른 Excel.exe 프로세스 | 공유하지 않음을 명확히 안내; 메뉴 기준 상태로 구별 |

| ID | 시나리오 | 기대 결과 |
|---|---|---|

| F03 | 필터 제목 옆 일반 데이터 | 제목 셀만 제외하고 옆 데이터 유지 |
| F04 | Table 제목/합계행 | 해당 셀만 제외 |
| F05 | 전부 숨김 / 빈칸 / 오류뿐인 B | 비교 가능한 값 없음 안내; A 유지 |
| F06 | 일부 오류값 포함 | 제외 건수 명시; 원본 전체 완전 동일 판정 금지 |
| F07 | 병합 셀 포함 | 병합 셀 미지원 안내, 기준 유지 |
| F08 | 수동 계산 / 계산 진행 중 | 강제 계산하지 않음; 계산 중 실행 거절 |

|---|---|---|

| P02 | 가시 20,000셀 | 값 읽기 전 경고, 기본 '아니요' |
| P03 | 기준 15,000셀 + B 5,000셀 | 합계 기준 경고 |
| P04 | 가시 100,000셀 / 100,001셀 | 전자 허용·경고, 후자 중단 |
| P05 | 영역 조각 500개 / 5,001개 | 경고 / 중단 |
| P06 | 가시성 검사 200,000셀 / 2,000,001셀 | 가시성 확인 전 경고 / 중단 |
| P07 | 경고에서 아니요 / 처리 중 Esc | A 유지, 원본/이전 결과 변경 없음 |
| P08 | 오래 걸리는 작업 | 체크포인트에서 약 30초 지연 보호; 하드 시간 보장 아님 |
| P09 | 4,097자 셀 / 전체 5,000,001자 | 잘라서 비교하지 않고 전체 중단 |
| P10 | 양쪽 100,000개가 전부 다름 | 출력 규모/메모리/취소 응답 실제 측정; 상한 조정 검토 |

## 출력과 충돌

| ID | 시나리오 | 기대 결과 |
|---|---|---|
| C01 | 다른 추가 기능이 Ctrl+Shift+M 사용 | 본 도구가 키를 바꾸지 않음 |
| C02 | 설치/시작/메뉴 재등록 반복 | 본 메뉴만 1세트, 기존 메뉴 유지 |
| C03 | 오류/취소 전후 Excel 설정 | ScreenUpdating, EnableEvents, Interactive 등 복원 |
| C04 | 타 기능이 상태표시줄 변경 | 자기 표시가 아닐 때 해제 코드가 덮지 않음 |
| C05 | 기존 결과를 편집/저장한 뒤 다음 비교 | 기존 결과 보존, 필요할 때 새 결과 |
| C06 | `=1+1`, `+...`, `-...`, `@...` 원문 | 결과가 수식으로 실행되지 않음; HasFormula 확인 |
| C07 | 숫자/문자숫자/앞자리 0/메일 도메인 | README 규칙대로 정확히 판정 |
| C08 | 업무 문서의 Undo 기록 | 실제 영향 기록; 무영향 보장하지 않음 |

## 설치와 제거

| ID | 시나리오 | 기대 결과 |
|---|---|---|
| I01 | 승인된 개발 PC에서 Build_Release.cmd | Excel 테스트 통과 후에만 Release 생성 |
| I02 | 완성 Release의 Install.cmd | VBA 프로젝트 접근 권한 없이 등록 |
| I03 | Excel 완전 종료 후 재실행 | 메뉴 자동 표시 |
| I04 | Excel을 열어둔 채 설치/삭제 | 강제 종료 없이 중단 |
| I05 | 매크로/조직 PS/프로젝트 접근 정책 차단 | 조직 정책·영구 보안 설정을 변경하지 않고 실패 안내. 로컬 Restricted는 RC4의 I16 적용 |
| I06 | 재설치/버전 변경 실패 | 이전 파일 백업 복원; 재활성화 필요 여부 안내 |
| I07 | Uninstall.cmd | 자기 등록·파일만 제거; 타 파일/추가 기능 보존 |
| I08 | 사용자 파일을 설치 폴더에 추가 후 제거 | 추가 파일은 남겨둠 |
| I09 | 설치/삭제 동시 실행 | 전용 잠금으로 중복 실행 방지 |
| I10 | 한국어/공백 경로, Office 32/64비트 | 경로/인코딩/COM 확인 |
| I11 | v0.1 또는 PERSONAL.XLSB에 이전 코드 존재 | 임의 삭제하지 않음; 이전 버전 분리 제거 확인 |
| I12 | RC2 Install.cmd와 정상 Excel 시작 | 제품 로컬 폴더만 신뢰 위치 등록, 새 항목의 하위 폴더 제외, 매크로 승인 클릭 없이 제품 실행 |
| I13 | 기존 신뢰 위치, 재설치와 외부 수정 | 기존 항목 보존, 자기 항목 재사용, 외부 수정 항목은 덮어쓰거나 삭제하지 않음 |
| I14 | 모든 신뢰 위치 차단 / 정책 위치만 허용 | 종료 코드 6으로 안내, 회사 정책과 전체 매크로 설정 보존 |
| I15 | 신뢰 등록 중 실패·동시 생성·제거 | 소유 기록과 토큰으로 자기 변경만 복구, 동시 생성된 외부 키 보존 |
| I16 | 그룹 정책 없는 Restricted + 다운로드한 RC4 | Install.cmd가 자기 Setup.ps1만 차단 해제하고 프로세스 한정 RemoteSigned로 실행 |
| I17 | 설치·제거·진단 실행기 | 작업 인자·STA·종료 코드 전달, 부모 프로세스 및 영구 실행 정책 보존 |
| I18 | 그룹 정책 또는 유효 AllSigned | 차단 표시·기존 정책 보존, 추가 실행 허용 없이 원래 정책으로 판단 |
| I19 | Setup.ps1 누락 또는 차단 해제 실패 | 준비 단계에서 실패하고 설치 본체를 실행하지 않음 |
| I20 | 한국어·공백·따옴표·특수문자 경로 | 스크립트 경로를 PowerShell 코드에 삽입하지 않고 정확한 파일로 실행 |

I12~I15는 명시적 후속 요청에 따라 RC2에서 추가했다. [ADR-0003](ADR-0003-Product-trusted-location.md)과 [실제 실행·격리 시험·미실행 구분](WINDOWS_TRUST_LOCATION_REPORT.md)을 따른다. 회사 정책 실기는 이번 시험에서 실행하지 않았다.

I16~I20은 수동 설치 준비를 실행기에 포함해 릴리즈해 달라는 후속 요청이다. [ADR-0005](ADR-0005-Process-scoped-launchers.md)와 [RC4 검증 기록](WINDOWS_LAUNCHER_REPORT.md)에 실제 프로세스 시험과 정책 모의 시험을 구분한다.
