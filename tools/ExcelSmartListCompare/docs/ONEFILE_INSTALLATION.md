# Excel 명단 비교 설치 안내

**0.2.0 RC9 제한 평가판 · LIMITED EVALUATION**입니다. 사용자가 현재 가능한 파일의 배포를 요청해 서명 없는 EXE·ZIP을 준비합니다. 실제 게시 여부는 배포 페이지를 확인하세요. **전체 인수는 NOT_MET이며 새 EXE의 실제 설치·업데이트·제거는 미검증입니다.**

candidate-07 XLAM은 수정 CMD로 설치해 실제 해시 일치를 확인했습니다. 이후 복구 진단에서 Excel이 비정상 종료했고 창 없는 시험 프로세스가 남아 기존 설치 보호가 추가 설치를 막고 있습니다. 모든 창을 닫았더라도 이 상태의 PC에서는 설치가 계속 차단될 수 있습니다. 보호를 끄거나 반복 설치하지 마세요.

[알려진 실패와 사용 범위](RELEASE_README.md) · [실제 검증 기록](RC9_APPROVED_RETEST_20260917.md) · [제한 평가판 결정](ADR-0015-Limited-evaluation-release.md)

## 설치 시도하기

1. 배포 페이지의 RC9 파일명·평가판 표시와 제공된 SHA-256 값을 확인합니다.
2. 작업 중인 파일을 저장하고 Excel 창을 모두 닫습니다. Excel 프로세스가 남았다는 안내가 계속 나오면 설치를 중단합니다.
3. EXE를 실행하고 제한 안내를 읽은 뒤 **설치**를 누릅니다. ZIP은 모두 푼 뒤 `Release` 폴더의 **Install.cmd**를 실행합니다.
4. 설치가 완료되면 Excel을 열어 **추가 기능** 탭의 **첫 번째 목록 담기**를 확인합니다. 자동 로드는 이번 파일에서 검증을 마치지 못했습니다.

이 절차는 설치기의 사용 방법이며 새 EXE에서 실제 통과한 수명주기 검사가 아닙니다. 현재 Windows 계정에 설치하며 관리자 권한·Python·VBA 편집기는 필요하지 않습니다. 64비트 Windows·Excel에서 평가했고 32비트 Office는 미검증입니다.

## 설치 위치와 보안

프로그램은 `%LOCALAPPDATA%\ExcelSmartListCompare`, 설치 관리 파일은 `%LOCALAPPDATA%\ExcelSmartListCompare.Setup`을 사용합니다. 탐색기 주소창에 붙여 넣어 확인할 수 있습니다.

제품 폴더 한 곳만 Excel의 **신뢰할 수 있는 위치**로 등록하고 새 항목에는 하위 폴더를 포함하지 않습니다. 이곳의 매크로는 별도 알림 없이 실행될 수 있으므로 제품 파일만 보관하세요. 회사 정책·기존 신뢰 위치·전체 매크로 설정은 유지합니다.

CMD는 그룹 정책과 `AllSigned`를 따릅니다. 그 외에는 같은 폴더의 `Setup.ps1` 한 파일만 다운로드 차단을 해제하고 해당 실행에만 `RemoteSigned`를 적용합니다. 영구 실행 정책은 바꾸지 않지만 해당 파일의 다운로드 차단 해제는 유지됩니다.

## 다시 설치하거나 제거하기

설계상 같은 버전은 재설치하고 이 설치기로 설치한 이전 버전은 바꿉니다. 더 최신 버전이나 확인할 수 없는 기록은 남기고 중단합니다. 직접 등록한 추가 기능과 `PERSONAL.XLSB`의 코드는 지우지 않습니다. 이번 EXE에서 이 전체 과정을 실제 검증한 것은 아닙니다.

제거는 Excel 프로세스가 없을 때 **Windows 설정 → 앱 → 설치된 앱 → Excel 명단 비교 → 제거**를 선택합니다. ZIP 설치는 **Uninstall.cmd**를 실행합니다. 업무 파일·다른 추가 기능·설치 폴더에 따로 넣은 파일은 보존합니다.

`Uninstall.cmd`로 먼저 제거해 앱 목록에 이름이 남으면 앱 목록의 제거 항목으로 관리 정보를 정리할 수 있습니다. 오류가 계속되면 반복 실행하거나 파일을 강제로 지우지 말고 오류와 **문제 확인용 코드**를 보관하세요.

설치 기록에는 사용자 이름과 경로가 들어갈 수 있으므로 공개 게시하지 마세요. 평가판 배포 결정은 회사의 업무 도입 승인이나 코드 서명을 뜻하지 않습니다.
