# Excel 명단 비교 설치 안내

현재 RC9 소스에서 처리 부하·취소·실행기를 보완하고 있습니다. **아직 출시 가능한 새 설치 파일은 없습니다.** [RC9 진행 결과](RC9_STABILITY_REPORT.md)를 확인하세요. 아래 RC8 파일의 이름과 결과는 과거 시험 안내이며 새 소스가 반영된 파일이 아닙니다.

**RC8은 시험용 버전이며, 배포를 보류한 상태입니다.** 실제 Excel에서 Esc로 취소되지 않았고, 처음 설치할 때 접근 거부 오류가 발생했습니다. 같은 파일로 다시 설치했을 때는 성공했지만 첫 실패의 원인은 아직 확인하지 못했습니다. 아래는 시험용 설치 방법입니다. 자세한 결과는 [RC8 검증 기록](RC8_COMPLETION_REPORT.md)에서 확인할 수 있습니다. 이 시험 파일은 [이전에 공개한 버전](https://github.com/prozac0401/Workspace/releases)과 다릅니다.

이번에는 화면과 설치 안내의 한국어 소스를 교정했습니다. 바뀐 문구를 모두 반영한 새 XLAM과 설치 파일은 아직 만들지 않았습니다. [이번 문구 교정 범위](KOREAN_WORDING_REVIEW.md)를 확인하세요. 아래 파일 이름과 시험 결과는 기존 RC8 파일을 가리킵니다.

설치 파일 하나에 Excel 추가 기능과 설치에 필요한 파일을 모두 담았습니다.

## 설치와 업데이트

1. 받은 파일의 이름이 `ExcelSmartListCompare-0.2.0-rc.8-Setup.exe`인지 확인하세요. 함께 제공된 검증 요약의 SHA-256 값과도 비교하세요. SHA-256은 파일이 원본과 같은지 확인하는 값입니다.
2. Excel에서 작업 중인 내용을 저장하고 모든 Excel 창을 닫으세요.
3. 설치 파일을 실행하고 안내를 읽은 뒤 **설치**를 누르세요.
4. 설치가 끝나면 Excel을 여세요. 첫 번째 목록의 셀을 선택한 뒤 **첫 번째 목록 담기**를 누르세요.
5. 두 번째 목록의 셀을 선택한 뒤 **두 번째 목록 담아 비교**를 누르세요.

이전 버전이 설치되어 있으면 RC8로 바꿉니다. RC8이 이미 있으면 다시 설치합니다. 더 새로운 버전이 있거나 기존 설치 기록을 확인할 수 없으면 설치를 중단하고 기존 파일을 그대로 둡니다. 실제 시험 결과와 아직 확인하지 못한 사항은 [현재 검증 기록](RC8_COMPLETION_REPORT.md)을 참고하세요.

## 제거

1. Excel에서 작업 중인 내용을 저장하고 모든 Excel 창을 닫으세요.
2. **Windows 설정 → 앱 → 설치된 앱**에서 **Excel 명단 비교**를 찾으세요.
3. **제거**를 누르고 안내에 따라 진행하세요.

Excel 명단 비교의 파일과 이 프로그램이 추가한 Excel 설정을 제거합니다. 다른 추가 기능, 기존 Excel 파일, 설치 폴더에 따로 넣은 파일은 그대로 둡니다.

`Uninstall.cmd`로 먼저 제거했다면 Windows 앱 목록에 이름이 남을 수 있습니다. 앱 목록에서 다시 **제거**를 누르면 남은 설치 관리 정보도 정리됩니다. 제거에 필요한 파일이 없다면 같은 설치 파일로 다시 설치한 뒤 제거하세요.

RC8에서는 제거할 때 필요한 파일 두 개를 임시 폴더에 복사해 실행합니다. 실행 중인 파일이 지워져 제거가 중단되는 문제를 피하기 위한 처리입니다. 이 복사본은 임시 폴더에 남을 수 있습니다. 업무 파일은 복사하지 않습니다. RC7에서 발생했던 접근 거부와 제거 실패는 [당시 기록](UNLOCKED_UI_REPORT.md)에 남겨 두었습니다. 첫 접근 거부의 원인은 아직 확인하지 못했으며, 모든 제거 실패가 같은 원인이라고 단정하지 않습니다.

## 설치 위치와 실행 조건

- 프로그램 파일: `%LOCALAPPDATA%\ExcelSmartListCompare`
- 설치·제거 관리 파일: `%LOCALAPPDATA%\ExcelSmartListCompare.Setup`
- 지금 로그인한 Windows 계정에서 사용할 수 있도록 설치합니다. 관리자 권한은 필요하지 않습니다. Windows에 설치된 데스크톱용 Excel과 Windows PowerShell이 필요합니다.
- 프로그램 폴더에서 매크로를 실행할 수 있도록 Excel의 **신뢰할 수 있는 위치**에 등록합니다. 새로 등록할 때는 하위 폴더를 포함하지 않습니다. 이 폴더의 매크로는 별도 확인 없이 실행될 수 있으므로 Excel 명단 비교 파일만 보관하세요.
- 회사에서 정한 보안 정책과 서명된 스크립트만 실행하도록 하는 설정(`AllSigned`)은 그대로 따릅니다. Excel 전체의 매크로 설정이나 Windows에 저장된 PowerShell 실행 정책은 바꾸지 않습니다.

`%LOCALAPPDATA%`는 지금 로그인한 계정의 프로그램 데이터를 저장하는 폴더입니다. 파일 탐색기의 주소 표시줄에 위 경로를 붙여 넣으면 해당 폴더를 열 수 있습니다.

## 실패했을 때

- **Excel이 열려 있다는 안내가 나오면:** 작업 중인 내용을 저장하고 모든 Excel 창을 닫은 뒤 다시 실행하세요.
- **다른 설치나 제거가 진행 중이라는 안내가 나오면:** 해당 작업이 끝날 때까지 기다린 뒤 다시 실행하세요.
- **업데이트에 실패하면:** 복구할 수 있는 경우 이전 파일과 Excel 설정으로 되돌립니다. 다른 작업에서 바뀐 파일이나 설정은 덮어쓰지 않고 경고로 알려 줍니다.
- **프로그램은 설치됐지만 Windows 앱 목록에 등록되지 않았다면:** 같은 설치 파일을 다시 실행하세요.
- **기존 설치 관리 폴더를 확인할 수 없다는 안내가 나오면:** 출처가 확인되지 않은 폴더는 덮어쓰지 않습니다. 폴더와 설치 기록을 확인해야 합니다.

문제가 계속되면 오류 화면과 **문제 확인용 코드**를 보관하세요. 자세한 설치 기록은 임시 폴더(`%TEMP%`)의 `Setup Log` 파일에 있습니다. 이 기록에는 사용자 이름이 들어간 폴더 경로가 포함될 수 있으므로 공개 게시하지 마세요.

이 파일은 **코드 서명이 없는 시험용 설치 프로그램**입니다. Windows나 회사의 보안 정책에 따라 실행되지 않을 수 있습니다. 회사에서 배포를 승인한 버전은 아닙니다. 다른 Office 환경 등 아직 확인하지 못한 사항은 [RC8 검증 기록](RC8_COMPLETION_REPORT.md)에 정리했습니다.

## 개발자용: 기존 RC8 파일로 설치 프로그램 만들기

검사에 사용한 RC8 Release 폴더와 Inno Setup 6.5 이상이 필요합니다. 이 명령은 기존 RC8 추가 기능과 설치 스크립트를 포장합니다. 이번에 고친 Excel 화면과 Setup.ps1 문구까지 반영하려면 승인된 개발 환경에서 추가 기능을 새로 만들고 검증한 다음 포장 기준도 갱신해야 합니다.

```powershell
python scripts/build-excel-onefile.py --engine-version 0.2.0-rc.8 --release-directory artifacts/excel-rc8-release/Release --output-directory artifacts/excel-rc8-onefile-new
```

출력 폴더는 저장소의 `artifacts` 안에 새로 만들어야 합니다. 제작 도구는 입력 파일 5개가 `installer/RC8-Payload.json`에 기록된 SHA-256 값과 일치하는지 확인한 뒤 EXE, SHA-256 파일, `OneFile-Build.json`을 만듭니다. 파일을 만들었다는 사실만으로 실제 설치·사용 검사가 끝난 것은 아닙니다. RC7을 재현할 때는 `--engine-version 0.2.0-rc.7`과 해당 버전의 Release 폴더를 사용합니다. 로컬 진단 기록과 제작 중간 파일은 배포하지 않습니다.
