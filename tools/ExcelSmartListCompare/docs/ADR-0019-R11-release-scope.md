# ADR-0019 · R11 구현과 필수 검사 후 배포 범위

상태: 채택 · 날짜: 2026-09-20 · 범위: 0.2.0-rc.11

결정 담당: 도구 개발·검증 담당

관련 요구: R11 REQ-EXCEL-025~031 및 사용자 요청 “r11 릴리즈 완성, github에 배포”, “시간이 소요될 테스트 시나리오는 우선 테스트 목록에서 배제”, “필수 테스트는 진행”, “구체적인 재현경로, 기대되는 결과”.

## 결정

R11은 메일 범위·대소문자·첫 목록 유지 설정, 일치 시 결과 미생성, 기본 자동 비우기를 구현한다. 구현 진행 요청에 따라 직전 권장안인 **마지막 설정 자동 기억 + 기본값으로 되돌리기**를 적용한다. 차이 결과는 RC9의 단일 `명단비교_결과` 시트와 8행 제목·9행 데이터·열 순서를 사용하며 값·개수가 다른 항목만 출력한다. 설정은 추가 기능 탭과 셀 우클릭의 **비교 설정** 메뉴에 같은 체크 항목으로 표시한다.

필수 검사 통과 후 GitHub에 EXE·설치 ZIP·소스 ZIP·별도 검증 ZIP과 각 SHA-256을 게시한다. 배포 프로필은 `documented-exceptions`, 결정은 `PUBLISH_WITH_RECORDED_RESULTS`이며 `fullAcceptancePassed=false`를 유지한다. 이 버전의 명시적 사용자 요청에 근거하며 RC9·RC10 배포 예외를 재사용하지 않는다.

## 설정 저장·복구

설정은 같은 Windows 계정의 `HKCU\Software\VB and VBA Program Settings\ExcelSmartListCompare\Preferences`에 `OptionsV1` 문자열 하나로 저장한다. 형식은 `1|전체주소|대소문자무시|첫목록유지`이며 각 값은 `0` 또는 `1`이다. 기본은 `1|0|0|0`이다. 하나의 레지스트리 값 쓰기로 세 옵션을 함께 적용하고 저장 실패 시 메모리 설정도 바꾸지 않는다.

설정이 없거나 읽지 못하거나 값이 유효하지 않으면 기본값을 사용한다. 읽기만으로 저장값을 덮어쓰지 않는다. 같은 프로세스의 창은 메모리 설정을 공유한다. 별도 Excel 프로세스는 시작 시 저장값을 읽고, 다음 시작에 사용할 설정은 마지막으로 성공한 저장값이 된다. 이미 담은 목록과 진행 중인 비교 규칙은 외부 설정 변경으로 바뀌지 않는다.

명단·출처·담은 시각은 저장하지 않는다. 업데이트·재설치·제거는 이 사용자 선택을 보존하며 **기본값으로 되돌리기**로 초기화한다. 테스트는 고유한 `R11Test-…` 하위 항목에만 임시 설정을 쓰고 종료 시 그 항목을 제거한다. 실제 사용자의 설정은 시험 값으로 바꾸지 않는다.

## 배포 전 필수 검사

- 독립적인 비교 기대값, 네 옵션 조합, 숫자·앞자리 0·전체 개수와 기존 데이터 보존에 관한 빠른 Python 검사.
- 실제 Excel에서 새로 저장하고 다시 연 동일 XLAM의 `SLC_TestAll`과 `SLC_UsabilityTests`. 기본값·설정 저장 및 재읽기·메뉴 연결·잠금·일치 미출력·비우기와 유지·출력 오류 복구·수식 방지를 확인한다.
- 직렬화 VBA와 RibbonX를 현재 소스에 대조하고, 실제 시험한 파일의 SHA-256을 패키지에 고정한다. Excel 정상 종료와 일시적 개발 설정 복원을 확인한다.
- 설치 엔진 구문, 버전, 포장 게이트, EXE 제작, ZIP 구성·파일 해시·압축 무결성·배포 후 다운로드 일치. 실제 사용자 설치를 수행한 것으로 표시하지 않는다.
- 문서 strict 빌드와 로컬 링크·공개 범위 검사.

소스 대조, 실제 비교 통합, 설정·상태, 출력 복구, Python, 문서 검사는 이 버전의 예외 프로필에서도 PASS가 필요하다. 결과를 실제로 얻기 전에는 통과로 채우지 않는다.

## 배포 후 검증으로 분리

대용량 시간·메모리 측정, 실제 Esc 입력 길이·취소 버튼 반복, 모든 컨텍스트·창·배율·키보드 조합, 설치·업데이트·재시작·재설치·제거 반복, 여러 PC·Excel 빌드·32비트 Excel과 조직 정책 검증은 이번 선배포 실행 목록에서 제외한다. 변경하지 않은 실행기·감시기의 고의 대기·시간 초과 반복 회귀도 별도 범위로 둔다.

재현 순서와 기대 결과는 [사용자 검증 안내](RC11_USER_VALIDATION.md)에 제공한다. 이 항목은 NOT_RUN 또는 확인한 부분만 PARTIAL로 기록한다. 기존 버전의 상태표시줄 복원과 실제 취소 문제는 과거 기록에 보존하고 R11에서 해결됐다고 추정하지 않는다.

## 안내와 증거

설치 패키지에는 제품명·버전·사용법을 제공하고 시험판 문구와 시험 실패 목록을 넣지 않는다. 실행 결과·미실행 범위·후속 재현 절차는 별도 Verification.zip과 저장소에 제공한다. 원시 계정 경로·사용자 로그·레지스트리 덤프와 업무 자료는 게시하지 않는다. 실제 판정은 [R11 검증 기록](RC11_TEST_REPORT.md)에 연결한다.
