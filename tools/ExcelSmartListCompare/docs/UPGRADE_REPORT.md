# RC6 · 이전 버전 감지·제거·설치 검증

도구 ID: ExcelSmartListCompare · 설치기 버전: 0.2.0-rc.6 · 날짜: 2026-09-15

상태: 서명되지 않은 후보. [ADR-0007](ADR-0007-Replace-previous-installation.md), [인수 요구 I21~I25](ACCEPTANCE_TESTS.md), [추가 도구 개발 기준](../../../docs/policies/tools.md)을 따른다.

## 변경 내용

새 Install.cmd는 제품 설치 기록에서 이전 버전을 감지한다. 사용자 확인 한 번으로 이전 XLAM·설치기·제거 실행기·README와 제품 자동 실행 등록을 제거한 뒤 새 파일을 설치한다. 같은 버전은 재설치하고, 더 최신 버전 또는 알 수 없는 기록은 보존한다. 파일 없는 패키지는 제거 전에 거절한다.

업데이트 중에는 제품 폴더 신뢰 위치와 소유 기록을 유지한다. 완성된 파일과 새 설치 기록을 원자적으로 교체하며, 처리 가능한 설치 실패에서는 이전 제품 파일과 등록을 복구한다. 외부 동시 변경은 보존하고 경고한다. 추가 파일·다른 추가 기능·업무 문서는 삭제하지 않는다.

## 검증 대상

- Windows 11 23H2, 데스크톱 Excel x64 `16.0.20326.20144`, Windows PowerShell 5.1, 관리자 권한 없는 일반 사용자.
- 이전 RC5 XLAM: `e6eff07df465933f7159ab073b3cb656c23691d74f522733ca450f19a3f077de`
- 새 RC6 XLAM: `81d8b3e58aee1c352fbf19a1447581297a2e64d11edce9102523ebbbf7e07322`
- 최종 Setup.ps1: `35dfe7209bcecea3eef2d0f8b600dac4fb940aa6a9a93e4a3726ad48d905662f`

VBA 기능과 새 바이너리 제작 근거는 [창 전환 검증 기록](WINDOW_STATE_REPORT.md)을 따른다. 설치 변경 후 XLAM 바이트는 바꾸지 않았고 실제 업데이트 설치 파일과 다시 대조했다.

초기 수명주기 실행은 PowerShell이 예상된 중복 설치 오류의 표준 오류 출력을 테스트 자체의 예외로 처리해 중단됐다. 제품의 실패 복구는 이미 통과했고 미설치·14개 설정 그룹도 복원됐다. 시험 도구를 자식 프로세스 종료 코드와 별도 오류 로그를 수집하도록 수정한 뒤 위 전체 순서를 새로 실행했다. 초기 중단을 제품 설치 실패나 최종 통과로 혼동하지 않는다.

## 원복과 제한

최종 실행 후 Excel 프로세스는 0개이고 임시 예약 작업을 제거했다. 시험 설치는 시작 전처럼 미설치이며, 제품 제작 때 임시 허용했던 VBA 접근도 원래 미설정 상태다. 원시 계정·레지스트리·설치 로그와 합성 파일은 로컬 artifacts에만 보관한다. 배포본에는 식별자가 없는 검증 요약을 포함한다.

중단 재실행은 중간 상태를 구성한 시험이다. 실제 전원 차단이나 모든 강제 종료 시점의 자동 롤백을 검증한 것은 아니다. 백업은 메모리에 있으므로 강제 종료 후에는 새 Install.cmd를 다시 실행하거나 제품을 제거해야 한다. 외부 동시 변경으로 복원이 일부 제한되면 경고를 확인해야 한다.

잠긴 데스크톱에서 확인창을 직접 클릭하거나 새 화면·실제 우클릭·Esc 입력을 검증하지 않았다. 테스트는 승인된 제품 확인 생략 인자를 사용했고 설치기 기본 확인창은 유지된다. 다른 Office 버전·x86·조직 정책·전자 서명·수동 등록한 v0.1 및 PERSONAL.XLSB 코드의 제거는 이번 평가에 포함하지 않는다.

배포 검사기는 XLAM·설치기 해시, 5개 VBA 소스, 업그레이드 검증과 창 상태 검증의 일치를 확인한다. ZIP의 `Validation.json`, `BUILD_INFO.json`, `SHA256SUMS.txt`에서 최종 파일과 검증 범위를 확인할 수 있다.
