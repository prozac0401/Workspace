# ADR-0021 · R13 집중 문구 평가 후보

상태: 채택 · 집중 소스 확인 완료, R13 제작·실제 시험·출하 보류

날짜: 2026-10-03 · 적용: 0.2.0-rc.13 한정

결정 담당: 도구 개발·검증 담당

관련 요구사항·정책: [R13 명세](../../../docs/tools/excel-list-compare/r13-specification.md)의 R13-01~03, [추가 도구 개발 기준](../../../docs/policies/tools.md), [정책 문서 작성 규칙](../../../docs/policies/documentation.md). 사용자가 이미 선택한 작은 개선의 필요한 검증·버전·패키지·PR·병합·릴리스 준비를 승인한 범위에 근거한다.

대체·대체됨 관계: [ADR-0020](ADR-0020-R12-wording-release.md)의 R12 한정 제작·시험 생략 결정은 그대로 보존한다. 이 결정은 RC13에 대한 별도 기준이며 R11·R12의 실제 결과와 기존 전체 인수 미완료 판정을 대체하지 않는다.

## 맥락

첫 목록 확인 요약의 ‘수정한 범위를 다시 담으세요’는 실제 사용해야 할 기존 명령을 충분히 구체적으로 안내하지 못했다. 선택된 수정은 ‘수정한 범위를 선택해 [첫 번째 목록 바꾸기]를 누르세요’ 한 줄이다. PR #10의 과거 집중 소스 검사 13 PASS는 새 XLAM·설치 파일의 검증이 아니다.

기존 R12 제작·게시에서는 사용자의 당시 요청에 따른 시험 생략 예외를 적용했다. 이번 요청에는 필요한 확인과 새 버전 제작·출시 준비가 포함되므로 R12 전용 `package_r12.py`와 `wording-only-no-tests` 결정을 RC13에 복제하지 않는다.

## 결정

R13은 `focused-wording-evaluation` 프로필의 별도 평가 후보다. `fullAcceptancePassed=false`를 유지하며 안정판·회사 배포 승인·전체 인수 완료로 표시하지 않는다. 새 후보를 준비하되 실제 필수 확인이 끝나기 전에는 출하 완료로 기록하지 않는다.

제품 변경은 요약 안내 한 줄, `SLC_ReleaseVersion`의 UTF-8/ASCII 쌍과 `Setup.ps1`의 설치 버전 문자열에 한정한다. 기존 메뉴·Replace 호출·처리·설정·취소·복구·설치 엔진을 변경하지 않는다. 제작 실행기는 허용 버전 목록에 RC13만 추가하며 소유권·정책·해시·기존 설치 보존·종료·복구 방어는 유지한다.

RC13 전용 제작 기록과 packager는 새 소스·실제 후보 XLAM·관련 증거의 해시를 묶는다. 같은 후보 SHA의 성공한 BuildOnly 기록, 저장한 XLAM의 VBA/RibbonX 소스 audit, 현재 집중 검사, 새 안내·Replace native 흐름, T11 설치·비교·결과·제거의 실제 증거를 모두 요구한다. R12 BuildOnly의 빈 시험 목록을 RC13 시험 통과로 사용하지 않는다. 각 검사 결과와 미완료 항목을 별도로 기록하고, 파일이 바뀌면 이전 후보의 결과를 승계하지 않는다. 기존 R12 공개 파일과 해시는 유지한다.

## 검토한 대안

- R12 자산 교체: 이미 게시된 파일과 고정 해시를 바꾸므로 사용하지 않는다.
- R12 시험 생략 예외 재사용: 해당 버전 한정 결정과 이번 필요한 검증 요청에 맞지 않아 사용하지 않는다.
- 전체 GUI·공존·성능·설치 suite 반복: 선택된 한 줄과 무관한 이미 완료한 수동 시험을 다시 수행하지 않는다. 변경 흐름·새 후보 제작과 T11에 필요한 최소 확인을 기록한다.

## 영향과 이행

새 명령이나 사용자 데이터 형식을 추가하지 않는다. 기존 제품의 일반 사용자·현재 계정·HKCU 설치·설정 보존 계약을 유지한다. 임시 VBA 프로젝트 접근은 별도 승인 또는 기존 허용 상태를 확인하고 제작 후 정확한 이전 상태로 복구한다. 조직 정책, 매크로 보안, 신뢰 저장소를 임의 변경하지 않는다.

사용 안내는 RC13 준비 상태와 기존 R12 공개 상태를 구분한다. RC13 실제 자산 게시 전에는 공개 다운로드를 새 버전으로 바꾸지 않는다. 설치·검증 로그, 사용자 경로와 업무 자료는 로컬에 두고 공개 패키지에는 검토한 요약만 넣는다. 원래 R11/R12 명세·ADR·시험 기록은 수정하지 않는다.

## 실패와 복구

소스·후보·해시 불일치, 소유 Excel 정상 종료 실패, 임시 설정 원복 실패 또는 기존 설치·파일 보존 실패 시 패키지·출하 단계를 중단한다. 알 수 없는 통합문서는 닫거나 저장하지 않고 사용자 Excel을 일괄 종료하지 않는다.

설치 확인은 기존 R12·설정·등록을 보존할 수 있는 시험 환경을 확보한 경우에만 실행한다. 확보하지 못하거나 새 안내의 실제 확인이 남으면 NOT_RUN·환경 제약을 기록하고 RC13의 출하 판단을 다시 한다. 소스·평가 후보 초안 준비는 가능하지만 이를 출시 검증 완료로 표시하지 않는다.

## 검증

1. 현재 소스의 집중 문구·명령 연결·요약 14항목 검사와 ASCII/UTF-8 일치를 확인한다. 과거 13 PASS와 새 결과를 구분한다.
2. 실제 BuildOnly 제작 기록과 저장한 새 XLAM의 VBA 7개 모듈·RibbonX·버전이 동결한 소스와 일치하는 audit를 묶는다. 동일 후보의 실제 기능 흐름·정상 종료·설정 원복·기존 설치 보존을 별도로 확인한다. BuildOnly 자체는 실제 기능 시험 PASS가 아니다.
3. 작은 합성 첫 목록 담기 → 원본 한 값 수정 → 첫 목록 확인의 새 요약 읽기 → 수정 범위 선택 → 기존 Replace → 새 확인 자료의 변경값 반영 한 흐름을 확인한다. 기존 확인 파일·원본은 자동 수정하지 않는다.
4. T11의 다음 제품 후보 조건인 설치·대표 비교·결과·제거를 보존 가능한 환경에서 확인한다. 이번 결과를 전체 설치 순열·취소·GUI·성능 시험으로 확대하지 않는다.
5. 후보·EXE·ZIP·안내·버전·SHA-256·소스와 증거의 연결, 문서 strict 빌드·생성 링크·공개 범위를 확인한다.

기존 부분 검사 82 PASS / 오래된 `제외·발생위치` 기대값 1 FAIL / 스냅샷에 없던 `modSLCMain.bas`·`Setup.ps1` 2 ERROR는 별도 보존한다. 현재 저장소에 두 파일이 있는 것과 과거 부분 스냅샷의 오류를 구분한다. R11의 취소 완료 안내·상태표시줄 자료형 복원 FAIL과 전체 인수 미완료, R12 제작 당시 시험 생략 및 2026-09-27 대표 공존 PASS도 유지한다.

## 현재 확인과 보류

현재 집중 소스 검사는 13 PASS / 0 FAIL / 0 ERROR / 0 SKIP이다. 오래된 시트명 기대값의 `UsabilitySourceContracts.test_difference_is_one_sheet_and_preview_has_locations`는 검사명으로 명시해 선정 목록에서 제외했고, 해당 기존 FAIL을 PASS로 바꾸지 않았다. 전체 suite 통과가 아니다. ASCII/UTF-8 5쌍과 Setup·격리 실행기의 PowerShell AST 두 건은 PASS다. RC12 태그 커밋 `c1e365d2155a594d4b864609da7656796bd1a345`와 실제 source scope_guard 대조에서도 선택 안내 한 줄·릴리스/설치 버전만 변경되고 나머지 엔진·설치 입력이 불변임을 확인했다. RC13 packager의 Python AST 및 다른 SHA·NOT_RUN·중복 JSON 필드·선택하지 않은 엔진 변경을 거절하는 합성 방어 4건도 PASS다. 합성 자료의 거절은 실제 후보 제작·출하 게이트 통과가 아니다.

임시 VBA 프로젝트 접근에 대한 별도 승인 답변이 없어 설정 변경은 0회다. HKCU/HKLM의 32/64비트 일반·정책 경로 8곳은 읽기 전용 확인에서 AccessVBOM 값이 없었다. 기존 R12 설치·등록을 보존해야 하며 후보 설치·제거를 위한 시험 환경은 확보하지 못했다. 따라서 새 XLAM·EXE·ZIP, 실제 Excel·native·설치·패키징·병합·태그·Release는 NOT_RUN·보류로 남긴다. 소스 준비용 Draft PR만 다음 검토 범위이며 문서 strict·생성 링크 검증은 별도 실행 대기다.

실제 결과는 [R13 검증 기록](RC13_RELEASE_REPORT.md)과 [실행·출하 준비 기록](../../../docs/delivery/excel-smart-list-compare-rc13-20261003.md)을 따른다.
