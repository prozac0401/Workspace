# Excel 명단 비교 0.2.0 RC10

두 목록의 값과 개수를 비교하고, 결과를 새 Excel 파일로 확인합니다. 원본과 이전 결과 파일은 그대로 유지합니다.

## 설치하기

64비트 Windows와 PC에 설치된 데스크톱 Excel이 필요합니다. Mac과 브라우저용 Excel은 지원하지 않습니다.

1. 작업 중인 파일을 저장하고 Excel 창을 모두 닫습니다.
2. **ExcelSmartListCompare-0.2.0-rc.10-Setup.exe**를 실행하고 **설치**를 누릅니다.
3. Excel을 열어 **추가 기능** 탭의 명단 비교 버튼을 확인합니다. 셀을 마우스 오른쪽 버튼으로 눌러도 사용할 수 있습니다.

ZIP은 모두 푼 뒤 `Release` 폴더의 **Install.cmd**를 실행합니다. 현재 Windows 계정에 설치하며 관리자 권한·Python·VBA 편집기는 필요하지 않습니다.

제품 폴더 한 곳을 Excel의 신뢰할 수 있는 위치에 등록합니다. 이곳에는 제품 파일만 보관하세요. 회사 정책으로 설치가 차단되면 승인된 설치 절차를 따르세요.

## 첫 목록 담고 확인하기

1. 일반 범위의 제목을 빼고 비교할 셀을 선택합니다.
2. **첫 번째 목록 담기**를 누릅니다.
3. **담은 목록 확인**을 눌러 파일·시트·범위·담은 시각·항목 수와 값 표본을 확인합니다.

원본을 고치거나 닫아도 담긴 값은 바뀌지 않습니다. 최신 원본을 사용하려면 셀을 다시 선택하고 **첫 번째 목록 바꾸기**를 누르세요. 확인용 파일을 닫아도 첫 목록은 유지됩니다.

## 두 번째 목록 비교하기

1. 같은 Excel에서 두 번째 목록을 선택합니다.
2. **두 번째 목록 담아 비교**를 누릅니다.
3. 새 결과 파일의 **요약**을 확인하고 필요한 위치에 저장합니다.

일치하는 경우에도 결과 파일을 만듭니다. 비교가 끝나도 첫 목록은 남으므로 다른 목록을 선택해 같은 기준과 다시 비교할 수 있습니다. **첫 번째 목록 비우기**는 기억한 값만 지우고 원본 셀은 지우지 않습니다.

| 결과 시트 | 확인할 내용 |
|---|---|
| 요약 | 일치·남은 값·중복·제외 개수와 목록의 출처·시각 |
| 차이·중복 | 값별로 각 목록에 나온 개수와 짝을 짓고 남은 개수 |
| 제외·발생위치 | 오류와 값이 나온 셀의 위치 표본 |
| 규칙으로 같아진 값 | 서로 다른 원래 값이 같은 비교값으로 모인 예 |

위치는 표본입니다. 목록 하나에서 발생 위치는 최대 1,200개, 원문 변형은 600개, 오류는 200개를 기록합니다. 발생 위치와 원문 변형은 같은 비교값당 최대 5개이며 생략 범위를 함께 표시합니다. 전체 값의 개수는 계속 집계합니다. 원문 차이 표는 원문의 예이며 원문별 출현 횟수를 비교한 표는 아닙니다.

결과와 확인용 파일에는 원래 값 표본이 들어갈 수 있으므로 저장·공유할 때 내용을 확인하세요. 명단은 외부 서비스로 보내지 않습니다.

## 비교 규칙

- 순서를 무시하고 같은 값의 개수를 비교합니다. 첫 목록에 2개, 두 번째에 1개가 있으면 첫 목록에 1개가 남습니다.
- 숨긴 셀·필터로 가려진 셀·빈칸·오류·표의 제목과 합계는 비교에서 뺍니다. 일반 범위의 제목은 직접 빼고 선택하세요.
- 메일 주소는 `@` 앞부분만 비교합니다. `user@a.com`과 `user@b.com`이 같다고 나올 수 있습니다.
- 영문 대소문자와 일부 공백·숫자 표기 차이를 정리합니다. 문자로 입력한 `00123`과 숫자 `123`은 다르게 봅니다.
- 병합 셀은 비교할 수 없습니다. 수동 계산 중이면 먼저 수식을 계산하세요.
- Excel을 종료하면 담긴 목록이 사라집니다. 별도 Excel 프로세스끼리는 목록을 공유하지 않습니다.

오류 셀을 제외한 결과가 같아도 원본 전체가 완전히 같다는 뜻은 아닙니다. VBA 실행 후 Excel의 기본 실행 취소 기록은 유지되지 않을 수 있습니다.

## 큰 목록과 작업 중단

한 목록의 입력 상한은 숨기지 않은 선택 셀 **100,000개**, 셀 하나 **4,096자**, 원문 합계 **5,000,000자**입니다. 선택 셀 수에는 빈칸도 포함됩니다. 값의 길이·서로 다른 값의 수·PC 부하에 따라 시간 제한으로 중단될 수 있습니다.

처리 중 **작업 취소**를 누르면 취소를 요청합니다. Excel 내부 처리 중에는 요청 확인이 늦어질 수 있으므로 종료 안내와 남아 있는 첫 목록의 출처·개수를 확인하세요. 큰 선택 경고에서 **아니요**를 누르면 작업을 시작하지 않습니다.

두 목록을 같은 행 수로 잘라 비교하면 다른 구간으로 이동한 같은 값이 차이로 나올 수 있습니다. 나누려면 비교 규칙을 적용한 같은 값의 모든 항목이 양쪽에서 같은 묶음에 포함되어야 합니다.

## 다시 설치하거나 제거하기

파일을 저장하고 Excel을 닫은 뒤 EXE 또는 **Install.cmd**로 같은 버전을 다시 설치하거나 이전 버전을 바꿀 수 있습니다.

EXE 설치는 **Windows 설정 → 앱 → 설치된 앱 → Excel 명단 비교 → 제거**에서 제거합니다. ZIP 설치는 **Uninstall.cmd**를 실행합니다. 업무 파일·다른 추가 기능·설치 폴더에 따로 넣은 파일은 유지합니다.

오류가 나면 표시된 내용을 보관하고 문의하세요. 설치 기록에는 사용자 경로가 들어갈 수 있으므로 그대로 공개하지 마세요.
