# Excel 명단 비교 R12 · 배포 기록

버전: 0.2.0-rc.12 · 날짜: 2026-09-21

상태: 문구·표 표시 교정 완료, 설치본 제작·게시 준비 중

## 변경 내용

- 차이 결과의 ‘남은 수’를 ‘더 많은 개수’, ‘대표 주소’를 ‘원본 셀 (예)’로 고쳤다.
- 결과표는 주요 6열을 먼저 표시하고 추가 개수·원본 셀을 담은 G:J열은 숨겼다. 데이터 열 순서, 제목 8행·데이터 9행은 유지한다.
- 담은 목록 요약을 2열·14항목으로 줄이고, 비교 전인 두 번째 목록 칸과 내부 처리 지표·반복 설명을 정리했다.
- ‘제외·발생위치’를 ‘값과 위치’로 바꾸고, 일부만 표시한다는 설명과 표시하지 않은 개수를 명확히 했다.
- 비교·수집·정규화·설정·취소·복구 로직은 변경하지 않았다. 설치 엔진은 버전만 올렸다.

## 이번에 실행하지 않은 항목

사용자의 명시적 요청에 따라 Python 회귀, Excel 기능·UI·성능·취소, 설치·업데이트·제거 테스트는 **NOT_RUN**이다. R11의 결과를 R12의 PASS로 사용하지 않는다. 새 문구에 맞춰 기존 내장 확인문의 기대 문자열만 바꿨으며 실행하지 않았다.

## 제작과 게시 확인

실제 XLAM 제작·소스 대조, EXE·ZIP 생성, 파일 해시, 문서 strict 빌드·링크와 게시 후 다운로드 결과는 완료 시 기록한다. 제작 성공은 기능 테스트 통과를 의미하지 않는다.

이번 배포는 [ADR-0020](ADR-0020-R12-wording-release.md)의 R12 한정 예외이며 `fullAcceptancePassed=false`다. 설치 파일은 코드 서명이 없으며 상용 인수 승인으로 표시하지 않는다. 사용자 계정 경로·원시 로그·업무 자료는 공개 산출물에서 제외한다.
