# Excel 명단 비교 · RC10 로컬 개발 버전 사용 안내

버전: **0.2.0-rc.10 로컬 개발 버전** · 날짜: 2026-09-20 · 상태: 기본 실제 UI·기존 RC9 파일 5개 물리 복원 확인, 실제 취소 인수 미충족·상태표시줄 복원 실패·후속 설치 전체 검증 미완료

이 문서는 RC10 개발 단계의 확인 절차를 보존합니다. 게시용 설치·사용 안내는 [RC10 사용자 안내](RC10_USER_GUIDE.md), 확인 범위는 [RC10 구현·검증 기록](USABILITY_RC10_REPORT.md)을 따릅니다. 이전 RC9에는 아래의 새 기능이 포함되지 않습니다.

## 첫 목록 담고 확인하기

1. 일반 범위의 제목을 빼고 비교할 셀을 선택합니다.
2. **첫 번째 목록 담기**를 누릅니다.
3. **담은 목록 확인**을 눌러 확인용 파일에서 파일·시트·범위·담은 시각·항목 수와 값 표본을 확인합니다.

확인은 담아 둔 값으로 만듭니다. 원본을 고치거나 닫아도 담긴 값은 바뀌지 않습니다. 최신 원본을 사용하려면 셀을 다시 선택하고 **첫 번째 목록 바꾸기**를 누르세요. 확인용 파일을 닫아도 첫 목록은 유지됩니다.

항목 수는 빈칸 등 제외한 셀을 뺀 값의 수입니다. 다른 셀에 같은 값이 있으면 각각 셉니다. 숨긴 셀·필터로 제외된 셀·빈칸·오류·표의 제목과 합계는 비교에서 빠집니다. 확인용 파일의 제외 집계와 규칙을 함께 읽으세요.

## 여러 목록을 같은 첫 목록과 비교하기

1. 두 번째 목록을 선택하고 **두 번째 목록 담아 비교**를 누릅니다.
2. 새 결과 파일의 **요약**을 확인합니다. 일치하는 경우에도 결과 파일을 만듭니다.
3. 또 다른 목록을 비교하려면 그 셀을 선택하고 **두 번째 목록 담아 비교**를 다시 누릅니다.

비교가 끝나도 첫 목록이 남습니다. 기준을 바꾸려면 **첫 번째 목록 바꾸기**, 새 작업을 시작하려면 **첫 번째 목록 비우기**를 누르세요. 비우기는 기억한 값만 지우며 원본 셀을 지우지 않습니다. Excel을 종료하면 기억한 목록은 사라지고 별도 Excel 프로세스끼리는 공유하지 않습니다.

## 결과에서 근거 확인하기

| 시트 | 확인할 내용 |
|---|---|
| 요약 | 같은 값과 남은 값의 개수, 중복·제외 개수, 비교한 목록의 출처·시각과 규칙 |
| 차이·중복 | 비교에 쓴 값별로 각 목록의 개수와 짝을 짓고 남은 개수 |
| 제외·발생위치 | 오류와 값이 나온 셀의 위치 표본, 표본에서 생략한 수 |
| 규칙으로 같아진 값 | 서로 다른 원래 값이 같은 비교값으로 모인 예 |

순서는 무시하고 같은 값의 개수를 비교합니다. 메일 주소는 @ 앞부분을 비교하므로 user@a.com과 user@b.com도 같게 볼 수 있습니다. 공백·대소문자·일부 숫자 표기를 정리한 뒤의 일치가 원래 셀의 문자까지 같다는 뜻은 아닙니다. 오류를 제외하고 같다고 나온 경우 원본 전체가 완전히 같다고 판단하지 마세요.

위치는 표본입니다. 목록 하나에서 발생 위치는 최대 1,200개, 원문 변형은 600개, 오류는 200개를 기록합니다. 발생 위치와 원문 변형은 같은 비교값당 최대 5개입니다. 표본을 다 기록하지 못해도 전체 개수는 집계하고 생략 범위를 표시합니다. 원문 변형에서 기록하지 못한 후보 수는 서로 다른 원문 종류 수가 아닙니다.

중복이 나온 셀 가운데 어느 셀을 수정할지는 업무 기준으로 판단하세요. 위치 표본은 특정 셀이 잘못됐다는 표시가 아닙니다. 결과와 확인용 파일에는 원래 값 표본이 들어갈 수 있으므로 저장·공유할 때 내용을 확인하세요. 원본과 이전 결과는 바꾸지 않으며 새 파일은 필요한 위치에 직접 저장합니다.

## 처리와 취소 확인하기

작업 상태는 **읽는 중 / 비교 중 / 결과 작성 중 / 취소 요청됨**으로 표시합니다. **작업 취소**를 누르면 취소를 요청합니다. 버튼이나 키를 눌렀다는 사실만으로 중단됐다고 판단하지 말고 종료 안내와 남아 있는 첫 목록의 출처·개수를 확인하세요. Excel 내부 처리 때문에 요청을 바로 확인하지 못하는 구간이 있을 수 있습니다.

확정 전 취소·실패에서는 이전 첫 목록을 유지합니다. 미완성 결과를 정리하고 최종 상태를 안내합니다. 이미 확정된 결과를 취소된 것으로 표시하지 않습니다. 실제 Esc 입력·응답 시간·단계별 취소·설정 복원의 확인 여부는 [이번 검증 기록](USABILITY_RC10_REPORT.md)을 따릅니다.

이번 실제 화면 시험에서는 처리 중 Esc와 **작업 취소** 클릭을 시도했지만 시간 제한 오류로 끝났습니다. 정상적인 취소 완료는 확인하지 못했습니다. 또한 후속 시험에서 첫 목록을 담은 뒤 상태표시줄의 기본값이 문자열 FALSE로 바뀌는 실패를 확인했습니다. 담은 목록 확인 뒤에도 FALSE 표시를 관찰했으며 원인과 해결은 아직 확정하지 않았습니다. 두 항목은 해결·인수 완료로 안내하지 않습니다.

## 큰 목록을 다룰 때

기존 입력 상한은 목록당 숨기지 않은 선택 셀 100,000개, 셀 하나 4,096자, 원문 합계 5,000,000자입니다. 상한까지 정상 완료된다는 보장이 아니며 값 길이·서로 다른 값의 수·PC 부하에 따라 시간 제한으로 중단될 수 있습니다. RC9의 측정 결과를 이 시험판의 처리량으로 사용하지 않습니다.

50,000개 × 96자 입력에서는 큰 목록 경고의 기본 선택이 **아니요**이고, 거절하면 이전 첫 목록 3개가 유지되는 것을 실제 화면에서 확인했습니다. 이는 큰 목록의 정상 처리 완료를 확인한 결과가 아닙니다.

두 목록을 행 번호로 같은 크기씩 잘라 비교하지 마세요. 같은 값이 다른 구간으로 이동했으면 각 조각은 다르다고 나옵니다. 나누려면 비교 규칙을 적용한 같은 값의 모든 항목이 양쪽에서 같은 묶음에 들어가야 합니다. 이 조건으로 나눌 수 없다면 전체 목록을 처리할 수 있는 다른 도구를 사용하세요.

## 로컬 개발 버전 설치와 검증 범위

설치 전 작업 파일을 저장하고 Excel을 모두 닫으세요. 설치기는 열린 Excel을 자동 종료하지 않고 중단합니다. 일반 설치에는 VBA 프로젝트 접근 설정을 켤 필요가 없습니다. 이번 PC에서는 단일 EXE와 CMD 실행기의 PowerShell 준비 단계가 접근 거부로 실패했습니다. 원인은 미확정이며 해당 경로가 설치 검증을 통과했다고 안내하지 않습니다. 고정한 Release/Setup.ps1의 직접 설치는 성공했지만 설치 전체 흐름을 완료한 것은 아닙니다. 실제 결과는 [전체 흐름 검증 기록](RC10_END_TO_END_REPORT.md)을 따릅니다.

이 파일은 서명 없는 로컬 개발 버전입니다. 실제 64비트 Excel 화면에서 첫 목록 담기, 3개 시트의 확인용 파일, 4개 시트의 일치·차이 결과, 첫 목록 재사용·바꾸기·비우기와 이전 결과 보존을 확인했습니다. 해당 화면 시험의 소유 Excel 정상 종료와 XLAM 해시 보존도 확인했습니다. 합성 오류 복구는 별도 시험 결과이며 실제 취소 입력의 인수 성공을 뜻하지 않습니다.

후속 시험에서 자동화 환경의 RC9 파일·등록 비교는 일치했지만, 실제 경로가 앱 캐시로 확인돼 원래 설치 위치 복원 완료 판정은 철회했습니다. 당시 제품 추가 기능·도구 모음 부재 검사는 통과했으나 빈 시험 소유 Excel의 정상 종료 실패는 유지합니다. 후속 재시작·재설치·제거 일부 단계의 성공과 새 설치·화면 배율별 인수 미완료를 구분하며, 공개 다운로드는 RC9을 유지합니다.

2026-09-20 사용자가 보안 알림에서 매크로 포함을 직접 선택한 뒤 상태표시줄 진단을 재개했습니다. 초기화 명령 직후 값의 형식이 바뀌는 추적 결과를 얻었으며, 별도 빈 Excel 대조에서도 같은 현상이 나타났습니다. 진단·대조용 Excel은 정상 종료했고 진단 파일과 검사한 보안 설정은 보존했습니다. 원인과 해결은 아직 미확정이며 제품 VBA 소스나 원래 패키지 바이트에 추가 변경을 적용하지 않았습니다.

후속 설치기 소스에서는 문자 표시 준비에 쓰는 `chcp.com`의 시스템 경로를 명시했습니다. 명령 검색 실패를 줄이는 변경이며, 준비용 PowerShell의 접근 거부나 상태표시줄·취소 문제를 해결했다는 뜻은 아닙니다. 이 수정으로 다시 만든 패키지도 로컬 시험 후보입니다.

패키지의 검증 JSON과 SHA-256 목록에서 실제 파일을 확인할 수 있습니다. 최신 문서와 시험 소스를 담은 별도 보충 검증 ZIP을 제공할 예정입니다. 보충 자료나 로컬 개발 버전 생성은 회사 도입 승인이나 전체 인수 완료를 뜻하지 않습니다.

후속 설치 전용 시험에서는 재시작·재설치·제거·재제거를 확인했으나 새 설치가 실제 저장 경로 불일치로 중단됐습니다. 자동화 환경에서 복원한 RC9 파일은 앱 전용 캐시에 있었습니다. 일반 Windows 진단으로 파일 부재와 원래 등록 보존을 확인한 뒤, 2026-09-20 별도 복원 창에서 원래 설치 폴더의 RC9 파일 5개를 복원했습니다. 파일별 실제 경로·해시·수정 시각·속성과 등록 보존을 확인했습니다. 복원 후 일반 Excel 시작 및 RC10 추가 설치 시험은 아직 실행하지 않았습니다. 최신 판정은 [전체 흐름 검증 기록](RC10_END_TO_END_REPORT.md)을 확인하세요.

원문 차이 표는 저장된 원문의 예를 보여줍니다. 원문별 출현 횟수를 비교한 표는 아닙니다.
