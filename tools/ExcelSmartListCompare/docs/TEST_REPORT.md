## 실제로 실행한 검증

Linux/Python 환경에서 `python -m unittest discover -s tests -p 'test_*.py' -v` 실행: **53개 통과**.

구성: 정규화 참조 로직 24개, 범위/가시성/개수 참조 로직 13개, 경계값 참조 로직 10개, 소스 정적 안전장치 점검 6개.

정적 점검은 ASCII 가져오기 파일 동기화, VBA 프로시저 이름/끝 짝, 전역 단축키·Find·클립보드·계산 모드 변경 코드 부재, 설치 스크립트의 보안 우회/프로세스 강제 종료/재귀 삭제 코드 부재, 값 읽기 전 경고 배치, 기준 스냅샷의 Range 참조 미보유를 검사합니다.

## 실행하지 못한 검증

Windows Excel이 없는 작성 환경이므로 **VBA 컴파일/런타임 테스트, PowerShell 설치·삭제 실행, Excel 버전별 UI, 실제 성능과 취소 응답시간을 검증하지 못했습니다.** Python 참조 구현의 성공은 VBA 코드가 Excel에서 같은 결과를 낸다는 증명이 아닙니다. 정적 검사는 VBA/PowerShell 문법 검사기를 대신하지 않습니다.

`SLC_TestAll`에는 정규화 검사 14개와 실제 Excel 범위·필터·숨김·파일 종료 스냅샷·상한 검사 19개를 넣었습니다. Windows 빌더는 이를 실행해 성공한 경우만 배포 파일을 만듭니다. 작성 환경에서는 실행하지 않았습니다.

특히 인수 테스트에서 남은 중요한 항목은 설치/재설치/삭제/재실행 후 자동 로드, 보안 정책 차단 시 정지, 32/64비트 Excel, 다른 추가 기능과 병행, 대량 필터 영역, 경고 취소/실행 취소의 상태 복원, 출력의 수식 실행 방지와 이전 결과 보존입니다.

## 전달물의 정확한 범위

수정 소스 + 자동 빌더 + 설치/삭제 스크립트 + 테스트/문서 패키지입니다. 미리 생성된 `.xlam`, 서명된 바이너리, Windows Excel 검증 완료 로그는 포함하지 않습니다.
