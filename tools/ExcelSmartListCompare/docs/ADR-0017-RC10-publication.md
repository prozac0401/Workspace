# ADR-0017 · RC10 게시와 검증 자료 분리

상태: 채택 · 날짜: 2026-09-20 · 범위: 0.2.0-rc.10 게시

## 배경과 결정

사용자가 “현재상태로 rc10 릴리즈 부탁합니다”라고 요청했다. 이어 설치 패키지에 실패 내역과 “시험판” 문구를 넣지 않도록 명시했다. 현재 RC10을 제품명과 버전으로 게시하고 설치·사용 안내와 검증 자료를 분리한다.

배포 결정은 `PUBLISH_WITH_RECORDED_RESULTS`, 포장 프로필은 `documented-exceptions`다. 전체 인수는 `NOT_MET`, `fullAcceptancePassed=false`를 유지한다. 게시 허용은 전체 인수나 회사 도입 승인을 뜻하지 않는다. RC9에 대한 과거 예외를 RC10 승인으로 재사용하지 않는다.

## 파일과 검증 경계

- XLAM은 실제 합성 기능·기본 UI 검증에 사용한 SHA-256 `2386375cbe0aec6e62fdfa2129cfbc18d358451666504be8bab2fab3c33f719b`를 재사용한다. 진단 코드가 든 별도 XLAM은 배포하지 않는다.
- 현재 VBA 소스·직렬화 소스·정확한 파일의 실제 내장 시험을 대조한다. 소스와 다른 파일이나 진단 파일의 결과는 근거로 사용하지 않는다.
- 최신 설치 안내를 반영해 ZIP과 EXE를 새로 만든다. 새 EXE 제작은 실제 설치 성공을 뜻하지 않는다. 일반 사용자의 보안 설정·설치 보호는 바꾸지 않는다.
- 설치 ZIP은 XLAM, Setup.ps1, Install.cmd, Uninstall.cmd, README.md, QuickGuide.html, SHA256SUMS.txt의 7개 파일로 구성한다. 사용자 안내는 [RC10 설치·사용 안내](RC10_USER_GUIDE.md)를 사용한다.
- 실패·부분 확인·미실행 결과는 별도 Verification.zip과 저장소 검증 기록에 보존한다. 계정 경로·원시 레지스트리·사용자 로그·로컬 진단은 게시하지 않는다.

RC10의 예외 경로도 직렬화 소스 대조·정확한 파일의 내장 기능 시험·Python 회귀·문서 검증 PASS를 요구한다. 선택 조합 전체, 네이티브 컨텍스트 전체, 실제 취소, 상태표시줄, 설치 수명주기 등 나머지 14개 판정 항목은 실제 결과를 유지하고 미충족 항목 집합을 정확하게 명시해야 한다. 기본 full 프로필과 RC9 요구는 유지한다.

## 현재 결과와 후속 조건

기본 비교·결과·첫 목록 관리 UI와 큰 선택 거절은 확인했다. 상태표시줄 복원은 FAIL, 실제 취소는 NOT_MET이며 새 EXE 실기·전체 설치 인수는 미완료다. RC9 원래 파일 5개의 물리 복원과 기존 등록 보존은 완료했다. 이번 게시에서 Excel 실행이나 새 설치를 다시 시작하지 않는다.

[전체 흐름 검증](RC10_END_TO_END_REPORT.md)과 [사용성 검증](USABILITY_RC10_REPORT.md), 공개용 `evidence/rc10/validation.json`에 결과를 보존한다. 게시 후 업로드한 자산을 다시 다운로드해 해시를 대조한다. 검증 미완료 항목은 같은 최종 파일의 실제 재검증으로만 변경한다.
