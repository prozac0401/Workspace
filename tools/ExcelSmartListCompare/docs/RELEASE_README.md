# Excel 명단 비교 · 설치와 사용

Windows 데스크톱 Excel에서 두 목록의 값과 개수를 비교하는 추가 기능입니다.

**이 문서는 RC9 검증 후보의 안내입니다. 최종 인수와 출시는 아직 미확정입니다.** candidate-07에서 용량 14조건·선택 14조건·실제 메뉴 5동작·보호 안내 7조건을 확인했고, 고유값 각 50,000·100,000개는 시간 제한으로 중단됐습니다. 현재 결과와 남은 기능·취소·최종 설치 인수는 소스의 `docs/RC9_APPROVED_RETEST_20260917.md`를 따릅니다. 이전 RC8의 실패 기록은 해당 파일의 결과로 보존합니다.

## 설치하기

1. 작업 중인 파일을 저장하고 Excel 창을 모두 닫습니다.
2. EXE를 받았다면 실행하고 **설치**를 누릅니다. ZIP을 받았다면 압축을 모두 푼 뒤 `Release` 폴더의 **Install.cmd**를 더블클릭합니다.
3. 설치가 끝나면 Excel을 엽니다.
4. **추가 기능** 탭에서 명단 비교 버튼을 확인합니다.

이전 버전이 있어도 새 설치 파일을 실행하면 됩니다. 이 설치기로 설치한 이전 버전은 새 버전으로 바꾸고, 같은 버전은 다시 설치합니다. 더 최신 버전이 있거나 설치 기록을 확인할 수 없으면 기존 내용을 남기고 중단합니다. 직접 등록한 v0.1 추가 기능이나 `PERSONAL.XLSB`에 넣은 코드는 자동으로 지우지 않습니다.

지금 로그인한 Windows 계정에 설치합니다. 관리자 권한, Python, VBA 편집기는 일반 설치에 필요하지 않습니다. 설치와 제거에는 Windows PowerShell을 사용합니다.

설치 위치는 `%LOCALAPPDATA%\ExcelSmartListCompare`입니다. 이 경로를 탐색기 주소창에 붙여 넣어 확인할 수 있습니다.

## 비교하기

1. 첫 번째 목록의 셀을 선택하고 **첫 번째 목록 담기**를 누릅니다.
2. 두 번째 목록의 셀을 선택하고 **두 번째 목록 담아 비교**를 누릅니다.
3. 결과 파일이 열리면 확인한 뒤 필요한 위치에 저장합니다.

셀을 오른쪽 클릭하고 **명단 비교** 메뉴에서도 실행할 수 있습니다. 가로·세로·사각형이나 여러 곳을 선택해도 전체를 목록 하나로 읽습니다. 일반 범위의 제목은 빼고 선택하세요.

**목록**은 선택한 셀 전체, **항목**은 그 안의 값 하나입니다. `첫 번째 목록: 42개 항목`은 빈칸 등 비교에서 제외할 셀을 빼고 값 42개를 담았다는 뜻입니다. 같은 값이 여러 셀에 있으면 각각 셉니다.

**첫 번째 목록 비우기**는 기억해 둔 목록만 비웁니다. 원본 셀은 지우지 않습니다. **첫 번째 목록 바꾸기**는 현재 선택한 셀로 다시 담습니다. 비교가 끝나면 첫 번째 목록 담기로 돌아갑니다.

## 결과 확인하기

순서는 비교하지 않으며, 같은 값의 개수까지 비교합니다. 차이·중복·오류가 있으면 새 결과 파일을 엽니다. 모두 같고 중복·오류도 없으면 같다는 안내만 나옵니다.

- **비교에 쓴 값:** 공백 등 비교 규칙을 적용한 값입니다.
- **원래 값 (예) / 셀 주소:** 해당 값이 처음 나온 셀의 값과 위치입니다.
- **남은 개수:** 같은 값을 하나씩 짝지은 뒤 남는 수입니다. 첫 번째 목록에 2개, 두 번째에 1개라면 첫 번째에 1개가 남습니다.

원본 값·수식·서식·필터와 이전 결과 파일은 바꾸지 않습니다. 결과는 직접 저장해야 합니다. 명단을 외부 서비스로 보내지 않습니다.

## 사용할 때 알아둘 점

- 필터에서 제외되거나 숨긴 셀은 읽지 않습니다. 지금 화면에 보이는 위치만 읽는다는 뜻은 아닙니다.
- 메일 주소는 `@` 앞부분만 비교합니다. 뒷부분이 달라도 같다고 나올 수 있습니다.
- 텍스트의 앞자리 0은 보존합니다. 셀 서식으로만 붙인 0은 비교값에 포함하지 않습니다.
- 첫 번째 목록을 담은 뒤 원본을 고쳐도 이미 담은 값은 바뀌지 않습니다.
- 같은 Excel에서 연 파일끼리 비교할 수 있습니다. 별도로 실행한 Excel끼리는 목록을 공유하지 않습니다. Excel을 완전히 종료하면 담긴 목록은 사라집니다.
- **RC8에서는 Esc를 눌러도 취소되지 않은 사례가 있습니다.** 처리 중에는 원본을 편집하지 말고 기다리세요. 큰 목록은 나누어 비교하세요.
- 한 목록은 숨기지 않은 선택 셀 100,000개까지 읽습니다. 항상 그 크기까지 비교를 마친다는 보장은 없습니다. 오래 걸리면 중간 점검에서 작업을 중단합니다.
- VBA 실행 후 Excel의 기본 **실행 취소** 기록은 유지되지 않을 수 있습니다.

## 다시 설치하거나 제거하기

업데이트하거나 다시 설치하려면 Excel을 모두 닫고 새 EXE 또는 **Install.cmd**를 실행합니다. 되돌릴 수 있는 설치 오류가 나면 이전 파일과 등록을 복원합니다. 다른 프로그램이나 사용자가 동시에 바꾼 내용은 남기고 알려 줍니다.

제거하려면 Excel을 모두 닫은 뒤 **Windows 설정 → 앱 → 설치된 앱 → Excel 명단 비교 → 제거**를 선택합니다. ZIP으로 설치했다면 제공된 **Uninstall.cmd**를 실행합니다.

업무 파일, 다른 추가 기능, 설치 폴더에 따로 넣은 파일은 남깁니다. Uninstall.cmd로 먼저 제거하면 앱 목록에 이름이 남을 수 있습니다. 앱 목록에서 한 번 더 제거하면 설치 관리 항목도 정리됩니다. 제거에 쓰는 작은 임시 파일이 남을 수 있지만 업무 데이터는 들어 있지 않습니다.

## 설치 권한과 보안 설정

이 제품 폴더 한 곳만 Excel의 **신뢰할 수 있는 위치**로 등록합니다. 새로 등록할 때는 하위 폴더를 포함하지 않습니다. 이곳에 둔 매크로는 알림 없이 실행될 수 있으므로 제품 파일만 보관하세요. 기존 신뢰 위치와 회사 정책은 유지합니다. 회사 정책에서 등록을 막으면 설치하지 않습니다.

CMD 실행기는 회사 그룹 정책이나 `AllSigned`가 있으면 그대로 따릅니다. 그렇지 않으면 같은 폴더의 `Setup.ps1` 한 파일만 다운로드 차단을 해제하고, 해당 PowerShell 실행에만 `RemoteSigned`를 적용합니다. 영구 실행 정책은 바꾸지 않습니다. 파일 한 개의 다운로드 차단 해제는 유지됩니다.

설치 파일이 예상과 다른 위치에 저장되면 중단합니다. 이 경우 일반 Windows 탐색기에서 압축을 푼 **Install.cmd**를 실행하세요. 정책으로 차단되면 회사의 승인된 설치 절차를 따르세요.

서명 없는 시험용 버전입니다. 이전 시험의 통과 결과나 화면을 이번 교정 소스의 실행 결과로 보지 마세요. 실제 검증 보고서와 함께 설치 파일의 버전·해시를 확인해야 합니다.
