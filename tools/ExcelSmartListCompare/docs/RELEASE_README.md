# Excel 명단 비교 · 설치와 사용

Windows 데스크톱 Excel에서 두 목록의 값과 개수를 비교하는 추가 기능입니다. **0.2.0 RC9 제한 평가판 · LIMITED EVALUATION**입니다. EXE와 ZIP은 코드 서명이 없으며 전체 인수 기준을 통과하지 못했습니다.

사용자가 현재 상태의 배포를 요청해 확인한 범위와 남은 문제를 함께 제공합니다. 실제 공개 여부와 파일 해시는 배포 페이지를 확인하세요. 새 EXE의 실제 설치·업데이트·제거는 검증하지 않았습니다.

실제 확인한 환경은 **Windows 11, Excel 16.0.20326.20144 64비트**입니다. 32비트 Office와 회사의 매크로 API 차단 환경은 확인하지 못했습니다. Mac과 브라우저용 Excel은 지원하지 않습니다.

## 먼저 확인하세요

- **상태표시줄 복원 실패:** 일부 진단에서 Excel 상태표시줄의 원래 값과 형식이 복원되지 않았습니다. 모든 Excel 설정이 원래대로 돌아온다고 보장하지 않습니다.
- **취소는 부분 검증:** 첫 목록 바꾸기의 약 100ms 유지 입력만 대조 실험으로 상태 보존을 확인했습니다. 취소 안내는 관찰하지 못했고 다른 작업·입력 시간은 보장하지 않습니다.
- **현재 시험 환경의 설치 차단:** 복구 진단 중 Excel이 비정상 종료했고 창 없는 시험 프로세스가 남았습니다. 설치기는 이 상태에서 중단합니다. 창을 닫는 것만으로 현재 PC에서 설치할 수 있다고 안내하지 않습니다.
- 자동 로드·전체 창 전환·다른 Excel 프로세스와의 격리·새 EXE 설치 수명주기는 이번 파일에서 검증을 마치지 못했습니다.

업무에 바로 도입하기보다 별도의 자료 복사본으로 확인하세요. 막힌 설치를 반복하거나 보호를 끄고 실행하지 마세요.

## 설치하기

1. 작업 중인 파일을 저장하고 Excel 창을 모두 닫습니다.
2. EXE를 실행하고 **설치**를 누릅니다. ZIP을 받았다면 모두 푼 뒤 `Release` 폴더의 **Install.cmd**를 실행합니다.
3. Excel을 열어 **추가 기능** 탭의 명단 비교 버튼을 확인합니다.

현재 Windows 계정에 설치합니다. 일반 설치에 관리자 권한·Python·VBA 편집기는 필요하지 않습니다. 설치 위치는 `%LOCALAPPDATA%\ExcelSmartListCompare`입니다. 설치와 제거에는 Windows PowerShell을 사용합니다.

제품 폴더 한 곳을 Excel의 **신뢰할 수 있는 위치**로 등록합니다. 이곳의 매크로는 별도 알림 없이 실행될 수 있으므로 제품 파일만 보관하세요. 회사 정책은 바꾸지 않습니다. 정책으로 차단되면 회사의 승인된 설치 절차를 따르세요.

## 비교하기

1. 첫 번째 목록의 셀을 선택하고 **첫 번째 목록 담기**를 누릅니다.
2. 두 번째 목록을 선택하고 **두 번째 목록 담아 비교**를 누릅니다.
3. 새 결과 파일을 확인하고 필요한 위치에 직접 저장합니다.

셀을 오른쪽 클릭한 **명단 비교** 메뉴에서도 실행할 수 있습니다. 선택한 가로·세로·사각형·여러 영역 전체를 목록 하나로 읽습니다. 일반 범위의 제목은 빼고 선택하세요.

**첫 번째 목록: 42개 항목**은 빈칸 등 제외한 셀을 뺀 값의 수입니다. 같은 값이 여러 셀에 있으면 각각 셉니다. **첫 번째 목록 비우기**는 기억한 목록만 비우며, **첫 번째 목록 바꾸기**는 현재 선택으로 다시 담습니다. 원본 셀은 지우지 않습니다.

## 결과와 비교 규칙

순서는 무시하고 같은 값의 개수를 비교합니다. 차이·중복·오류가 있으면 새 결과 파일을 만들고, 모두 같고 중복·오류도 없으면 안내만 표시합니다. **남은 개수**는 같은 값을 하나씩 짝지은 뒤 남는 수입니다.

- 숨긴 셀·필터로 제외된 셀·빈칸·오류·표의 제목과 합계는 비교에서 뺍니다. 병합한 셀은 비교할 수 없습니다.
- 메일 주소는 `@` 앞부분만 비교합니다. 뒷부분이 달라도 같다고 나올 수 있습니다.
- 영문 대소문자와 일부 공백·숫자 표기는 정리합니다. 문자로 입력한 `00123`과 숫자 `123`은 다르게 봅니다.
- 첫 목록을 담은 뒤 원본을 고쳐도 담긴 값은 유지됩니다. 수동 계산 중이면 담기 전에 수식을 계산하세요.
- 같은 Excel에서 연 파일끼리 비교할 수 있습니다. 별도 Excel 프로세스끼리는 목록을 공유하지 않으며 Excel을 종료하면 담긴 목록이 사라집니다.

원본과 이전 결과를 바꾸지 않으며 명단을 외부 서비스로 보내지 않습니다. VBA 실행 후 Excel의 기본 **실행 취소** 기록은 유지되지 않을 수 있습니다.

## 목록 크기와 취소

한 목록의 입력 상한은 숨기지 않은 선택 셀 **100,000개**이며 빈칸도 포함합니다. 그 크기까지 항상 비교를 마친다는 보장은 없습니다. 값의 길이·고유값 수·필터·PC 부하에 따라 시간이 달라지고, 오래 걸리면 시간 제한으로 중단됩니다. 큰 목록은 나누어 비교하세요.

용량 14조건에서 비교 완료를 확인했으며 대표 범위는 다음과 같습니다. 모든 같은 크기 목록의 완료나 속도를 보장하는 수치는 아닙니다.

| 목록 하나의 입력 | 결과 |
|---|---|
| 서로 다른 48자 값 20,000개씩 | 40,000행 결과 완료 |
| 같은 48자 값 100,000개씩 | 1행 결과 완료 |
| 서로 다른 4,096자 값 1,000개씩 | 2,000행 결과 완료 |
| 중복 위주 1,221셀, 원문 합계 각 5,000,000자 | 1행 결과 완료 |

서로 다른 48자 값 **50,000개씩 또는 100,000개씩 비교한 시험은 약 30초 처리 제한으로 중단돼 결과를 만들지 못했습니다.** 같은 값 100,000개의 완료를 서로 다른 값 100,000개의 완료로 보지 마세요. 이 크기의 서로 다른 값은 나누어 비교하세요.

취소를 시도할 때는 작업 중인 Excel 창을 앞에 두고 **Esc를 누른 채 유지**하세요. 첫 목록 바꾸기의 100ms 요청 두 시험은 이전 42개 목록을 보존했고, 같은 조건에서 키를 누르지 않으면 교체를 완료했습니다. 이는 대조 실험에 근거한 부분 확인이며 취소 안내 화면은 관찰하지 못했습니다. 순간 입력·다른 작업·일정 시간 내 취소는 보장하지 않습니다. 작업 종료와 첫 목록 항목 수를 확인하기 전에는 중단됐다고 판단하지 마세요. 경고창에서 **아니요**를 누르면 작업을 시작하지 않습니다.

## 다시 설치하거나 제거하기

다음은 설치기의 동작 방식이며 새 EXE로 실제 검증한 절차는 아닙니다. Excel 프로세스가 없을 때 새 EXE 또는 **Install.cmd**로 같은 버전을 다시 설치하거나 이 설치기로 설치한 이전 버전을 바꿉니다. 더 최신 버전이나 확인할 수 없는 설치 기록은 남기고 중단합니다. 직접 등록한 추가 기능과 `PERSONAL.XLSB`의 코드는 자동으로 지우지 않습니다.

제거는 **Windows 설정 → 앱 → 설치된 앱 → Excel 명단 비교 → 제거**에서 합니다. ZIP 설치는 **Uninstall.cmd**를 실행합니다. 업무 파일·다른 추가 기능·설치 폴더에 따로 넣은 파일은 남깁니다. Uninstall.cmd로 먼저 제거해 앱 목록에 이름이 남으면 앱 목록에서 한 번 더 제거하세요.

설치 오류가 나면 기존 파일과 등록의 복원을 시도합니다. 다른 프로그램이나 사용자가 바꾼 내용은 덮어쓰지 않고 알려 줍니다. 오류가 남으면 반복해서 파일을 지우지 말고 오류 내용을 보관하세요. 설치 기록에는 사용자 경로가 들어갈 수 있으므로 그대로 공개하지 마세요.

CMD는 회사 그룹 정책과 `AllSigned`를 따릅니다. 그 외에는 같은 폴더의 `Setup.ps1`만 다운로드 차단을 해제하고 해당 실행에만 `RemoteSigned`를 적용합니다. 영구 실행 정책은 바꾸지 않지만 해당 파일의 다운로드 차단 해제는 유지됩니다.
