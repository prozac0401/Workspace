# Excel 명단 비교 · 설치와 사용

**Excel 명단 비교 0.2.0 RC9**는 Windows 데스크톱 Excel에서 두 목록의 값과 개수를 비교하는 추가 기능입니다. 차이와 중복을 새 결과 파일에 보여 주고 원본은 그대로 둡니다.

64비트 Windows와 PC에 설치된 데스크톱 Excel이 필요합니다. Mac과 브라우저용 Excel은 지원하지 않습니다. 설치 파일에는 코드 서명이 없습니다.

## 설치하기

1. 작업 중인 파일을 저장하고 Excel 창을 모두 닫습니다.
2. EXE를 실행하고 **설치**를 누릅니다. ZIP을 받았다면 모두 푼 뒤 `Release` 폴더의 **Install.cmd**를 실행합니다.
3. Excel을 열어 **추가 기능** 탭의 명단 비교 버튼을 확인합니다.

현재 Windows 계정에 설치합니다. 관리자 권한·Python·VBA 편집기는 필요하지 않습니다. 설치 위치는 `%LOCALAPPDATA%\ExcelSmartListCompare`이며 설치와 제거에는 Windows PowerShell을 사용합니다.

Excel이 실행 중이라는 안내가 계속 나오면 설치를 중단하고 오류 내용을 문의하세요. 제품 폴더 한 곳을 Excel의 **신뢰할 수 있는 위치**로 등록하므로 이 폴더에는 제품 파일만 보관하세요. 회사 정책으로 차단되면 승인된 설치 절차를 따르세요.

## 두 목록 비교하기

1. 첫 번째 목록의 셀을 선택하고 **첫 번째 목록 담기**를 누릅니다.
2. 두 번째 목록을 선택하고 **두 번째 목록 담아 비교**를 누릅니다.
3. 새 결과 파일을 확인하고 필요한 위치에 직접 저장합니다.

셀을 오른쪽 클릭한 **명단 비교** 메뉴에서도 실행할 수 있습니다. 가로·세로·사각형·여러 영역을 선택하면 전체를 목록 하나로 읽습니다. 일반 범위의 제목은 빼고 선택하세요.

**첫 번째 목록: 42개 항목**은 빈칸 등 제외한 셀을 뺀 값의 수입니다. 같은 값이 여러 셀에 있으면 각각 셉니다. **첫 번째 목록 비우기**는 기억한 목록만 비우며, **첫 번째 목록 바꾸기**는 현재 선택으로 다시 담습니다. 원본 셀은 지우지 않습니다.

## 결과와 비교 규칙

순서는 무시하고 같은 값의 개수를 비교합니다. 차이·중복·오류가 있으면 새 결과 파일을 만들고, 모두 같고 중복·오류도 없으면 안내만 표시합니다. **남은 개수**는 같은 값을 하나씩 짝지은 뒤 남는 수입니다.

- 숨긴 셀·필터로 제외된 셀·빈칸·오류·표의 제목과 합계는 비교에서 뺍니다. 병합한 셀은 비교할 수 없습니다.
- 메일 주소는 `@` 앞부분만 비교합니다. 뒷부분이 달라도 같다고 나올 수 있습니다.
- 영문 대소문자와 일부 공백·숫자 표기는 정리합니다. 문자로 입력한 `00123`과 숫자 `123`은 다르게 봅니다.
- 첫 목록을 담은 뒤 원본을 고쳐도 담긴 값은 유지됩니다. 수동 계산 중이면 담기 전에 수식을 계산하세요.
- 같은 Excel에서 연 파일끼리 비교할 수 있습니다. 별도 Excel 프로세스끼리는 목록을 공유하지 않으며 Excel을 종료하면 담긴 목록이 사라집니다.

원본과 이전 결과를 바꾸지 않으며 명단을 외부 서비스로 보내지 않습니다. VBA 실행 후 Excel의 기본 **실행 취소** 기록은 유지되지 않을 수 있습니다.

## 큰 목록과 작업 중단

한 목록의 입력 상한은 숨기지 않은 선택 셀 **100,000개**, 셀 하나의 값 **4,096자**, 원문 합계 **5,000,000자**입니다. 선택 셀 수에는 빈칸도 포함합니다. 상한 안에서도 값의 길이·서로 다른 값의 수·PC 부하에 따라 시간 제한으로 중단될 수 있습니다.

두 목록을 행 번호로 같은 크기씩 잘라 비교하면, 다른 구간으로 이동한 같은 값이 차이로 나올 수 있습니다. 나누려면 양쪽에서 비교에 쓰는 값이 같은 항목을 반드시 같은 묶음에 모두 포함하세요. 공백·대소문자·메일 주소 등을 정리하는 비교 규칙도 적용해야 합니다. 이 기준으로 나눌 수 없다면 두 목록 전체를 처리할 수 있는 다른 도구를 사용하세요.

취소를 시도할 때는 작업 중인 Excel 창을 앞에 두고 **Esc를 누른 채 유지**하세요. 키 입력만으로 중단됐다고 판단하지 말고 작업 종료와 첫 목록 항목 수를 확인하세요. 경고창에서 **아니요**를 누르면 작업을 시작하지 않습니다. 오류 이후 상태표시줄 문구가 남을 수 있습니다.

## 다시 설치하거나 제거하기

파일을 저장하고 Excel을 닫은 뒤 EXE 또는 **Install.cmd**로 같은 버전을 다시 설치하거나 이전 버전을 바꿀 수 있습니다. 더 최신 버전이나 확인할 수 없는 설치 기록이 있으면 중단합니다.

제거는 **Windows 설정 → 앱 → 설치된 앱 → Excel 명단 비교 → 제거**에서 합니다. ZIP 설치는 **Uninstall.cmd**를 실행합니다. 업무 파일·다른 추가 기능·설치 폴더에 따로 넣은 파일은 남깁니다. Uninstall.cmd로 먼저 제거해 앱 목록에 이름이 남으면 앱 목록에서 한 번 더 제거하세요.

설치나 제거에 실패하면 오류 내용을 보관하고 문의하세요. 설치 기록에는 사용자 경로가 들어갈 수 있으므로 그대로 공개하지 마세요.
