# Excel Smart List Compare 0.2.0 RC8 · 첫 번째 목록 / 두 번째 목록

Windows 데스크톱 Excel용 목록 비교 추가 기능입니다. RC8은 처리 중 취소 오류를 전달하고 설치 폴더에서 실행한 제거 명령을 별도 복사본으로 실행하도록 보완한, 코드 서명이 없는 평가용 후보입니다. RC7의 우클릭 메뉴 구성과 비교 규칙을 유지합니다. 사용자 PC에서 빌드할 필요가 없습니다.

## 설치와 사용

1. ZIP을 모두 압축 해제합니다. Excel 업무를 저장하고 모든 Excel 창을 닫습니다.
2. Release 폴더의 **Install.cmd를 더블클릭**하고 이 제품 설치를 확인합니다. PowerShell 명령을 따로 입력할 필요가 없습니다.
3. Excel에서 첫 번째 목록을 선택하고 **[첫 번째 목록 담기]**를 누르세요.
4. 이어서 두 번째 목록을 선택하고 **[두 번째 목록 담아 비교]**를 누르세요.
5. 필요한 결과는 새 통합문서로 저장합니다. 원본과 기존 결과를 덮어쓰지 않습니다.

목록은 선택한 셀 전체, 항목은 그 안의 값 하나입니다. 담긴 상태는 **첫 번째 목록: 42개 항목**처럼 표시합니다. **첫 번째 목록 비우기 / 첫 번째 목록 바꾸기**로 담아 둔 목록을 관리합니다. 결과도 **첫 번째 목록 / 두 번째 목록**으로 구분합니다. 메뉴를 여는 시점의 첫 번째 목록으로 명령·개수를 구성합니다. 사용 안내에서 설치 버전 `0.2.0-rc.8`을 확인할 수 있습니다.

Release 폴더의 **QuickGuide.html**은 사용 안내, **Completion-Report.html**, **Validation.json**은 RC8의 실제 검증 결과입니다. **RC7-Native-Report.html**, **Context-Menu-Report.html**과 나머지 보고서는 이전 버전의 기록입니다. EXE와 함께 제공하는 **OneFile-Validation.json**에서 해당 설치 파일의 해시와 시험 결과를 확인하세요.

현재 바이너리의 실제 시험 범위·실패 이력·원복 상태는 위 검증 보고서를 따릅니다. 이전 버전의 캡처나 취소 시험을 현재 버전의 통과 증거로 사용하지 않습니다. 회사 배포 승인과 다른 Office 환경 인수는 별도입니다.

## 간편 설치

실제 PC에서 RC3가 `UnauthorizedAccess`로 막히던 `Restricted` 환경에 대응했습니다. 그룹 정책이 없고 유효 정책이 `AllSigned`가 아니면 실행기가 같은 폴더의 `Setup.ps1` 한 파일의 다운로드 차단 표시를 해제하고, 설치용 PowerShell 프로세스에만 `RemoteSigned`를 적용합니다. 관리자 권한이나 실행 정책 변경 질문은 필요하지 않으며 제품 설치 확인창은 유지합니다.

사용자·컴퓨터의 영구 실행 정책은 바꾸지 않습니다. 프로세스가 끝나면 임시 실행 정책은 사라지고, `Setup.ps1` 한 파일의 차단 해제는 유지됩니다. 회사 그룹 정책이나 유효 `AllSigned` 설정이 있으면 파일 차단을 해제하지 않고 기존 정책으로 실행하므로 서명 요구·실행 차단이 그대로 적용됩니다. 다른 파일의 다운로드 차단을 일괄 해제하지 않습니다.

## 제거와 다시 설치

**업데이트는 새 EXE 또는 Release의 Install.cmd를 실행하세요.** 이전 버전이 있으면 버전을 확인하고 이전 제품 파일과 자동 실행 등록을 교체합니다. RC1~RC7의 이 설치기로 설치한 제품을 감지합니다. 같은 버전은 다시 설치하며, 더 최신 버전이나 알 수 없는 설치 기록은 보존하고 중단합니다.

설치 중 처리 가능한 오류가 나면 이전 제품 파일과 등록을 복구합니다. 외부에서 동시에 바뀐 항목은 보존하고 경고합니다. 중단된 설치는 Excel을 닫고 새 Release의 Install.cmd를 다시 실행하세요. 별도로 등록한 v0.1 추가 기능이나 PERSONAL.XLSB의 코드는 자동 제거 대상이 아닙니다.

완전히 제거하려면 Excel을 모두 닫고 설치된 앱의 **Excel 명단 비교 → 제거**를 실행합니다. ZIP 설치는 이 폴더 또는 설치 폴더의 Uninstall.cmd를 실행합니다. 설치 폴더에서 시작한 CMD는 두 실행 파일을 사용자 임시 폴더에 복사해 제어를 넘깁니다. 이 작은 실행 복사본은 임시 폴더에 남을 수 있으며 업무 데이터는 담지 않습니다. 제거 실행기도 같은 정책 준비를 처리합니다. 진단용 Test_Excel.cmd는 일반 사용에 필요하지 않습니다.

설치 위치: %LOCALAPPDATA%\ExcelSmartListCompare

Install.cmd가 이 제품 폴더만 Excel 신뢰 위치로 자동 등록합니다(하위 폴더 제외). 이 폴더의 파일은 매크로 알림 없이 실행될 수 있으므로 제품 파일만 보관하세요. 기존 신뢰 위치는 보존하며 제거할 때는 설치기가 만든 변경되지 않은 항목만 삭제합니다. 회사 정책에서 사용자 신뢰 위치를 막으면 종료 코드 6으로 중단합니다. 전역 매크로 설정과 회사 정책은 변경하지 않습니다.

RC3부터 설치 파일의 실제 저장 경로를 검증합니다. 경로가 리디렉션되면 종료 코드 6으로 되돌리므로 일반 Windows 파일 탐색기에서 Release/Install.cmd를 실행하세요.

일반 사용자 설치이며 별도 Python이나 VBA 프로젝트 접근 권한이 필요하지 않습니다. 설치·제거는 Windows PowerShell을 사용합니다. 조직의 매크로/설치 정책이 차단하면 승인된 배포 절차를 이용하세요.

## 사용 경계

- 같은 Excel 프로세스 안에서만 첫 번째 목록을 공유합니다. Excel을 완전히 종료하면 담긴 목록은 사라집니다.
- 필터로 제외되거나 숨긴 셀은 읽지 않습니다. 일반 범위의 제목은 빼고 선택합니다.
- 이메일은 @ 앞 ID로 비교하고 텍스트 앞자리 0은 보존합니다. 값별 개수도 비교합니다.
- 처리 중 원본을 편집하지 말고 기다리세요. 취소는 Esc입니다. Excel이 제어권을 반환하는 체크포인트에서 처리합니다.
- VBA 실행 후 Excel 기본 Undo 기록 보존은 보장하지 않습니다.
- 100,000셀은 입력 안전 상한입니다. 결과가 많은 작업은 활성 처리 약 30초의 지연 보호로 완료되지 않을 수 있으므로 범위를 나누세요.
