# ADR-0007 · 이전 버전 제거 후 업데이트 설치

상태: 채택 · 날짜: 2026-09-15 · 결정 담당: 사용자 요청에 따른 설치 변경

관련 요구: [I21~I25](ACCEPTANCE_TESTS.md), [추가 도구 개발 기준](../../../docs/policies/tools.md). [ADR-0002](ADR-0002-Excel-native-lifecycle.md)의 설치 거래와 [ADR-0003](ADR-0003-Product-trusted-location.md)의 소유권 계약을 확장한다.

## 맥락

기존 설치기는 같은 경로의 파일을 덮어쓰는 재설치였다. 사용자는 Install 실행 시 이전 버전을 감지하고 제거한 다음 새 버전을 설치하도록 요청했다. 제거를 별도 프로세스로 먼저 실행하면 이후 패키지 누락이나 설치 오류 때 이전 버전까지 잃을 수 있다.

## 결정

제품 ID와 설치 경로가 일치하는 `install.json`의 `installerVersion`으로 설치 상태를 판정한다. 이 필드가 없는 알려진 제품 버전 `0.2.0` 기록은 RC1로 취급한다. 숫자 제품 버전과 숫자 RC 순서를 비교한다. 더 이전 버전은 제거 후 설치, 같은 버전은 재설치, 더 최신 버전·알 수 없는 형식은 보존 후 중단한다. Office 등록 버전이 달라졌으면 기존 설치의 Uninstall.cmd로 먼저 제거하도록 안내한다. 표식 없는 v0.1 또는 PERSONAL.XLSB 코드는 추측해 삭제하지 않는다.

기존 제품 잠금 안에서 다음 순서를 수행하며 확인창은 한 번만 표시한다.

1. 패키지의 XLAM·설치기·제거 실행기·README를 모두 메모리에 준비한다. 소유권·경로·정책·신뢰 위치를 확인한다.
2. 이전 고정 제품 파일과 제품 경로에 정확히 일치하는 OPEN 및 Add-in Manager 등록을 백업한다.
3. 이전 자동 실행·추가 기능 등록과 XLAM·Setup.ps1·Uninstall.cmd·README.md를 실제로 제거한다. 추가 파일은 건드리지 않는다.
4. 새 파일을 같은 폴더의 고유 임시 파일에 완전히 쓰고 원자적으로 이동/교체한다. 기대한 파일 해시가 달라졌으면 외부 변경을 보존하고 중단한다.
5. 새 설치 기록을 원자적으로 교체하고 검증한 제품 신뢰 위치와 자동 실행 등록을 활성화한다.

신뢰 위치는 버전에 종속되지 않는 제품 폴더 설정이므로 업데이트 도중 유지한다. 기존 소유 토큰과 사용자 신뢰 위치의 소유권을 이어받으며, 전체 제거에서는 기존 규칙대로 자기 항목만 삭제한다. 이전 설치 기록도 새 기록을 커밋할 때까지 남겨 중단된 설치를 다시 인식할 수 있게 한다. 기존 Uninstall.cmd를 별도로 실행하지 않는 이유는 확인·잠금·실패 복구를 하나의 작업 안에서 유지하기 위해서다.

## 실패와 복구

새 패키지가 불완전하면 제거 전에 중단한다. 처리 가능한 오류에서는 완전히 기록한 자기 파일만 이전 백업으로 복구하고, 비어 있는 자기 등록 슬롯을 복원한다. 동시에 바뀐 외부 파일·등록은 덮어쓰지 않고 경고한다. 모든 새 파일을 임시 파일로 완성한 뒤 교체하므로 쓰기 실패가 부분 XLAM을 남기지 않는다.

프로세스가 강제로 끝나면 메모리 백업은 유지되지 않는다. 소유 표식이 남은 상태에서 새 Install.cmd를 재실행하거나 Uninstall.cmd로 정리할 수 있다. 이는 모든 전원 단절 시점의 이전 버전 자동 복구 보장이 아니다. 중단 상태를 구성한 재실행 시험과 실제 실패 주입은 [업데이트 검증 기록](UPGRADE_REPORT.md)에 구분한다.

## 검증

`tests/windows-upgrade.ps1`은 합성 제품 파일과 격리 HKCU에서 제거 순서·롤백·버전 판정·외부 변경·중단 재실행을 검사한다. `tests/windows-upgrade-lifecycle.ps1`은 처음 미설치인 일반 사용자 환경에서 실제 RC5 Install.cmd → RC6 실패 복구 → RC6 Install.cmd → 자동 로드·70개 창 상태 검사 → 제거 → 초기 상태 복원을 수행한다. 잠긴 데스크톱에서는 확인창·실제 마우스 입력의 육안 검증을 통과로 표시하지 않는다.
