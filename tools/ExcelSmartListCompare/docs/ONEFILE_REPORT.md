# Excel RC7 · 단일 EXE 검증 기록

도구 ID: ExcelSmartListCompare · 엔진: 0.2.0-rc.7 · 포장: 1 · 날짜: 2026-09-15

상태: 설치 수명주기와 실제 Excel 실행을 검증한 **코드 서명이 없는 평가용 설치기**. 실제 설치 화면의 육안 확인·클릭은 데스크톱 잠금으로 미실행입니다.

## 변경 범위

RC7의 XLAM·Install.cmd·Uninstall.cmd·Setup.ps1·README.md를 그대로 내장한 Inno Setup 설치 화면과 Windows 앱 제거 항목을 추가합니다. [설계 결정](ADR-0009-Single-file-installer.md)과 [사용 안내](ONEFILE_INSTALLATION.md)를 따릅니다.

## 검증 대상과 결과

환경: Windows 11 23H2 x64 `10.0.22631`, Windows PowerShell `5.1.22621.6133`, 데스크톱 Excel x64 `16.0.20326.20144`, 일반 사용자. 컴파일러는 설치된 Inno Setup `6.7.0`입니다.

공개 RC7 ZIP을 다시 다운로드해 ZIP 해시와 내장할 5개 파일을 대조했습니다. 모두 고정 해시와 일치합니다. XLAM은 `5da5ff891232dde733d60ee6151cbfb26e251d6b75a51cb6a3f224effde4c18b`, Setup.ps1은 `1ae6bc71c3fa8b7bc8bc46401f76df6570e60664b5369e57919c77a845120801`입니다. VBA를 다시 빌드하거나 수정하지 않았습니다.

`tests/windows-onefile.ps1 -IncludeExcelSmoke`는 기존 제품·관리 폴더·앱 항목·Excel 프로세스가 없을 때만 시작합니다. 실행 후 시험 설치를 제거하고 Office·PowerShell 관련 14개 설정 그룹과 초기 미설치 상태를 확인했습니다. Excel 시험이 바꾼 창 위치 값은 처음 값으로 복원했습니다. 남은 Excel 프로세스는 0개이며, 일반 사용자 테스트용 임시 예약 작업도 제거했습니다.

배포 EXE의 정확한 해시·소스 커밋·입력 해시는 함께 제공하는 `OneFile-Build.json`과 `.sha256`, 해당 배포 파일의 실행 검증은 `OneFile-Validation.json`에 기록합니다. 공개 요약에는 사용자 경로·계정·프로세스 ID·원시 로그를 넣지 않습니다. 원래 RC7의 전체 VBA 검증과 이번 EXE 진입점 검사를 구분하며, 모든 Windows·Office 환경에서의 상용 승인으로 해석하지 않습니다.

## 초기 시험에서 확인한 사항

- 패키지 실행 호스트의 AppData 리디렉션을 원래 엔진이 코드 6으로 차단했습니다. 일반 사용자 실행 환경의 설치 성공과 구분합니다.
- 제거 스크립트를 설치 폴더 안에서 직접 실행하면 작업 디렉터리 잠금과 실행 중인 CMD 삭제 문제가 발생했습니다. 최종 설계는 두 엔진 파일을 전용 임시 폴더에 복사해 실행합니다.
- Inno 제거의 원래 실행 파일은 임시 제거 프로세스보다 먼저 끝날 수 있습니다. 시험은 원래 프로세스 종료뿐 아니라 제거 로그의 완료와 파일·앱 항목 상태를 확인합니다.

## 한계

EXE는 코드 서명이 없는 평가용 배포입니다. 실제 전원 단절, 다른 Windows·Office 환경, 조직 GPO·MDM 정책 배포를 통과했다고 주장하지 않습니다. 데스크톱 잠금 상태에서 설치 창의 접근성 텍스트는 읽었지만 실제 화면·마우스 클릭·취소 버튼을 확인하지 못했습니다. 원시 로그와 사용자별 설치 진단은 로컬 artifacts에만 보관합니다.
