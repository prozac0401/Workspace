# Excel 명단 비교 사용 안내

**첫 번째 목록을 담고, 두 번째 목록을 선택해 비교합니다.** 가로·세로 방향이나 비교 모드를 따로 고를 필요는 없습니다.

## 1. 설치하기

작업 중인 파일을 저장하고 Excel 창을 모두 닫습니다. EXE를 실행해 **설치**를 누르거나, ZIP을 모두 푼 뒤 `Release` 폴더의 **Install.cmd**를 실행합니다. Excel을 열어 **추가 기능** 탭의 명단 비교 버튼을 확인하세요.

64비트 Windows와 데스크톱 Excel이 필요합니다. Excel 실행 중이라는 안내가 계속 나오면 설치를 중단하고 오류 내용을 문의하세요. [자세한 설치 안내](RELEASE_README.md)

## 2. 첫 번째 목록 담기

비교할 값이 들어 있는 셀을 선택하고 **첫 번째 목록 담기**를 누릅니다. 일반 범위의 제목은 빼고 선택하세요. 가로·세로·사각형·여러 영역 전체를 목록 하나로 읽습니다.

**첫 번째 목록: 42개 항목**은 빈칸 등 제외한 셀을 빼고 값 42개를 담았다는 뜻입니다. 같은 값이 여러 셀에 있으면 각각 셉니다. 담은 뒤 원본을 고쳐도 기억한 값은 바뀌지 않습니다.

## 3. 두 번째 목록 비교하기

두 번째 목록을 선택하고 **두 번째 목록 담아 비교**를 누릅니다. 같은 Excel에서 연 다른 파일도 비교할 수 있습니다. 셀을 오른쪽 클릭한 **명단 비교** 메뉴에서도 실행할 수 있습니다.

숨긴 셀·필터로 제외된 셀·빈칸·오류·표의 제목과 합계는 비교에서 뺍니다. 병합한 셀은 비교할 수 없습니다. 수동 계산 중이면 먼저 수식을 계산하세요.

## 4. 결과 확인하고 저장하기

차이·중복·오류가 있으면 새 결과 파일을 만듭니다. 모두 같고 중복·오류도 없으면 안내만 나옵니다. 원본과 이전 결과는 바꾸지 않으며 결과는 원하는 위치에 직접 저장해야 합니다.

| 결과표의 문구 | 뜻 |
|---|---|
| 비교에 쓴 값 | 공백 등을 정리해 실제 비교한 값 |
| 원래 값 (예) | 해당 값이 처음 나온 셀의 원래 값 |
| 첫 번째 목록 / 두 번째 목록 개수 | 각 목록에서 같은 값이 나온 횟수 |
| 남은 개수 | 같은 값을 하나씩 짝지은 뒤 남는 수 |
| 셀 주소 | 해당 값이 처음 나온 셀의 위치 |

순서는 무시하고 같은 값의 개수를 비교합니다. 메일 주소는 `@` 앞부분만 비교합니다. 문자로 입력한 `00123`과 숫자 `123`은 다르게 봅니다. [전체 비교 규칙](RELEASE_README.md)

## 5. 목록 비우기와 바꾸기

- **첫 번째 목록 비우기:** 기억한 목록만 비웁니다. 원본 셀은 지우지 않습니다.
- **첫 번째 목록 바꾸기:** 현재 선택한 셀로 첫 목록을 다시 담습니다.

별도 Excel 프로세스끼리는 목록을 공유하지 않습니다. Excel을 종료하면 담긴 목록이 사라집니다. VBA 실행 후 Excel의 기본 실행 취소 기록은 유지되지 않을 수 있습니다.

## 6. 큰 목록과 작업 중단

한 목록은 숨기지 않은 선택 셀 **100,000개**, 셀 하나의 값 **4,096자**, 원문 합계 **5,000,000자**까지 받을 수 있습니다. 선택 셀 수에는 빈칸도 포함합니다. 상한 안에서도 시간 제한으로 중단될 수 있으므로 큰 목록은 나누어 비교하세요.

취소를 시도할 때는 작업 중인 Excel 창을 앞에 두고 **Esc를 누른 채 유지**하세요. 키 입력만으로 중단됐다고 판단하지 말고 작업 종료와 첫 목록 항목 수를 확인하세요. 경고창에서 **아니요**를 누르면 작업을 시작하지 않습니다. 오류 이후 상태표시줄 문구가 남을 수 있습니다.

## 7. 프로그램 제거하기

파일을 저장하고 Excel 창을 모두 닫습니다. EXE 설치는 **Windows 설정 → 앱 → 설치된 앱 → Excel 명단 비교 → 제거**에서, ZIP 설치는 **Uninstall.cmd**로 제거합니다. 업무 파일·다른 추가 기능·설치 폴더에 따로 넣은 파일은 남깁니다.

설치나 제거에 실패하면 오류 내용을 보관하고 문의하세요. 설치 기록에는 사용자 경로가 들어갈 수 있으므로 그대로 공개하지 마세요. [설치·사용 안내](RELEASE_README.md)
