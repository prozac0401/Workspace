# Excel 화면·설치 안내 문구 검수 · 2026-09-17

한국어 사용자가 기능을 짐작하지 않고 읽을 수 있도록 화면과 설치 안내를 고쳤습니다. 어려운 명사 대신 하는 일과 결과를 썼고, 개수를 설명할 때는 예시를 붙였습니다.

**소스 교정은 완료했습니다. 바뀐 문구를 모두 반영한 새 XLAM과 배포용 EXE는 아직 만들지 않았습니다.** 기존 RC8의 Esc 취소 실패와 첫 설치 접근 거부는 해결된 것으로 표시하지 않습니다. 기존 파일의 배포 보류는 그대로이며, [실제 시험 결과](RC8_COMPLETION_REPORT.md)를 유지합니다.

## 바꾼 문구

| 이전 표현 | 바꾼 표현 | 이유 |
|---|---|---|
| 비교키 | 비교에 쓴 값 | 프로그램 내부 용어를 없앴습니다. |
| 원본 예 | 원래 값 (예) | 원래 셀의 값이라는 뜻을 드러냈습니다. |
| 잔여 | 남은 개수 / 남은 항목 | 무엇이 남는지 설명합니다. |
| 주소 | 셀 주소 | 파일 주소와 구분합니다. |
| 개수 차이 | 개수가 다름 | 결과를 문장으로 표현했습니다. |
| 출처 / 시점 | 위치 / 담은 시각 | 어느 파일의 값을 언제 담았는지 나타냅니다. |
| 중복 초과 | 중복 + 계산 예시 | 같은 값이 3개 있으면 중복은 2개라고 설명합니다. |
| 가시성 확인 대상 | 숨김 여부를 확인할 셀 | 숨긴 셀을 확인한다는 뜻을 풀었습니다. |
| 지연 보호 한도에 도달 | 작업 시간이 길어져 중단했습니다 | 사용자가 알아야 할 결과와 다음 행동을 먼저 말합니다. |
| 엔진 종료 코드 | 문제 확인용 코드 | 오류를 문의할 때 필요한 값이라는 뜻을 전달합니다. |

‘남은 개수’는 같은 값이 첫 번째 목록에 2개, 두 번째에 1개 있으면 첫 번째에 1개가 남는다는 예시로 설명합니다. ‘원래 값 (예)’와 ‘셀 주소’는 해당 항목이 각 목록에서 처음 나온 셀을 가리킨다고 안내합니다. 모든 셀의 값을 보여 준다는 오해를 막았습니다.

## 반영한 곳

- Excel 메뉴 주변 안내, 결과표, 경고·오류·완료 안내, 사용 안내 창
- `Setup.ps1`의 설치·업데이트·제거·제작·검사 안내와 오류
- `Install.cmd`, `Uninstall.cmd`, `Test_Excel.cmd`의 실행 준비 단계 안내
- `SingleFile.iss`의 자체 안내와 기본 설치·진행·오류·제거 메시지 67개
- [프로젝트 안내](../README.md), [사용 안내](QUICK_GUIDE.md), [설치 안내](ONEFILE_INSTALLATION.md), [배포 안내 원본](RELEASE_README.md)

네 버튼 이름과 `첫 번째 목록: 42개 항목` 형태의 상태 표시는 유지했습니다. 파일명, 함수명, 오류 코드, 검사 표식, 버전과 설치 식별자는 바꾸지 않았습니다. Windows와 Excel이 직접 만드는 오류 원문은 그대로 표시될 수 있습니다.

원본 VBA와 Excel로 가져올 ASCII 파일을 함께 갱신했습니다. 결과표의 설명이 늘어나 중복·제외 안내 행은 48에서 60, 비교 규칙 행은 36에서 48로 높였습니다. 비교 순서·규칙·결과 개수·출력 위치와 설치·제거 절차는 유지합니다.

## 파일과 남은 확인

문구별 전후 목록은 상위 작업 공간의 로컬 `artifacts/korean-wording-20260917/excel-text-review/`에 있습니다. 원본 소스의 문자열과 문서 문단을 나누며, 화면에서 동적으로 합쳐지는 값은 실제 실행 화면과 구분합니다.

설치기 컴파일 확인 자료는 이 저장소의 `artifacts/korean-wording-20260917/compile-check/`에 있습니다. 확인용 EXE는 **기존 RC8 파일을 내장한 컴파일 검사 전용**입니다. 새 Excel·Setup·CMD 문구가 모두 들어간 설치 파일이 아니므로 설치하거나 배포하지 않습니다. `RC8-Payload.json`과 과거 시험 파일의 해시는 바꾸지 않았습니다.

이번에는 Excel 보안 설정을 변경하지 않았으며, XLAM 제작·실제 Excel 화면·실제 설치와 제거를 실행하지 않았습니다. 승인된 개발 환경에서 새 파일을 만든 뒤 결과표와 안내 창의 줄바꿈·잘림, 실제 취소, 설치·업데이트·제거를 확인해야 합니다. 학력이나 사용 경험이 다른 사용자를 대상으로 한 이해도 시험도 아직 하지 않았습니다.

문구 교정 결과는 로컬 소스에만 반영했습니다. 원격 저장소나 공개 사이트에 게시하지 않았습니다.
