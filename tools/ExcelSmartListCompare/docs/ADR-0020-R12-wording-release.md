# ADR-0020 · R12 문구 교정과 테스트 미실행 배포

상태: 채택 · 날짜: 2026-09-21 · 적용: 0.2.0-rc.12 한정

결정 담당: 도구 개발·배포 담당

관련 요구: [R12 명세](../../../docs/tools/excel-list-compare/r12-specification.md), 사용자 요청 “로직은 수정하지 않으며”, “텍스트만 수정”, “테스트를 진행하지 않고 반영 및 릴리즈”, “설치본은 r12”.

## 맥락

차이 결과와 담은 목록 확인의 설명이 이해하기 어렵다는 피드백이 있다. R11은 기능·설정 변경과 필수 검사를 묶어 배포했지만, 이번 요청은 문구와 표 표시만 정리하고 기존 테스트를 생략하는 범위다.

## 결정

비교·정규화·개수 집계·설정 저장·취소·복구·설치 엔진은 유지한다. 문구, 요약의 표시 항목, 열 너비·숨김·병합만 정리한다. 기존 차이 결과의 10개 데이터 열과 순서는 그대로 두고 6개 주요 열을 먼저 보여준다. 확인용 파일의 요약은 첫 목록 중심으로 줄인다. 메뉴 동작·기능은 추가하지 않는다.

R12는 `wording-only-no-tests` 프로필, `PUBLISH_WORDING_ONLY_WITHOUT_RUNTIME_TESTS` 결정으로 제작·게시한다. `fullAcceptancePassed=false`를 유지한다. Python 회귀, Excel 비교·UI·성능·취소 및 설치·업데이트·제거 시험은 NOT_RUN이다. 이 예외는 R12에만 적용하며 이전 포장 게이트의 필수 검사 조건은 변경하지 않는다.

## 제작과 영향

기존 격리 제작 도구에 명시적인 `-BuildOnly` 선택을 추가한다. 이 경로는 새 XLAM의 소스를 가져와 저장하고 가져온 소스의 버전을 확인한다. 저장한 XLAM의 재개방과 매크로 실행은 하지 않는다. 직렬화 소스와 RibbonX는 기존 `audit_candidate.py`로 읽기 전용 대조한다. 기능 시험 진입점과 시험용 데이터 작성은 실행하지 않는다. 기본 제작·시험 경로는 유지한다.

`package_r12.py`는 이 제작 기록과 소스·파일 해시를 확인한 뒤 기존 Inno Setup 정의로 R12 EXE를 만든다. 비교 관련 모듈과 설치 엔진이 R11에서 바뀌지 않았는지 대조한다. 제품 코드의 문구·표 표시 변경과 별도로, 이 제작 선택과 R12 전용 포장 경로는 배포를 위한 변경이다.

## 실패와 복구

기존 설치·사용자 파일을 수정하지 않고 새 산출물을 저장소의 artifacts 아래 만든다. 제작 도구는 소유 Excel만 종료하고, 사용자에게 허용받은 임시 VBA 프로젝트 접근 설정은 원래 값으로 복구한다. 소스 불일치·해시 불일치·복구 실패 시 포장을 중단한다. 회사 보안 정책은 변경하지 않는다.

## 검증 기록

새 제품 시험은 실행하지 않는다. 소스와 산출물의 대응, 제작 성공과 다운로드 파일 일치만 실제 결과로 기록한다. 문서 게시에는 저장소의 strict 빌드·링크 규칙을 적용한다. R11의 검증 기록은 당시 버전의 증거로 보존하며 R12 검증으로 복사하지 않는다. [R12 배포 기록](RC12_RELEASE_REPORT.md)에 실제 완료 범위를 남긴다.
