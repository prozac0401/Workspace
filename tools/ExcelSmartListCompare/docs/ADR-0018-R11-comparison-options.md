# ADR-0018 · R11 비교 설정과 완료 동작

상태: 채택 · 사용자 요구사항과 구현 기준 확정. 제품 구현·실제 Excel 검증 전

날짜: 2026-09-20

결정 담당: 도구 개발·검증 담당

관련 요구사항·정책: [R11 제품 명세](../../../docs/tools/excel-list-compare/r11-specification.md)의 REQ-EXCEL-025~031, [추가 도구 개발 기준](../../../docs/policies/tools.md), [정책 문서 작성 규칙](../../../docs/policies/documentation.md), [R11 인수 요구사항](ACCEPTANCE_TESTS.md#r11-2026-09-20)

대체·대체됨 관계: R11에서는 [ADR-0016](ADR-0016-Comparison-usability.md)의 항상 결과 생성·첫 목록 유지와 비교 규칙 선택 제외 결정을 아래 내용으로 대체한다. 원문 변형의 자동 수집·상세 시트 작성 요구도 R11 기본 흐름에서 제거한다. 기존 원본 보존·복구·설치 계약, [ADR-0017](ADR-0017-RC10-publication.md)의 RC10 게시 결정과 당시 검증 결과는 유지한다.

후속 결정: [ADR-0019](ADR-0019-R11-release-scope.md)에서 설정 자동 기억·기본값 복원, 단일 결과 시트와 필수 검사 후 배포 범위를 채택했다. 아래 미결정·구현 전 표기는 최초 요구사항 기록이며 현재 상태는 R11 명세·검증 기록을 따른다.

## 맥락

사용자는 빠르고 가벼운 명단 비교를 원하며, 일치한 목록마다 결과 파일을 만드는 동작과 성공 후 첫 목록이 남는 흐름을 변경하도록 요청했다. 메일 주소의 비교 범위와 대소문자 처리에는 선택권을 두고, 첫 목록을 유지하는 RC10 흐름도 별도 옵션으로 남기도록 했다. 이어 설정 접근 경로와 설정을 바꿀 수 있는 시점을 R11 명세에 포함하도록 요청했다.

## 결정

- 기본값은 **메일 `@` 앞부분만 비교 / 대소문자 무시 꺼짐 / 비교 후 첫 목록 유지 꺼짐**이다. 메일 전체 주소 비교, 대소문자 무시, 첫 목록 유지를 각각 선택할 수 있다.
- 설정은 **Excel → 추가 기능 탭 → 비교 설정** 및 **셀 우클릭 → 명단 비교 → 비교 설정**으로 연다. 두 경로는 같은 상태와 현재값을 사용하며 비교마다 설정 창을 띄우지 않는다.
- 첫 목록을 담으면 메일·대소문자 규칙도 함께 보관한다. 이 두 옵션은 첫 목록을 비우기 전까지 변경하지 못한다. 첫 목록 유지 옵션은 비교 시작 전까지 바꿀 수 있으며, 담기·바꾸기·비교·결과 작성 중에는 세 옵션 모두 잠근다.
- 선택한 규칙에 따른 값과 개수가 같으면 짧게 안내하고 결과 통합문서·시트를 만들지 않는다. 양쪽에 같은 중복이 있어도 같다. 오류 제외 후 일치는 제외 개수를 알리고 원본 전체 일치로 표현하지 않는다. 유효 값 없음은 일치 성공이 아니다.
- 값·개수 차이가 있을 때만 결과를 작성한다. 사용자가 무시하기로 한 원문 차이의 상세 수집·대조와 **규칙으로 같아진 값** 시트를 자동 생성하지 않는다. 전체 개수·필요한 차이 근거와 수식 실행 방지는 유지한다.
- 정상 완료 후 첫 목록 유지가 꺼져 있으면 비우고 켜져 있으면 같은 스냅샷을 보존한다. 일치 판정과 차이 결과 작성 성공에 같은 완료 정책을 적용한다.
- 차이 결과표의 시트·열 배치와 Excel 재시작 후 설정 기억 여부는 별도 미결정 사항이다. 최초 기본값과 위 동작을 미결정으로 되돌리지 않는다.

## 검토한 대안

- RC10처럼 모든 비교의 상세 결과를 작성하고 항상 첫 목록 유지: 근거 저장과 반복 비교에는 유리하지만 사용자가 요청한 간단한 기본 흐름과 맞지 않는다.
- RC9 흐름을 고정하고 옵션을 제공하지 않음: 기본 사용은 단순하지만 전체 메일 주소 비교와 첫 목록 재사용 요구를 충족하지 못한다.
- 첫 목록을 담은 후 비교 규칙 즉시 변경: 다시 담는 수고를 줄이지만 이미 정규화된 첫 목록과 두 번째 목록의 기준이 달라질 수 있다. 원본을 자동 재독하지 않고 첫 목록을 비운 뒤 변경한다.
- 매 비교마다 옵션 선택: 결과의 기준을 직접 확인할 수 있지만 반복 조작이 늘어난다. 사용자가 필요할 때 여는 설정과 현재값 표시를 사용한다.

## 영향과 이행

같은 Excel 프로세스의 두 메뉴와 여러 창이 설정을 공유한다. 비교 규칙은 스냅샷에 고정하고 완료 후 유지 여부는 각 작업 시작 시 고정한다. 설정이 없는 최초 상태부터 명시한 기본값을 적용한다. 숫자 정규화·앞자리 0·선택 제외·안전 상한·이전 결과 보존을 변경하지 않는다.

R11 요구와 이전 명세의 경계를 표시하고 인수표에 새 기대값을 추가한다. 공개 사용 안내는 실제 구현·검증한 버전에 맞춰 갱신한다. 설치 패키지의 제품명·버전 중심 안내와 별도 검증 자료 구분을 유지한다. 설정 영구 저장 여부에 의존하는 파일·레지스트리·업그레이드·제거 설계는 해당 결정을 마친 뒤 추가한다.

## 실패와 복구

경고 거절·취소·실패·비교할 값 없음과 결과 작성 실패는 완료 후 비우기 대상이 아니다. 두 유지 설정 모두 기존 첫 목록의 값·규칙·출처·시각·개수를 보존한다. 첫 목록 바꾸기 실패도 이전 스냅샷을 보존한다. 이번 작업의 미완성 결과만 정리하고 원본·이전 결과·Excel 설정을 보존·복원한다. 취소 요청을 취소 성공으로 기록하지 않는다.

## 검증

[인수표](ACCEPTANCE_TESTS.md#r11-2026-09-20)의 R11-01~R11-12를 적용한다. 설정 기본값과 비교 네 조합, 동일값·동일 중복의 결과 미생성, 설정 잠금·공유, 유지 여부별 다음 행동, 실패 복구와 기존 데이터 계약을 확인한다. 같은 조건에서 RC9·RC10·R11의 시간·메모리도 비교한다. 실제 메뉴·창·키 입력과 최종 파일의 설치 검증은 자동 참조·정적 검증과 구분한다.

현재 제품 구현과 위 기능 검증은 **NOT_RUN**이다. 요구사항 채택과 문서 검사를 제품 동작의 PASS 또는 배포 완료로 표시하지 않는다.
