# 변경 이력

## 0.2.0 · 폴더 감시 prerelease 게시 완료 · 2026-10-04

- 브라우저 확장 대신 지정 폴더 한 곳을 비재귀로 감시하는 네이티브 C++ 프로그램을 추가했습니다.
- 최초 기존 번호 그룹은 사용자가 최신 파일과 표시된 전체 처리 순서에 동의하거나 보존하도록 구성했습니다.
- 이후 새 번호 파일은 3초 안정·잠금 조건으로 처리합니다. 같은 원래 대상의 동시 후보는 모두 보존합니다.
- 기존 비교·History·객체 이름 이동·rollback을 재사용하며 폴더 경로는 브라우저 완료 순서 상태를 사용하지 않습니다.
- 현재 Windows 다운로드 위치·위치 변경 추종·사용자 폴더 선택과 기본 로그인 자동 실행/설치 시 해제를 제공합니다.
- MSI 식별자·설치 경로를 0.1.0과 분리하고 브라우저 등록을 요구하지 않습니다. 구버전 설치·순서 상태는 자동 이행하지 않습니다.
- 엔진 8건·watcher 대표 세션 15건·최초 그룹 4건과 수정 후보의 설치·실행·repair·제거·보존 5건, 화면 높이 수정 후보의 설치·실행·제거·보존 4건이 PASS입니다. 최종 안내 문구 수정은 관련 증거를 재사용하고 위자드 폴더 선택은 표준 MSI 컨트롤로 바꿔 경로 표시·설정 전달·취소를 확인했으며 새 late-failure의 제품 등록 rollback 실패는 확인된 제한으로 남깁니다.
- [무서명 평가용 릴리즈](https://github.com/prozac0401/Workspace/releases/tag/download-version-manager-v0.2.0)를 게시하고 실제 MSI·체크섬 다운로드를 확인했습니다. 상용 승인으로 분류하지 않습니다.

## 0.1.0 · 평가 후보 · 2026-09-30

- 후속 평가에서 protocol 2의 완료 시각·다운로드 token과 138-byte HKCU 상태를 추가해 역순 요청이 최신 객체를 바꾸는 결함을 수정했습니다. 같은 완료 시각은 두 파일을 보존합니다.
- Host 82건·확장 38건과 1 GiB streaming 시험을 통과했습니다. 제품 게시 뒤 두 실패 지점의 MSI 등록 rollback/reinstall 실패는 별도 관문으로 남깁니다.

- MV3 다운로드 완료 이벤트와 단발 Native Messaging x64 C++ Host를 추가했습니다.
- 크기 우선·streaming SHA-256 비교, 신규 객체의 원래 이름 승계, 다른 이전 내용만 timestamp History로 이동합니다.
- 대상 mutex, 안전한 핸들 이동, rollback과 정확한 실패 경로, 정상 성공 무알림을 제공합니다.
- per-user 단일 MSI 후보와 공식 개발용 확장 활성화 안내를 제공합니다. 스토어 배포·완전 자동 통합 설치는 미완료이며 stable 릴리스가 아닙니다.
