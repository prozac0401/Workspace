DownloadVersionManager 설치 마무리

0.1.0 평가판입니다. MSI 설치만으로 Chrome·Edge 확장이 활성화되지 않습니다.

프로그램과 확장 파일은 이 설치 파일 하나에 있습니다. 브라우저의 공식 개발용 불러오기 기능으로 확장을 활성화할 수 있습니다. 조직에서 개발 모드를 금지했다면 담당자의 배포 절차를 따르세요.

  1. Chrome은 주소창에 chrome://extensions, Edge는 edge://extensions를 입력합니다.
  2. 평가용 브라우저에서 개발자 모드를 켜고 ‘압축해제된 확장 프로그램을 로드합니다’ 또는 ‘압축 풀린 확장 로드’를 선택합니다.
  3. 이 설치 폴더 안의 extension 폴더를 선택합니다. 기본 위치는 %LOCALAPPDATA%\Programs\DownloadVersionManager\extension입니다.
  4. 확장을 활성화하면 새 다운로드부터 자동 정리합니다. 확장의 ‘설치 연결 확인’은 설치된 프로그램과의 연결을 진단합니다. 시험 다운로드 전에 눌러 연결됐는지 확인하세요.

자동 감시·시작 프로그램·서비스가 없습니다. 내용이 같은 재다운로드도 새 파일 자체가 원래 이름을 승계합니다. 다른 내용의 이전 파일은 해당 폴더의 _history에 보관합니다.

같은 이름을 정하는 다른 확장과 함께 사용하지 마세요. 직접 이름을 바꾸는 저장 대화상자와 클라우드·네트워크 경로에는 제한이 있습니다. 오류가 나면 남아 있는 파일을 확인하세요.

제거: Windows의 설치된 앱에서 DownloadVersionManager를 제거하고, 각 브라우저에서 확장을 제거합니다. 다운로드와 _history는 지우지 않습니다.

일반 배포에는 Chrome Web Store/Edge Add-ons의 검토·게시와 실제 통합 설치 검증이 필요합니다. 평가판은 그 관문을 충족했다고 표시하지 않습니다.
