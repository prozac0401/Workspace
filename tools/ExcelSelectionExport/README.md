# 선택범위 내보내기 · 사용 안내

Excel에서 선택한 범위의 보이는 행과 열만 **저장 전 새 통합문서**로 만듭니다. 명단 비교와 별도로 설치하고 제거하는 제품입니다.

현재 버전은 **0.1.0-rc.10 · 서명되지 않은 평가판**입니다. Windows 11 x64와 PC에 설치된 Excel을 대상으로 합니다. 현재 PC의 Excel x64에서 검증을 진행하고 있으며, Excel x86은 빌드와 실제 호환 검증을 구분합니다. x86 Excel 실제 시험, 격리 사용자 환경, Windows 재로그인·재부팅 시험은 완료되지 않았습니다. Mac·브라우저용 Excel은 지원하지 않습니다.

## 설치하기

1. Excel의 **파일 → 계정 → Excel 정보**에서 32비트인지 64비트인지 확인합니다.
2. Excel에 맞는 **ExcelSelectionExport-0.1.0-rc.10-x86-Setup.exe** 또는 **ExcelSelectionExport-0.1.0-rc.10-x64-Setup.exe**를 실행하고 안내에 따라 설치합니다.
3. Excel을 평소처럼 엽니다. 이미 열려 있었다면 작업을 저장하고 모든 Excel 창을 닫은 뒤 다시 엽니다.

이후에는 Excel을 시작할 때 메뉴가 자동으로 준비됩니다. Alt+F8·Alt+F11, VBA 등록·실행, 매크로 허용, 추가 기능 수동 체크, 매번 별도 실행 프로그램을 여는 단계는 없습니다. 시작이나 셀 선택만으로 내보내기가 실행되지는 않습니다.

현재 Windows 계정에 설치하며 관리자 권한을 요구하지 않습니다. .NET Framework 4.8 이상이 필요하고 현재 시험 PC에는 4.8.1이 설치되어 있습니다. Python이나 개발 SDK는 필요하지 않습니다. 회사 정책이 추가 기능 또는 서명 없는 프로그램을 차단하면 회사의 승인된 설치 절차를 따르세요. 이 설치기는 보안 설정을 낮추거나 추가 기능 차단을 해제하지 않습니다.

## 새 Excel로 내보내기

1. 한 시트에서 필요한 **직사각형 셀 범위**를 선택합니다.
2. 선택한 셀 안에서 우클릭합니다.
3. **선택범위 내보내기 → 새 Excel로**를 누릅니다.
4. 결과를 확인하고 필요할 때 Excel의 **저장**을 사용합니다.

한 셀이나 가로·세로 목록도 선택할 수 있습니다. 제목·합계가 필요하면 함께 선택하세요. 프로그램이 제목을 추정해서 넣거나 내용을 정렬하지 않습니다. 저장 위치는 실행할 때 묻지 않습니다.

필터와 수동 숨김으로 가려진 행·열은 빠지고 나머지가 원래 순서대로 연결됩니다. 선택에 포함된 빈칸·빈 행·빈 열은 구조를 유지합니다. 화면 밖으로 스크롤된 셀은 숨긴 셀이 아니므로 포함됩니다.

수식은 Excel이 실행 시점에 가지고 있는 계산 결과로 바뀝니다. 원본의 날짜 기준, 값의 타입, 앞자리 0, 숫자 표시 형식과 기본 글꼴·색·배경·테두리·정렬·줄바꿈·너비·높이를 유지하도록 구현했습니다. 셀 전체에 적용된 위 첨자·아래 첨자도 유지하며, 한 셀 안에서 적용 상태가 섞인 경우에는 안내 후 중단합니다. 계산 중에는 작업을 시작하지 않으며 원본 재계산이나 외부 연결 갱신을 강제하지 않습니다. 수동 계산 모드에서 재계산을 기다리는 셀은 현재 남아 있는 계산 결과로 내보냅니다. 그 결과가 최신이라고 보장하지 않습니다.

원본의 실행 취소 기록에 영향을 주지 않도록 결과의 값과 서식은 별도 Excel 작업 인스턴스에서 만듭니다. 작업 중 사용자 임시 폴더에 중간 파일을 저장하고, 같은 원본 Excel에 저장 전 새 결과를 연 뒤 중간 파일을 삭제합니다. 작업 중 Excel이나 Windows가 강제 종료되면 중간 파일이 남을 수 있습니다. 결과는 아직 저장하지 않은 문서로 표시하므로 닫을 때 Excel의 저장 확인이 나옵니다.

## 알아둘 제한

- 떨어진 범위를 Ctrl로 여러 개 선택하거나 전체 행·열·시트를 선택할 수 없습니다. 필요한 셀 범위 하나로 다시 선택하세요. 여러 시트를 함께 선택한 상태, 차트·개체 선택, 보호된 보기에서도 실행할 수 없습니다.
- 병합 셀은 병합 영역 전체가 선택되어 있고 그 행·열이 모두 보일 때만 유지합니다. 일부만 선택되거나 숨김 때문에 잘린 병합은 안내 후 중단합니다.
- 원본의 다른 시트·매크로·외부 연결·정의 이름·메모·댓글·하이퍼링크·입력 제한 규칙은 옮기지 않습니다. 도형·차트·이미지·스파크라인도 대상이 아닙니다.
- 조건부 서식의 현재 글자색·배경색 등은 정적 서식으로 옮기고 규칙 자체는 옮기지 않습니다. 데이터 막대·아이콘은 제외된다는 안내를 확인한 뒤 진행할 수 있습니다. 그라데이션 배경과 한 셀 안에서 글꼴 등이 섞인 서식은 현재 지원하지 않아 해당 셀을 제외하도록 안내합니다.
- 선택 범위는 숨긴 셀 포함 **1,000,000칸**, 보이는 결과는 **100,000칸**, 원문 문자열 합계는 **10,000,000자**까지입니다. 초과하면 범위를 나누어 선택해야 하며 데이터를 조용히 잘라내지 않습니다.
- 보이는 셀이 20,000개를 넘으면 실행 전에 한 번 확인합니다. 오래 걸리는 작업에는 진행 단계와 **취소**가 표시됩니다. 실패·취소 시에는 이번에 만든 불완전한 결과만 정리합니다.
- Excel의 이벤트 처리가 꺼진 상태에서는 원본 변경을 감지할 수 없어 중단합니다. 작업을 저장하고 Excel을 다시 시작한 뒤 시도하세요. rc.9에서는 내보낸 뒤 원본의 실행 취소가 비활성화됐습니다. rc.10은 이를 막도록 출력 생성 방식을 바꿨으며, 실제 확인 범위는 아래 검증 상태를 따릅니다.

## 업데이트·제거하기

새 버전 설치 파일을 실행하면 제품의 별도 버전 폴더에 설치합니다. 이미 열린 Excel은 기존 코드를 계속 사용하므로 작업을 저장하고 Excel을 모두 닫았다가 다시 열어야 새 버전이 적용됩니다. 같은 버전을 다시 설치하거나 제거할 때는 먼저 모든 Excel 창을 닫아야 합니다. 설치기가 열린 문서를 강제로 닫거나 저장하지 않습니다.

제거는 **Windows 설정 → 앱 → 설치된 앱 → 선택범위 내보내기 → 제거**를 사용합니다. 사용자가 저장한 결과와 원본 Excel 파일은 제거 대상이 아닙니다. 명단 비교의 메뉴·설치·제거 항목도 별도입니다.

## 현재 검증 상태

rc.10은 원본 Undo 손실을 수정하는 평가 버전입니다. 현재 PC의 Excel x64 16.0 Build 20326에서 원인을 단계별로 조사했습니다. 원본과 같은 Excel 인스턴스에서 새 결과의 시트 이름·기본 글꼴·셀 값을 쓰는 과정이 원본 Undo를 비활성화했습니다. 완성한 파일을 바탕으로 저장 전 새 통합문서를 만드는 경로에서는 Undo가 활성 상태를 유지했습니다.

rc.10 제품 빌드·설치·실제 메뉴와 여러 단계 실행 취소 시험의 최종 판정은 대기 중입니다. 조사용 개별 동작의 결과를 완성된 제품의 검증 결과로 간주하지 않습니다. rc.9의 실제 Undo 손실과 API 시험 뒤 창 없는 Excel 잔존 실패 기록도 보존합니다. 상세 실행 범위와 미실행 항목은 개발 원본의 인수 대응표와 2026-09-26 Undo 조사·수정 검증 기록을 확인하세요.
