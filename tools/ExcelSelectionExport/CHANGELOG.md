# 선택범위 내보내기 · 변경 기록

## 0.1.0-rc.9 · 2026-09-24 · 서명되지 않은 평가판

- 완료 단계에서 Excel 전역 상태 복원이 실패하면 성공으로 처리하거나 결과 창을 활성화하지 않도록 보완합니다. 오류 정리 경로에서 복원을 다시 시도합니다.
- 이 문서의 검증 내용은 패키지 작성 시점의 결과이며, 이후 실제 시험은 별도 평가 검증 기록에서 패키지 버전·시험 방식별로 확인합니다. 이전 패키지의 통과 결과를 rc.9의 인수 완료로 간주하지 않습니다.

## 0.1.0-rc.8 · 2026-09-24 · 서명되지 않은 평가판

- 새 결과 통합문서를 만든 뒤 출력 단계에서 Interactive를 다시 꺼 입력을 차단하도록 보완합니다. 창 생성 전에 원래 상태를 복원하는 rc.7의 순서를 유지하며 작업 중 원본 변경 방지를 완성하기 위한 변경입니다.
- rc.7의 현재 PC 실제 메뉴 실행에서 새 결과 창이 자동으로 앞에 표시되는 것을 처음 확인했습니다. 이 결과를 전체 인수 완료나 rc.8의 검증 결과로 간주하지 않습니다.
- rc.8은 빌드 검사 183개를 통과했고 x64 설치 종료 코드 0을 확인했습니다. rc.8 실제 Excel 시험은 미실행이며 최종 rc.9 패키지 평가로 구분합니다.

## 0.1.0-rc.7 · 2026-09-24 · 서명되지 않은 평가판

- 새 결과 통합문서를 만들기 전에 Excel의 Interactive·ScreenUpdating 상태를 복원하고, 생성 후 출력 작업 동안 화면 갱신을 억제하도록 순서를 조정합니다. rc.6 실제 메뉴 실행에서 원본 창이 계속 앞에 남던 문제에 대한 수정입니다.
- rc.6의 데이터 진단은 결과 창 활성화 인수 시험과 별도로 판정합니다. rc.7 설치 콜백의 기능 시험 11개 사례·930개 검사, 실제 메뉴의 결과 창 표시와 정상 종료를 현재 PC에서 확인했습니다.

## 0.1.0-rc.6 · 2026-09-24 · 서명되지 않은 평가판

- 메뉴 클릭 시 원본 통합문서·시트·선택 범위를 확보하고, Office의 메뉴 처리가 끝난 뒤 같은 원본으로 내보내기를 시작하도록 실행 순서를 수정했습니다. 메뉴 콜백 종료 후 원본 창이 결과를 가리던 문제를 해결하기 위한 변경입니다.
- 취소 시험 드라이버가 비동기 완료를 최대 120초 기다리도록 보완했습니다. 종료를 확인하지 못하면 진행 중 원본을 닫지 않고 UI 확인과 수동 정리가 필요하다고 기록합니다.
- rc.6의 빌드·설치·실제 메뉴·기능·취소 시험 판정은 아직 대기 중입니다. 이전 버전의 확인 결과를 이번 버전 통과로 간주하지 않습니다.

## 0.1.0-rc.5 · 2026-09-24 · 서명되지 않은 평가판

- 셀 전체에 적용된 위 첨자·아래 첨자를 결과에 유지하고, 한 셀 안에서 적용 상태가 섞인 경우에는 안내 후 중단하도록 보완했습니다.
- 설치 보존 시험은 Windows의 알려진 로컬 앱 데이터 폴더를 사용하며, 지문이 달라지면 해당 검사 범위를 기록합니다. 이 개발 시험 도구는 사용자 설치 과정에 필요하지 않습니다.
- rc.4의 설치된 콜백에서 구조와 값 타입 시험을 통과했으나 전체 인수 판정은 아직 완료되지 않았습니다.
- Office의 메뉴 처리가 끝난 뒤 검증된 결과 창을 활성화하도록 보완했습니다. 원본 창이 다시 앞에 오던 실제 메뉴 실행 문제에 대한 수정입니다.
- 각 패키지의 빌드·설치·실제 Excel 검증 결과와 미실행 항목은 별도 평가 검증 기록에서 구분합니다.

## 0.1.0-rc.4 · 2026-09-24 · 서명되지 않은 평가판

- 숨김 상태가 섞인 여러 행의 일괄 Hidden 조회에 의존하지 않고 각 행의 숨김 여부를 확인하도록 수정했습니다. 가시 행 계획을 확정한 뒤 해당 값만 읽습니다.
- 표시된 숫자 형식을 NumberFormatLocal로 읽고 결과에도 NumberFormatLocal로 적용해 한국어 일반 형식 등 로캘별 형식을 처리하도록 수정했습니다.
- 실제 Excel 기능 시험의 합성 자료와 값·서식·원본 상태 검증을 보완했습니다.
- rc.4 빌드·설치·실제 Excel 시험 판정은 아직 완료되지 않았습니다. 이전 버전의 확인 결과와 이번 버전의 결과를 구분합니다.

## 0.1.0-rc.3 · 2026-09-24 · 서명되지 않은 평가판

- 실제 Excel 시험에서 발견한 COM helper 동적 바인딩 오류와 완료 후 결과 창 활성화 순서를 수정했습니다.
- 수동 계산에서 재계산을 기다리는 셀의 현재 결과를 재계산 없이 읽습니다. 실제 계산 진행 중에는 계속 중단합니다.
- 원본 읽기·출력·값 검증을 최대 256셀 단위로 나누고 상태 복원 회귀 검사를 추가했습니다.
- 오류 안내를 해당 Excel 창에 연결하고 메모리에만 유지하는 상세 오류 진단을 제공합니다.
- 설치된 Excel 버전에 해당하는 정책과 비활성화 기록을 검사해 과거 Office 설정의 오차단을 방지합니다.
- 실제 Excel 기능·잘못된 선택 시험 도구와 설치 수명주기 시험을 포함합니다. 실제 결과와 미실행 항목은 별도 평가 검증 기록에서 구분합니다.

## 0.1.0-rc.2 · 2026-09-24 · 서명되지 않은 평가판

- 현재 수정본의 재검증용 패키지를 별도 버전 경로에 설치하도록 버전을 구분했습니다. 이미 열린 Excel의 이전 평가 DLL을 덮어쓰지 않습니다.
- 설치 payload에 한국어 사용 안내와 변경 기록을 포함합니다. 설치 후 별도 인터넷 연결 없이 기본 설치·사용·제거 조건을 읽을 수 있습니다.
- 종료 후 잔류 프로세스 문제와 기능 시험의 최종 결과는 아직 확정되지 않았습니다. 아래 rc.1의 미실행·배포 승인 제한을 유지하며 통과 범위를 확대하지 않습니다.

## 0.1.0-rc.1 · 2026-09-24 · 서명되지 않은 평가판

독립 제품의 첫 기능 평가 버전입니다. 구현·패키징 상태와 실제 시험 판정은 구분하며 전체 인수·상용 배포 승인을 뜻하지 않습니다.

### 추가

- C# .NET Framework 기반 설치형 Excel COM 추가 기능. 현재 사용자 등록으로 Excel 시작 시 셀·Table 우클릭 메뉴를 준비하고 메뉴 클릭 때만 내보냅니다.
- **선택범위 내보내기 → 새 Excel로**에서 보이는 행·열을 원래 순서로 연결한 저장 전 통합문서를 만듭니다. 결과 시트는 하나입니다.
- 값·문자열·Excel 오류·수식 계산 결과, 1900/1904 날짜 기준, 기본 표시 서식, 완전히 포함된 병합의 재구성을 구현했습니다.
- 입력 범위·보이는 셀·문자열 상한, 대량 작업 확인, 진행 단계·취소, 원본 변경 감지, 실패 시 불완전한 결과 정리를 추가했습니다.
- Ctrl 다중 범위, 전체 행·열, 여러 시트, 보호된 보기, 잘린 병합, 그라데이션 및 셀 내부 혼합 글꼴 등 지원하지 않는 조건의 안내를 추가했습니다.
- 독립 x86/x64 평가 설치기, 버전별 payload 경로, 비트수·런타임·정책 사전검사와 별도 제거 항목을 추가했습니다. 보안 설정·신뢰 위치·인증서 신뢰를 변경하지 않습니다.
- 원작업지시 원문, ADR, 요구사항 대응표, 계획 모델 시험 및 실제 Excel API 통합시험 harness를 추가했습니다.

### 초기 M1에서 조정

- 최소 메뉴 콜백 확인용 안내를 실제 내보내기 명령으로 교체했습니다.
- Office 연결 인터페이스의 SAFEARRAY 매개변수를 명시했습니다. 연결 해제 시 COM 참조 정리를 보완했으며 Excel 종료 후 잔류 프로세스 문제의 재검증이 필요합니다.
- 지역별 숫자 표시 형식을 고려해 원본 형식을 읽어 사용합니다. 작은따옴표로 시작하는 문자열과 실제 Excel 오류의 형식 보존을 처리합니다.
- 신규 버전은 별도 폴더에 설치해 이미 열린 Excel의 DLL을 덮어쓰지 않습니다. 기존 Excel에는 재시작 후 새 버전이 적용됩니다. 같은 버전 재설치·제거는 열린 Excel이 있으면 중단합니다.

### 검증과 남은 제한

- M1 최소 빌드의 현재 PC 설치·정상 시작·실제 우클릭 메뉴 콜백을 확인했습니다. 종료 후 잔류 프로세스가 발견되어 수정·재검증 중이며 전체 자동 로드 게이트 통과로 간주하지 않습니다.
- 기능 버전의 데이터·복구·성능·공존·설치 수명주기 검증은 진행 중입니다. 개발 원본의 `docs/tools/excel-selection-export/acceptance.md`에 세부 결과를 기록합니다.
- Excel x86 실제 실행, 깨끗한 사용자 프로필/격리 VM, Windows 재로그인·재부팅은 미실행입니다. 현재 Excel x64 시험만으로 x86 지원을 확정하지 않습니다.
- .NET Framework 4.8 이상이 필요합니다. 코드 서명과 조직별 배포 승인은 미확정입니다. 공개 사이트나 GitHub 릴리스에 게시하지 않았습니다.
