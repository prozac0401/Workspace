# 변경 이력

## 0.1.1 · 미배포 · 수정 구현 및 실제 종료 재검증 대기

- 0.1.0 게시 후 실제 메뉴를 사용하고 Excel을 닫을 때 종료 실패가 합성 시나리오에서 3회 확인됐습니다. 붙여넣기만 수행한 경로도 포함합니다.
- COM callback·연결 인자·대기 작업과 엔진의 임시/준비된 작업 참조를 명시적으로 정리하는 수명 관리를 보완했습니다. 값 쓰기·숨긴 셀 보존·실패 복구 정책은 유지합니다.
- 동일 작업의 재진입 거절이 바깥 작업을 해제하지 않도록 보호하고, 이전 연결 정리가 실패해도 새 연결 인자를 정리합니다. 이전 Undo 기록 해제 실패 이후 복구와 소유권 폐기도 보완했습니다.
- 수정본의 실제 설치·사용 후 종료는 아직 검증하지 못했습니다. 남은 Excel 프로세스로 설치가 차단되어 가드를 유지합니다. 소스 변경을 종료 오류 해결이나 공개 완료로 표시하지 않습니다.

## 0.1.0 · 2026-09-24 게시 후 보류

종료 실패 확인 후 릴리스를 초안(draft)으로 바꾸고 최신 릴리스 표시를 해제했습니다. 태그는 유지하며 아래 내용은 이 버전의 변경 이력입니다. 현재 공개 배포가 완료된 상태로 해석하지 않습니다.

- 독립 Windows Excel COM 추가 기능으로 제공합니다. 설치 후 Excel을 평소처럼 실행하면 우클릭 메뉴가 자동으로 준비됩니다. 메뉴·설치·제거·되돌리기 기록을 다른 Excel 도구와 분리합니다.
- 한 행 또는 한 열에서 복사한 값을 선택한 한 열의 보이는 칸에 순서대로 넣습니다. 필터·수동 숨김 행과 선택 밖 셀은 유지하고, 원본과 대상의 개수가 다르면 수정 없이 중단합니다.
- 빈칸의 위치와 값 종류를 유지하고 수식은 계산 결과로 넣습니다. 대상의 표시 형식과 서식을 유지하며, 내용을 지우거나 기존 수식을 덮어쓸 때는 실행 전에 확인합니다.
- 구조화 복사 정보와 Excel의 네이티브 복사 정보를 함께 읽어 날짜·시간의 원래 숫자 값을 확인합니다. 날짜 문자열에서 값을 추측하지 않으며, 정보가 없거나 항목 대응이 다르면 중단합니다. 1900·1904 날짜 체계 사이를 자동 보정하지 않습니다.
- 최근 성공한 작업 한 번을 되돌리는 우클릭 메뉴와 쓰기 실패 시 복구 절차를 추가했습니다. 이 도구로 값을 쓰면 Excel의 기존 Ctrl+Z 기록이 지워질 수 있으므로 자체 최근 1회 되돌리기 메뉴를 사용합니다. 선택·편집·파일 전환·구조 변경 뒤에는 복구를 제한하며, 기존 정렬 설정이 남아 있는 시트나 표에서는 즉시 되돌리기도 제공하지 않습니다.
- 빈칸으로 내용만 지우고, 일반 값·수식·표시 형식을 함께 복구하도록 처리했습니다. 연속된 대상의 검사·백업·쓰기·복구를 묶고 데이터 유효성 검사 규칙은 선택당 한 번 조회합니다.
- 우클릭 메뉴의 기본 항목 앞에 두 도구 명령을 배치해 작은 화면에서도 찾기 쉽게 했습니다. 중복 연결과 연결 도중 실패 시 정리를 추가했습니다.
- 한글·공백·작은따옴표·퍼센트·#이 포함된 설치 경로를 CLR이 해석하는 파일 주소 형식으로 등록합니다. 실행 중인 Excel이 있으면 설치·제거를 중단하고, 제거 시 자기 등록과 소유 파일만 정리합니다.
- Windows 사용자별 설치 ZIP과 파일 해시, 설치·사용·지원 범위·되돌리기·제거 안내를 제공합니다. 설치 파일에는 코드 서명이 없으며 Office와 조직의 보안 정책을 변경하지 않습니다.

사용 방법과 지원 범위는 [README](README.md), 세부 근거와 이력은 [시험 보고서](docs/test-report.md) 및 [배포 점검](docs/release-checklist.md)에 기록합니다.
