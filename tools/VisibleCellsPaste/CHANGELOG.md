# 변경 이력

## 0.1.1 · 2026-09-26

- 0.1.0 실제 메뉴 사용 후 종료 실패 3회에 대응해 임시 COM 참조·준비된 작업·callback의 소유권과 정리를 명시했습니다. 재진입 거절이 바깥 작업을 해제하지 않도록 하고 이전 Undo 해제 실패·재연결 실패도 보완했습니다.
- 초기 수정 설치본은 실제 업그레이드와 붙여넣기만 / 붙여넣기·Undo 두 UI 종료를 통과했습니다. 그러나 후속 최종 후보 `8741b19f…`는 정상 자동 로드·붙여넣기 성공 후 2026-09-26 08:32:09 UTC에 종료 충돌이 재현됐습니다. 새 덤프가 없어 원인은 확정하지 않았으며 당시 공개를 보류했습니다.
- 실제 59개 기능·복구 본문은 통과했으나 종료 wrapper의 상태바 타입 복원이 실패했습니다. 현재 Excel에서 Boolean false 할당이 문자열 FALSE로 읽히는 현상을 대조했고, 공용 복원 함수가 실제 Boolean false를 검증하고 필요한 경우 확인된 빈 문자열 reset을 적용하도록 보완했습니다. 문자열 값은 그대로 보존하고 복원 실패는 후속 쓰기를 차단합니다.
- 종료 재현 뒤 ComEventsHelper를 전용 IDispatch 이벤트 관찰자로 바꿔 사용하지 않는 이벤트 인자의 RCW 생성을 피하도록 했습니다. 기존 14개 이벤트만 관찰하고 Cancel 인자는 읽거나 바꾸지 않으며 자기 connection point·cookie만 정리합니다. 이 변경으로 충돌 원인이 입증되거나 해결됐다고 판정하지 않습니다.
- 연결 때 받은 Application 참조의 단일 소유권, IDTExtensibility2 custom의 [In] 계약, 실행 중 재진입한 연결 종료의 지연 정리를 보완했습니다. 값 쓰기·숨긴 셀 보존·복구 정책은 유지합니다.
- 종료 실패 후보까지의 전체 자동 검사 206개와 R17 실제 클립보드 4종·8회 거절은 통과했습니다. 실제 제거·메뉴 부재·재설치도 통과했으나 이후 종료는 실패했습니다.
- 후속 소스의 COM 수명·native 이벤트 검사는 x64·x86 각각 36개, 연결 수명 46개, 안내/진입 26개가 개별 통과했습니다. 후속 full-build-03의 9종 284개와 PE/COM·ZIP 내부 무결성도 통과했습니다. 실제 60개 회귀와 wrapper의 파일·선택·전역 상태 타입/값 정확 복원도 통과했고 새 생산 DLL의 R17 4종·8회 거절 불변을 확인했습니다. 잔여 프로세스 정리 후 Excel 0개에서 DLL `7080305a…`를 실제 설치했습니다. 정상 자동 메뉴로 붙여넣기와 별도 시작의 붙여넣기·즉시 Undo를 수행한 뒤 모두 저장하지 않고 닫았으며, 지연 관찰에서 프로세스 소멸·새 Excel 오류 이벤트와 WER 0개를 확인했습니다. 이 두 결과를 모든 환경의 종료 보증으로 확대하지 않습니다. 같은 DLL의 비승격 제거·재설치도 확인했으며 제거 후 자체 메뉴만 사라지고 다른 추가 기능 메뉴는 유지됐습니다. 재설치 뒤 붙여넣고 숨김을 풀어 대상값 85/90/78과 숨긴 원래값 102/103/105/106의 보존을 직접 확인했습니다. 시험 범위·제한과 실제 게시 근거는 시험 보고서·배포 점검에 기록합니다.

## 0.1.0 · 2026-09-24 게시 후 보류

종료 실패 확인 후 릴리스를 초안(draft)으로 바꾸고 최신 릴리스 표시를 해제했습니다. 태그는 유지하며 아래 내용은 이 버전의 변경 이력입니다. 현재 공개 배포가 완료된 상태로 해석하지 않습니다.

- 독립 Windows Excel COM 추가 기능으로 제공합니다. 설치 후 Excel을 평소처럼 실행하면 우클릭 메뉴가 자동으로 준비됩니다. 메뉴·설치·제거·되돌리기 기록을 다른 Excel 도구와 분리합니다.
- 한 행 또는 한 열에서 복사한 값을 선택한 한 열의 보이는 칸에 순서대로 넣습니다. 필터·수동 숨김 행과 선택 밖 셀은 유지하고, 원본과 대상의 개수가 다르면 수정 없이 중단합니다.
- 빈칸의 위치와 값 종류를 유지하고 수식은 계산 결과로 넣습니다. 대상의 표시 형식과 서식을 유지하며, 내용을 지우거나 기존 수식을 덮어쓸 때는 실행 전에 확인합니다.
- 구조화 복사 정보와 Excel의 네이티브 복사 정보를 함께 읽어 날짜·시간의 원래 숫자 값을 확인합니다. 날짜 문자열에서 값을 추측하지 않으며, 정보가 없거나 항목 대응이 다르면 중단합니다. 1900·1904 날짜 체계 사이를 자동 보정하지 않습니다.
- 최근 성공한 작업 한 번을 되돌리는 우클릭 메뉴와 쓰기 실패 시 복구 절차를 추가했습니다. 이 도구로 값을 쓰면 Excel의 기존 Ctrl+Z 기록이 지워질 수 있으므로 자체 최근 1회 되돌리기 메뉴를 사용합니다. 선택·편집·파일 전환·구조 변경 뒤에는 복구를 제한하며, 기존 정렬 설정이 남아 있는 시트나 표에서는 즉시 되돌리기도 제공하지 않습니다.
- 빈칸으로 내용만 지우고, 일반 값·수식·표시 형식을 함께 복구하도록 처리했습니다. 연속된 대상의 검사·백업·쓰기·복구를 묶고 데이터 유효성 검사 규칙은 선택당 한 번 조회합니다.
- 우클릭 메뉴의 기본 항목 앞에 두 도구 명령을 배치해 작은 화면에서도 찾기 쉽게 했습니다. 중복 연결과 연결 도중 실패 시 정리를 추가했습니다.
- 한글·공백·작은따옴표·퍼센트·#이 포함된 설치 경로를 CLR이 해석하는 파일 주소 형식으로 등록합니다. 실행 중인 Excel이 있으면 설치·제거를 중단하고, 제거 시 자기 등록과 소유 파일만 정리합니다.
- Windows 사용자별 설치 ZIP과 파일 해시, 설치·사용·지원 범위·되돌리기·제거 안내를 제공합니다. 설치 파일에는 코드 서명이 없으며 Office와 조직의 보안 정책을 변경하지 않습니다.

사용 방법과 지원 범위는 [README](README.md), 세부 근거와 이력은 [시험 보고서](docs/test-report.md) 및 [배포 점검](docs/release-checklist.md)에 기록합니다.
