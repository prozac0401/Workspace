# 보이는 칸 붙여넣기

**버전 0.2.0-rc.1 · 서명 없는 사전 공개 버전**

여러 행·열 영역을 복사해 대상의 보이는 행·열에 같은 모양으로 붙여넣습니다. Windows Installer의 x64·x86 MSI로 현재 사용자에게 설치합니다. 이번 결과와 실제 클립보드·설치 검증 범위는 [시험 보고서](docs/test-report.md#msi-020rc1)를 확인하세요. 아래 0.1.2·0.1.1 결과는 당시 이력이며 새 MSI의 통과를 대신하지 않습니다.

### 이전 버전 확인 이력

0.1.2는 붙여넣기 뒤 자체 되돌리기를 제공하지 못하는 경우와 되돌리기 거절의 변경 범위를 더 정확히 안내합니다. Windows 제작·자동 검사 302개와 후보 ZIP 무결성 검사가 통과했습니다. 현재 생산 DLL을 시험 전용 위치에 설치한 뒤 정상 Excel 시작·실제 메뉴 붙여넣기와 Undo 거절 안내·저장하지 않은 자연 종료·시험 설치 제거를 좁은 합성 흐름에서 확인했습니다. 기존 안전 조건이나 지원 범위를 넓히는 변경은 아닙니다. 앞선 외부 시험 호스트의 종료 실패와 확인 범위는 [시험 보고서](docs/test-report.md)에 별도로 보존합니다.

다음은 0.1.1의 확인 이력이며 0.1.2의 실제 시험 결과를 대신하지 않습니다.

2026-09-26 후속 수정본의 실제 설치·자동 로드·붙여넣기·되돌리기와 사용 후 종료를 확인했습니다. 제거·재설치 후 실제 붙여넣기에서도 숨긴 셀의 원래 값이 유지됐습니다. 확인한 환경과 이전 후보의 종료 실패 이력은 [시험 보고서](docs/test-report.md), 패키지와 게시 근거는 [배포 점검](docs/release-checklist.md)을 따릅니다.

현재 버전은 Excel에서 복사한 영역의 값을 선택한 영역의 보이는 행·열에 순서대로 넣습니다. 필터·행 숨김·열 숨김과 선택 밖 셀을 유지합니다. 원본과 대상의 보이는 행 수·열 수가 각각 다르면 아무 셀도 바꾸지 않습니다.

## 설치하기

Windows 데스크톱 Excel과 .NET Framework 4.8이 필요합니다. 웹용 Excel과 Mac용 Excel은 지원하지 않습니다.

1. 열려 있는 Excel 문서를 저장하고 모든 Excel을 종료합니다.
2. 이전 EXE·ZIP 또는 다른 MSI 버전으로 설치했다면 Windows **설치된 앱**에서 기존 **보이는 칸 붙여넣기**를 먼저 제거합니다. 새 MSI가 기존 설치를 자동으로 전환하지 않습니다.
3. Excel **파일 → 계정 → Excel 정보**의 64비트·32비트를 확인하고 맞는 MSI를 실행합니다. 64비트 Excel은 `x64`, 32비트 Excel은 `x86`을 선택합니다. Windows 비트 수가 아니라 Excel 비트 수 기준입니다.
4. 평소처럼 Excel을 실행합니다. 셀을 우클릭하면 **보이는 칸에 붙여넣기**와 **마지막 붙여넣기 되돌리기**가 나타납니다.

MSI의 기본 위치는 현재 사용자 계정의 `%LOCALAPPDATA%\Programs\VisibleCellsPaste`이며 HKCU에 등록합니다. 관리자 권한, VBA 편집기, 모듈 가져오기, 매크로 수동 실행은 필요하지 않습니다. 이전 ZIP·EXE의 기본 위치 `%LOCALAPPDATA%\VisibleCellsPaste`와 구분합니다.

Excel 프로세스가 실행 중이면 설치·제거를 중단합니다. 설치 프로그램이 Excel을 강제로 종료하거나 통합문서를 저장하지 않습니다. 메뉴가 없으면 Excel이 정상 종료됐는지 확인하고 다시 실행하세요. 자세한 확인 순서는 [설치·제거 안내](docs/install-security.md)를 따릅니다.

## 보이는 칸에 붙여넣기

1. 원본 Excel에서 **연속된 사각형 영역**을 선택하고 **Ctrl+C**로 복사합니다. 한 행·한 열·한 셀도 가능합니다. 원본 Excel은 열어 둡니다.
2. 대상에서 값을 넣을 **연속된 사각형 영역 전체**를 선택합니다. 숨김·필터를 뺀 행 수·열 수가 원본과 각각 같아야 합니다.
3. 선택 안을 우클릭하고 **보이는 칸에 붙여넣기**를 누릅니다.
4. 기존 수식을 덮어쓰거나 빈칸으로 내용을 지우는 경우에는 안내된 개수를 확인하고 진행합니다.

각 행은 왼쪽에서 오른쪽으로, 행은 위에서 아래로 대응합니다. 보이는 원본이 `2행 × 2열`이고 대상 `E2:G4`에서 3행과 F열을 숨겼다면 첫 행은 E2·G2, 둘째 행은 E4·G4에 들어갑니다. 숨긴 셀의 내용은 그대로 두고 빈칸의 위치도 유지합니다.

`2행 × 3열`을 `3행 × 2열`에 넣으면 총 6칸이어도 모양이 달라 수정 없이 중단합니다. 기존 **한 행 원본을 한 열 대상에 위에서 아래로 넣는 방법**은 유지합니다. 한 값을 반복하거나 시작 셀에서 대상을 자동 확장하지 않습니다. 스크롤 밖의 일반 셀은 숨긴 셀이 아니므로 대상에 포함됩니다.

**복사한 순서대로 입력합니다.** 이름이나 사번을 찾아 연결하지 않습니다. 원본과 대상의 개수가 같아도 사람의 순서까지 일치한다는 뜻은 아닙니다.

## 값·빈칸·날짜

- 숫자, 글자, 참·거짓, 실제 빈칸과 지원하는 Excel 오류값을 처리합니다. `00123` 같은 문자열, 긴 식별번호, 공백·한글·셀 내부 탭과 줄바꿈을 유지합니다.
- 실제 빈칸도 한 항목입니다. 처음·가운데·마지막 빈칸은 대응하는 대상의 내용만 비웁니다. 수식 `=""`의 빈 문자열 결과도 항목 위치를 유지합니다. 빈 문자열은 값으로 입력할 때 실제 빈칸으로 저장될 수 있습니다.
- 수식은 **복사된 계산 결과**를 사용합니다. 수식 자체를 넣거나 원본을 다시 계산하지 않습니다. 기존 대상의 일반 수식을 덮어쓸 때는 실행 전에 확인합니다.
- 대상의 숫자 표시 형식·글꼴·배경·테두리·조건부 서식을 유지합니다. 실제 숫자 `123`이 표시 형식 때문에 `00123`으로 보이더라도 넣는 값은 숫자 `123`입니다.
- 날짜·시간·백분율은 원래 숫자 값을 사용합니다. 날짜·시간의 원래 숫자 값은 Excel 클립보드의 추가 복사 정보와 항목 대응을 함께 확인합니다. 값이나 대응을 확정할 수 없으면 아무 셀도 바꾸지 않고 중단합니다. 표시된 날짜 문자열을 해석해 일련번호를 추측하지 않습니다.
- **1900·1904 날짜 체계 사이의 자동 보정은 하지 않습니다.** 원래 숫자 값을 그대로 넣으므로 원본과 대상의 날짜 체계나 표시 형식이 다르면 보이는 날짜가 달라질 수 있습니다.

날짜·시간 처리 가능 여부는 Excel이 복사 정보에 제공한 원래 숫자 값에 따라 달라집니다. 모든 Excel 버전이나 복사 형식에서 읽을 수 있다는 뜻은 아닙니다. 자세한 입력 조건은 [클립보드 호환성](docs/clipboard-compatibility.md)을 확인하세요.

## 지원 범위와 크기

원본은 Excel에서 Ctrl+C로 복사한 연속 영역이어야 합니다. 다른 통합문서나 Excel 창에서 복사할 수 있습니다. 원본 Excel을 열어 두고, 복사 출처와 일반 복사 상태를 확인할 수 있도록 해 주세요. 원본 숨김은 복사 정보의 행·열 메타데이터로 판단하며 현재 원본 셀을 다시 읽지 않습니다. 모양·타입·빈칸을 확정할 수 없으면 수정 없이 중단합니다.

다음 범위는 처리하지 않습니다.

- 전체 행·열·시트, 직접 만든 여러 영역 선택, 보이는 셀이 없는 영역, 보이는 행·열 모양이 다른 대상. 기존 한 행 원본→한 열 대상만 방향 전환을 허용합니다.
- 병합 셀, 보호된 시트, 읽기 전용 파일, 제한된 보기, 여러 시트가 함께 선택된 상태.
- 배열 수식·동적 배열 결과 범위, 피벗테이블, 데이터 유효성 검사 규칙이 있는 보이는 대상.
- 잘라내기, 일반 텍스트·그림·파일·웹 표 복사, 지원하지 않는 오류 종류(예: `#SPILL!`, `#CALC!`).

표는 값만 있는 데이터 열을 대상으로 합니다. 수정할 표 열의 숨긴 행에 수식이 있어도 중단합니다. 수정하지 않는 숨긴 계산 열은 별도의 보이는 값 열 작업을 막지 않습니다. 다른 프로그램이나 추가 기능이 동시에 셀·행·정렬을 변경하는 동안에는 사용하지 마세요.

한 번에 복사 항목과 보이는 대상 각각 **50,000개**, 선택 범위 **200,000셀**, 클립보드 **32 MiB**, 보이는 구간 **20,000개**까지 처리합니다. 복사 정보에 숨긴 셀을 포함하면 숨김 제거 전 원본 행×열도 50,000칸 이하여야 합니다. 5,000칸 또는 1,000구간부터 진행 여부를 확인합니다. 숨긴 행·열로 구간이 나뉘면 같은 개수의 연속 범위보다 오래 걸릴 수 있습니다.

## 마지막 작업 되돌리기

붙여넣은 직후 **같은 선택을 유지한 채** 우클릭하고 **마지막 붙여넣기 되돌리기**를 누릅니다. 이 도구로 마지막에 성공한 작업 한 번의 원래 값과 수식을 같은 Excel 프로세스의 메모리에 보관합니다.

파일 닫기·재시작·선택 변경·편집·시트 또는 통합문서 전환·구조 변경 뒤에는 되돌리기가 제한됩니다. 대상 위치와 실행 직후 상태를 안전하게 확인할 수 없으면 중단합니다. 다른 파일 뒤에서 조용히 복구하지 않습니다.

**기존 정렬 설정이 남아 있는 시트나 그 안의 표에서는 즉시 되돌리기도 제공하지 않습니다.** 정렬로 위치가 바뀐 행에 잘못 복구하는 일을 막기 위한 조건입니다.

붙여넣기 직후 자체 되돌리기를 제공할 수 없는 경우에는 기존 완료 상태 표시줄에 그 제한도 함께 표시합니다. 되돌리기 검사에서 거절되면 이번 되돌리기로 변경된 셀이 없음을 알립니다. 이전 붙여넣기 기록이 있고 복구 중이 아닌 경우에는 마지막 붙여넣기가 취소되지 않았다는 점도 구분해 안내합니다. 기록이 없거나 복구를 확인하지 못한 경우에 이전 붙여넣기가 그대로 남았다고 단정하지 않습니다.

이 도구로 값을 쓰면 Excel의 기존 **Ctrl+Z 기록이 지워질 수 있습니다.** 방금 실행한 작업은 이 도구의 **마지막 붙여넣기 되돌리기** 메뉴로 복구하세요. 파일을 닫은 뒤에도 남는 영구 백업 기능은 아닙니다. 자세한 조건은 [되돌리기 안전성](docs/undo-safety.md)을 확인하세요.

쓰기 도중 실패하면 작업 전 상태로 복구를 시도하고 확인합니다. 일부 복구를 확인하지 못하면 영향을 받을 수 있는 범위와 오류를 알리고 후속 쓰기를 막습니다. 자동 저장하지 않습니다. Excel 강제 종료·운영체제 장애·감지되지 않은 외부 동시 편집까지 완전 복구하는 기능은 아닙니다.

## 업데이트·제거와 보안

MSI 버전을 바꿀 때는 Excel을 저장·종료하고 Windows **설치된 앱**에서 기존 제품을 제거한 뒤 새 MSI를 실행합니다. 이 버전은 다른 MSI 버전이나 기존 EXE·ZIP을 자동 업그레이드하지 않습니다. 같은 MSI 버전의 복구·제거는 Windows Installer로 진행합니다. 이전 EXE·ZIP은 당시 배포물의 제거 방법을 사용합니다.

이 도구의 자동 로드 등록과 소유 파일만 정리합니다. 사용자 통합문서, 다른 추가 기능, PERSONAL.XLSB와 Office 보안 설정은 지우지 않습니다. MSI가 설치한 파일의 해시나 자기 등록 값이 달라졌으면 복구·제거를 중단합니다. 사용자가 추가 기능을 비활성화하여 LoadBehavior가 달라진 경우도 포함합니다. 알 수 없는 추가 파일·등록 값은 지우지 않습니다. 이 안내를 보안 설정을 자동으로 원복한다는 뜻으로 해석하지 마세요.

**설치 파일에는 코드 서명이 없습니다.** 회사에서 서명된 추가 기능이나 사전 승인을 요구하면 담당자의 배포 절차를 따르세요. 전체 매크로 허용, VBA 프로젝트 접근 허용, 신뢰 위치 확대나 보안 정책 우회를 요구하지 않습니다.

이 도구는 외부 API나 사용 통계 전송 기능을 사용하지 않습니다. 실제 업무 데이터·클립보드 내용·수식·전체 파일 경로를 기본 진단 로그에 기록하지 않습니다.

소스는 `src`, 시험은 `tests`, 제작 스크립트는 `build`, 설치 구성은 `installer`에 있습니다. 제작하려면 저장소에서 다음 명령을 실행합니다.


기본 ZIP과 `SHA256SUMS.txt`는 `artifacts/visible-cells-paste/0.2.0-rc.1`에 생성됩니다. MSI 제작·검사 명령은 저장소의 `build/README.md`를 따릅니다. 최종 사용자는 개발 SDK·Python·Node.js를 설치하거나 VBA 코드를 만들 필요가 없습니다.

## 이전 0.1.2 단일 설치 파일 이력

0.1.2의 단일 EXE는 새 버전의 ZIP과 그 SHA-256을 입력으로 제작하며 제품 버전은 0.1.2, wrapper 버전은 0.1.2.1입니다. 문서를 동결한 뒤 수행하는 최종 ZIP 재포장·wrapper 제작·검사·자산 게시 결과는 별도 `single-installer-manifest.json`과 [0.1.2 릴리스](https://github.com/prozac0401/Workspace/releases/tag/visible-cells-paste-v0.1.2)에서 확인합니다. 이 문서의 제작·native 확인을 실제 게시 완료의 근거로 대신하지 않습니다.

공개 0.1.1 payload를 그대로 포함한 [기존 단일 EXE 릴리스](https://github.com/prozac0401/Workspace/releases/tag/visible-cells-paste-v0.1.1-setup.1)와 기존 ZIP도 보존합니다. 설치·제거와 재현 방법은 [단일 설치 안내](https://github.com/prozac0401/Workspace/blob/visible-cells-paste-v0.1.2/tools/VisibleCellsPaste/docs/single-installer.md)를 따릅니다.
