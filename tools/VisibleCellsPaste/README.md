# 보이는 칸 붙여넣기

**버전 0.1.1**

2026-09-26 후속 수정본의 실제 설치·자동 로드·붙여넣기·되돌리기와 사용 후 종료를 확인했습니다. 제거·재설치 후 실제 붙여넣기에서도 숨긴 셀의 원래 값이 유지됐습니다. 확인한 환경과 이전 후보의 종료 실패 이력은 [시험 보고서](docs/test-report.md), 패키지와 게시 근거는 [배포 점검](docs/release-checklist.md)을 따릅니다.

Excel에서 복사한 한 행 또는 한 열의 값을, 선택한 한 열의 보이는 칸에 순서대로 넣는 독립 도구입니다. 필터로 가려진 행과 직접 숨긴 행, 선택 밖의 셀은 건드리지 않습니다. 원본과 대상의 개수가 다르면 아무 셀도 바꾸지 않습니다.

## 설치하기

Windows 데스크톱 Excel과 .NET Framework 4.8이 필요합니다. 웹용 Excel과 Mac용 Excel은 지원하지 않습니다.

1. 열려 있는 Excel 문서를 저장하고 모든 Excel을 종료합니다.
2. 배포 ZIP을 한 폴더에 모두 풉니다.
3. **Install.cmd**를 실행합니다. 설치 프로그램이 Excel의 32·64비트를 확인하고 맞는 파일을 설치합니다.
4. 평소처럼 Excel을 실행합니다. 셀을 우클릭하면 **보이는 칸에 붙여넣기**와 **마지막 붙여넣기 되돌리기**가 나타납니다.

현재 Windows 사용자 계정의 `%LOCALAPPDATA%\VisibleCellsPaste`에 설치하며 Excel 시작 시 자동으로 로드됩니다. 관리자 권한, VBA 편집기, 모듈 가져오기, 매크로 수동 실행은 필요하지 않습니다.

Excel 프로세스가 실행 중이면 설치·제거를 중단합니다. 설치 프로그램이 Excel을 강제로 종료하거나 통합문서를 저장하지 않습니다. 메뉴가 없으면 Excel이 정상 종료됐는지 확인하고 다시 실행하세요. 자세한 확인 순서는 [설치·제거 안내](docs/install-security.md)를 따릅니다.

## 보이는 칸에 붙여넣기

1. 원본 Excel에서 **한 행 또는 한 열**을 선택하고 **Ctrl+C**로 복사합니다. 원본 Excel은 열어 둡니다.
2. 대상에서 값을 넣을 **한 열의 연속된 범위**를 선택합니다. 필터나 행 숨김을 적용한 상태로 선택하면 됩니다.
3. 선택 안을 우클릭하고 **보이는 칸에 붙여넣기**를 누릅니다.
4. 기존 수식을 덮어쓰거나 빈칸으로 내용을 지우는 경우에는 안내된 개수를 확인하고 진행합니다.

가로로 복사한 한 행도 위에서 아래로 입력합니다. 원본 3개와 보이는 대상 2개를 선택하면 수정 없이 중단합니다. 한 값을 여러 칸에 반복하거나 대상 범위를 자동으로 늘리지 않습니다. 스크롤 아래에 있어 화면에 안 보이는 셀도 숨김 상태가 아니라면 대상에 포함됩니다.

**복사한 순서대로 입력합니다.** 이름이나 사번을 찾아 연결하지 않습니다. 원본과 대상의 개수가 같아도 사람의 순서까지 일치한다는 뜻은 아닙니다.

## 값·빈칸·날짜

- 숫자, 글자, 참·거짓, 실제 빈칸과 지원하는 Excel 오류값을 처리합니다. `00123` 같은 문자열, 긴 식별번호, 공백·한글·셀 내부 탭과 줄바꿈을 유지합니다.
- 실제 빈칸도 한 항목입니다. 처음·가운데·마지막 빈칸은 대응하는 대상의 내용만 비웁니다. 수식 `=""`의 빈 문자열 결과도 항목 위치를 유지합니다. 빈 문자열은 값으로 입력할 때 실제 빈칸으로 저장될 수 있습니다.
- 수식은 **복사된 계산 결과**를 사용합니다. 수식 자체를 넣거나 원본을 다시 계산하지 않습니다. 기존 대상의 일반 수식을 덮어쓸 때는 실행 전에 확인합니다.
- 대상의 숫자 표시 형식·글꼴·배경·테두리·조건부 서식을 유지합니다. 실제 숫자 `123`이 표시 형식 때문에 `00123`으로 보이더라도 넣는 값은 숫자 `123`입니다.
- 날짜·시간·백분율은 원래 숫자 값을 사용합니다. 날짜·시간의 원래 숫자 값은 Excel 클립보드의 추가 복사 정보와 항목 대응을 함께 확인합니다. 값이나 대응을 확정할 수 없으면 아무 셀도 바꾸지 않고 중단합니다. 표시된 날짜 문자열을 해석해 일련번호를 추측하지 않습니다.
- **1900·1904 날짜 체계 사이의 자동 보정은 하지 않습니다.** 원래 숫자 값을 그대로 넣으므로 원본과 대상의 날짜 체계나 표시 형식이 다르면 보이는 날짜가 달라질 수 있습니다.

날짜·시간 처리 가능 여부는 Excel이 복사 정보에 제공한 원래 숫자 값에 따라 달라집니다. 모든 Excel 버전이나 복사 형식에서 읽을 수 있다는 뜻은 아닙니다. 자세한 입력 조건은 [클립보드 호환성](docs/clipboard-compatibility.md)을 확인하세요.

## 지원 범위와 크기

원본은 Excel에서 Ctrl+C로 복사한 한 행 또는 한 열이어야 합니다. 다른 통합문서나 Excel 창에서 복사할 수 있습니다. 원본 Excel을 열어 두고, 복사 출처와 일반 복사 상태를 확인할 수 있도록 해 주세요.

다음 범위는 처리하지 않습니다.

- 여러 행과 여러 열로 된 원본, 여러 열 대상, 전체 행·열, 직접 만든 여러 영역 선택, 숨긴 대상 열.
- 병합 셀, 보호된 시트, 읽기 전용 파일, 제한된 보기, 여러 시트가 함께 선택된 상태.
- 배열 수식·동적 배열 결과 범위, 피벗테이블, 데이터 유효성 검사 규칙이 있는 보이는 대상.
- 잘라내기, 일반 텍스트·그림·파일·웹 표 복사, 지원하지 않는 오류 종류(예: `#SPILL!`, `#CALC!`).

표는 값만 있는 데이터 열을 대상으로 합니다. 같은 표 열의 숨긴 행에 수식이 있어도 중단합니다. 다른 프로그램이나 추가 기능이 동시에 셀·행·정렬을 변경하는 동안에는 사용하지 마세요.

한 번에 복사 항목과 보이는 대상 각각 **50,000개**, 선택 범위 **200,000셀**, 클립보드 **32 MiB**, 보이는 구간 **20,000개**까지 처리합니다. 5,000칸 또는 1,000구간부터 진행 여부를 확인합니다. 숨긴 행이 번갈아 많으면 같은 개수의 연속 범위보다 오래 걸릴 수 있습니다.

## 마지막 작업 되돌리기

붙여넣은 직후 **같은 선택을 유지한 채** 우클릭하고 **마지막 붙여넣기 되돌리기**를 누릅니다. 이 도구로 마지막에 성공한 작업 한 번의 원래 값과 수식을 같은 Excel 프로세스의 메모리에 보관합니다.

파일 닫기·재시작·선택 변경·편집·시트 또는 통합문서 전환·구조 변경 뒤에는 되돌리기가 제한됩니다. 대상 위치와 실행 직후 상태를 안전하게 확인할 수 없으면 중단합니다. 다른 파일 뒤에서 조용히 복구하지 않습니다.

**기존 정렬 설정이 남아 있는 시트나 그 안의 표에서는 즉시 되돌리기도 제공하지 않습니다.** 정렬로 위치가 바뀐 행에 잘못 복구하는 일을 막기 위한 조건입니다.

이 도구로 값을 쓰면 Excel의 기존 **Ctrl+Z 기록이 지워질 수 있습니다.** 방금 실행한 작업은 이 도구의 **마지막 붙여넣기 되돌리기** 메뉴로 복구하세요. 파일을 닫은 뒤에도 남는 영구 백업 기능은 아닙니다. 자세한 조건은 [되돌리기 안전성](docs/undo-safety.md)을 확인하세요.

쓰기 도중 실패하면 작업 전 상태로 복구를 시도하고 확인합니다. 일부 복구를 확인하지 못하면 영향을 받을 수 있는 범위와 오류를 알리고 후속 쓰기를 막습니다. 자동 저장하지 않습니다. Excel 강제 종료·운영체제 장애·감지되지 않은 외부 동시 편집까지 완전 복구하는 기능은 아닙니다.

## 업데이트·제거와 보안

업데이트는 Excel을 저장·종료하고 새 ZIP을 모두 푼 뒤 **Install.cmd**를 실행합니다. 제거는 Excel을 저장·종료하고 **Uninstall.cmd**를 실행하거나 Windows의 설치된 앱에서 **보이는 칸 붙여넣기**를 제거합니다.

이 도구의 자동 로드 등록과 소유 파일만 정리합니다. 사용자 통합문서, 다른 추가 기능, PERSONAL.XLSB와 Office 보안 설정은 지우지 않습니다. 외부에서 수정한 파일은 덮어쓰거나 지우지 않으므로 남은 파일 안내를 확인하세요.

**설치 파일에는 코드 서명이 없습니다.** 회사에서 서명된 추가 기능이나 사전 승인을 요구하면 담당자의 배포 절차를 따르세요. 전체 매크로 허용, VBA 프로젝트 접근 허용, 신뢰 위치 확대나 보안 정책 우회를 요구하지 않습니다.

이 도구는 외부 API나 사용 통계 전송 기능을 사용하지 않습니다. 실제 업무 데이터·클립보드 내용·수식·전체 파일 경로를 기본 진단 로그에 기록하지 않습니다.

## 관련 자료와 제작

[변경 이력](CHANGELOG.md) · [구조](docs/architecture.md) · [시험 보고서](docs/test-report.md) · [배포 점검](docs/release-checklist.md)

소스는 `src`, 시험은 `tests`, 제작 스크립트는 `build`, 설치 구성은 `installer`에 있습니다. 제작하려면 저장소에서 다음 명령을 실행합니다.

```powershell
powershell -NoProfile -File tools/VisibleCellsPaste/build/build.ps1 -Version 0.1.1
```

ZIP과 `SHA256SUMS.txt`는 `artifacts/visible-cells-paste/0.1.1`에 생성됩니다. 최종 사용자는 개발 SDK·Python·Node.js를 설치하거나 VBA 코드를 만들 필요가 없습니다.

## 로컬 단일 설치 파일 후보

공개 0.1.1 payload를 포함한 단일 EXE 후보의 설치·제거와 재현 방법은 [단일 설치 안내](docs/single-installer.md)를 따릅니다. 공개 ZIP을 대체해 게시한 상태는 아닙니다.
