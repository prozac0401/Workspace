# 음력 표시 데이터

2026-10-11 사용자 선택에 따라 음력 표시는 양력 1983-01-01~2050-12-31에만 제공한다. 달력 자체의 연도 범위 1983~2099는 유지한다. 음력 표시를 켜면 날짜 오른쪽에 `(MM.DD)`를 붙이며, 윤달도 같은 숫자 형식을 쓰고 모델에는 `isLeapMonth`를 보존한다. 표시 여부는 미리보기와 XLSX가 공유하는 설정이다.

## 출처와 범위

- [한국천문연구원 음양력 변환 계산](https://astro.kasi.re.kr/life/pageView/8)은 양력 변환 입력의 마지막 날짜를 2050-12-31로 안내한다. 이 페이지의 지원 범위 확인을 개별 날짜의 API 검증으로 표현하지 않는다.
- [korean-lunar-calendar](https://github.com/usingsky/korean_lunar_calendar_js)의 0.4.0 버전을 개발 의존성으로 고정했다. 해당 프로젝트는 KASI 기준의 내장 변환표를 사용한다고 설명한다. 이번 표는 그 패키지에서 생성했으며, 이번 실행에서 직접 수집한 KASI 응답이나 KASI의 새 검수 결과가 아니다.
- 패키지는 MIT License, 저작권 표시는 `Copyright (c) 2022 Jinil Lee`다. 배포되는 `lunar-data.mjs` 머리말에 패키지의 전체 LICENSE를 보존하고 lockfile에 버전·무결성을 고정한다.

## 생성과 실행

```powershell
npm ci --prefix tools/calendar
node tools/calendar/generate-lunar-data.mjs
node tools/calendar/generate-lunar-data.mjs --check
node --test tools/calendar/tests/lunar.test.mjs
```

생성기는 지원 날짜를 포함하는 각 음력 월의 첫 양력 날짜와 음력 연·월·윤달 여부만 기록한다. 1983년 첫날을 포함하는 앞선 월 시작도 한 행 포함한다. 생성 시각이나 실행 환경 정보는 표에 쓰지 않아 같은 고정 패키지에서 바이트 단위로 재현한다. `--check`는 파일을 수정하지 않으며 결과가 다르면 실패한다.

브라우저는 월 시작의 이진 검색과 정수 UTC 일수 차이만 계산한다. 브라우저의 `Intl` 달력 구현, 사용자의 시간대, 외부 라이브러리 CDN, 원격 API, Secret은 사용하지 않는다. 지원 범위 밖이나 유효하지 않은 날짜는 오류로 처리하며 중국 음력이나 미래 천문 계산으로 대체하지 않는다. 공휴일 수집과 이 정적 음력표는 별개다.

## 선택 근거와 검증의 한계

대안 조사에서 Node 24.13.1 / ICU 78.2의 `Intl` 한국 전통력 `dangi`는 고정 한국 표와 1983~2050의 24,837일 중 30일이 달랐다. 차이는 2017-02-26~03-27이다. 실제 Edge 155.0.4283.45에서도 2017-02-26 결과가 음력 1월 30일로 나타났지만 고정 한국 표는 2월 1일이다. 따라서 브라우저별 계산 결과를 런타임 자료로 사용하지 않는다.

검사는 지원 범위의 모든 날짜를 고정 패키지와 대조하고 29/30일 월 경계, 2017년 윤5월, 2033년 윤11월, 범위 양 끝, 잘못된 날짜, 시간대 독립성 및 생성물 재현성을 확인한다. 이는 생성·조회 구현과 참조 패키지의 일치를 검증하며, 독립적인 KASI 실응답 전수 대조를 완료했다는 뜻은 아니다. 2051~2099 음력은 제공하지 않는다.

2026-10-11 로컬 실행에서 음력 관련 단위 검사 4개가 통과했다. 또한 최초 수집한 실제 `getRestDeInfo` 자료의 2004~2028년 설날·추석 각각 25개, 총 50개 기준 날짜를 대조해 모두 일치했다. 자료에서 같은 명칭의 3일 연휴가 연속인지 확인한 뒤 가운데 날짜를 설날 당일(음력 1월 1일)·추석 당일(8월 15일)로 검사했다. 원본 JSON SHA-256은 `eadb9a96020bebe8b55ef36f7b389f7a356bb09869e090041e326fe48e22c146`이며, 결과는 로컬 `artifacts/calendar/lunar-research/official-festival-anchors.json`에 보존한다. 이 50개 공휴일 기준 날짜 확인은 음양력 API의 모든 날짜 검증을 대신하지 않는다.
