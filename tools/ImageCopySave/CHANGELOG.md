# 그림 복사·저장 변경 이력

## 0.2.1 · 2026-10-03 · 출하 후보 검증 완료, PR·게시 대기

- 완료 전 취소가 확인된 경우의 helper 안내를 ‘그림 작업을 완료하기 전에 취소했습니다.’로 바꿉니다. 종료 코드 3과 기존의 정확한 worker 진단이 함께 맞는 경우에만 바뀝니다.
- copy·save, 개행, 다른 종료 코드, 강제 중단과 이미 완료된 작업의 안내를 구분하는 기존 helper 집중 8건을 실제 출하 DLL에 연결해 **8 PASS / 0 FAIL / 0 SKIP**을 확인했습니다. 취소와 이미지 처리·클립보드·파일·메뉴·설치 보호 동작은 바꾸지 않습니다.
- 관리 코드와 패키지 기본 버전을 0.2.1에 맞췄습니다. 출하 payload 입력 18개·내용 해시와 MSI 404파일·내장 보호·0.1.1/공개 0.2.0의 소유 목록 정적 감사를 완료했습니다. builder의 합성 보호 시험 39 PASS를 실제 MSI 설치 확인으로 확대하지 않습니다. 식별 정보는 [0.2.1 기록](../../docs/delivery/image-copy-save-021-20261003.md), 최종 게시 상태는 GitHub Release 페이지·본문을 따릅니다. 실제 WPF·Explorer·클립보드 전체 suite·새 MSI 설치 수명주기는 실행하지 않았습니다.
