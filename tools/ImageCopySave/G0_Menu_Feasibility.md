# G0 메뉴 구현성 검증

## 2026-09-27 배포 준비 후속

사용자가 Windows 11 기본 메뉴 경로에서 그림 복사·저장 두 기능이 모두 정상이라고 직접 확인했습니다. 두 동작의 사용자 확인 PASS이며 자동화 관찰·조건별 숨김·창/탭 전체 시험으로 확대하지 않습니다. 현재 MSI 정적 검사는 PASS지만 기존·외부 수정 설치 자원 보존 요구와 MSI 자체 보호의 차이를 발견해 공개 배포는 보류합니다. [최신 판정](../../docs/delivery/image-release-readiness-20260927.md)을 따르며 아래 앞선 실기 기록은 당시 결과로 보존합니다.

현재 기준은 [요구명세 v1.2 변경 계약](../../docs/tools/image-copy-save/ImageCopySave_Requirements_v1.2.md)입니다. Windows 11 클래식 직접 표시 모드의 독립 저장·비이미지 및 실제 파일 클립보드 완전 숨김·실제 PNG 복사/저장, 무서명 MSI 설치·Repair·업데이트·제거·설치 실패 롤백·재설치는 확인한 시나리오에서 PASS입니다. 실제 0.1.0 helper 비상승 실행을 관찰했으며 0.1.1에서도 실제 8×8 PNG 저장·클립보드 불변과 PNG 이미지 복사를 확인했습니다. 클래식 전환 15회·46개 관찰 행은 모두 PASS이며 1~8회는 0.1.0, 9~15회는 0.1.1입니다. 02:53 UTC의 새 시험 창 복구 시에는 기존 창과 프로세스를 보존했습니다. 이후 승인된 모드 시험에서 Explorer를 한 차례 수동 재시작하고 Workspace 경로를 복원했습니다. 제품 설치기의 재시작은 아닙니다. 16~20회는 사용자 지시에 따라 반복 생략합니다. HKCU override를 백업·이동했지만 기본 새 메뉴 경로는 미확인입니다. 재시작 후 일시적 Explorer ‘응답 없음’은 자체 회복했으며 단일 최소덤프로 원인을 확정하지 못했습니다. 03:27:33 UTC 최종 설정 복원은 원본 키·값·Owner·Group·DACL 보존과 백업 키 제거로 PASS입니다. 비교 요청과 추가 재시도는 중단했으며 전체 G0는 **미완료**입니다.

사용자가 불필요한 반복시험을 지양하도록 지시하여 고정 20회 반복은 완료 관문에서 제외했습니다. 미확인 기능은 대표 1회 확인하고 실패·변경에 관련된 사례만 재시험합니다. 생략한 반복은 제품 실패나 필수 잔여가 아니며 기본 Windows 11 경로와 설정 원상복구는 필수로 유지합니다.

Windows 11 기본 메뉴에서는 ‘더 많은 옵션 표시’ 뒤에, 클래식 직접 표시 모드에서는 바로 두 명령을 제공합니다. HKLM native IExplorerCommand·ExplorerCommandHandler 등록과 무서명 관리자 MSI를 검증하며 평소 Explorer/helper는 일반 사용자 권한으로 실행합니다. 이미지 없음의 완전 숨김·무상주·원본 보존은 유지합니다.

현재 판정과 모드별 확인 항목은 Markdown 원본인 [전체 G0 매트릭스](../../docs/tools/image-copy-save/G0_Menu_Feasibility.md)와 [ADR-0023](../../docs/design/0023-image-copy-save-classic-menu.md)를 따릅니다. 이전 첫 메뉴·MSIX·진단 MSI 기록은 당시 증거로 보존합니다. Windows 11의 클래식 직접 표시 시험은 실제 Windows 10 OS 지원 인증이 아닙니다.
